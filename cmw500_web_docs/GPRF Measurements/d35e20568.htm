TRIGger:GPRF:MEAS<i>:SPECtrum:MGAP <MinimumGap>

Sets a minimum time during which the IF signal must be below the trigger threshold before the trigger is armed so that an IF power trigger event can be generated.

Parameters:
<MinimumGap>
Range: 0 s  to  0.01 s
Increment: 10E-9
*RST:0 s
Default unit: s

See "Specifying Measurement-Specific Settings"

Firmware/Software: 

V3.0.10

Options: R&S CMW-KM010
Manual operation: See "Minimum Trigger Gap"
