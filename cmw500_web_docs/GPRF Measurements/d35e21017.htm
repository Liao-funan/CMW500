CONFigure:GPRF:MEAS<i>:SPECtrum:FSWeep:SWT <SweepTime>

Sets or gets the sweep time (SWT) for the frequency sweep mode. Setting this value is only possible if the Auto-SWT selection for the sweep mode is switched OFF (see CONFigure:​GPRF:​MEAS<i>:​SPECtrum:​FSWeep:​SWT:​AUTO).

Parameters:
<SweepTime>
Range: 0 s  to  2000 s
*RST:0.0646 s
Default unit: s
Firmware/Software: 

V3.0.10

Options: R&S CMW-KM010
Manual operation: See "Frequency Sweep > Sweep Time"
