CONFigure:GPRF:MEAS<i>:POWer:PSET:CATalog:PDEFset?

Gets a comma-separated list of predefined parameter sets that can be loaded as parameter set in retriggered list mode (see CONFigure:​GPRF:​MEAS<i>:​POWer:​PSET:​PDEFset).

See also "Measurement Settings and Predefined Parameter Sets"

Return values: 
<PredefinedSet>

Examples for strings: "GSM Power","WCDMA UE Power","WCDMA Off Power","LTE TX Power 20","LTE OFF Power 20","Customized"

Usage: Query only
Firmware/Software: 

V3.2.10

Manual operation: See "Parameter Set List"
