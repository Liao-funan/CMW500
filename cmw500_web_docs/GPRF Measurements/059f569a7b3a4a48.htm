GPRF Measurements > Programming > External Power Sensor Measurement > Key Features
Key Features
The external power sensor measurement is programmed as follows:
  • The measurement is controlled by SCPI commands with the following syntax: ...GPRF:MEAS:EPSensor...
  • After a *RST, the measurement is switched off. Use READ:GPRF:MEAS:EPSensor? to initiate a single-shot measurement and retrieve the results.
Advanced settings

A zeroing procedure is recommended to improve the accuracy.

You can also run the measurement in continuous mode and retrieve the results using FETCh:GPRF:MEAS:EPSensor?.
