Capture Buffer Analyzer

The capture buffer analyzer gives access to the raw I/Q data captured by the firmware applications. It helps you to analyze problems with failing measurements. You can access the I/Q data of the last measurement interval of the last measurement.

The capture buffer analyzer is especially useful to debug list mode measurements.

The capture buffer analyzer is only supported on R&S CMW100/CMW with MUA.

Because it is a debugging tool, it is only visible in user mode "User (Extended)".
