CONFigure:GPRF:MEAS<i>:IQVSlot:SCOunt <StepCount>

Defines the number of measurement steps per subsweep. The total number of steps, i.e. the step count times the number of subsweeps, must not exceed 3000 (see CONFigure:​GPRF:​MEAS<i>:​IQVSlot:​LIST:​COUNt?).

Parameters:
<StepCount>
Range: 1  to  3000
*RST:20
