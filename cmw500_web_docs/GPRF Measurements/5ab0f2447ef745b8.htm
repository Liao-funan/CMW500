V1.0.10.1 (Compared to V1.0.5.3)
New features:
  • I/Q recorder: "List Mode"
  • I/Q recorder: Configurable sampling rate, see "Filter Settings and Samples".
  • FFT spectrum analyzer (option R&S CMW–KM010): Linear or logarithmic averaging, see "Averaging Mode".
  • FFT spectrum analyzer: Fixed or variable "Trigger Offset".
  • FFT spectrum analyzer: Selectable number of markers for peak search mode, see "Marker - Peak Search Setup".
  • Error codes for single power and I/Q vs. slot results in remote control (CALCulate...?).
