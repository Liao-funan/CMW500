INITiate:GPRF:MEAS<i>:PLOSs:OPEN <Connector>
INITiate:GPRF:MEAS<i>:PLOSs:SHORt <Connector>
INITiate:GPRF:MEAS<i>:PLOSs:EVALuate <Connector>

Sets the measurement mode according to the last mnemonic ("Open", "Short" or "Eval"), selects an RF connector and starts the measurement.

For possible connector values, see "Values for RF Path Selection".

Parameters:
<Connector>

RF connector of the path to be measured
