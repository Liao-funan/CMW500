FETCh:GPRF:MEAS<i>:FFTSanalyzer:STATe?

Queries the main measurement state. Use FETCh:...:STATe:ALL? to query the measurement state including the substates. Use INITiate..., STOP..., ABORt...to change the measurement state.

See also: "Measurement Control"

Return values: 
<MeasState>
OFF | RUN | RDY

OFF: measurement off, no resources allocated, no results

RUN: measurement running, synchronization pending or adjusted, resources active or queued

RDY: measurement finished

*RST:OFF

See "Single-Shot and Continuous Measurements"

Usage: Query only
