Modifying the Diagrams

Use the "Display" parameters to change the appearance and contents of the diagrams. The following "Display" hotkeys are available:

Hotkey

Description

"Time Domain On / Off"

Display or hide both time domain diagrams.

"Select Trace"

Select the trace types to be displayed in the view.

"X Scale... / Y Scale..."

Modify the ranges of the X-axis and the Y-axis.

The "Trigger > Trigger Offset" parameters define the position of the FFT window and thus the time domain diagram relative to the trigger events.

Hotkey

Description

"Trigger Offset Mode: Fixed"

Set the center of the FFT window (and thus, the center of the time domain diagram) relative to the trigger events.

"Trigger Offset Mode: Variable"

For statistic count > 1: Vary the center of the time domain diagram between an offset start time and an offset stop time.

For more hotkeys, see "Additional Hotkeys".
