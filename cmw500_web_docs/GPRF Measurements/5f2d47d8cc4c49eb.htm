CONFigure:GPRF:MEAS<i>:POWer:PSET:FILTer:TYPE:ALL <Filter>...

Selects the IF filter type for all parameter sets.

Parameters:
<Filter>
BANDpass | GAUSs | WCDMa | CDMA | TDSCdma

Comma-separated list of 32 values, for parameter set no. 0 to 31

BANDpass: Bandpass filter with selectable bandwidth

GAUSs: Filter of Gaussian shape with selectable bandwidth

WCDMA: 3.84 MHz RRC filter with a roll-off = 0.22 for WCDMA TX tests

CDMA: 1.2288 MHz-wide channel filter for CDMA 2000 TX tests

TDSCdma: 1.28 MHz RRC filter with a roll-off = 0.22 for TD-SCDMA TX tests

*RST:GAUS
