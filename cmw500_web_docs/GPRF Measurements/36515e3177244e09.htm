Measurement Control

To turn the measurement on or off, select the control softkey and press ON | OFF or RESTART | STOP. Alternatively, right-click the control softkey.

See also: "Measurement Control"

EPS (Softkey)

The softkey shows the current measurement state. Additional measurement substates can be retrieved via remote control.

Remote command: 

INITiate:​GPRF:​MEAS<i>:​EPSensor

STOP:​GPRF:​MEAS<i>:​EPSensor

ABORt:​GPRF:​MEAS<i>:​EPSensor

FETCh:​GPRF:​MEAS<i>:​EPSensor:​STATe?

FETCh:​GPRF:​MEAS<i>:​EPSensor:​STATe:​ALL?

FETCh:​GPRF:​MEAS<i>:​EPSensor:​IDN?

 
Start Zeroing

Initiates "Zeroing" of the external power sensor. The "Start Zeroing" hotkey is associated with the "EPS" softkey.

Remote command: 

CALibration:​GPRF:​MEAS<i>:​EPSensor:​ZERO
