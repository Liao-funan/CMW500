V3.5.90 (Compared to V3.5.10)
New features:
  • I/Q recorder enhancement for all models, see "Write Results to IQ File".
    This setting was only configurable via the INIT command. Now it is also configurable via the GUI and via a new command. It is now also possible to store the results to a file only and not to the memory.
