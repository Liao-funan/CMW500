FETCh:GPRF:MEAS<i>:IQRecorder:STATe:ALL?

Queries the main measurement state and the measurement substates. Both measurement substates are relevant for running measurements only. Use FETCh:...:STATe? to query the main measurement state only. Use INITiate..., STOP..., ABORt... to change the measurement state.

See also: "Measurement Control"

Return values: 
<MainState>
OFF | RUN | RDY

OFF: measurement off, no resources allocated, no results

RUN: measurement running, substates apply

RDY: measurement finished

*RST:OFF
<SyncState>
PEND | ADJ | INV

PEND: waiting for resource allocation, adjustment, hardware switching

ADJ: adjusted, measurement running

INV: state not applicable, <MainState> OFF or RDY

<ResourceState>
QUE | ACT | INV

QUE: measurement without resources, no results available

ACT: resources allocated, acquisition of results in progress

INV: state not applicable, <MainState> OFF or RDY
