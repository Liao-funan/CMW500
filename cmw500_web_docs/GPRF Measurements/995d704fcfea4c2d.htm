Using Markers

Use the "Marker" parameters to activate markers and to modify their position. The following "Marker" hotkeys are available:

Hotkey

Description

"Ref. Marker ..."

Enable or disable the reference marker, select a trace and the marker position on that trace

"Marker 1 /2 ..."

Enable or disable marker 1 or 2 and define the marker position (absolute or relative to the reference marker)

Depending on the trace mode, a trace can also be selected.

"Select Trace Mode"

Define whether all markers are collectively set to the same trace or to individual traces

"Peak Search Setup..."

Refine the peak search in the spectrum diagram, see "Additional Hotkeys".
