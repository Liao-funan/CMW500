CONFigure:GPRF:MEAS<i>:POWer:PSET:FILTer:GAUSs:BWIDth:ALL <Bandwidth>...

Selects the bandwidth for a filter of Gaussian shape for all parameter sets.

Parameters:
<Bandwidth>

Comma-separated list of 32 values, for parameter set no. 0 to 31

Range: 10 Hz | 30 Hz | 50 Hz | 100 Hz | 300 Hz | 500 Hz | 1 kHz | 3 kHz | 5 kHz | 10 kHz | 30 kHz | 50 kHz | 100 kHz | 300 kHz | 500 kHz | 1 MHz | 3 MHz | 5 MHz | 10 MHz
*RST:1E+6 Hz
Default unit: Hz

See "Performing an I/Q Data Measurement"

V2.1.25
