Trigger Signals

On an R&S CMW100/CMW with MUA, the GPRF power measurement provides trigger signals that can be used by other R&S CMW applications like the GPRF generator to synchronize to the measurement. This feature is not available on R&S CMW500/2xx with BB Meas.

A trigger signal is generated every time when the armed trigger system of the measurement detects a trigger event.

To address the trigger signals of the measurement in remote commands, use the following string, with <i> replaced by the instance number of the measurement:
  • "GPRF Meas<i>: Power"
