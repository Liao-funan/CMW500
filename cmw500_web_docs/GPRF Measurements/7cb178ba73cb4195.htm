Spectrum Analyzer

The tab for the spectrum analyzer is labeled "Spectrum". The tab provides all measurement results and displays the most important measurement settings.

To configure measurement settings, press the hotkey "Config". It opens a dialog box containing several tabs with settings. The tabs are described in the following.

The spectrum analyzer requires option R&S CMW-KM010.
