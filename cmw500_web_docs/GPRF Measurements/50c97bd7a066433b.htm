Result Diagram

The diagram shows the gain of the signal path versus the carrier frequency. So you can see the frequency response of your signal path. Typically, the signal path attenuates the signal and the gain is negative.

You get a separate trace for each measured connector.

Result diagram view

You can configure the diagram via the following "Display" hotkeys.

Display hotkeys

Hotkey

Description

"Display Diag / Table"

Switches between the diagram view and the table view.

"Average Filter Taps"

Configures the number of frequencies over which the gain results are averaged. For details, see "Average Filter Taps (hotkey)".

"Select Trace"

Hides or shows the traces for the individual connectors.

"X Scale... / Y Scale..."

Modify the ranges of the X-axis and the Y-axis.
