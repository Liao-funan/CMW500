Measurement Control

To measure the pathloss for one connector, you must run the measurement three times in different modes: mode "Open", mode "Short" and finally mode "Eval". Hotkeys assigned to the softkey "Pathloss" facilitate starting the measurement.

Alternatively, you can configure the measurement mode directly and then start the measurement in the usual way, like any other measurement.

Measurement control hotkeys

The hotkeys "Open", "Short" and "Evaluate" set the corresponding measurement mode and start the measurement. So you can start the measurement in any mode via a single click.

The hotkey "Clear" discards all measurement results.

INITiate:​GPRF:​MEAS<i>:​PLOSs:​CLEar

INITiate:​GPRF:​MEAS<i>:​PLOSs:​OPEN

INITiate:​GPRF:​MEAS<i>:​PLOSs:​SHORt

INITiate:​GPRF:​MEAS<i>:​PLOSs:​EVALuate

 
Pathloss (softkey)

To turn on the measurement in the configured mode or to turn off the measurement, select the control softkey and press ON | OFF or RESTART | STOP. Alternatively, right-click the control softkey.

Turning off the measurement does not discard the measurement results. Use the "Clear" hotkey to reset the results.

To check the result states, see "Important Settings and States".
