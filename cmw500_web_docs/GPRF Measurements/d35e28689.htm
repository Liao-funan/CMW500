CONFigure:GPRF:MEAS<i>:EPSensor:RESolution <Resolution>

Defines the number of digits of the power results in the measurement dialog. This command does not affect the remote control results.

Parameters:
<Resolution>
PD0 | PD1 | PD2 | PD3

PD0: 1 (results rounded to 1 dB)

PD1: 0.1

PD2: 0.01

PD3: 0.001

*RST:PD2

See "Performing a Single-Shot Measurement"
