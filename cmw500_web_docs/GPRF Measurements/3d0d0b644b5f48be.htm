CONFigure:GPRF:MEAS<i>:IQRecorder:WTFile <WriteToIQFile>

Selects whether the results are written to an I/Q file, to the memory or both.

For file selection, see CONFigure:​GPRF:​MEAS<i>:​IQRecorder:​IQFile.

Parameters:
<WriteToIQFile>
OFF | ON | ONLY
OFF

The results are only stored in the memory.

ON

The results are stored in the memory and in a file.

ONLY

The results are only stored in a file.

*RST:OFF

See "Performing a Single-Shot Measurement"
