Test Setup

The measurement generates an RF signal and measures the reflected signal to determine the attenuation in the signal path to the DUT.

For each RF signal path, the reflected signal must be measured twice: with a short at the end of the path and with an open at the end of the path. So you need DUT dummies for this measurement, with a built-in short and with a built-in open.

Prepare all RF connections between the instrument and the DUT dummies, for which you want to determine the pathloss. During the measurement, you must change the dummies. It does not matter whether you measure first an open path and then a short path or vice versa.
