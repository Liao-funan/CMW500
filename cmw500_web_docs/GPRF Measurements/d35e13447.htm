FETCh, READ and CALCulate Commands
All commands are used to retrieve measurement results:
  • FETCh... returns the results of the current measurement cycle (single-shot measurement) after they are valid. FETCh... must be used after the measurement has been started (INITiate..., measurement states RUN or RDY).
  • READ... starts a new single-shot measurement and returns the results.
  • CALCulate... returns one error indicator (OK, OFL, INV, NAV) per FETCh result.

See also: "Retrieving Measurement Results"
