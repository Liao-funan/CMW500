CONFigure:GPRF:MEAS<i>:IQRecorder:IQFile <IQSaveFile>

Selects the name and path of a file that is used to store the I/Q recorder results in binary format. To write the file, the I/Q recorder measurement must be started using INITiate:GPRF:MEAS<i>:IQRecorder ON.

Parameters:
<IQSaveFile>

String parameter to specify the name and path of the I/Q file. The extension "*.iqw" is appended automatically.
