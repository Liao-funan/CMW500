FETCh:GPRF:MEAS<i>:POWer:IQINfo? <ListIndex>[, <ResultIndex>]

Returns the number of samples and the sampling rate of the I/Q data measurement in a particular frequency/level step <index>.

With the optional <ResultIndex> parameter, it is also possible to get results for a particular list index repetition.

Query parameters: 
<ListIndex>
Range: 0 to 3999
<ResultIndex>
Range: 0 to #repetitions of <ListIndex>
Return values: 
<Reliability>

See "Reliability Indicator"

<NumberOfSamples>
Range: 0 to 4E+6
<SampleRate>
Range: 250 Hz to 50 MHz
Default unit: dB

See "Performing an I/Q Data Measurement"

Usage: Query only
