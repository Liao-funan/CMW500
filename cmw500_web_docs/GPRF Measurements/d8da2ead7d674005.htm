CONFigure:GPRF:MEAS<i>:IQRecorder:LIST:COUNt?

Queries the total number of results, given by <StopIndex> – <StartIndex> + 1 (see CONFigure:​GPRF:​MEAS<i>:​IQRecorder:​LIST:​STARt and CONFigure:​GPRF:​MEAS<i>:​IQRecorder:​LIST:​STOP).

Return values: 
<ResultCount>
Range: 1  to  2000
