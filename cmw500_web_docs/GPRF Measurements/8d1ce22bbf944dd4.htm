CONFigure:GPRF:MEAS<i>:FFTSanalyzer:AMODe <AveragingMode>

Selects the averaging mode for the average FFT trace (see READ:​GPRF:​MEAS<i>:​FFTSanalyzer:​POWer:​AVERage?).

Parameters:
<AveragingMode>
LINear | LOGarithmic

LINear: averaging of linear power values

LOGarithmic: averaging of logarithmic (displayed) power values

*RST:LOG
