FFT Spectrum Analyzer

The tab for the FFT spectrum analyzer is labeled "FFT Spectrum". The tab provides all measurement results and displays the most important measurement settings.

To configure measurement settings, press the hotkey "Config". It opens a dialog box containing several tabs with settings. The tabs are described in the following.
