TRIGger:GPRF:MEAS<i>:POWer:PSET:OFFSet <Index>, <TriggerOffset>
TRIGger:GPRF:MEAS<i>:POWer:PSET:OFFSet? <Index>

Defines a delay time relative to the trigger event for a particular parameter set <Index>.

Parameters:
<TriggerOffset>
Range: 0 s  to  1 s
*RST:50E-6 s
Default unit: s
Parameters for setting and query: 
<Index>

Number of the parameter set

Range: 0 to 31
