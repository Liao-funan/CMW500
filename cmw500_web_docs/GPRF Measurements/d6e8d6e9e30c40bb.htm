FETCh:GPRF:MEAS<i>:EPSensor?
READ:GPRF:MEAS<i>:EPSensor?

Returns statistical evaluation values of the sensor power results, see "Measurement Results".

Return values: 
<Reliability>

See "Reliability Indicator"

<CurrentPower> <AveragePower> <MinimumPower> <MaximumPower>

RF power (single values)

Default unit: dBm
<ElapsedStat>

Elapsed measurement cycles
