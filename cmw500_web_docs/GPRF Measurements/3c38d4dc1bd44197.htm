Measurement Settings and Predefined Parameter Sets

For a description of all settings for power measurements, see "Power Measurement".

The power measurement can be performed with a wide range of IF filters of various shapes and bandwidths. In addition to Gaussian and bandpass filters, the measurement provides special filter types for various network standards.

There are predefined parameter sets for GSM, WCDMA, TD-SCMA, CDMA2000® 1xRTT, CDMA2000® 1xEV-DO, LTE, Bluetooth®, WLAN and WiMAX.

You can adapt the parameter sets to your needs.
