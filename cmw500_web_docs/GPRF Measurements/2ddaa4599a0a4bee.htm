FETCh:GPRF:MEAS<i>:IQRecorder:BIN?
READ:GPRF:MEAS<i>:IQRecorder:BIN?

Retrieve IQ recorder results in binary format.

The number n of sample values is set via CONFigure:​GPRF:​MEAS<i>:​IQRecorder:​CAPTure.

Return values:

<dblock>
