What's New in This Version

This documentation describes version 3.7.21 and later of the GPRF measurements firmware application. Compared to version 3.7.20, it provides the following new features and changes:

  • Support of spectrum analyzer option R&S CMW-KM010 on R&S CMW100
  • Measurement of external attenuation in RF signal path, see "Pathloss Measurement"
