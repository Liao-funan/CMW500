Using the Capture Buffer Analyzer

The capture buffer analyzer evaluates the raw I/Q data captured during the last measurement execution. The measurement to be analyzed must have reached the state RDY.

Proceed as follows to start the analyzer:

  1. In the setup dialog, select section "System".

  2. Press the softkey "User Mode Login".

    A dialog box opens.

  3. Set the "User Mode" to "User (Extended)".

  4. Close the dialog box and the setup dialog.

  5. Open the GPRF measurement GUI.

  6. Select the tab "Capture Analyzer".

    This tab is only visible in the selected user mode.

  7. Right-click the softkey "Capture Analyzer". Select "ON".

    The capture buffer analyzer reads the last measured data from a buffer and shows the data in result diagrams.

Some diagrams show a certain time period of the total captured data. You can move the period via the hotkey "Segment Number". For details, see "Scope of the capture buffer, segments and steps".
