CONFigure:GPRF:MEAS<i>:IQRecorder:FILTer:BANDpass:BWIDth <BandPassBW>

Selects the bandwidth for a bandpass filter.

Parameters:
<BandPassBW>
1 kHz | 10 kHz | 100 kHz | 1 MHz | 10 MHz | 40 MHz | 160 MHz

Values in-between are rounded.

*RST:1 kHz
Default unit: Hz
Example: 

See "Specifying Measurement-Specific Settings"

Firmware/Software: 

V1.0.4.11, V3.7.10 added 160 MHz

Options: R&S CMW with TRX160 required for 160 MHz
Manual operation: See "Filter"
