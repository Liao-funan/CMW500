CONFigure:GPRF:MEAS<i>:POWer:PSET:FILTer:BANDpass:BWIDth:ALL <Bandwidth>...

Selects the bandpass filter bandwidth for all parameter sets.

Parameters:
<Bandwidth>
1 kHz | 3 kHz | 5 kHz | 10 kHz | 30 kHz | 50 kHz | 100 kHz | 300 kHz | 500 kHz | 1 MHz | 3 MHz | 5 MHz | 10 MHz | 30 MHz | 40 MHz

Comma-separated list of 32 values, for parameter set no. 0 to 31

Values in-between the allowed values are rounded.

*RST:300E+3 Hz
Default unit: Hz
