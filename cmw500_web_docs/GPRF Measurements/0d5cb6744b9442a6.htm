List Mode: Diagram View

In list mode, the measured power values appear in a bar graph. The numerical results at a particular power step are displayed in a table.

Power measurement results: diagram view (list mode)
  • Use the "List Configuration Tab" parameters to control the number of measured steps.
  • Use the "Display and Marker Tab" parameters to control the result presentation.
    For quick access, use the hotkeys of the "Marker/Display" softkey.
  • "Results @ Marker" area:
    This area shows a statistical evaluation of the power values at the current marker position.
  • "Settings" area:
    This area shows an overview of the essential current settings of the power measurement.
