I/Q Recorder Measurement

For R&S CMW500/2xx with BB Meas, the "IQ Recorder" tab contains the recorder settings.

For R&S CMW100/CMW with MUA, the "IQ Recorder" tab shows the recorder results. To access the settings, press the "Config" softkey. See also "Result Diagrams".

Additional settings (e.g. the list mode settings) are available via remote control.
