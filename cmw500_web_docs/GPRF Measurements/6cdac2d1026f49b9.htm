READ:GPRF:MEAS<i>:FFTSanalyzer:PEAKs:AVERage?

Returns the results of the peak search. Separate commands retrieve current and average values.

There are results for search range no. 0 to 4:

<Reliability>, <Frequency0>, <Power0>, ..., <Frequency4>, <Power4>

Return values: 
<Reliability>

See "Reliability Indicator"

<Frequency>

The range depends on the search range settings, see CONFigure:​GPRF:​MEAS<i>:​FFTSanalyzer:​PSEarch.

Default unit: Hz
<Power>
Range: -100 dBm  to  57 dBm
Default unit: dBm

See "Single-Shot and Continuous Measurements"

Usage: Query only
