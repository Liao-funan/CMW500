Performing a Measurement

To measure the pathloss for a single path / a single RF connector, you need to start the measurement three times, in different modes. The following procedure explains the individual steps.

In this procedure, the pathloss is first measured with an open, then with a short. The other way round is also possible.

The procedure measures the pathloss for a single RF path at a single RF connector.

  1. Set up the RF path that you want to measure. At the end of the path, connect the DUT dummy containing an open.

  2. Access the "Pathloss" tab of the GPRF measurement. Press the "Config" hotkey to open the main configuration dialog.

  3. For "RF Routing", select the RF connector of the signal path.

  4. Expand the node of the RF connector of the signal path. Configure the list of frequencies for that connector.

    If you want to create an attenuation table with frequency-dependent attenuations, configure all frequencies for which you want to get pathloss results.

    If you only want to see the frequency response in a diagram, two entries are sufficient. Configure the lowest frequency and the highest frequency you are interested in.

  5. Close the main configuration dialog box.

  6. Select the softkey "Pathloss".

  7. Press the hotkey "Open".

    A frequency sweep is started and the reflected power is measured.

    At the bottom of the "Pathloss" tab, the indicator for the used connector and the measurement mode "Open" turns orange . A progress bar shows the progress of the measurement.

    At the end of a successful measurement, the indicator changes to green and the measurement state changes to RDY.

  8. After the measurement is complete, connect the DUT dummy containing a short.

  9. Press the hotkey "Short".

    A frequency sweep is started and the reflected power is measured.

    At the end of a successful measurement, you get a second green indicator .

  10. After the measurement is finished, press the hotkey "Evaluate".

    The evaluation of the measured reflected powers is started.

    After a successful evaluation, the diagram shows the resulting gain vs. the frequency.

    To see the result table, press the softkey "Display" and the hotkey "Display Diag / Table".

Repeat the measurement for all signal paths that you want to analyze.

You can first prepare all paths and configure the frequencies for all connectors and then measure all paths.

You can even measure all paths in one mode and then in the other mode. But ensure that you have "Open" and "Short" results for a connector, before you start a measurement in the "Eval" mode for that connector.

It does not matter whether frequency-dependent attenuation tables are active for the measured paths. Any external attenuation settings are ignored by the pathloss measurement.
