FETCh:GPRF:MEAS<i>:IQRecorder:RELiability?

Queries the reliability indicator for the I/Q recorder measurement, see "Reliability Indicator".

Return values: 
<ReliabilityFlag>

Two equal values, separated by a comma (e.g. 0,0 for "OK")

See "Performing a Single-Shot Measurement"
