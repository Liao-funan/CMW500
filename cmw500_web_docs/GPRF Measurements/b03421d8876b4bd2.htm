TRIGger:GPRF:MEAS<i>:POWer:SOURce <Source>

Selects the source of the trigger events. Some values are always available in this firmware application. They are listed below. Depending on the installed options, additional values are available. A complete list of all supported values can be displayed using TRIGger:...:CATalog:SOURce?.

Parameters:
<Source>

'IF Power': IF power trigger

'Free Run': free run (untriggered)

*RST:'Free Run'
