CONFigure:GPRF:MEAS<i>:POWer:PDEFset <PredefinedSet>

This command is related to the global parameter set.

A setting command loads a predefined set of parameters into the global parameter set. A query returns the name of the predefined set assigned to the global parameter set.

To get a list of predefined-set strings, use CONFigure:​GPRF:​MEAS<i>:​POWer:​PSET:​CATalog:​PDEFset?.

Parameters:
<PredefinedSet>

Predefined set as string

Firmware/Software: 

V3.2.10

Manual operation: See "Predefined Set"
