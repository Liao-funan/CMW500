CONFigure:GPRF:MEAS<i>:IQRecorder:FORMat <Format>

Selects the coordinates that are used to represent the I/Q recorder results.

Parameters:
<Format>
IQ | RPHI

IQ: cartesian coordinates (I and Q axis)

RPHI: polar coordinates (radius R and angle PHI).

*RST:IQ
Firmware/Software: 

V3.0.10

Manual operation: See "Format"
