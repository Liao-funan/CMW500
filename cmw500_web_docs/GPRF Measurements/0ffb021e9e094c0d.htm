CONFigure:GPRF:MEAS<i>:POWer:LIST:IQData <Index>, <IQData>
CONFigure:GPRF:MEAS<i>:POWer:LIST:IQData? <Index>

Enables the I/Q data measurement in a selected frequency/level step.

Parameters:
<IQData>
OFF | ON

Disables or enables the I/Q data measurement.

*RST:OFF (all frequency/level steps)
Parameters for setting and query: 
<Index>

Number of the frequency/level step in the table

Range: 0  to  3999

See "Performing an I/Q Data Measurement"
