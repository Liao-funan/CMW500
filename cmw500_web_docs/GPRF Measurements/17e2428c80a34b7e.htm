CONFigure:GPRF:MEAS<i>:IQVSlot:FTYPe <FilterType>

Selects the IF filter type.

Parameters:
<FilterType>
GAUSs | NYQuist | NY1Mhz

GAUSs: filter of Gaussian shape, 100 kHz bandwidth

NYQuist: Nyquist filter, 100 kHz bandwidth

NY1Mhz: Nyquist filter, 1 MHz bandwidth

*RST:GAUS

See "Specifying Measurement-Specific Settings"

Options: R&S CMW-KM011
Manual operation: See "Filter Type"
