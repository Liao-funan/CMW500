V2.0.10 (Compared to V1.0.15.20/21/22)
New features:
  • Graphical user interface for "I/Q Recorder" measurement, see "I/Q Recorder Measurement".
  • Power measurement: New trigger mode "Retrigger Preselect", see "Trigger Modes". New command FETCh:​GPRF:​MEAS<i>:​POWer:​ESTatistics?.
  • Power measurement, list mode: Each frequency/level step can be measured repeatedly, see "List > Frequency, Ref. Level, Exp. Nom. Pow.".
  • I/Q vs. slot measurement: New trigger mode "Retrigger Preselect", see "Trigger Modes".
  • "RF Routing": selection of RF 3 and RF 4 connectors modified, RX module selectable (see ROUTe:​GPRF:​MEAS<i>:​SCENario:​SALone). New command ROUTe:​GPRF:​MEAS<i>?.
    Alias ROUTe:GPRF:MEAS<i>:RFSettings:CONNector no longer supported
  • Remote control: New commands CONFigure:GPRF:MEAS<i>:...TOUT, define a specific timeout value for each measurement.
