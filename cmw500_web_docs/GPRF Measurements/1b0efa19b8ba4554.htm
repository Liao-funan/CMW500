V3.0.10 (Compared to V2.1.25)
  • New classic spectrum analyzer measurement application (option R&S CMW–KM010), see "Spectrum Analyzer".
    FFT analysis is now included free of charge in the CMW500 base functions.
  • Power measurement:
    –Statistic evaluation mode (CCDF and APD results) in single-step measurements, see "Single Step: Statistic Evaluation Mode".
    –Up to 10000 results in list mode.
    –New convenience method to configure list section, see CONFigure:​GPRF:​MEAS<i>:​POWer:​LIST:​SSTop.
  • IQ recorder:
    –Configurable coordinates for binary output: cartesian (default) or polar, see CONFigure:​GPRF:​MEAS<i>:​IQRecorder:​FORMat.
    –Configurable trigger offset, see TRIGger:​GPRF:​MEAS<i>:​IQRecorder:​OFFSet.
    –New remote command to read binary IQ results, see FETCh:​GPRF:​MEAS<i>:​IQRecorder:​BIN?.
