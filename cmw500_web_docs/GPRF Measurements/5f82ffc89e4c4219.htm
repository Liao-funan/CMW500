CONFigure:GPRF:MEAS<i>:POWer:LIST:IQData:ALL <IQData>...

Enables or disables the I/Q data measurement for all frequency/level steps.

Parameters:
<IQData>
ON | OFF

Comma-separated list of up to 2000 values, one per frequency/level step

A query returns 2000 values (maximum number of steps).

*RST:OFF
