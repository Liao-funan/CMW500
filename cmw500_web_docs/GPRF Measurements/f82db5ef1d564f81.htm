TRIGger:GPRF:MEAS<i>:SPECtrum:CATalog:SOURce?

Lists all trigger source values that can be set using TRIGger:​GPRF:​MEAS<i>:​SPECtrum:​SOURce.

Comma-separated list of all supported values. Each value is represented as a string.
