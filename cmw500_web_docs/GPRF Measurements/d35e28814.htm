CONFigure:GPRF:MEAS<i>:EPSensor:ATTenuation <Attenuation>

Specifies the external input attenuation factor to correct the power reading at the sensor.

Parameters:
<Attenuation>
Range: -50 dB  to  50 dB
*RST:0 dB
Default unit: dB
