Event Details

The lower part of the main view shows detailed information for the currently selected entry of the "Events" area.

If the entry includes a session setup, the information covers the entire history of the session. Each status change is listed with its timestamp. Important settings are also listed.

The ID shown at the top is an automatically generated unique ID, identifying the event in the DAU.
