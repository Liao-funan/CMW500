SENSe:DATA:MEAS<i>:IPANalysis:IPConnect:AFLowid? <FlowID>

Queries "IP Connectivity" results for a specific connection, selected via its flow ID.

Query parameters: 
<FlowID>

Selects the connection for which information is queried

Return values: 
<App>

Application name as string

<Feature>

Feature name as string (for example: audio, video, SMS)

See "Performing IP Analysis"

Usage: Query only

V3.7.20

Options: R&S CMW-KM051
Manual operation: See "Results"
