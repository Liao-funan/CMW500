CONFigure:DATA:CONTrol:EPDG:AUTHentic:RAND <AuthRAND>

Defines the random number RAND as 32-digit hexadecimal number. Leading zeros can be omitted.

Parameters:
<AuthRAND>
Range: #H0  to  #HFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF
*RST:#H55555555555555555555555555555555

See "Configuring the ePDG Service"
