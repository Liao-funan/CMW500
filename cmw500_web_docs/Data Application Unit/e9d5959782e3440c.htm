CONFigure:DATA:CONTrol:MTU <MaxTransUnit>

Specifies the MTU, that is the maximum IP packet size that can be transmitted without fragmentation.

Parameters:
<MaxTransUnit>
Range: 552 bytes  to  4096 bytes
*RST:1500 bytes
Default unit: bytes
