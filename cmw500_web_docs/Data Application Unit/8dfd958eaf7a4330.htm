V3.2.11 (Compared to V3.0.30)
New features:
  • Additional chapter about network impairments, see "Annex: Network Impairments"
  • Wizard for initial configuration of the IP network settings of the DAU, see "Adapting the DAU IP Configuration"
  • Voice over IMS settings: codec modes configurable independently for NB AMR and WB AMR, see "Common View Elements"
  • Command for deregistration of a DUT from IMS server
  • Command for query of minimum, maximum and average ping latencies, see FETCh:​DATA:​MEAS<i>:​PING:​OVERall?
  • "IP Analysis" application:
    –"IP Connectivity" view: overhead information separately for uplink and downlink, see "View IP Connectivity"
    –"Flow Throughput and Trigger" view: number of connections displayed in parallel enhanced to 10, see "View Flow Throughput and Trigger"
    –Remote control commands, see "IP Analysis and Security"
