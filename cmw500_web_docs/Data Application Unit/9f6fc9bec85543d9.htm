V3.2.20 (Compared to V3.2.11)
New features:
  • IP settings: configurable MTU, see "Maximum Transmission Unit (MTU)"
  • DNS server: new command CONFigure:​DATA:​CONTrol:​DNS:​FOReign:​UDHCp
    The new command combines four old CONFigure:...:UDHCp commands. The old commands are still supported for backward compatibility, but no longer documented.
  • IMS server: new state "ringing" for voice calls
  • Ping measurement: configurable timeout, see "Config"
  • Iperf tests:
    –New command querying all results, see FETCh:​DATA:​MEAS<i>:​IPERf:​ALL?
    –Configurable packet size for iperf tests, see "Packet Size"
  • Softkeys providing direct access to a selected signaling application, see "Signaling Parameter (softkey)" and "... Signaling (softkey)".
