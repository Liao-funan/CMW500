Using PCAP Streaming

For a VoIMS audio or video downlink, you can use media streaming. The streaming is synchronized with the VoIMS call. It starts and stops automatically on call establishment/termination, hold/resume. For video streaming, audio and video packets are read from the same PCAP file and streamed without drifting.

As streaming source, you need a packet capture file (PCAP file) containing the media information. Configure the streaming via the virtual subscriber profile. For details, refer to the following sections.
