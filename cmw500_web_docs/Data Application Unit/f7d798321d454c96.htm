CONFigure:DATA:CONTrol:IPVSix:ROUTing:TYPE <RoutingType>

Selects the mechanism to be used for IPv6 route configuration.

The routes are only relevant for mobile-originating packets with destination addresses that do not belong to the subnet of the DAU and that are not reachable via the default router.

Parameters:
<RoutingType>
MANual

In the current software version, the value is fixed.

MANual: manually configured routes

*RST:MANual

See "Configuring IPv6 Settings"
