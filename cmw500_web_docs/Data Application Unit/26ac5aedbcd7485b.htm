CONFigure:DATA:MEAS<i>:ADELay:MSAMples <MaxSamples>

Configures the maximum number of samples that can be displayed in the result diagrams. The traces cover the sample range -<MaxSamples> + 1 to 0.

Parameters:
<MaxSamples>
Range: 1500  to  6000
*RST:3000
