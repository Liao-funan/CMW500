CONFigure:DATA:CONTrol:IPVFour:STATic:ADDResses:DELete <IPAddress>

Deletes an address from the IPv4 address pool for DUTs, for static IPv4 configuration.

Setting parameters: 
<IPAddress>

IP address to be deleted, either identified via its index number or as string

Range: 0 to <total number of entries> - 1 | '0.0.0.0' to '255.255.255.255'
Example: 

See "Configuring IPv4 Settings"

Usage: Event
Firmware/Software: 

V1.0.15.20

Manual operation: See "Mobile IPv4 Address Pool"
