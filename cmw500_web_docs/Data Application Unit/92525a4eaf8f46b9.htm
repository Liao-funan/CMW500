ePDG Service Control and Softkeys

The ePDG service must be running before you can perform WLAN offloading with signaling applications.

Service control

Start or stop the service using the [ON | OFF] key. Alternatively, right-click the "ePDG Service" softkey.

The softkey shows the current service state.

Remote command: 

SOURce:​DATA:​CONTrol:​EPDG:​STATe

 
Release Connection (softkey)

This softkey releases one or more selected ePDG connections.

To select the connections to be released, use column "Release" in the connection list, see "ePDG Connection Information".
