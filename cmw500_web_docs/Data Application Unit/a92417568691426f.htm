Using the IMS Server

The internal IMS server of the DAU simulates parts of an IMS network, especially a P‑CSCF. It allows an IMS client on the DUT to register to the IMS domain. Option R&S CMW-KAA20 is required for usage of the IMS server.

With a registered DUT, you can test voice over IMS and messaging over IMS. You can perform mobile-originating calls and mobile-terminating calls. If you register two DUTs, you can also perform mobile-to-mobile calls.

This section provides an overview of the IMS server settings, followed by basic step-by-step procedures.

IMS server settings overview
The IMS settings are divided into the following parts:
  • General settings
    The "Config" hotkey accesses the general settings. They select whether the internal IMS server or an external IMS network is used.
    The remainder of this section assumes that you use the internal IMS server.
    For a GUI description, see "General IMS Settings".
  • P-CSCF settings
    The "P-CSCF" hotkey accesses settings related to the simulated P-CSCF. They define the P-CSCF address and the reaction of the P-CSCF on incoming SIP messages from a DUT.
    You can define several P-CSCF profiles with different addresses and settings. A list of all P-CSCFs is sent to the DUT. The DUT selects a P-CSCF from the list for registration.
    Two P-CSCF profiles are predefined and ready-to-use, one for IPv4 and one for IPv6.
    For a GUI description, see "P-CSCF Settings".
  • Subscriber settings
    The "Subscriber" hotkey accesses settings related to the tested DUTs. They define the private user ID, the public user IDs and authentication settings.
    You can define several subscriber profiles, for example if you use SIM cards with different properties. If all your test SIM cards have the same properties, one subscriber profile is sufficient.
    The applicable profile is selected via the user ID included in SIP messages from the DUT.
    For a GUI description, see "Subscriber Settings".
  • Virtual subscriber settings
    The "Virtual Subscriber" hotkey accesses settings related to simulated subscribers. A virtual subscriber can call a tested DUT and it can be called from a tested DUT.
    The settings include, for example, the public user ID via which the virtual subscriber can be reached, the reaction of the virtual subscriber to a call and codec settings.
    You can define several virtual subscriber profiles and use a specific profile for a call.
    For a GUI description, see "Common View Elements".
