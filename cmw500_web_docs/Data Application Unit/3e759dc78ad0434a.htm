CONFigure:DATA:MEAS<i>:IPANalysis:TCPanalysis:TWSThreshold <Threshold>

Defines a threshold (upper limit) for the current TCP window size as percentage of the negotiated maximum window size.

Parameters:
<Threshold>
Range: 0 %  to  100 %
*RST:90 %
Default unit: %
