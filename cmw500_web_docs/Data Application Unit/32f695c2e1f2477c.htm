Setting Up a Conference Call

In the current software version, there is exactly one DUT in a conference call. All other participants are virtual subscribers. The conference can only be initiated by the DUT, not by the DAU.

Initial situation: The GUI shows the "IMS" tab of the "Data Application Control" dialog. The IMS service is switched off.

For conference calls, option R&S CMW-KAA21 is required.

  1. Press the "Config" hotkey.

    A dialog box opens.

  2. Fill the "Factory List" with the conference server addresses used by your DUTs.

    Example: sip:confserver@test.3gpp.com

  3. Press OK to close the dialog box.

  4. Press the "Virtual Subscriber" hotkey.

    A dialog box opens.

  5. Press the leftmost button to access the basic settings.

  6. Press the button repeatedly to create as many virtual subscribers as you need.

    A conference call comprises the DUT and at least two virtual subscribers.

  7. Configure virtual subscriber 1 and the other virtual subscribers compatible to your DUT, as for a normal call.

    The settings of the individual subscribers are relevant when the DUT calls each of them. Most settings of virtual subscriber 1 are also relevant for the conference call, for example the behavior, the signaling type and the media endpoint settings.

  8. Register your DUT to the IMS server.

    For details, see "Registering a DUT to the IMS Server".

  9. Set up a voice over IMS call between the DUT and one virtual subscriber.

    The "Events" area lists the connection, for example, as "S1 VS1 Established".

  10. At your DUT, add a second voice over IMS call to another virtual subscriber.

    The already existing call is automatically put on hold. In the "Events" area, you see both calls. For example, "S1 VS1 Hold" and "S1 VS2 Established".

  11. At your DUT, initiate the conference (for example "Join" or "Merge" button).

    The calls to the virtual subscribers are released by the DUT. New calls between the conference server and all participants are established.

    In the "Events" area, you see the released calls. For example as "S1 VS1 Released" and "S1 VS2 Released". The conference is listed, for example, as "S1 C1 Established", "C1 VS1 Established" and "C1 VS2 Established".

  12. To add more virtual subscribers:

    1. Establish an additional call.

    2. Add the call to the conference (join/merge).

    3. Repeat these steps.

  13. To remove a virtual subscriber from the conference:

    1. Press the "Release Call" softkey.

      A dialog box opens.

    2. Enable the checkbox of the connection that you want to release.

    3. Select whether the virtual subscriber leaves the conference ("Depart") or the conference server releases the connection ("Eject").

    4. Press the "Release" button.
