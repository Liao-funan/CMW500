Configuring PCAP Streaming

After preparing the PCAP files and the XML meta file on the samba share, you can use PCAP streaming.

Configure the virtual subscriber profile to be used, as follows:

  1. Set "Media Endpoint" to "PCAP".

  2. Use "PCAP Meta File Selection" to select the meta file that you want to use.

  3. If you want to force a certain audio codec for mobile-originating calls, enable the audio setting "Force Codec for MO Calls".

    See also "Basic Virtual Subscriber Settings".
