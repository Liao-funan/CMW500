V3.0.10 (Compared to V2.0.20)
New features:
  • New DAU services:
    –IP multimedia subsystem (IMS)
    –Internal DNS server, see "DNS Tab"
  • New DAU measurements:
    –DNS requests monitor, see "DNS Requests Tab"
    –IP logging application, see "IP Logging Tab"
  • Network impairments can be applied to the IP traffic from the DAU to the DUT, see "Quality-of-Service Settings"
  • Enhanced DNS server settings - including usage of internal and external DNS servers for IPv4 and IPv6, statically and dynamically configured server addresses, see "DNS Tab"
  • Enhanced IPv6 address configuration - including automatic predefined configuration, static configuration, dynamic autoconfiguration and DHCP prefix delegation, see "IP Address Configuration Methods"
  • The state of the LAN DAU connector is displayed, see "Displayed Information"
  • The DAU can be started/stopped independent of the R&S CMW base software, see "DAU (softkey)"
  • The ping measurement now also indicates the number of ping requests without reply and the detected reason (e.g. timeout, no route), see "'No Reply' Count"
  • The throughput measurement provides the minimum and current throughputs in addition to the maximum throughputs, see "Throughput Tab"
  • The DAU tools are now also available on the samba share, see "Using the System Drive of the DAU"
  • The multimedia folder of the samba share can now also be accessed via WebDAV, see "Accessing the samba share via WebDAV"
  • The following commands have been renamed (old commands still available as alias):
    –CONFigure:DATA:CONTrol:IPVFour:CURRent:SMASk? to SENSe:DATA:CONTrol:IPVFour:CURRent:SMASk?
    –CONFigure:DATA:CONTrol:IPVFour:CURRent:IPADdress? to SENSe:DATA:CONTrol:IPVFour:CURRent:IPADdress?
    –CONFigure:DATA:CONTrol:IPVFour:CURRent:GIP? to SENSe:DATA:CONTrol:IPVFour:CURRent:GIP?
    –CONFigure:DATA:CONTrol:IPVFour:STATic:ADDResses:CATalog? to SENSe:DATA:CONTrol:IPVFour:STATic:ADDResses:CATalog?
    –CONFigure:DATA:CONTrol:IPVSix:PREFixes:CATalog? to SENSe:DATA:CONTrol:IPVSix:STATic:PREFixes:CATalog?
    –CONFigure:DATA:CONTrol:IPVSix:PREFixes:ADD to CONFigure:DATA:CONTrol:IPVSix:STATic:PREFixes:ADD
    –CONFigure:DATA:CONTrol:IPVSix:PREFixes:DELete to CONFigure:DATA:CONTrol:IPVSix:STATic:PREFixes:DELete
    –CONF:DATA:CONTrol:IPVFour:STATic:DNSPrimary:IPADdress to CONF:DATA:CONTrol:DNS:FOReign:IPVFour:PRIMary:ADDRess
    –CONF:DATA:CONTrol:IPVFour:STATic:DNSSecondary:IPADdress to CONF:DATA:CONTrol:DNS:FOReign:IPVFour:SECondary:ADDRess
    –CONFigure:DATA:CONTrol:FTP:USER:CATalog? to SENSe:DATA:CONTrol:FTP:USER:CATalog?
