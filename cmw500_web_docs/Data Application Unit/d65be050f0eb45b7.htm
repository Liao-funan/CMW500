Setting Up a Mobile-Terminating Voice over IMS Call

Initial situation: The DUT has registered to the IMS server. The GUI shows the "IMS" tab of the "Data Application Control" dialog.

  1. Press the "Virtual Subscriber" hotkey.

    A dialog box opens.

  2. Press the leftmost button to access the basic settings.

  3. Configure the "Virtual 1" tab as follows:

    1. Set the "Signaling Type" compatible to your DUT (call setup with or without SIP preconditions).

    2. Configure the audio codec settings compatible to your DUT.

    3. For video calls, configure the video codec settings compatible to your DUT.

    4. For "Media Endpoint", we use the default value "Loopback".

  4. Press the button.

    The mobile-terminating call (MTC) settings of the virtual subscriber are displayed.

  5. Configure the following call settings:

    1. If there are several registered DUTs, select the "Destination" that you want to call.

    2. Select the "Call Type".

  6. Press the "Call" button.

    The dialog box is closed and the DUT is alerted.

    A new line is added to the "Events" area. The status in that line equals "Ringing".

  7. Accept the call at the DUT.

    The status in the "Events" area changes to "Established".

  8. Perform an echo test. Speak a word into the microphone of the DUT. Listen to the echo at the loudspeaker of the DUT.

    For further tests, you can create additional virtual subscriber profiles with different call settings.
