FETCh:DATA:MEAS<i>:IPReplay:FILelist?

Queries a list of all files in the directory ip_replay of the samba share.

Return values: 
<Files>

Comma-separated list of strings, one string per filename

Example: 

See "Performing IP Replay"

Usage: Query only

V3.5.10
