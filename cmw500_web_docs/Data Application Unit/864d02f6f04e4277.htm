PCAP File Requirements and File Selection

The PCAP file must contain only RTP packets carrying the media information. The file must use the "raw IP" format, so that all packets start with the IP header. You can use the "IP Logging" application of the DAU to record such PCAP files from the U-plane IP interface.

The PCAP file used for a call must comply with the media formats negotiated between the UE and the DAU (SDP negotiation). So you need several PCAP files, one for each combination of audio/video codec and AMR alignment mode (octet-aligned, bandwidth-efficient).

The PCAP file selection is controlled by an XML meta file on the samba share of the DAU, subdirectory ims/pcap. The meta file contains a lookup table with <MediaConfig> elements. Each <MediaConfig> element has attributes, specifying conditions and a PCAP file to be used if the conditions are met.

For UL DAU IP logging, usually port 49200.

VideoPort

Video calls mandatory

Integer

Target UDP port of video media in PCAP file must match.

For UL DAU IP logging, usually port 49250.

Media configurations without this attribute are not used for video calls.

FileName

Mandatory

Filename with file extension

PCAP file to be used if the other attributes match.

Path relative to ims/pcap on the samba share.

1) Setting the attributes PayloadTypeAudio/Video is an alternative to setting the attributes AmrAligMode and Codec. The payload type number contains information about the alignment mode and the codec.

Example of an XML meta file
<?xml version="1.0" encoding="UTF-8"?>
<PcapEndPointConfig xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
    xsi:noNamespaceSchemaLocation="file:/etc/ims/pcap/pcapendpconfig_schema.xsd">
  <MediaConfig AmrAligMode="AMR_OCTET_ALIGNED" Codec="AMR_NARROWBAND"
    AudioPort="49200" VideoPort="49250" FileName="amr-nb_oa+h264.pcap"/>
  <MediaConfig AmrAligMode="AMR_OCTET_ALIGNED" Codec="AMR_WIDEBAND"
    AudioPort="49200" VideoPort="49250" FileName="amr-wb_oe+h264.pcap"/>
  <MediaConfig AmrAligMode="AMR_BANDWIDTH_EFFICIENT" Codec="AMR_NARROWBAND"
    AudioPort="49200" VideoPort="49250" FileName="amr-nb_be+h264.pcap"/>
  <MediaConfig AmrAligMode="AMR_BANDWIDTH_EFFICIENT" Codec="AMR_WIDEBAND"
    AudioPort="49200" VideoPort="49250" FileName="amr-wb_be+h264.pcap"/>
</PcapEndPointConfig>
