SOURce:DATA:MEAS<i>:QOS:STATe <Control>

Switches the QoS feature on or off. To enable QoS profiles, see CONFigure:​DATA:​MEAS<i>:​QOS:​FILTer<Index>:​ENABle.

Setting parameters: 
<Control>
ON | OFF

Switch the QoS feature on or off

Return values: 
<NIState>
OFF | PENDing | ON

OFF: QoS feature switched off

PEND: switching on/off is ongoing

ON: QoS feature switched on

*RST:OFF
