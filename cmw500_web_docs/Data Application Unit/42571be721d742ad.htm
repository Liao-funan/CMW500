View IP Connection Security

The IP connection security analysis evaluates the traffic between a DUT and the Internet under IP security aspects. It provides an overview of security-relevant parameters for each connection.

The provided information includes for example:
  • Whether a connection is encrypted at all
  • Whether critical information like a password is transmitted unencrypted
  • Which SSL/TLS protocol version is used
  • Details about the SSL/TLS handshake, including the used key lengths, the parameters offered by the client and the values selected by the server
  • Certificates sent by the server
  • Country, city and domain of the server end point
  • Open IP ports at the DUT

The information allows you to detect security problems of a DUT or security risks of specific apps.

To use the IP connection security analysis, you need option R&S CMW-KM052. Without this option, the "IP Connection Security" view is hidden. Option R&S CMW-KM051 is a prerequisite for option R&S CMW-KM052.

A restart of the measurement clears all results.

In the context of this application, the term "destination" refers to the connection partner of the DUT, typically a server on the Internet. The term is used independent of which side initiated a connection and in which direction the traffic is transmitted.
