CONFigure:DATA:CONTrol:IPVSix:MOBile:PREFix:TYPE <PrefixType>

Selects the method to be used to define the IPv6 prefix pool for DUTs.

This setting is only relevant for test setups with connected external network. It is ignored for a standalone test setup (AUTO set via CONFigure:​DATA:​CONTrol:​IPVSix:​ADDRess:​TYPE).

Parameters:
<PrefixType>
STATic | DHCP

STATic: static IP configuration

DHCP: DHCP prefix delegation

*RST:STAT
