DAU Measurements GUI Reference

Data application measurements require option R&S CMW-KM050. Activate the measurements via the "Measurement Controller" dialog, entry "Data Appl. > Measurements". You can then access the main view of the measurements dialog from the task bar.

The "Data Application Measurements" dialog contains common elements at the top, one overview tab and one tab per DAU measurement. Refer to the following sections for a detailed description. The QoS settings are also described.
