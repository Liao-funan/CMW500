Troubleshooting a Failed Registration

If your DUT registers to the radio access network, but not to the IMS, check the following settings.

  1. Is the internal IMS server used and switched on?

    1. Check the upper right corner of the "IMS" tab. It must state "intern IMS", not "extern IMS".

      To modify this setting, press the "Config" hotkey.

    2. Check the "IMS Service" softkey. It must state "ON", not "OFF".

  2. Subscriber settings (hotkey "Subscriber"):

    1. Is the private user ID correct?

      If you are not sure which ID your DUT uses, you can analyze SIP register messages sent by your DUT. The private user ID is contained in the header as username="...".

    2. Are the authentication settings correct?

      If the DUT does not support or require authentication, set "No Authentication".

      If the DUT requires authentication, select the AKA version and configure all "Authentication Data" settings compatible to your DUT.

  3. "P-CSCF" settings (hotkey "P-CSCF").

    Search the tab containing the IP address to which the DUT sends the REGISTER message and check the settings:

    1. The "Behavior" must be "Normal".

    2. If the DUT suggests an expiration interval in its REGISTER message, check "Registration" > "Expiration Time". The value suggested by the DUT must be within the range "MIN" to "MAX".
