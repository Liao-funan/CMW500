CONFigure:DATA:MEAS<i>:QOS:FILTer<Index>:JITTer <Jitter>

Specifies the jitter for a QoS profile. The jitter must be smaller than or equal to the configured delay.

Suffix: 
<Index>
1..15

Selects the QoS profile

Parameters:
<Jitter>
Range: 0 s  to  10 s
*RST:0 s
Default unit: s
Example: 

See "Configuring QoS Profiles"

Firmware/Software: 

V3.5.30

Manual operation: See "Jitter, Jitter Distribution"
