General IMS Info

The "General IMS Info" area in the main view reports events and errors like IMS state changes, registration events and subscription events.

The button to the right clears the displayed entries.

General IMS Info area of the IMS tab
Entries

Each entry consists of a timestamp, an icon indicating the category of the event and a short text describing the event.

Meaning of the category icons: = information, warning and error
