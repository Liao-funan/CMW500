Certificate Settings

The following settings are related to SSL certificates.

If you want to use SSL without certificates, disable the checkbox.

If you want to use an SSL certificate:
  • Store the server certificate file and the key file with the private key of the server on the samba share, in the directory security/certificates/epdg.
    Only PEM files are supported.
  • Store the server certificate file on the DUT.
  • Ensure that the ePDG ID used in the server certificate matches the configured ePDG ID, see "ePDG ID Configuration".
  • Enable the checkbox in the following settings.
  • Select the key file and the certificate file via the following parameters. The list offers only PEM files stored in the correct directory on the samba share.
