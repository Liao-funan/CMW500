CONFigure:DATA:CONTrol:IMS2:UPDate:INBand:AMRWb:CODec:RATes <AMRWBBitrate>

Configures an AMR wideband codec rate to be requested via CMR.

Parameters:
<AMRWBBitrate>
R660 | R885 | R1265 | R1425 | R1585 | R1825 | R1985 | R2305 | RA2385 | NOReq

R660 to RA2385: 6.60 kbit/s to 23.85 kbit/s

NOReq: no codec rate requirement (NO_REQ)

*RST:R660
Example: 

See "Updating an established call"

Firmware/Software: 

V3.5.50

Options: R&S CMW-KAA21
Manual operation: See "Inband tab"
