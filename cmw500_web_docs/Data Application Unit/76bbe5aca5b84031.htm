V3.5.30 (Compared to V3.5.21)
New features:
  • Support of video streaming from the DAU to a DUT, see "Streaming Videos from the Web Portal"
  • DNS server: Resolve DNS queries without database entry, see "Internal DNS server"
  • ePDG service:
    –3DES supported for IKEv2 encryption, see "Encryption"
    –3DES supported for ESP encryption, see "Encryption"
    –SHA2 supported for IKEv2 PRF, see "PRF"
    –SHA2 supported for IKEv2 integrity, see "Integrity"
    –SHA2 supported for ESP integrity, see "Integrity"
  • IMS server:
    –TCP keep-alive messages can be disabled, see "General IMS Settings"
    –A call can be put on hold / resumed, see "Update Call (softkey)"
    –The audio measurements instance can be selected, see "Audio Instance"
    –A specific codec type can be forced for MO calls, see "Force Codec for MO Calls"
    –Commands for the EVS audio codec, see "Virtual Subscriber Settings"
    –Configurable channel-aware mode, see "Channel-Aware Mode"
    –Standalone RCS messages, pager mode and large mode, see "Mobile-Terminating Messages"
    Configurable QCI value, see "Chat QCI"
  • Network impairments, see "Quality-of-Service Settings"
    –Renamed to "Quality of Service" settings and enhanced as follows
    –Prioritization of traffic matching sets of filter criteria
    –Additional filter criteria: source port range and protocol
    –TCP acknowledgment prioritization
    –Configurable hop limit and maximum bit rate
  • Support of iperf3, see "IPerf Type"
  • Throughput measurement, see "Throughput Tab"
    The throughput can be measured per RAN (up to four RANs in parallel).
