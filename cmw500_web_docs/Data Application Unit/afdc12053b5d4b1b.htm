CONFigure:DATA:CONTrol:IMS2:VIRTualsub<v>:EVS:IO:MODE:CONFig <EVSIOModeCnfg>

Selects the speech packet type to be sent from the audio board to the DUT for the EVS AMR-WB IO mode.

Suffix: 
<v>
1..20
Parameters:
<EVSIOModeCnfg>
EVSamrwb | AMRWb

AMRWb: AMR-WB encoded packets

EVSamrwb: EVS AMR-WB IO encoded packets

*RST:EVS
Firmware/Software: 

V3.5.51

Manual operation: See "EVS IO Mode Codec"
