CONFigure:DATA:CONTrol:IMS2:VIRTualsub<v>:MTFiletfr:FILE:SELection <Selected File>

Selects a file for file transfers by virtual subscriber number <v>. The file must be on the samba share of the DAU, in the subdirectory ims/rcs/samples.

Suffix: 
<v>
1..20
Parameters:
<Selected File>

File name as string

Example: 

See "Transferring a file to the DUT"

Firmware/Software: 

V3.5.40

Options: R&S CMW-KAA21
Manual operation: See "File selection"
