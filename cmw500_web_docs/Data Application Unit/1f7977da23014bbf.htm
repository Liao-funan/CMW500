Data Application Measurements

This section provides programming examples for the SCPI commands with the syntax ...:DATA:MEAS:....

Most measurements require a signaling connection to the DUT, for example an LTE connection, set up via the LTE signaling application. To set up the signaling connection, use the commands provided by the application.
