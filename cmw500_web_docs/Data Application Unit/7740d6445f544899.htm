CONFigure:DATA:CONTrol:IMS2:VIRTualsub<v>:MTCall:DESTination <Destination>

Specifies the destination to be called by virtual subscriber number <v>.

To query a list of all possible destination strings, see SENSe:​DATA:​CONTrol:​IMS2:​VIRTualsub<v>:​MTCall:​DESTination:​LIST?.

Suffix: 
<v>
1..20
Parameters:
<Destination>

Destination string

See "Performing a mobile-terminating voice over IMS call"
