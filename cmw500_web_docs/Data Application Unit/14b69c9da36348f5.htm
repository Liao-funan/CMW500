Sending a Message from the DUT (SMS or RCS)

Initial situation: The DUT has registered to the IMS server. The GUI shows the "IMS" tab of the "Data Application Control" dialog.

For RCS messages, option R&S CMW-KAA21 is required.

  1. Send a message from your DUT to the DAU.

    With the default virtual subscriber settings, you can send the message to any public user ID. Virtual subscriber 1 (public user ID "*") accepts it.

  2. Check the "Events" area of the main view.

    After a successful message transfer, there is a new line with the event or and the status "OK" or "Text Transferred".

  3. Select this line in the "Events" area.

    The lower part of the main view displays details about the received message, for example the message text.
