CONFigure:DATA:CONTrol:IMS2:CONFerence:MAX:PARTicipant <MaxParticipant>

Configures the maximum number of virtual subscribers allowed to participate in a conference call.

Parameters:
<MaxParticipant>

The value 0 means that there is no limit.

Range: 0  to  10
*RST:0
Example: 

See "Using the internal IMS server"

Firmware/Software: 

V3.7.11

Options: R&S CMW-KAA21
Manual operation: See "Max No. of Virtual Participants"
