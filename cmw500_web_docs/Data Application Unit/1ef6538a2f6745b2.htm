V3.5.51 (Compared to V3.5.50)
New features:
  • IMS enhancements:
    –New message type for RCS group chats, see "Mobile-Terminating Messages"
    –Mobile-initiated conference calls, see "Setting Up a Conference Call"
    –Public IDs in the PAU header of REGISTER responses are configurable, see "IMPUs in PAU Header"
    –For the EVS AMR-WB IO mode with audio board endpoint, you can send AMR-WB encoded packets to the DUT, see "EVS IO Mode Codec"
  • "IP Analysis" enhancements:
    –"Voice Over IMS" view lists audio codec rate, see "Flows Info tab (lower part)"
    –"IP Connectivity" view filter configuration via remote command, see CONFigure:​DATA:​MEAS<i>:​IPANalysis:​IPConnect:​FILTer
  • The ePDG event log can be cleared, see "ePDG Event Log"
