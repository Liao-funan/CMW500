IP Config Tab

This tab specifies the IP settings for the DAU and the DUT. The settings must be compatible to the test setup.

To apply changes of the IP settings and make them known to the signaling units, you must "restart" the generation of downlink signals by the signaling units. Switch downlink signal generation off and on again in the signaling application or restart protocol tests.

You can specify IP settings both for IPv4 and for IPv6. Which IP version is used depends on the DUT and the used signaling application or protocol test application. It is not selected by the DAU. To use IPv4, you need R&S CMW-KA100. IPv6 requires also option R&S CMW-KA150.

You can configure the DAU IP settings manually or via the "Initial Setup Wizard". For an introduction to both methods and background information concerning IPv4 and IPv6, see "Adapting the DAU IP Configuration". For a setup with a connected external network, contact your network administrator before configuring the IP settings.
