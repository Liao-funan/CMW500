CONFigure:DATA:CONTrol:IPVFour:STATic:IPADdress <IPAddress>

Sets the IP address of the DAU to be used for static IPv4 configuration.

Parameters:
<IPAddress>

IP address as string

Range: '0.0.0.0' to '255.255.255.255'
*RST:'192.168.168.170'
