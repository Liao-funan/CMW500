CONFigure:DATA:CONTrol:IMS2:UPDate:CALL:EVENt <UpdateCallEvent>

Puts a call on hold or resumes a call that has been put on hold.

To select the call, use CONFigure:​DATA:​CONTrol:​IMS2:​UPDate:​CALL:​ID.

Parameters:
<UpdateCallEvent>
HOLD | RESume
Firmware/Software: 

V3.5.30

Manual operation: See "Outband tab"
