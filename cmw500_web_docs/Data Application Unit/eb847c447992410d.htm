FETCh:DATA:MEAS<i>:PING:OVERall?

Query the statistical ping results over all ping requests.

Return values: 
<Reliability>

See "Reliability Indicator"

<MinPing>

Minimum ping latency

Range: 0 s  to  10 s
Default unit: s
<MaxPing>

Maximum ping latency

Range: 0 s  to  10 s
Default unit: s
<AveragePing>

Average ping latency

Range: 0 s  to  10 s
Default unit: s

See "Performing a Ping Measurement"

Usage: Query only
Firmware/Software: 

V3.2.11

Manual operation: See "Average / Minimum / Maximum"
