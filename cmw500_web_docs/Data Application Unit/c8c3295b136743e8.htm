CONFigure:DATA:CONTrol:IMS2:VIRTualsub<v>:EVS:SYNCh:SELect <BWRANGE>

Selects a configuration mode for the bandwidth and bit-rate settings of the EVS primary mode.

The uplink (receive) and the downlink (send) can be configured together (COMMon) or separately (SENDrx).

Suffix: 
<v>
1..20
Parameters:
<BWRANGE>
COMMon | SENDrx
COMMon
