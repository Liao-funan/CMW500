IMS Service

The commands described in this section configure and control the IMS service. It provides, for example, voice over IMS calls and SMS over IMS.

Do not combine the described ...:IMS2:... commands with older ...:IMS:... commands from software versions before 3.5.10. Scripts using only the old commands are still supported.
