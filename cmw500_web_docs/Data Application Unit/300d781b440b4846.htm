V3.7.11 (Compared to V3.7.10)
New features:
  • IMS enhancements:
    –Additional virtual subscriber behaviors (CF before/after ringing, CD), see "Behavior"
    –Configurable ringing time before incoming call is forwarded or accepted, see "Accept/Forward Call After"
    –Subscriber authentication commands accept hexadecimal numbers also in hex format, not only as strings.
    –Switching the view within the virtual subscriber settings applies previous changes.
    –Session timer support, see "Session Timer"
    –Generic SMS for full control of RPDU contents, see "Mobile-Terminating Messages"
    –Improved configuration of conference server settings, see "Conference Parameters"
    –Support of calls with early media, see "Signaling Type"
    –Command for query of last entry from the event log, see SENSe:​DATA:​CONTrol:​IMS2:​EVENts:​LAST?
  • "IP Analysis" enhancements:
    –"Voice Over IMS" view enhanced with current jitter results, see "Jitter tab (lower part)"
    –"TCP Analysis" view enhanced with diagrams showing results vs. time, see "TCP Analysis Graphs"
    –Connection flow filter enhanced, see "Filtering Evaluated Connections"
    –Port scan added to IP connection security analysis, see "Port Scan Tab"
    –Improvements of some IPCSecurity commands
  • Support of 48-bit IPv6 prefixes, assigned to the DUT via prefix delegation, see "IPv6 Configuration"
  • Maximum iperf client bitrate increased, see CONFigure:​DATA:​MEAS<i>:​IPERf:​CLIent<Index>:​BITRate
