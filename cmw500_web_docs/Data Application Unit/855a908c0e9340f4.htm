V2.0.20 (Compared to V2.0.10)
New features:
  • Iperf measurements
    The iperf functionality has been changed completely. Up to eight server and client instances can be defined in parallel, see "Iperf Tab".
    The following remote control commands are obsolete and return an error:
    –CONFigure:DATA:MEAS<i>:IPERf:BITRate
    –CONFigure:DATA:MEAS<i>:IPERf:IPADdress
    –CONFigure:DATA:MEAS<i>:IPERf:PCONnection
    –CONFigure:DATA:MEAS<i>:IPERf:LPORt
    –CONFigure:DATA:MEAS<i>:IPERf:PORT
    –CONFigure:DATA:MEAS<i>:IPERf:PROTocol
    –CONFigure:DATA:MEAS<i>:IPERf:STYPe
    –CONFigure:DATA:MEAS<i>:IPERf:WSIZe
    –FETCh:DATA:MEAS<i>:IPERf
    –READ:DATA:MEAS<i>:IPERf
  • Web server
    The web server provides an enhanced web portal which can be used at once for web browsing. The portal provides information, statistics and tools for data testing, see "Accessing the Built-In Web Server".
  • IPv6 connections to external PCs by static hosts
    You can use IPv6 to establish IP connections between external PCs. An IPv6 configuration tool simplifies IPv6 configuration on the PC that is connected to the LAN DAU Ethernet adapter, see the description in the web portal.
