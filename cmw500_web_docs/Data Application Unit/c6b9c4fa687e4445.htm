DAU Services Command Reference

The following sections provide detailed reference information on the remote control commands related to the DAU services (...:DATA:CONTrol:... commands).

The commands configure the IP settings, configure and control the DAU services and control the DAU unit.

Reset

The data application control settings are considered as system settings and are not affected by the command *RST.

But you can reset data application control settings via other commands, for example via SYSTem:RESet "Data Appl. Control". The "*RST:" information in the command descriptions indicates the result of such commands.

Refer to the base software manual for a description of the reset commands.
