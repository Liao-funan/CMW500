V3.5.40 (Compared to V3.5.31)
New features:
  • IMS enhancements:
    –File transfer via MSRP from virtual subscriber to DUT, see "File Transfer"
    –Text for message transfers can be imported from a file, see "Import"
    –Many new event states, see "Status column"
  • ePDG enhancements:
    –Manual release of individual ePDG connections, see "ePDG Service Control and Softkeys"
  • Throughput measurement enhancement:
    –Command for RAN throughput max array size: CONFigure:​DATA:​MEAS<i>:​THRoughput:​RAN:​MCOunt
    –Command for query of RAN strings: CONFigure:​DATA:​MEAS<i>:​THRoughput:​RAN:​CATaloge?
  • Secure user plane location server (SUPL) added to DAU services.
    First version without GUI. Provides services to the software options R&S CMW-KA09x (test software for eCall / ERA-GLONASS and A-GNSS).
