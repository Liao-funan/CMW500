What's New in This Version

This documentation describes version 3.7.20 and later of the data application unit firmware application. Compared to version 3.7.11, it provides the following new features and changes:

  • "IP Analysis" enhancements:
    –Connection flow filter enhanced, see "Filtering Evaluated Connections"
    New properties for filtering: application, country, source port, destination port, connection state
    Several filter criteria can be combined by AND.
    The filter results can be displayed in the view "Flow Throughput and Trigger" by selecting flow ID 0.
    –"IP Connectivity" view changes, see "View IP Connectivity"
    Removed "Overhead DL/UL" and "Avg. P-Size DL/UL".
    Added "App." and "Country".
    –"TCP Analysis" view changes, see "View TCP Analysis"
    The diagrams are reachable via hotkey instead of tabs and they cover an entire hour.
    –Export DB function changes, see "Export Results (hotkey)"
    Stores more results, using JSON files instead of CSV files.
    Hotkey renamed.
    File location changed from samba share to log files folder on R&S CMW system drive.
  • "IP Connection Security" enhancements:
    –Remote commands for the port scan, see "Port Scan Settings and Results"
    –Timeout for the port scan, see "Timeout"
    –Import of keywords for the keyword search, see "Import Keywords From File"
  • ePDG enhancements:
    Added automatic mode for the IP type, see "P-CSCF IKEv2 Attributes"
