CONFigure:DATA:CONTrol:IMS2:UPDate:EVS:BWCommon <BWCommon>

Selects the codec bandwidths supported in the EVS primary mode, for a call update and common configuration.

Parameters:
<BWCommon>
NB | WB | SWB | FB | NBWB | NBSWb | NBFB

NB: narrowband only

WB: wideband only

SWB: super wideband only

FB: fullband only

NBWB: narrowband and wideband

NBSWb: narrowband, wideband and super wideband

NBFB: narrowband, wideband, super wideband and fullband
