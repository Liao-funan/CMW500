V3.5.50 (Compared to V3.5.40)
New features:
  • IMS enhancements:
    –New message type for RCS 1 to 1 chat, see "Mobile-Terminating Messages"
    –Configurable service capability information for presence-based services, see "Supported Features"
    –Configurable codec mode requests (CMR) during a call, see "Update Call (softkey)"
    –Automatic selection of integrity and encryption algorithms for IPsec, see "Integrity Algorithm" / "Encryption Algorithm"
  • "IP Analysis" enhancements:
    –"TCP Analysis" view redesigned, packet size and round-trip time results added, see "View TCP Analysis"
    –"VoIMS" view redesigned, "Flows Info" enhanced, "Bitrate\CMR" results added, see "View Voice over IMS"
  • IP logging for scenarios where the DAU acts as client, see "Logging Interface"
