V3.5.20 (Compared to V3.5.11)
New features:
  • New DAU measurement: "Audio Delay", see "Audio Delay Tab"
  • New DAU services:
    –ePDG, see "ePDG Tab" and "Using the ePDG Service for WLAN Offload"
    –eMBMS service layer, see "Using the eMBMS Service"
  • IP logging: configurable snap length, see "Settings"
  • IMS server: The same subscriber profile can be used for several DUTs with the same test SIM. A unique contact ID is assigned to each DUT (IP address) during registration. See "Destination".
