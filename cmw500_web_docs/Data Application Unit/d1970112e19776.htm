CONFigure:DATA:CONTrol:HTTP:ENConnection <ExtNetConn>

Specifies whether access to the internal web server is allowed from an external network (via LAN DAU).

Parameters:
<ExtNetConn>
OFF | ON

OFF: not allowed

ON: allowed

*RST:ON
