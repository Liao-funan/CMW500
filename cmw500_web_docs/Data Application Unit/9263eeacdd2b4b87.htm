SENSe:DATA:MEAS<i>:THRoughput:INTerval?

Queries the time interval between two throughput measurement results.

Return values: 
<Interval>

In the current software version, the value is fixed.

*RST:1 s
Default unit: s
Usage: Query only
Firmware/Software: 

V3.0.10

Manual operation: See "Settings"
