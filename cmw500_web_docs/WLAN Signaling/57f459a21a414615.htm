Options and Equipment Required
A WLAN combined signal path measurement requires the following equipment:
  • R&S CMW with firmware version 2.1.30 or higher. The latest firmware version is recommended.
  • Option R&S CMW-KS650, "WLAN IEEE 802.11a/b/g, basic signaling"
  • Option R&S CMW-KM650, "WLAN IEEE 802.11a/b/g, TX measurement"
  • For 802.11n:
    –Option R&S CMW-KS651, "WLAN IEEE 802.11n, basic signaling"
    –Option R&S CMW-KM651, "WLAN IEEE 802.11n SISO, TX measurement"
  • For 802.11ac:
    –Option R&S CMW-KS651, "WLAN IEEE 802.11n, basic signaling"
    –Option R&S CMW-KS656, "WLAN IEEE 802.11ac, basic signaling"
    –Option R&S CMW-KM651, "WLAN IEEE 802.11n SISO, TX measurement"
    –Option R&S CMW-KM656, "WLAN IEEE 802.11ac SISO, TX measurement"
  • For 802.11ax:
    –Option R&S CMW-KS651, "WLAN IEEE 802.11n, basic signaling"
    –Option R&S CMW-KS656, "WLAN IEEE 802.11ac, basic signaling"
    –Option R&S CMW-KS657, "WLAN IEEE 802.11ax, basic signaling"
    –Option R&S CMW-KM651, "WLAN IEEE 802.11n SISO, TX measurement"
    –Option R&S CMW-KM656, "WLAN IEEE 802.11ac SISO, TX measurement"
    –Option R&S CMW-KM657, "WLAN IEEE 802.11ax SISO, TX measurement"
  • Option R&S CMW-KB036, "6 GHz Enabling" for operation above 3.3 GHz
