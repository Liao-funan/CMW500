V3.2.11 (Compared to V3.2.10)
New features:
  • Support for downlink TX MIMO in 5 GHz band, AP mode (option R&S CMW-KS670)
    –Two DL signals routed to different output connectors
    –TX diversity, spatial multiplexing or space time block coding (STBC)
    –Standards 802.11a/n, 802.11g(OFDM)/n and 802.11n(GF)
  • Burst output power: Reset value changed from -80 dBm to -40 dBm
  • Beacon interval: Maximum length increased to 16000 time units
  • MAC frame RX trigger mode: Generate trigger signals for selected burst types only
  • New adaptive RX filter for CCK signals
  • Packet generator: Default payload size increased to 500 bytes
