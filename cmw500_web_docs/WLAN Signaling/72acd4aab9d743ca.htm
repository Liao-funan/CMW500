IP Communication

For an R&S CMW without data application unit (DAU, see "Data End-to-End Tests"), the signaling application runs its own IPv4/IPv6 stack. It is used by the "Packet Generator" and the built-in DHCP server/IPv6 stateless autoconfiguration.

If a DAU is installed, the WLAN signaling application relays incoming DHCP requests/IPv6 stateless autoconfiguration to the DAU.
