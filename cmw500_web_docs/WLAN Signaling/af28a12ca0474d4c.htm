DUT/UE Info

The "DUT / UE Info" area presents information about the associated device under test.

DUT / UE capabilities in main view
MAC Address

The MAC address of the associated DUT is a 48-bit number, displayed as hexadecimal number. It uniquely identifies a IEEE 802 device. An AP registers a station's MAC address during association.

Remote command: 

SENSe:​WLAN:​SIGN<i>:​UECapability:​MAC:​ADDRess?

 
MAC Version

The MAC version depends on the configured IEEE 802.11 standard, as follows:

MAC version

IEEE standard

0

802.11a, 802.11b, 802.11g, 802.11g(OFDM)

1

802.11a/n, 802.11g/n, 802.11g(OFDM)/n, 802.11n(GF), 802.11ac, 802.11ax

Remote command: 

SENSe:​WLAN:​SIGN<i>:​UECapability:​MAC:​VERSion?

 
IPv4 address / IPv6 Prefix[0]

IPv4 address and first IPv6 address prefix of the connected DUT.

This information is only available for data end-to-end tests with the DAU.

Remote command: 

SENSe:​WLAN:​SIGN<i>:​UESinfo:​UEADdress:​IPV<n>?
