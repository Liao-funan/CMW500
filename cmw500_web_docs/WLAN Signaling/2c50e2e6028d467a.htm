CONFigure:WLAN:SIGN<i>:IPVFour:STATic:IPADdress:GATeway <Octet1>, <Octet2>, <Octet3>, <Octet4>

Provides the IPv4 address of the default gateway to the built-in IPv4 stack.

Parameters:
<Octet1>, <Octet2>, <Octet3>, <Octet4>

Address <Octet1>.<Octet2>.<Octet3>.<Octet4>

Range: 0 to 255
*RST:100, 100, 100, 1
