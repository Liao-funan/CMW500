Packet Generator

The WLAN signaling application includes a packet generator that allows you to send IP traffic towards the DUT. In the current release, the R&S CMW supports the generation of ICMP echo request ("Ping") packets and UDP packets.

The ICMP echo request packets are targeted at the DUT's IP stack. The DUT is expected to answer with a well-defined echo reply packet whose payload is identical to the payload of the corresponding request. "Pinging" triggers the DUT to transmit a burst of a certain length which is useful for combined signal path measurements.

UDP packets are used to put background traffic on the air interface, for example to prevent the DUT from entering the power save mode.
