CONFigure:WLAN:SIGN<i>:PER:DFRame:HEMU:USER<index>:ALLocation <CH20_Index>, <RU_Index>

Configures allocations for the user in HE MU PPDU. Maps the user to a resource unit (RU).

Suffix: 
<index>
1
Parameters:
<CH20_Index>
CHA1 | CHA2 | CHA3 | CHA4
*RST:CHA1
<RU_Index>
RU1 | RU2 | RU3 | RU4 | RU5 | RU6 | RU7 | RU8 | RU9
*RST:RU1
