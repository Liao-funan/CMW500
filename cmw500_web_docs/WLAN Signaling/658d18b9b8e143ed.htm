CONFigure:WLAN:SIGN<i>:CONNection:WDIRect:ATYPe <Method>, <Mode>, <Pin>

Configures the WPS method to be used for authentication in mode Wi-Fi Direct.

Parameters:
<Method>
PBUTton | DISPlay | KEYPad

Push button, display or keypad

*RST:PBUT
<Mode>
AUTO | MANual

Authentication started automatically or initiated manually via CALL:​WLAN:​SIGN<i>:​ACTion:​WDIRect:​SCONnection

*RST:AUTO
<Pin>

PIN for the authentication methods DISPlay and KEYPad

*RST:1234
