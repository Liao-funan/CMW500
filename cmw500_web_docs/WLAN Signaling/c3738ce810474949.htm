Features-Specific Hardware Requirements

The functionality supported by the WLAN signaling software depends on the type of installed signaling unit and TX/RX modules.

The following term is used for groups of instrument models:
  • R&S CMW: Stands for the R&S CMW500, 270 and 290.
    The instrument provides RF ports and contains a computer where the test software is running. The instrument can be equipped with a signaling unit universal (SUU) or a signaling unit advanced (SUA).
  • R&S CMW with TRX160: R&S CMW500/270/290 equipped with SUA and 160 MHz TX/RX modules (R&S CMW-B570H). The instrument provides up to 160 MHz TX/RX bandwidth.
Signaling unit
An SUA is required for the following features:
  • Option R&S CMW-KS656, IEEE 802.11ac
  • Option R&S CMW-KS657, IEEE 802.11ax
  • 40 MHz bandwidth for IEEE 802.11n
  • Configuring the contents of log files
  • Display of data rate information in the "RX Statistics" area
The SUA does not (yet) support the following features:
  • Operation modes IBSS, Wi-Fi Direct
  • WLAN security with WPS
  • MIMO scenario
  • Standard "802.11n(GF)"
  • Advanced RF settings I/Q swap and RX set
  • RX filter for IEEE 802.11b (inter-symbol interference filter)
TX/RX module
An R&S CMW with TRX160 is required for the following features:
  • Option R&S CMW-KS657, IEEE 802.11ax
  • Channel bandwidth ≧ 80 MHz

If you use a 160 MHz TX/RX modules, you need the base software version 3.7.20 or higher.

A channel bandwidth of 160 MHz is supported as one segment only, 80+80 MHz is not supported.
