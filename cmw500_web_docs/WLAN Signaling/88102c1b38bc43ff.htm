CONFigure:WLAN:SIGN<i>:CONNection:BEACon <BeaconInterval>

Sets the interval between two beacon frame transmissions for a simulated infrastructure/ad-hoc network.

Parameters:
<BeaconInterval>

Interval in time units (1 TU = 1024 µs)

Range: 20  to  16000
*RST:100
Example: 

See "Configuring Connection Settings"

Firmware/Software: 

V2.1.40

V3.0.20: minimum increased to 20, maximum decreased to 1000

V3.2.11: maximum increased to 16000

Manual operation: See "Beacon Interval"
