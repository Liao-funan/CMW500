Wi-Fi Direct

Wi-Fi Direct (or Peer-to-Peer) is a specification from Wi-Fi Alliance. It allows Wi-Fi Direct devices to connect directly without the need for an access point. All Wi-Fi Direct connections are protected by WPA/WPA2 personal security (see "WLAN Security").

Wi-Fi Direct devices listen on the "social channels" 1, 6 and 11 in the 2.4 GHz band to begin device discovery. If another Wi-Fi device is found, the group ownership is negotiated. After negotiation, the group owner invites other Wi-Fi Direct devices to become members (clients) of its Wi-Fi Direct group.

More details can be found in the Wi-Fi peer-to-peer (P2P) technical specification.

  • Option R&S CMW-KS660 is required for this operation mode.
  • In the current release, the R&S CMW can only act as Wi-Fi Direct group owner (AP-like) and supports only a single client connection.
  • The current release supports single channel operation in the 2.4 GHz band.

Wi-Fi Direct uses WPS for authentication, see "Wi-Fi Protected Setup (WPS)".

For Wi-Fi Direct, enable WLAN security. If security is disabled, some Android devices restart automatically.
