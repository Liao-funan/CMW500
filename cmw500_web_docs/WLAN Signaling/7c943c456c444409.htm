CONFigure:WLAN:SIGN<i>:RFSettings:BOPower <BurstOutputPow>

Sets the burst power of the transmitted signal.

The allowed value range depends on the used connector and the external attenuation in the output path.

Minimum = levelconnector, min - ext. att.out

Maximum = levelconnector, max - ext. att.out

With levelconnector, min = -145.98 dBm (-137.98 dBm), levelconnector, max = -15.98 dBm (-2.98 dBm) for RF COM (RF OUT); please also notice the ranges quoted in the data sheet.

Parameters:
<BurstOutputPow>
Range: see above
*RST:-40 dBm
Default unit: dBm
