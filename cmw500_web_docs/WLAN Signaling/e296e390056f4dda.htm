V3.7.20 (Compared to V3.7.10)
New features and changes:
  • Support of 80 MHz channel bandwidth, see "Operating Channel Width"
  • Indication of UE "HE Capabilities"
  • Packet generator enhancement: "Interval" = 0 supported, see "Interval"
  • PER measurement enhancement: "Data Interval" = 0 supported, see "Data Interval"
  • Length range of MAC frame RX trigger extended, see "Min Length: Bytes or Symbols"
