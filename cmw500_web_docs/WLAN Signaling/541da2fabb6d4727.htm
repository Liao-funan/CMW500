CONFigure:WLAN:SIGN<i>:CONNection:HETF:MLTF <MU_MIMO_LTF>

Sets MU-MIMO long training fields (LTF).

Parameters:
<MU_MIMO_LTF>
SING | MASK

SING: single stream pilots

MASK: mask LTF sequence of each spatial stream by a distinct orthogonal code

*RST:SING
Example: 

See "IEEE 802.11ax connection settings"

V3.7.30

Options: R&S CMW-KS657
Manual operation: See "MU-MIMO LTF"
