SOURce:WLAN:SIGN<i>:STATe:ALL?

Returns detailed information about the WLAN signaling generator state.

Return values: 
<MainState>
OFF | ON
<SyncState>
PENDing | ADJusted

PENDing: The generator has been turned on (off) but the signal is not yet (still) available.

ADJusted: The physical output signal corresponds to the main generator state.

Example: 

See "Associating the DUT"

Usage: Query only

V2.1.30
