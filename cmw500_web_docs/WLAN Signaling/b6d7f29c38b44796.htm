CONFigure:WLAN:SIGN<i>:CONNection:STATion:SCONnection <mode>

Specifies to which access points the simulated station is allowed to connect (operation mode "Station").

Parameters:
<mode>
ANY | SSID

ANY: Any AP is allowed.

SSID: Only a specific AP is allowed, identified by the configured SSID, see CONFigure:​WLAN:​SIGN<i>:​CONNection:​SSID.

*RST:ANY
