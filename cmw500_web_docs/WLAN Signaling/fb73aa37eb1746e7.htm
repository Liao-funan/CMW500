V3.2.70 (Compared to V3.2.60)
New features:
  • WPS for WPA/WPA2 personal security in AP mode
  • Station mode now allows the configuration of supported rates
  • Additional Hotspot 2.0 parameters
  • Support for three-digit mobile network codes in Hotspot 2.0
  • Configurable minimum length for MAC frame RX trigger
  • New remote command to define whether an internal or external RADIUS server is used for WPA/WPA2 enterprise security (requires R&S CMW-KS660)
