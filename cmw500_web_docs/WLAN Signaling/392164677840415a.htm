CONFigure:WLAN:SIGN<i>:CONNection:DFRame:HEMU:ALSField <CH20_Index>, <Subfield>
CONFigure:WLAN:SIGN<i>:CONNection:DFRame:HEMU:ALSField? <CH20_Index>

Sets 8-bit indices for resource unit (RU) allocation for the selected channel. The <Subfield> parameter specifies the number of RUs, their position and size. Refer to IEEE 802.11ax, table 28-23, RU allocation signaling.

Parameters:
<Subfield>

*RST:A192
Parameters for setting and query:
