Getting Monitoring and Measurement Results
The WLAN signaling application provides the following types of results:
  • Information in the main view, especially connection status, event log and DUT capabilities, see "Signaling View"
  • Results of a packet error rate (PER) test, see "Packet Error Rate Tests".

To obtain these results, proceed as follows:

  1. Establish a connection as described in "Establishing a WLAN Association"

  2. Check the information in the main view.

  3. To access the PER measurement, press the "WLAN PER" softkey. Configure and start the measurement.
