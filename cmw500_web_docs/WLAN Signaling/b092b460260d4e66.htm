V3.5.20 (Compared to V3.5.10)
New features:
  • Events are displayed at the GUI, see "Event Log"
  • Analyzer frequency offset can be set, see "Frequency Offset"
  • Hotspot 2.0, see "Hotspot 2.0 Settings":
    –Up to five cellular networks, domain names and realms can be configured
    –The realms can now support multiple EAPs and EAP-TLS
    –The current state of the EAP connection is displayed, see "Connection Status"
  • Data end-to-end:
    –The IPv4 address that the DAU assigns to the DUT via DHCP can be configured, see "Data End-To-End Settings"
    –Support of DAU on a separate R&S CMW, see "Data End-to-End Tests"
  • Message analysis:
    –Beta support for message logging with R&S CMWmars, see "Message Logging"
