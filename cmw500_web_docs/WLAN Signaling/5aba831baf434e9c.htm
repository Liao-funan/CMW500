Wi-Fi Protected Setup (WPS)

Wi-Fi protected setup - formerly known as Wi-Fi simple configuration (WSC) - allows you to set up a wireless protected network easily. The signaling application supports WPS for WPA/WPA2 personal security in the operation modes AP and Wi-Fi Direct.

Three different authentication types are supported as shown in the following table.

WPS methods

Auth. type

Start of authentication

Description

Push button

AP mode: auto

Wi-Fi Direct: auto or manual

No PIN required. With switched-on cell signal, simply push a button on the DUT (either physical or software-based) to start the connection.

In Wi-Fi Direct manual mode, sending an invitation to the DUT is initiated via a hotkey.

Display

AP mode: auto

Wi-Fi Direct: auto or manual

The signaling application expects that the DUT sends a specific numerical PIN. Define the expected PIN in the signaling application settings.

In Wi-Fi Direct manual mode, sending an invitation to the DUT is initiated via a hotkey.

Keypad

Manual

The DUT expects that the signaling application sends a specific numerical PIN. Define the PIN to be sent to the DUT in the signaling application settings.

Sending the PIN is initiated via a hotkey.

The PIN length is four or eight digits. For a PIN length of eight, the last digit is a checksum that is automatically calculated and displayed.

The following procedures provide step-by-step instructions for connection setup with WPS. For the basic setup procedure, see "Establishing a WLAN Association".

Push-button method

  1. If the DUT has remembered a previous connection, delete the corresponding entry on the DUT.

  2. Turn on the signaling application.

  3. If you use the Wi-Fi Direct operation mode with manual start of authentication:

    Press the hotkey "WDirect / WPS Start Conn." to send an invitation to the DUT.

  4. At the DUT, press/tap the "WPS push button" (physical or software-based button).

    The association is typically established within less than two minutes.

Display method

This procedure uses the operation mode "Wi-Fi Direct". With the operation mode "AP", most DUTs do not support the "Display" method.

  1. Turn on the signaling application.

  2. At the DUT, enable Wi-Fi Direct.

  3. If you use manual start of authentication:

    Press the hotkey "WDirect / WPS Start Conn." to send an invitation to the DUT.

  4. At the DUT, enter the PIN configured in the signaling application.

    The association is typically established within two minutes.

Keypad method

  1. If the DUT has remembered a previous connection, delete the corresponding entry on the DUT.

  2. Turn on the signaling application.

  3. Find out which PIN the DUT expects. For example, display the PIN at the DUT via the button "WPS PIN entry".

  4. Enter the PIN in the signaling application settings.

  5. Press the hotkey "WDirect / WPS Start Conn." to send the PIN.

    The association is typically established within two minutes.
