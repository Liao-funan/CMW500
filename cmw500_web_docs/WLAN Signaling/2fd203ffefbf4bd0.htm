CONFigure:WLAN:SIGN<i>:RFSettings:NPINdex <Np20>

Selects the position of the primary 20-MHz channel, for a signal with more than 20 MHz channel bandwidth.

Parameters:
<Np20>

Index of the 20-MHz channel configured as primary channel

Range: 0  to  <no of channels> - 1
Increment: 1
*RST:0
Example: 

See "Configuring Channel Frequencies"

Firmware/Software: 

V3.5.120

Manual operation: See "Np20 Index"
