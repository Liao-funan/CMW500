CONFigure:WLAN:SIGN<i>:CONNection:WDIRect:WDConf <Manufacturer>, <ModelName>, <ModelNumber>, <SerialNumber>, <DeviceName>

Defines the Wi-Fi Direct device properties of the simulated entity.

Parameters:
<Manufacturer>

Manufacturer name as string

*RST:ROHDE & SCHWARZ GMBH & CO. KG
<ModelName>

Model name as string

*RST:CMW-WLAN
<ModelNumber>

Model number as string

*RST:123
<SerialNumber>

Serial number as string

*RST:12345
<DeviceName>

User-friendly name as string

*RST:R&S-CMW-WLAN

See "Configuring Connection Settings"
