Measurement Results

The results of the PER measurement are displayed directly in the "PER" view.

PER results

The results are described in the following.

└ PER
└ Packets
└ Packets Lost
└ RX Burst Power
└ Last Ack Rate
└ PER diagram
PER

Packet error rate calculated as ratio of unacknowledged packets to transmitted packets.

Packets

Progress indicator of the measurement, displaying the number of already transmitted packets and the configured total number of packets to be transmitted.

Packets Lost

Number of unacknowledged transmitted packets. Lost packets are not retransmitted.

RX Burst Power

The average burst power of the received ACK frames, measured over the preamble.

Last Ack Rate

The modulation and coding rate/scheme of the last received ACK frame.

PER diagram

The diagram in the lower part of the dialog shows the PER vs. time/transmitted packets.
