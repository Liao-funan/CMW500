Establishing a WLAN Association

An established WLAN association is a prerequisite for any WLAN tests.

Proceed as follows:

  1. Connect your DUT to the R&S CMW (see "Test Setups").

  2. Configure the signaling application compatible to your DUT and the test case. You can modify the most important settings directly in the main view. The "Config" hotkey provides access to the configuration dialog box.

    Typical settings:

    1. WLAN standard: IEEE 802.11a, g, n, ...

    2. Scenario selection: standard cell (SISO) or MIMO

    3. Operation mode selection: AP, station, Wi-Fi Direct, ...

    4. Used RF connectors

    5. RF frequency / channel

    6. Power of the transmitted signal ("RF TX Burst Power")

    7. Expected power of the DUT signal ("RF Exp. Peak Envelope Power")

    Note: For the operation mode "Station", see also "Special requirements in station mode".

  3. To turn on the signal generator:

    1. Press ON | OFF, or

    2. Right-click the softkey "WLAN Signaling" > "ON".

  4. Wait until the "WLAN Signaling" softkey indicates the "Run" state. The hour glass symbol must disappear.

  5. Switch on the DUT and wait for association establishment. Note the connection status displayed in the main view.

    Perform an additional action if:
    • You have configured the "Station" operation mode with "Manual" connection mode.
      In that case, press the "Connect" hotkey.
    • You have enabled WPS with manual initiation.
      For details, see "Wi-Fi Protected Setup (WPS)".

    Note: Depending on the DUT, it takes a few seconds until the association procedures have finished. With authentication, it takes up to two minutes.

Special requirements in station mode
  • The configured WLAN channel must be the same as the one selected by the tested AP. The R&S CMW does not scan the supported frequency range.
  • The configured standard must be compatible with the beacon format of the tested AP.
Checks if the association fails
  • The "RF TX Burst Power" must be sufficient so that the DUT can receive the transmitted signal.
  • The "RF Exp. Peak Envelope Power" must be in accordance with the received signal power.
  • The selected WLAN channel and WLAN standard must be supported by the DUT.
  • For IEEE 802.11b, try a different "RX Filter" setting.
