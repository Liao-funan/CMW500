V3.5.120 (Compared to V3.5.40)
New features:
  • Option R&S CMW-KS656, IEEE 802.11ac (SUA required)
  • 40 MHz bandwidth for IEEE 802.11n (SUA required)
  • Full support for R&S CMWmars. The WLAN message logger and the WLAN message analyzer are no longer supported.
  • Selection of the signaling unit, see "Base Band Unit"
  • Configurable deactivation of RX while sending, see "RX Set"
  • Configurable deactivation of amplifier while not sending, see "TX Set"
  • Commands for the advanced RF settings, see "Advanced RF Settings"
  • Improvement of frame rate configuration, see:
    –"Frame Format, Rate"
    –"Non-HT, HT, VHT, HE Frame"
    –"Traffic Burst area"
  • Additional commands:
    –SENSe:​WLAN:​SIGN<i>:​UESinfo:​RXBPower?
    –SENSe:​WLAN:​SIGN<i>:​UESinfo:​ARXBpower?
