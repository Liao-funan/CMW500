PER Measurement Configuration

A packet error ratio (PER) measurement is included in the WLAN signaling application. To access the measurement, press the softkey "WLAN PER" in the WLAN signaling main view. The "PER" view and the related configuration dialogs are described in this section.

For background information, see "Packet Error Rate Tests".
