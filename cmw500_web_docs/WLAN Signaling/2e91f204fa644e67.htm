Hotspot 2.0

Hotspot 2.0 is a specification from Wi-Fi Alliance. It was created to improve the end-user hotspot experience and to address the market/operator need for cellular offloading. The goal is to make the hotspot network access as easy as cellular network access.

In the corresponding operation mode, the R&S CMW simulates a Hotspot 2.0 access point to allow mobile devices to join a WiFi subscriber service automatically when entering a Hotspot 2.0 area.

To ensure that mobile devices always have seamless connection with WLAN and cellular network, the current release supports SIM/USIM authentication using EAP-SIM, EAP-AKA and EAP-AKA’ (see "WLAN Security").

Option R&S CMW-KS660 is required for this operation mode.
