CONFigure:WLAN:SIGN<i>:CONNection:STANdard <Typ>

Selects the IEEE 802.11 WLAN standard to be used.

Parameters:
<Typ>
ASTD | GOSTd | NGFStd | ANSTd | GONStd | BSTD | GSTD | GNSTd | ACSTd | AXSTd

BSTD: 802.11b

ASTD: 802.11a

GSTD: 802.11g

GOSTd: 802.11g (OFDM)

NGFStd: 802.11n (GF)

ANSTd: 802.11a/n

GNSTd: 802.11g/n

GONStd: 802.11g (OFDM)/n

ACSTd: 802.11ac

AXSTd: 802.11ax

*RST:ASTD
Example: 

See "Specifying General Settings"

Firmware/Software: 

V2.1.40, V3.0.20: BSTD, GSTD, GNSTd, V3.5.120: ACSTd, V3.7.30: AXSTd

Options: R&S CMW-KS651 for NGFStd, ANSTd, GNSTd, GONStd, ACSTd
R&S CMW-KS656 for ACSTd
R&S CMW-KS657 for AXSTd
Manual operation: See "Standard"
