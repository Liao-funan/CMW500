MIMO Scenario

Option R&S CMW-KS670 is required for MIMO tests. It extends option R&S CMW-KS651.

The R&S CMW simulates an access point supporting TX MIMO with two DL signals.

The following transmission modes are supported:
  • Spatial multiplexing
    Data streams are transmitted on multiple spatial channels, with multiple antennas at the transmitter and receiver.
  • TX diversity
    There are more TX antennas than RX antennas. The same data is transmitted redundantly over several antennas.
  • Space time block coding (STBC)
    The number of spatial streams is less than the number of space-time streams.
    NSS < NSTS

The two DL signals are routed to different RF output connectors.

The supported connection standards are "802.11a/n", "802.11g(OFDM)/n" and "802.11n(GF)".

MIMO tests are possible in the 5-GHz band. If your DUT is able to connect using 802.11g (OFDM), operation at 2.4 GHz is also possible.
