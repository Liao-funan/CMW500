V3.2.60 (Compared to V3.2.40)
New features:
  • New advanced signaling option R&S CMW-KS660
    –Wi-Fi Direct operation
    –Hotspot 2.0 operation
    –WPA/WPA2 enterprise security in AP and Hotspot 2.0 mode, internal or external RADIUS server
    –Internal RADIUS server supporting EAP-SIM, EAP-AKA and EAP-AKA'
  • Configurable DTIM period
  • WPA/WPA2 personal security in station mode
  • Improved DAU interworking
  • IPv6 support for instruments without DAU (experimental)
  • New command to query the SSID of the attached AP in station mode
