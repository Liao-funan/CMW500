Analyzing the UL Signal from the DUT

While the DUT is associated and data traffic is sent on the UL, the signals from the DUT can be monitored using the WLAN measurements application (option R&S CMW-KM650/KM651). To ensure compatible measurement settings, the measurement must be coupled to the WLAN signaling application.

As a result, the measurement application uses the RF settings of the signaling application. The "FrameTrigger" from the signaling application is used as a trigger source.

  1. Press the softkey "WLAN Multi Evaluat".

    The measurement is coupled to the signaling application and the measurement view is opened.

  2. To start the measurement, right-click the softkey "Multi Evaluation". Select ON.

    The main view provides an overview of the measurement results.

  3. To enlarge a part of the overview, perform one of the following actions:
    • Double-click it using a connected mouse.
    • Select it by turning the rotary knob. Open it by pressing the rotary knob.
