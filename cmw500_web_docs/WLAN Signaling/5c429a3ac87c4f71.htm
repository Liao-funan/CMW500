General Configuration
The WLAN signaling application is programmed as follows:
  • The application is controlled by SCPI commands with the following syntax: ...:WLAN:SIGN:....
  • After a *RST, the application is switched off.
    To activate the signal transmission, use SOURce:WLAN:SIGN:STATe ON. *OPC? ensures that the signal is available at the selected RF output before the next command line is executed.
