CONFigure:WLAN:SIGN<i>:CONNection:STATion:CMODe <mode>

Selects the connection behavior of the simulated station (operation mode "Station").

Parameters:
<mode>
ACONnect | MANual

ACONnect: automatic connection

MANual: manual connection via CALL:​WLAN:​SIGN<i>:​ACTion:​STATion:​CONNect or CALL:​WLAN:​SIGN<i>:​ACTion:​STATion:​REConnect

*RST:ACON

See "Configuring Connection Settings"
