SENSe:WLAN:SIGN<i>:SINFo:EAPStat?

Queries the current state of the EAP connection for the security mode "WPA / WPA2 Enterprise".

Return values: 
<State>
IDLE | SUCCess | FAILure

EAP connection state

<Type>
IDENtity | NOTification | NAK | MD5 | OTP | GTC | TLS | CLEap | SIM | TTLS | AKA | AKAPrime

Authentication stage

Usage: Query only
Firmware/Software: 

V3.5.20

Options: R&S CMW-KS660
Manual operation: See "EAP Connection"
