V2.1.40 (Compared to Initial Release V2.1.30)
New features:
  • New standards IEEE 802.11g (OFDM), IEEE 802.11g (OFDM)/n
  • Maximum external attenuation at RF input decreased to 55 dB
  • Maximum TX burst power increased to -16 dBm
  • Minimum expected peak envelope power increased to -20 dBm
  • Maximum beacon interval decreased to 65535 time units
  • Message logger and message analyzer (R&S CMW-KT650) display received burst power, received frequency offset and CINR
