CONFigure:WLAN:SIGN<i>:CONNection:SRATes:VHTConf <VHT_rates>

Definition of supported OFDM VHT modulation and coding schemes (MCS).

These settings apply only if user-defined supported rates are enabled, see CONFigure:​WLAN:​SIGN<i>:​CONNection:​SRATes.

Parameters:
<VHT_rates>
MC07 | MC08 | MC09

MC07: MCS 0 to MCS 7

MC08: MCS 0 to MCS 8

MC09: MCS 0 to MCS 9

*RST:MC07
