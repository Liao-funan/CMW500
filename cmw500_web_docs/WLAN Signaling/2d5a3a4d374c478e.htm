What's New in This Version

This documentation describes version 3.7.30 and later of the WLAN signaling application. Compared to version 3.7.20, it provides the following new features:

  • Option R&S CMW-KS657 for standard IEEE 802.11ax. The standard is only supported by an R&S CMW with TRX160, see:
    –"Standard"
    –"Signal Properties"
    –"Data Frame Control Settings"
    –"Trigger Frame Settings"
    –"BSS Color"
    –"Buffered Data"
    –Additional trigger signal, see "HE_TB trigger"
    –Trigger extensions, see "MAC Frame RX Trigger"
  • Operating bandwidth 160 MHz (contiguous) supported with an R&S CMW with TRX160, see "Operating Channel Width"
  • Support of TIDs, see "QoS Data TID Settings"
  • Support of A-MPDU and multiple-TIDs, see "A-MPDU Settings"
  • Support of multiple packet generators, see "Packet Generator Settings"
  • Remote command for RX power quality, see "RX Power Indicator"
  • Additional debug settings, see "Debug Configuration"
  • Support of two instances of WLAN signaling per SUA, see "Values for Signal Path Selection"
