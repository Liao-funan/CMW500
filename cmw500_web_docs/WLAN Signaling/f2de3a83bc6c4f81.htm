WLAN Signaling > Command Reference > Connection Settings > Trigger Frame Control Settings > CONFigure:WLAN:SIGN<i>:CONNection:HETF:TTYP
CONFigure:WLAN:SIGN<i>:CONNection:HETF:TTYP <Type>

Specifies the trigger type as specified in the Common Info field.

Parameters:
<Type>
BTR | BRP | MRTS | BSRP | BQRP

BTR: Basic Trigger

BRP: Beamforming Report Poll

MRTS: MU-RTS

BSRP: Buffer Status Report Poll

BQRP: Bandwidth Query Report Poll

*RST:BTR
Example: 

See "IEEE 802.11ax connection settings"

Firmware/Software: 

V3.7.30

Options: R&S CMW-KS657
Manual operation: See "Trigger Type"
