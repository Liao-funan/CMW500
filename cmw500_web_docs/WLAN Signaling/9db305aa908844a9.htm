V3.0.20 (Compared to V3.0.10)
New features:
  • Support for DSSS/CKK modulation
    –Additional standards IEEE 802.11b, 802.11g and 802.11g/n
    –Selectable RX filters for CCK signals
  • Support for end-to-end data applications
  • Configurable supported rates
  • Frame rate control for management and data frames
  • UDP packet generator
  • Support for WPA personal
  • MAC frame TX trigger: Pulse length can be set to burst length
  • RX burst power display in connected state
  • Channel selection by channel number
  • Restricted value range for beacon interval to {20, 21, ...., 1000} TUs
  • Modified state enum in command CONFigure:​WLAN:​SIGN<i>:​CONNection:​CCODe:​CCSTate
