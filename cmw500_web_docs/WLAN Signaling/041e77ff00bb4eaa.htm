SENSe:WLAN:SIGN<i>:UESinfo:UEADdress:IPV<n>?

Queries the IPv4 address or the first IPv6 address prefix of the connected DUT.

This information is only available for data end-to-end tests with the DAU.

Suffix: 
<n>
4, 6

Selects the IP version

Return values: 
<IPAddress>

Assigned IPv4 address or first IPv6 address prefix as string

Example: 

See "Querying UE Information"

Usage: Query only
Firmware/Software: 

V3.0.20

Manual operation: See "IPv4 address / IPv6 Prefix[0]"
