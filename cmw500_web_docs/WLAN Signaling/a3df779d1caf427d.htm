V3.2.10 (Compared to V3.0.20)
New features:
  • Preliminary support for station mode with limited feature set:
    –Operate as WLAN station (on a single, configurable channel)
    –Connect to any available WLAN or to a configurable SSID only
    –Connect automatically or manually
  • WLAN security (AP mode only):
    –Support for WPA personal and WPA enterprise
    –WPA with optional TKIP encryption
    –WPA2 with optional AES encryption
    –EAP-SIM authentication for WPA enterprise
    –Configurable (external) RADIUS server for enterprise mode
