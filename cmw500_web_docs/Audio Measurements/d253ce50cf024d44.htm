Test Setups for the Scenario eCall / ERA-GLONASS

The scenario "eCall / ERA-GLONASS" must be used together with the test software R&S CMW-KA09x. The test software activates the scenario, configures all settings and controls the measurements. For test setups, refer to the documentation of the R&S CMW-KA09x test software.
