CONFigure:AUDio:MEAS<i>:ANALog:SINGletone:FILTer:BANDpass <CenterFreq>, <Bandwidth>
CONFigure:AUDio:MEAS<i>:DIGital:SINGletone:FILTer:BANDpass <CenterFreq>, <Bandwidth>

Configures the center frequency and bandwidth of the bandpass filter for single tone measurements.

Parameters:
<CenterFreq>
Range: 0 Hz  to  24E+3 Hz
*RST:1000 Hz
Default unit: Hz
<Bandwidth>
Range: 0 Hz  to  24E+3 Hz
*RST:200 Hz
Default unit: Hz
Example: 

See "Single Tone Measurement"

Firmware/Software: 

V3.2.10

Manual operation: See "Filter > Low Pass, High Pass, Weighting, Variable Bandpass"
