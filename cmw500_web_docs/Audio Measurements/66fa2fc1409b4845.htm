V3.7.10 (Compared to V3.5.35)
New features:
  • Peak level result for analog single tone measurements, see "Single Tone Results"
  • Limits for peak level results, see "Limits (Analog Measurement)"

  • Support of the software options R&S CMW-KA09x, so that no external modem is required.
  • CALCulate commands for query of limit check results, see "Single Tone Measurement Results"
