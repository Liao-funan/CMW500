Performing Audio Measurements

The required settings vary depending on the used scenario, the used type of audio test signal and the test setup components.

However, the general procedure outlined below is applicable to all audio measurements.

  1. Connect the components of your test setup (see "Test Setups").

  2. In the audio application main view, at the top, select a scenario matching your test setup.

  3. If your test setup involves an RF speech connection / a speech codec:

    1. On the "Speech Analysis" tab, select the application that sets up the speech call ("Controlled by" setting).

      The softkey bar includes now softkeys related to the controlling application.

    2. Establish a speech connection via the controlling application. You can use the softkeys to access settings of the controlling application and to control the call setup, see "Additional Softkeys and Hotkeys".

      In most signaling applications, you must select "Speech" as data source.

      For LTE speech calls, you must configure the IMS server of the DAU for audio tests.

      For details, refer to the documentation of the controlling application.

  4. If your test setup involves external equipment, configure it (for example an R&S UPV).

  5. If your test setup involves internal audio generators and measurements, configure them:

    1. Select the "Analog Meas" tab or the "Digital Meas" tab.

    2. Press the "Config" hotkey.

      A configuration dialog box opens. It contains all generator and measurement settings.

    3. Configure first the used generators. Especially select a signal type. And configure the measurement coupling.

    4. Configure the measurements.

  6. Turn on the used internal/external generators.

    To turn on an internal generator, proceed as follows:

    1. Select the "Analog Meas" tab or "Digital Meas" tab.

    2. Select the relevant generator softkey ("Analog Generator" or "Digital Generator"). Press [ON | OFF].

      Alternatively, right-click the softkey. Then click ON.

    3. Wait until the generator softkey indicates the "ON" state and the hour glass symbol disappears.

  7. Start the internal/external audio measurements.

    To start an internal measurement, proceed as follows:

    1. Select the tab of the measurement that you want to start ("Analog Meas" or "Digital Meas").

    2. Select the measurement softkey ("Analog Meas" or "Digital Meas"). Press [ON | OFF].

      Alternatively, right-click the softkey. Then click ON.

    The measurement results are displayed in the measurement tab.

Parallel measurements

One audio board supports two audio application instances. And each instance provides an analog generator, a digital generator, an analog measurement and a digital measurement. So in total there are four audio generators and four audio measurements. You can use all these resources in parallel, for example to test several DUTs in parallel or to perform stereo tests.

If your test setup contains more than one acoustic coupling, it is recommended to use only one coupling at a time, so that they do not interfere. That means, transmit an audio signal only via one coupling at a time.

Example: If both the microphone and the speaker of a DUT are coupled acoustically, test the speaker path and the microphone path one after the other. Activate the audio generator of only one path at a time.

If the audio board is equipped with a single speech codec, this codec can be used by the first instance of the audio application. Each codec can be coupled to only one signaling application at a time.
