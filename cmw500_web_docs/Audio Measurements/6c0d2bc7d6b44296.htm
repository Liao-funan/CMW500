Modifying Diagrams

To change the appearance and contents of a diagram, press the "Diagram" softkey. Then use the following hotkeys at the bottom of the GUI. Depending on the diagram, not all hotkeys are available.

Hotkey

Description

"Trace ..."

Select the trace types to be displayed in the view.

"X Scale... / Y Scale..."

Modify the ranges of the X-axis and the Y-axis.

"View Diagr. / Table"

Switch between diagram and table presentation.

To enlarge/reduce a diagram, double-click it or select the diagram and press ENTER or the rotary knob.
