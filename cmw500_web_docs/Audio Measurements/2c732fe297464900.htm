CONFigure:AUDio:MEAS<i>:ANALog:FFTNoise:FILTer:WEIGhting <Weighting>
CONFigure:AUDio:MEAS<i>:DIGital:FFTNoise:FILTer:WEIGhting <Weighting>

Configures the weighting filter for FFT noise measurements.

Parameters:
<Weighting>
OFF | AWEight | CCITt | CMSG

OFF: weighting filter disabled

AWEight: A-weighting filter

CCITt: CCITT weighting filter

CMSG: C-message weighting filter

*RST:OFF
