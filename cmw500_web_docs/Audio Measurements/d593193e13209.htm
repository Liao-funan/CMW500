SOURce:AUDio:GEN<i>:DIGital:MULTitone:TLEVel <TotalLevel>

Configures or queries the total level of a digital multitone signal.

For method TLEV, a setting command is executed and a query returns the configured level.

For method SEP, a setting command is ignored and a query returns the total level resulting from the levels of the individual tones.

For method configuration, see SOURce:​AUDio:​GEN<i>:​DIGital:​MULTitone:​LSELection.

Parameters:
<TotalLevel>
Range: 0 FS  to  1 FS
*RST:1 FS
Default unit: FS
