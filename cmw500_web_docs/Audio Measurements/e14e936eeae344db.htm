CONFigure:AUDio:MEAS<i>:ANALog:MULTitone:SCOunt <StatisticCount>
CONFigure:AUDio:MEAS<i>:DIGital:MULTitone:SCOunt <StatisticCount>

Specifies the statistic count for multitone measurements. The statistic count is equal to the number of measurement intervals per single shot.

Parameters:
<StatisticCount>
Range: 1  to  1000
*RST:20

See "Multitone Measurement"
