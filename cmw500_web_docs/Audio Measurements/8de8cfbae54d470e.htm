Using Markers

To access the markers of a diagram, press the "Diagram" softkey. Then use the following hotkeys at the bottom of the GUI to activate markers and to modify their position. Depending on the diagram, not all hotkeys are available.

Hotkey

Description

"Ref. Marker"

Enable or disable the reference marker and select the marker position. If several traces can be displayed, a trace can also be selected.

"Marker 1 /2"

Enable or disable marker 1 or marker 2 and define the marker position (absolute or relative to the reference marker).

Depending on the trace mode, a trace can also be selected.

"Select Trace Mode"

Define whether marker 1 and marker 2 are set to the same trace as the reference marker (collective) or to selectable individual traces.

"Marker for Result"

Enable a marker and define the marker position.

See also: "Markers"
