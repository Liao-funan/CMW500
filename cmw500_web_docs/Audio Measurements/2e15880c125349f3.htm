CONFigure:AUDio:SPEech<i>:ANALog:ILEVel <InputLevel>

Configures the A/D conversion for analog speech scenarios with an input signal at the AF connector.

Parameters:
<InputLevel>

Analog input signal peak voltage corresponding to digital signal full-scale value

Range: 0 V  to  42 V
*RST:0.1 V
Default unit: V
Firmware/Software: 

V3.2.10

Manual operation: See "Input Level Full-Scale (Peak)"
