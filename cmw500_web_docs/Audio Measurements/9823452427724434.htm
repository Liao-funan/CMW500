SOURce:AUDio:WAV<i>:PLAYback:STATe <Control>

Starts or stops the audio file playback.

See also: "Generator Control"

Setting parameters: 
<Control>
ON | OFF

Switch playback ON or OFF

Return values: 
<GenState>
OFF | PENDing | ON

OFF: playback switched off

PEND: playback switched on but no signal available yet

ON: playback switched on and signal available

*RST:OFF
