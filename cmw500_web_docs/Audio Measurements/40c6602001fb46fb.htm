Playing and Recording Waveform Files

The "Waveform" scenario allows you to play or record an audio file. You can use both features in parallel.

The following step-by-step instructions guide you through playing and recording a waveform file.

Playing a waveform file
An audio file to be played must have the following characteristics:
  • WAV file format
  • Sample rate 8 kHz or 48 kHz
  • 16-bit pulse-code modulation (PCM)
  • Mono or stereo

Proceed as follows:

  1. Prepare the cabling (see "Test Setups for the Scenario Waveform").

  2. Store the waveform file in the folder waveform in the CMW user data directory (for example D:\Rohde-Schwarz\CMW\Data\waveform).

  3. In the audio application main view, at the top, select the scenario "Waveform".

  4. On the right, press the softkey "Play".

  5. At the bottom, press the hotkey "Open File". Select your waveform file.

  6. In the middle, select the "Destination" of the generated audio signal: "Analog" audio connectors, "Digital" audio connector or "Speech" encoder.

    1. For "Analog", set the maximum "Output Level" via the hotkey at the bottom.

    2. For "Speech", select the controlling master application via "Controlled by" at the top.

  7. Start the playback:

    Press [ON | OFF].

    Alternatively, right-click the "Play" softkey. Then click ON.

    The waveform file is played once. Then the playback stops and the state changes from ON to OFF.

Recording a waveform file

Proceed as follows:

  1. Prepare the cabling (see "Test Setups for the Scenario Waveform").

  2. In the audio application main view, at the top, select the scenario "Waveform".

  3. On the right, press the softkey "Record".

  4. At the bottom, press the hotkey "Save File". Select the location and name of the target waveform file.

  5. In the middle, select the "Source" of the recorded audio signal: "Analog" audio connectors, "Digital" audio connector or "Speech" decoder.

    1. For "Analog", set the maximum "Input Level" via the hotkey at the bottom. Configure also the filter setting.

    2. For "Speech", select the controlling master application via "Controlled by" at the top.

  6. Start the recording:

    Press [ON | OFF].

    Alternatively, right-click the "Record" softkey. Then click ON.

  7. To stop the recording:

    Press [ON | OFF].

    Alternatively, right-click the "Record" softkey. Then click OFF.
