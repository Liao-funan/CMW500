CONFigure:AUDio:WAV<i>:RECord:ILEVel <InputLevel>

Configures the A/D conversion for the analog source of waveform recording.

Parameters:
<InputLevel>

Analog input signal peak voltage corresponding to digital signal full-scale value

Range: 0 V  to  42 V
*RST:0.1 V
Default unit: V

See "Recording a Waveform File"

V3.7.20
