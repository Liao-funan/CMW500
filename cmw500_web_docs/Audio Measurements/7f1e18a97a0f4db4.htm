CONFigure:AUDio:WAV<i>:PLAYback:FPAThname <FilePathName>

Selects the waveform file to be loaded.

Parameters:
<FilePathName>

String including path and file name.

For convenience, use the alias @WAVEFORM for the path.

Example: "@WAVEFORM\myWAVfile.wav".
