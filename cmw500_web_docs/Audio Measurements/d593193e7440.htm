CONFigure:AUDio:MEAS<i>:ANALog:ARANging <AutoRanging>

Enables or disables auto ranging for the input level at the AF connector.

With enabled auto ranging, the maximum expected AF input level is set automatically according to the average level of the measured AF signal plus an appropriate overload margin.

With disabled auto ranging, you must configure the maximum expected AF input level, see CONFigure:​AUDio:​MEAS<i>:​ANALog:​MLEVel.

Parameters:
<AutoRanging>
OFF | ON
*RST:ON
