CONFigure:AUDio:MEAS<i>:ANALog:MLEVel <MaxLevel>

Configures the maximum expected AF input level.

This setting is only relevant if auto ranging is disabled, see CONFigure:​AUDio:​MEAS<i>:​ANALog:​ARANging.

Parameters:
<MaxLevel>
Range: 0 V  to  42 V
*RST:2 V
Default unit: V
Example: 

See "General Measurement Settings"

Firmware/Software: 

V3.2.10

Manual operation: See "Auto Ranging, Maximum Level"
