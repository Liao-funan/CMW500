CONFigure:AUDio:MEAS<i>:ANALog:PCOupling <PathCoupling>

Configures the DC component handling for the analog input path.

Parameters:
<PathCoupling>
AC | DC
AC

The DC component of the measured AF signal is blocked. Only the AC component is measured.

DC

Both the DC component and the AC component of the AF input signal are measured.

*RST:AC
