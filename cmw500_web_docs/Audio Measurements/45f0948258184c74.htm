Returns the current, average, extreme and standard deviation results of a digital single tone measurement.

The values described below are returned by FETCh and READ commands. CALCulate commands return limit check results instead, one value for each result listed below.

The ranges indicated below apply to all results except standard deviation results. The minimum for standard deviation results equals 0. The maximum equals the width of the indicated range divided by two. Exceptions are explicitly stated.

Return values: 
<1_Reliability>

"Reliability Indicator"

<2_THDPercent>

THD result as percentage

Range: 0 %  to  100 %
Default unit: %
<3_THDdB>

THD result as dB value

Range: -150 dB  to  0 dB
Default unit: dB
<4_THDPlusN>

THD + N result

Range: 0 %  to  100 %
Default unit: %
<5_SINAD>
Range: 0 dB  to  150 dB
Default unit: dB
<6_SNR>
Range: 0 dB  to  150 dB
Default unit: dB
<7_WeightLevRMS>

Weighted level RMS result

Range: 0 FS  to  1 FS
Default unit: FS
<8_BandLevRMS>

Bandpass level RMS result

Range: 0 FS  to  1 FS
Default unit: FS
