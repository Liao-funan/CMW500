SOURce:AUDio:GEN<i>:ANALog:MULTitone:STOP <StopIndex>
SOURce:AUDio:GEN<i>:DIGital:MULTitone:STOP <StopIndex>

Specifies the last tone to be used. The value must be equal or greater than the configured start index.

Parameters:
<StopIndex>

Tone number in the multitone list

Range: 1  to  20
