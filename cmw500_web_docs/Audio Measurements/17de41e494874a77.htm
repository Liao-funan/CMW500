Common View Elements

This section describes elements that are displayed for all signal types.

Statistical results
Result tables provide columns with a statistical evaluation of the results. Some result diagrams provide a statistical evaluation via individual traces. The statistical values are calculated as follows:
  • "Current (Cur)": Value of the result obtained in the last measurement interval.
  • "Average (Avg)": Average of all "Current" values referenced to the last statistics cycle.
  • "Extreme (Ext)", "Minimum (Min)", "Maximum (Max)": Largest or smallest "Current" value that the R&S CMW obtained since the start of the measurement.
  • "Standard (Std)": Standard deviation of all "Current" values since the start of the measurement.
Statistic count

Progress bar for the measurement. During the first single shot after the start of the measurement, the bar shows the number of elapsed measurement intervals relative to the "Statistic Count". A filled progress bar indicates that the first shot is complete and the statistical depth has been reached.
