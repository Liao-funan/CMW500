SENSe:AUDio:WAV<i>:RECord:PATHname?

Queries the path and name of the waveform file to be written.

Return values: 
<Pathname>

String including path and file name.

Usage: Query only
Firmware/Software: 

V3.7.20

Manual operation: See "Save File hotkey"
