Audio Measurements > Command Reference > Audio Generators > Multitone Generator Settings > SOURce:AUDio:GEN<i>:ANALog:MULTitone:LSELection
SOURce:AUDio:GEN<i>:ANALog:MULTitone:LSELection <LevelSelection>
SOURce:AUDio:GEN<i>:DIGital:MULTitone:LSELection <LevelSelection>

Selects a method for multitone level configuration.

Parameters:
<LevelSelection>
TLEV | SEP
TLEV

All tones have the same level. To configure the total level, see:

SOURce:​AUDio:​GEN<i>:​ANALog:​MULTitone:​TLEVel

SOURce:​AUDio:​GEN<i>:​DIGital:​MULTitone:​TLEVel

SEP

The level of each tone is configured separately, see:

SOURce:​AUDio:​GEN<i>:​ANALog:​MULTitone:​TONE<no>:​TDEFinition

SOURce:​AUDio:​GEN<i>:​DIGital:​MULTitone:​TONE<no>:​TDEFinition

*RST:TLEV

See "Multitone Measurement"
