Additional Softkeys and Hotkeys

For scenarios with a controlling master application, there are additional softkeys related to that master application.

While one of these softkeys is selected, the "Config" hotkey opens the configuration dialog of the controlling application, not the configuration dialog of the audio measurement.

The softkeys are described in the following.

Signaling Parameter > ...

Provides hotkeys for access to the most essential settings of the controlling application.

Remote command: 

Use the commands of the controlling application.

 
... Signaling

Select this softkey and press [ON | OFF] to turn the downlink signal transmission on or off. Alternatively, right-click the softkey.

Press the softkey two times (select it and press it again) to switch to the controlling application.

Remote command: 

Use the commands of the controlling application.
