ROUTe:AUDio<i>:SCENario:CATalog:MASTer?

Returns a list of all possible master strings. The used master application is selected via the parameter <Master> in the scenario activation commands.

Return values: 
<SourceList>

Comma-separated list of all supported values. Each value is represented as a string.

Usage: Query only
Firmware/Software: 

V3.5.10

Manual operation: See "Global scenario commands"
