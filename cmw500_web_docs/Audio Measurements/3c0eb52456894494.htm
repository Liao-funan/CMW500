READ:AUDio:MEAS<i>:ANALog:FFTNoise:MAXimum?

Returns the current, average and maximum traces of an analog FFT noise measurement.

The Y-values of the traces are returned. To query the X-values of the traces, see READ:​AUDio:​MEAS<i>:​ANALog:​FFTNoise:​FREQuency?.

Return values: 
<Reliability>

"Reliability Indicator"

<Level>

Comma-separated list of values, one level value (Y-value) for each trace point

Range: -150 dBV to 36 dBV
Default unit: dBV

See "FFT Noise Measurement"

Usage: Query only
