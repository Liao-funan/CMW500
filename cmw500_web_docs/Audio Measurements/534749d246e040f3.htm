Multi-CMW Setups

To use an audio board in a multi-CMW setup, you need at least the base software version 3.5.131.

If the setup contains several instruments with an audio board, only one audio board is automatically selected and used. The information which audio board is used, is displayed in the event log on the "Speech Analysis" tab. You can also check the displayed connector names. They include the CMW number as a prefix (for example "2.AF 1 IN" for CMW 2, AF 1 IN).

The audio board serves the entire multi-CMW setup. You can connect the speech codec to any DAU or signaling application of the setup. It does not matter in which instrument the DAU is installed or which instrument is used by the signaling application (signaling unit, RF connectors, and so on).
