CONFigure:AUDio:MEAS<i>:ANALog:SINGletone:SCOunt <StatisticCount>
CONFigure:AUDio:MEAS<i>:DIGital:SINGletone:SCOunt <StatisticCount>

Specifies the statistic count for single tone measurements. The statistic count is equal to the number of measurement intervals per single shot.

Parameters:
<StatisticCount>
Range: 1  to  1000
*RST:20
