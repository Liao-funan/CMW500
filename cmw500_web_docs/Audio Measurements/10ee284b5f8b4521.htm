FETCh:AUDio:WAV<i>:RECord:STATe?

Queries the main recording state. Use FETCh:...:STATe:ALL? to query the main state plus substates. Use INITiate..., STOP..., ABORt... to change the state.

Return values: 
<MeasState>
OFF | RUN | RDY

OFF: recording off

RUN: recording running

RDY: recording paused

*RST:OFF
Example: 

See "Recording a Waveform File"

Usage: Query only
