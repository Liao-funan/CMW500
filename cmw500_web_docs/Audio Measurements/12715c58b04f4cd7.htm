CONFigure:AUDio:MEAS<i>:ANALog:SINGletone:FILTer:WFUNction <WindowFunct>
CONFigure:AUDio:MEAS<i>:DIGital:SINGletone:FILTer:WFUNction <WindowFunct>

Selects a window function for the single tone spectrum measurement.

Parameters:
<WindowFunct>
RECT | HAMM | HANN | BHAR | FTOP

RECT: Rectangular window

HAMM: Hamming window

HANN: Hann window

BHAR: Blackman-Harris window

FTOP: Flat-Top window

*RST:RECT
