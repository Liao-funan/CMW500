GSM Measurements > Command Reference > Multi-Evaluation Measurement Commands > Enabling Results and Views > CONFigure:GSM:MEAS<i>:MEValuation:RESult:AMPM
CONFigure:GSM:MEAS<i>:MEValuation:RESult:AMPM <Enable>
CONFigure:GSM:MEAS<i>:MEValuation:RESult:MSCalar <Enable>
CONFigure:GSM:MEAS<i>:MEValuation:RESult:BER <Enable>

Enables or disables the evaluation of the AM-PM results, the scalar modulation results, and the bit error rate (BER).

Parameters:
<Enable>
ON | OFF

ON: Evaluate results

OFF: Do not evaluate results

*RST:OFF (all except MSCalar)
Example: 

See "BER Measurement"

Firmware/Software: 

V1.0.0.4 (V1.0.5.3 for BER)

Manual operation: See "Assign Views"
