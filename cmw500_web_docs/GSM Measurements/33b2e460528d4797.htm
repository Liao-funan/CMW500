V1.0.15.0 (Compared to V1.0.10.1)
New features:
  • Support for 16-QAM-modulated bursts (option R&S CMW-KM201, GPRS EDGE evolution (EGPRS 2A, uplink)).
  • Combined signal path scenario: GSM measurements can be coupled to a GSM signaling or protocol test application.
  • In list mode, a trigger event can initiate a measurement of a single segment or an entire sequence of segments (TRIGger:​GSM:​MEAS<i>:​MEValuation:​LIST:​MODE).
