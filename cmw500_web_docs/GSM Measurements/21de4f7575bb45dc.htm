CONFigure:GSM:MEAS<i>:MEValuation:NBQSearch <Enable>

Enables or disables the search for 16-QAM-modulated normal bursts.

Parameters:
<Enable>
OFF | ON

ON: Enable 16-QAM NB search

OFF: Disable 16-QAM NB search

*RST:OFF
