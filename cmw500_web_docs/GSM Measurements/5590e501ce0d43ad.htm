CONFigure:GSM:MEAS<i>:MEValuation:PCL <Slot0>, <Slot1>, <Slot2>, <Slot3>, <Slot4>, <Slot5>, <Slot6>, <Slot7>

Sets the expected PCL values in all timeslots, to be used in CONFigure:​GSM:​MEAS<i>:​MEValuation:​PCLMode PCL. The PCL values are interpreted according to the current GSM band setting (CONFigure:​GSM:​MEAS<i>:​BAND).

For the combined signal path scenario, use:
  • CONFigure:​GSM:​SIGN<i>:​RFSettings:​PCL:​TCH:​CSWitched
  • CONFigure:​GSM:​SIGN<i>:​RFSettings:​CHCCombined:​TCH:​CSWitched
