Parallel Signaling and Measurement

The TX multi-evaluation measurement can be used in parallel to the GSM signaling application (options R&S CMW-KS200). A connection to the DUT can be set up by the signaling application and the resulting uplink signal can be measured using the multi-evaluation measurement.

To use both applications in parallel, the combined signal path scenario must be activated (see "Scenario"). Most signal routing and analyzer settings and some measurement control settings are then configured by the signaling application. The multi-evaluation measurement displays the corresponding signaling settings instead of its own settings. These signaling settings can be configured in both measurement and signaling application GUIs. Use signaling application commands to configure the settings via remote control. For a command mapping table, refer to "Combined Signal Path Commands".

In the measurement GUI the most important signaling parameters can be configured via additional hotkeys, see "Additional Softkeys and Hotkeys".

In the combined signal path scenario, the trigger signal from the signaling application is used as the measurement application trigger input. The selection of the trigger is done automatically, based on scenario.
