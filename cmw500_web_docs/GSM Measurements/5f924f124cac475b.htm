CONFigure:GSM:MEAS<i>:MEValuation:LIST:IIFRames <Ignore>

Selects whether idle frames are ignored or cause a "signal low" error. For details, see "Idle frame evaluation".

Parameters:
<Ignore>
OFF | ON
*RST:OFF
