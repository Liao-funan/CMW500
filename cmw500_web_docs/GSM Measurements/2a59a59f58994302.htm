List Mode Results (One Segment)

The following commands return the list mode results for a selected segment.

To configure the list mode, use the commands described in "List Mode Settings".

For a description of the list mode, see "List Mode".

The segment number <no> in the following commands refers to the range of measured segments (1..512), see CONFigure:​GSM:​MEAS<i>:​MEValuation:​LIST:​LRANge. It can differ from the absolute segment number used for segment configuration.
