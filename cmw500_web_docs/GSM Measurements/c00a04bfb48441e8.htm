Returns the values of the power vs. time traces. 16 results are available for each symbol period of the measured slots (CONFigure:​GSM:​MEAS<i>:​MEValuation:​MSLots). The trace covers 18.25 symbol periods before the beginning of the first slot in the measured slot range, 10 symbol periods after the end of the last measured slot.
