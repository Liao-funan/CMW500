CONFigure:GSM:SIGN<i>:RFSettings:HOPPing:ENABle:TCH[:CARRier<c>] <Enable>

Enable or disable frequency hopping in the downlink traffic channel.

Suffix: 
<c>
1..2

Selects the carrier to be configured - only relevant in dual carrier mode

Parameters:
<Enable>
OFF | ON
*RST:OFF
Firmware/Software: 

V2.0.10

Options: R&S CMW-KS210
R&S CMW-KS201 for carrier 2
Manual operation: See "Band, Channel / Frequency"
