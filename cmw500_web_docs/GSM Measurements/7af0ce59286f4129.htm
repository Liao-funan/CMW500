CONFigure:GSM:MEAS<i>:MEValuation:LIMit:GMSK:SMODulation:RPOWer <Minimum>, <Maximum>

Defines two reference power values for the modulation scheme GMSK. These values are relevant in the context of CONFigure:​GSM:​MEAS<i>:​MEValuation:​LIMit:​GMSK:​SMODulation:​MPOint<no>.

Parameters:
<Minimum>

Low reference power value

Range: 0 dBm  to  43 dBm
*RST:33 dBm
<Maximum>

High reference power value

Range: 0 dBm  to  43 dBm
*RST:39 dBm
Firmware/Software: 

V1.0.0.4

Manual operation: See "Spectrum Modulation and Spectrum Switching"
