CONFigure:GSM:MEAS<i>:MEValuation:BER:TSTart <ThresholdStart>

Selects the threshold start value for BER tests. This value is the maximum bit error rate in the first burst of the BER measurement.

Parameters:
<ThresholdStart>
Range: 0 %  to  100 %
*RST:10 %
Example: 

See "BER Measurement"

Firmware/Software: 

V1.0.10.1

Manual operation: See "Threshold Start"
