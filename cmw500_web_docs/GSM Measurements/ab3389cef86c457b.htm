GSM RX Tests

RX tests can be carried out in parallel to the "GSM TX Tests". The following sections describe how to perform GSM bit error rate (BER) tests in non-signaling mode, using the GSM multi-evaluation measurement. In signaling mode (combined signal path), use the RX measurements provided by the GSM signaling application.

For RX tests in non-signaling mode, you need the GPRF generator and a GSM waveform file. Option R&S CMW-KW200 is required to process GSM waveform files.

For a measurement example, refer to the application sheet "GSM BER Tests on ARB Signals".
