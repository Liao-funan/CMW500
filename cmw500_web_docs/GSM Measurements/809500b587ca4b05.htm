Possible Extensions
You can vary the list mode settings or use other settings to refine the evaluation:
  • Disable the calculation of some results if you need a subset only, and if you wish to gain speed.
  • Conversely, if you wish to analyze the results in all segments, enable the result calculation and step through the segments using the procedure in section "Using Offline Mode" repeatedly.
  • For maximum measurement speed, first configure all segments, then execute repeated measurements in different subranges.
  • Switch off the step length and use the <FramePattern> parameter if you wish to measure several (possibly non-equidistant) frame-periodic slots.
