Capturing GSM Burst Sequences

This application sheet describes the use of the R&S CMW "Modulation View" settings for capturing GSM frames filled with a particular burst sequence. The R&S CMW can detect and filter GMSK, 8PSK, 16-QAM, and access bursts.

Appropriate "Modulation View" settings are essential for measuring frames with burst sequences that the mobile transmits only occasionally, e.g:
  • SACCH frames and idle frames that the mobile transmits with a periodicity of 26 frames.
  • The periodic access bursts that the mobile can use during packet data connections to transmit its CTRK_ACK messages.

If no filter condition is specified ("Modulation View" = "Any"), the R&S CMW measures any burst sequence. Varying burst types during the measurement causes inconsistent statistical results.
