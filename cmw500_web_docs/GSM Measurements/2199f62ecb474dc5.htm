CONFigure:GSM:MEAS<i>:MEValuation:MODulation:DECode <Decode>

Defines whether the guard or tail bits are decoded.

Parameters:
<Decode>
STANdard | GTBits

STANdard: Guard and tail bits are assumed to be in line with GSM and therefore not decoded.

GTBits: Guard and tail bits are also decoded.

*RST:STAN
