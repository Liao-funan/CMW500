CONFigure:GSM:MEAS<i>:MEValuation:PCLMode <PCLmode>

Defines how the R&S CMW determines the PCL of the measured signal.

Parameters:
<PCLmode>
AUTO | PCL | SIGNaling

AUTO: Estimated PCL

PCL: PCL defined via CONFigure:​GSM:​MEAS<i>:​MEValuation:​PCL

SIGNaling: PCL determined by coupled signaling application (combined signal path only)

*RST:AUTO
