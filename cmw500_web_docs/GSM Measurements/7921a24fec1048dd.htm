V1.0.15.20 (Compared to V1.0.15.0)
New features:
  • Dynamic (PCL-dependent) limit lines for "Power vs. Time" measurement; see "Power Templates".
  • Mixer level offset, optimizes the measurement for low noise or low distortion (see "Mixer Level Offset").
  • "Measure @ Protocol Test" scenario, couples the RF parameters and analyzer settings of the GSM measurements to a protocol test application; see "Scenario".
  • Changed default value: limit check enabled for frequency error measurement.
