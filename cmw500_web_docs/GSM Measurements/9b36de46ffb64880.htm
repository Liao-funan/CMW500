CONFigure:GSM:MEAS<i>:MEValuation:ROTation:IQ <Rotation>

Specifies whether the rotation of the 8PSK and 16-QAM symbols is subtracted off before the symbols are displayed in the constellation diagram.

Parameters:
<Rotation>
P38 | P38R

P38: Rotation not removed, phase-rotated symbols displayed

P38R: Rotation removed

*RST:P38R
