GSM Measurements
The GSM multi-evaluation measurement (option R&S CMW-KM200) provides TX and RX tests on GSM uplink signals. The tests cover the following mobile transmitter properties:
  • Transmitter output power over a wide range of timeslots
  • Modulation accuracy
  • Spectrum due to switching and due to modulation
  • Off-carrier emissions vs. time
  • I/Q constellation diagram
  • Bit error rate (BER) test

Many of the tests and conformance requirements are specified in 3GPP TS 51.010-1, Digital Cellular Telecommunications System (Phase 2+); mobile station (MS) conformance specification.

With option R&S CMW-KM201, GPRS EDGE evolution (EGPRS2-A, uplink), the R&S CMW can also measure 16QAM-modulated bursts.

If you want to generate a GSM downlink signal in parallel to the measurement, you can use the GSM signaling (R&S CMW-KS200) or GPRF generator with a GSM waveform file. The following options enable processing of GSM waveform files:

  • R&S CMW-KW200, GSM EDGE R6, enable WinIQSIM2 waveforms for ARB
  • R&S CMW-KW201, GSM EDGEevo R7, enable WinIQSIM2 waveforms for ARB
