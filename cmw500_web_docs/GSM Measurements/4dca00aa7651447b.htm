Generator Shortcut

This feature enables you to start the GPRF generator and use GPRF-related hotkeys and softkeys within the measurement application. It improves the usability for non signaling tests where the DUT's reaction on varying generator signals is measured (see also "GSM RX Tests").

GPRF generator shortcut

When a connection to the GPRF generator instance is established, two additional softkeys with corresponding hotkey bars provide access to the generator configuration, see "Additional Softkeys and Hotkeys".

Use the appropriate softkey/hotkey combination to access the generator parameters.

For details on the available parameters, see the GPRF generator documentation.
