CONFigure:GSM:SIGN<i>:RFSettings:HOPPing:MAIO:TCH[:CARRier<c>] <MAIO>

Specifies the mobile allocation index offset (MAIO).

Suffix: 
<c>
1..2

Selects the carrier to be configured - only relevant in dual carrier mode

Parameters:
<MAIO>
Range: 0  to  63
*RST:0
Firmware/Software: 

V2.0.10

Options: R&S CMW-KS210
R&S CMW-KS201 for carrier 2
Manual operation: See "Band, Channel / Frequency"
