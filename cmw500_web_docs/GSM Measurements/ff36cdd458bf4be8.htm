V1.0.10.1 (Compared to V1.0.5.3)
New features:
  • Limit check for all measurement results
  • Extended receiver quality (BER) measurement: new parameters "threshold start", "threshold run", list mode commands
  • Extensions to GSM multi-evaluation list mode (remote control): Frame pattern mode
  • New commands for GSM multi-evaluation list mode (remote control):
    –FETCh:​GSM:​MEAS<i>:​MEValuation:​LIST:​BER?
    –FETCh:​GSM:​MEAS<i>:​MEValuation:​LIST:​PVTime:​CURRent:​SVECtor?
    –FETCh:​GSM:​MEAS<i>:​MEValuation:​PVTime:​MAXimum:​SVECtor?
  • New remote control command CONFigure:​GSM:​MEAS<i>:​MEValuation:​RESult[:​ALL], enables/disables all measurement results and views
