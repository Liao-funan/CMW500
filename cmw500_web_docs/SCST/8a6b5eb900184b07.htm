CONFigure:SCSTools:VARiable:INCRement <Name>
CONFigure:SCSTools:VARiable:INCRement? <Name>

Increments a variable by 1.

A query increments the variable by 1 and queries the resulting new value.

Parameters for setting and query: 
<Name>

String with the name of the variable to be incremented

Return values: 
<Value>

New value of the variable, returned by a query
