CONFigure:WCDMa:SIGN<i>:CONNection:CID <CallerID>

Sets the calling party number of the R&S CMW to be displayed at the UE. Allowed characters are 0 to 9, *, #, a, b, c.

Parameters:
<CallerID>

1 to 20-digit ID

*RST:764.332637249279E+12
