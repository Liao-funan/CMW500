CLEan:WCDMa:SIGN<i>:SMS:INComing:INFO:MTEXt

Resets all parameters related to a received SMS message. The message text and the information about the message length are deleted. The "message read" flag is set to true.

Example: 

See "Sending / Receiving a Short Message (Signaling)"

Usage: Event
Firmware/Software: 

V2.0.10

Manual operation: See "Clear Message Text"
