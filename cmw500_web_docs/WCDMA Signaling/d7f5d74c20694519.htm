V2.1.20 (Compared to V2.0.10)
New features:
  • Reduced signaling mode, see "Reduced Signaling Mode"
  • Support of HSDPA
  • "HSDPA ACK" measurement, see "HSDPA ACK Measurement"
  • Additional White Gaussian noise (AWGN) interferer, see "AWGN Noise (Ioc)"
  • UE capability information enhanced, see "UE Capabilities"
  • Automatic calculation of expected nominal power possible, see "RF Power Uplink > ..."
  • OCNS channels for release 5 and release 6, see "Orthogonal Channel Noise Simulator (OCNS)"
  • Code domain diagram illustrating configured channelization codes, code conflicts and power levels, see "Code Domain Diagram"
  • New status information DL/UL alignment, see "Connection Status"
  • Support of operating band L (requires R&S CMW-KS425)
  • PRACH parameters now configurable: message part power offset, message part length, DRX cycle length, see "PRACH Settings"
  • UTRAN registration area (URA) identity now configurable
  • Configurable delay time between sending of SMS message and RMC re-establishment, see "RMC Reestablish Delay"
  • Support of continuous mode for BER measurement, see "Repetition"
  • TX power control enhancements, see "TX Power Control - General Settings":
    –Fixed test steps ABC, EF, GH
    –Segmentation for fixed test steps
    –Target power as precondition
  • Reset values for channelization codes optimized
  • Retrieval of channelization code conflict status via remote command CONFigure:​WCDMa:​SIGN<i>:​DL:​CARRier<c>:​CODE:​CONFlict?
