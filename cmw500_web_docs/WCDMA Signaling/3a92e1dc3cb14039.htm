CONFigure:WCDMa:SIGN<i>:EAGCh:ETFCi:AUTO?

Queries the n E-TFCI values calculated according to the absolute grant (AG) configuration. The number of values n equals AG pattern length, see

CONFigure:​WCDMa:​SIGN<i>:​CELL:​CARRier<c>:​HSUPa:​EAGCh:​PATTern:​LENGth

Return values: 
<ETFCI>
Range: 0  to  127

See "Configuring the E-AGCH Measurement"

Firmware/Software: 

V3.5.20

Options: R&S CMW-KS401
Manual operation: See "Expected E-TFCI Values"
