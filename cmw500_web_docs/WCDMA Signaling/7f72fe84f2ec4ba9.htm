HSDPA ACK Measurement Configuration

The signaling HSDPA ACK measurement is included in the WCDMA signaling application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement...". The "HSDPA ACK" tab of the RX measurement view and the related configuration dialog is described in this section.

Option R&S CMW-KS401 is required.
