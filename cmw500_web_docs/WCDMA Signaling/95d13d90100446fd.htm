V3.5.30 (Compared to V3.5.20)
New features:
  • RMC on PS domain, see "Domain"
  • "Debug Configuration"
  • Multi-carrier routed via only one RF TX/RX module, see "Test Setup for Dual Carrier Scenarios" and "Test Setup for 3C-HSDPA Scenario"
  • WCDMA mobility management extensions:
    –Configuration of "Incoming IRAT HO Mobility"
    –The following additional types are now supported (see "Mobility Management"):
    CS fallback form LTE to test mode RMC call type
    Handover from GSM to voice loopback and test mode call types
    Handover from LTE to the call type packet data end to end
    Handover from LTE to test mode call type
  • Multiple PDP context, see "Connection Types" and "End-to-End Packet Data Connections"
  • Test mode type BTFD:
    –For configuration, see "Type"
    –For RMC description, see "Blind Transport Format Detection (BTFD)"
    –For test description, see "BTFD Tests (FDR and UL TFCI Faults)"
  • Extension of voice connection settings, see "TFCI Existence"
  • Additional configuration with the operating band XXXII for dual band HSDPA tests, see "DB DC HSDPA"
  • Extension of CBS messaging, see "Data Source", "From File", "ETWS"
  • SMS extensions:
    –Status check of the last sent SMS, see "Last Message Sent Status"
    –SMS status reporting upon the UE request, see "Messaging (SMS)"
    –Remote commands for SMS files:
    CONFigure:​WCDMa:​SIGN<i>:​SMS:​INComing:​FILE
    CONFigure:​WCDMa:​SIGN<i>:​SMS:​INComing:​FILE:​INFO?
    CONFigure:​WCDMa:​SIGN<i>:​SMS:​OUTGoing:​MESHandling
    CONFigure:​WCDMa:​SIGN<i>:​SMS:​OUTGoing:​FILE
    CONFigure:​WCDMa:​SIGN<i>:​SMS:​OUTGoing:​FILE:​INFO?
  • Configurable limitation of the NodeB release version, see "Maximum Release Version"
  • Rejection of "RRC Connection Request"
  • Selection of "E-DPDCH Power Formula" for a gain factor computation,
  • Indication of E-DPCCH power interpolation capability, see "Physical Uplink UE Capabilities"
  • Additional band XXVI, see "Operating Bands"
  • The channels for bands XI and XII have been modified according to specification, see "Operating Bands"
  • Remote command for the resetting of event log, see
    CLEan:​WCDMa:​SIGN<i>:​ELOGging
