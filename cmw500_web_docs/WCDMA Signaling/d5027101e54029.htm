CONFigure:WCDMa:SIGN<i>:UL:UEPClass:MANual <UEPowerClass>

Configures the UE power class value to be used by the R&S CMW if no reported value is available or usage of the reported value is disabled, see CONFigure:​WCDMa:​SIGN<i>:​UL:​UEPClass:​REPorted.

Parameters:
<UEPowerClass>
PC1 | PC2 | PC3 | PC3B | PC4

Power class 1, 2, 3, 3bis, 4

*RST:PC1
