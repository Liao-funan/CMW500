CONFigure:WCDMa:SIGN<i>:SMS:OUTGoing:LHANdling <LSMSHandling>

Defines the handling of an SMS message exceeding 160 characters.

Parameters:
<LSMSHandling>
TRUNcate | MSMS

TRUNcate: truncate

MSMS: multiple SMS

*RST:TRUN
