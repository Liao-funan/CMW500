CONFigure:WCDMa:SIGN<i>:CELL:CPC:DDRX:GMONitoring:ENABle <Enable>

Defines the settings for the discontinuous reception in the downlink, see "Continuous Packet Connectivity (CPC)".

Parameters:
<Enable>
OFF | ON

enables/disables UE monitoring of E-AGCH/E-RGCH when they overlap with the start of a UE DRX HS-SCCH reception

*RST:OFF
