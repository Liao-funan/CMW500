FETCh:WCDMa:SIGN<i>:UEReport:STATe?

Queries the state of UE measurement reporting.

Return values: 
<State>
RDY | PENDing

RDY: Any requested reports have been received.

PENDing: The instrument is waiting for reports from the UE.

*RST:RDY
Example: 

See "Retrieving Information Provided by the UE (Signaling)"

Usage: Query only

V2.0.10
