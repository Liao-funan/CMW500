V3.2.70 (Compared to V3.2.60)
New features:
  • Extension of voice connections involving audio measurements application:
    –For description, see "Audio Measurements"
    –For setting, see "Voice Connection Settings"
  • SMS extensions as binary SMS and large SMS handling, see "Outgoing SMS: General Settings"
  • Additional reselection parameters Qrxlevmin E-UTRA and time hysteresis, see "Cell Reselection"
  • Operating band XXV, see "Operating Band, Channel, Frequency, Offset, UL/DL Separation"
  • Display of additional UE capabilities:
    –"General UE Capabilities"
    –"HSDPA UE Capabilities"
    –"RF UE Capabilities"
    –"Positioning UE Capabilities"
    –"IMS Voice"
  • HSUPA extensions:
    –E-DPCCH power boosting, see "HSUPA"
    –Flexible RLC PDU size, see "RLC PDU Size"
    –Modulation setting for HSUPA connections, see "Modulation"
    –E-AGCH table index, see "E-AGCH Table Index"
  • Parameters codec, NB AMR and WB AMR now configurable also during the call, see "Voice Connection Settings"
  • DL/UL alignment indication per carrier, see "Connection Status"
  • Adaptation of the target and current E-TFCI settings to dual uplink carrier, see:
    CONFigure:​WCDMa:​SIGN<i>:​UL:​TPC:​MPEDch:​STATe?
  • Additional command for gain factor settings, see CONFigure:​WCDMa:​SIGN<i>:​UL:​GFACtor:​PDATa<no>
  • RLC throughput measurement settings "Update Interval" and "Windows Size" now possible also in unit subframe, see "Measurement Settings"
