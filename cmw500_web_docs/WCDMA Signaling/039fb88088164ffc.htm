V3.0.10 (Compared to V2.1.30)
New features:
  • Support of external fading for standard cell and dual carrier scenarios, see "External Fading"
  • Closed loop target power can be specified as maximum total power or as DPCH power, see "Closed Loop TPC Setup"
  • Handover to GSM: new dialog for configuration of destination band/channel, GSM downlink signal is switched on automatically by WCDMA signaling application, see "Inter/Intra-RAT... (hotkey)"
  • Message monitoring: disabled by default, external PC address pool configured globally, see "Message Monitoring Settings"
  • New H-Set 1A max input, see "H-Set"
  • The mechanism for selection of MAC-hs/MAC-ehs for HSDPA connections has been simplified, see "High Speed Packet Access (HSPA)"
  • P-CPICH can no longer be disabled
  • The measurements have been combined in a single RX measurement view
  • The "Signaling Parameter" hotkeys are now available in all views in a consistent way
  • The signaling application can be controlled from the RX measurement view
  • Gain factors are now configurable without R&S CMW-KS410/KS411, see "Gain Factors"
  • It is configurable whether the band indicator is broadcasted in the system information or not, see "Band Indicator"
  • A test loop can be kept closed when the operating band or the frequency is reconfigured for an established RMC connection, see "Keep Test Loop during Reconfiguration"
  • A test loop can be kept closed when an SMS is sent to the UE, see "Keep Test Loop during SMS"
  • WCDMA wizard providing predefined signal settings for HSDPA maximum throughput tests, see "WCDMA Wizards"
  • It is now possible to run two instances of the WCDMA signaling application in parallel - if the required hardware resources are available, e.g. two signaling unit wideband (SUW)
  • Additional commands for configuration of operating band and channel / carrier frequency:
