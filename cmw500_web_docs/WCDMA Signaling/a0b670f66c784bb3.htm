CONFigure:WCDMa:SIGN<i>:UL:GFACtor:HSUPa:ETFCi:REFerence <ETFCI>...

Specifies the E-TFCI values of the first n pairs of reference E-TFCIs and power offsets, with n = 1 to 8.

Parameters:
<ETFCI>

Comma-separated list of up to 8 values

Range: 0  to  127
*RST:11,67,71,75,81,90,100,127
Example: 

See "Configuring Physical Channel UL Settings"

Firmware/Software: 

V3.0.20

Options: R&S CMW-KS401
Manual operation: See "No of Reference E-TFCIs, Reference E-TFCI"
