CONFigure:WCDMa:SIGN<i>:FADing:CARRier<c>:FSIMulator:DSHift:MODE <Mode>

Sets the Doppler shift mode.

Suffix: 
<c>
1..*

Downlink carrier

Parameters:
<Mode>
NORMal | USER

NORMal: the maximum Doppler frequency is determined by the fading profile

USER: the maximum Doppler frequency can be adjusted manually

*RST:NORM
Example: 

See "Configuring Internal Fading"
