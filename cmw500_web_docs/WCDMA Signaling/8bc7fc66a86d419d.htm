CONFigure:WCDMa:SIGN<i>:CONNection:VOICe:AMR:NARRow <Rate>

Selects the mode of the NB AMR codec. The basic modes support one fixed bit-rate. Mode M supports several bit-rates.

Parameters:
<Rate>
A | B | C | D | E | F | G | H | M

A: 12.2 kbps

B: 10.2 kbps

C: 7.95 kbps

D: 7.4 kbps

E: 6.7 kbps

F: 5.9 kbps

G: 5.15 kbps

H: 4.75 kbps

M: A + C + F + H

*RST:A
