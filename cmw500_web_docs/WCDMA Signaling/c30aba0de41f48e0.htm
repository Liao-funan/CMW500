CONFigure:WCDMa:SIGN<i>:CELL:CPC:DTRX:OFFSet <Offset>

Defines the settings for the discontinuous transmission and reception, see "Continuous Packet Connectivity (CPC)".

Parameters:
<Offset>

Subframe offset to spread the DPCCH transmissions from different UEs

Range: 0 Subframe  to  159 Subframe
*RST:0 Subframe
