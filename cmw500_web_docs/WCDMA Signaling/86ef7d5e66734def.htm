V3.0.30 (Compared to V3.0.20)
New features:
  • Support of IP version 6
  • Fading without an external fader, see "Internal Fading"
  • External fading scenarios require now R&S CMW-KS410
  • Sending date and time information to the UE, see "Time"
  • Configurable rejection of location update and attach requests, see "Reject Causes"
  • TPC setup "Max. Power E-DCH", see "Max. Power E-DCH TPC Setup"
    Wizard for "Max. Power E-DCH", see "WCDMA Wizards"
    Related application sheet, see "Maximum Power Measurements with E-DCH"
  • TPC setup "Change of TFC", see "Change of TFC TPC Setup"
  • Generation of "Change of TFC" trigger signal, see "Trigger Signals"
  • OCNS R7, see "Orthogonal Channel Noise Simulator (OCNS)"
  • "UL Logging" measurement for HS-DPCCH, E-DPCCH and DPCCH logging, see "UL Logging Measurement"
  • CPC R7 for HSPA+, see "Continuous Packet Connectivity (CPC)"

Note that base software V3.0.11 or later is required for WCDMA signaling V3.0.30.
