RLC Throughput Measurement

The WCDMA Signaling "RLC Throughput" measurement provides the total data throughput (PDU) and the useful data throughput (SDU) in the downlink and in the uplink.

RLC throughput dialogs

The R&S CMW provides a separate tab and configuration dialog for RLC throughput tests, to be accessed from the "Measurement Controller" dialog, entry "RX Measurement...".
