CONFigure:WCDMa:SIGN<i>:THRoughput:UPDate <Interval>

Configures the time interval used to derive a single throughput result.

Parameters:
<Interval>
Range: 0.24 s / 120 subframes  to  2.4 s / 1200 subframes
Increment: 0.08 s / 40 subframes
*RST:120 subframes
Default unit: subframe
Example: 

See "Configuring the RLC Throughput Measurement"
