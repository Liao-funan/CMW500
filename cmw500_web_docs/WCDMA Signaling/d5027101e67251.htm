CONFigure:WCDMa:SIGN<i>:SMS:KTLoop <Enable>

Specifies whether the test loop is kept closed for an established RMC connection with test loop, when an SMS message is sent to the UE.

Parameters:
<Enable>
OFF | ON
*RST:ON
