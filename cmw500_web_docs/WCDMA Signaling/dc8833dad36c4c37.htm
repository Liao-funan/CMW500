Options and Equipment Required
The test procedure described in this application sheet requires the following equipment:
  • R&S CMW with software version ≥ V3.0.30. The latest software version is recommended. This application sheet describes software version V3.0.30.
    The tester must be equipped with a wideband signaling unit.
  • Option R&S CMW-KS400, "WCDMA R99, basic signaling"
  • Option R&S CMW-KS401, "WCDMA R5/6, basic signaling"
  • Option R&S CMW-KS411, "WCDMA R5/6, advanced signaling"
  • Option R&S CMW-KM400, "WCDMA R99, TX measurement, uplink"
