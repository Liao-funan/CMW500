What's New in This Version

This documentation describes version 3.7.20 and later of the "WCDMA Signaling" firmware application. Compared to version 3.7.10, it provides the following new features:

  • Additional UE capabilities, see:
    –"General UE Capabilities"
    –"HSDPA UE Capabilities"
    –"Physical Downlink UE Capabilities"
    –"Physical Uplink UE Capabilities"
    –"Multi-Mode and Multi-RAT UE Capabilities"
    –"Measurement Related UE Capabilities"
  • Configurable user data header for outgoing SMS, see "User Data Header"
  • CM service reject causes added, see "CM Service Request Reject Cause"
  • CM service types for CM service reject configurable, see "CM Service Request Type"
  • "IMSI Filter" added
  • Counters of CS connection attempts and rejections, see "Connection Attempt / Reject"
  • CS connection release without signaling information added, see "CS Call Release"
  • Initiation of test mode connection type RMC + HSPA possible also via remote command, see CALL:​WCDMa:​SIGN<i>:​PSWitched:​ACTion
