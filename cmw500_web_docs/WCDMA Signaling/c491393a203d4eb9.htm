UL Logging Measurement
The UL logging is applied on the following UL control channels:
  • High speed dedicated physical control channel (HS-DPCCH)
  • Enhanced dedicated physical control channel (E-DPCCH)
  • Dedicated physical control channel (DPCCH)
UL logging dialogs

The R&S CMW provides a separate tab and configuration dialog for UL logging tests, to be accessed from the "Measurement Controller" dialog, entry "RX Measurement...".
