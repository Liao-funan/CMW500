CONFigure:WCDMa:SIGN<i>:CONNection:VOICe:DELay:LOOPback <Delay>

Defines the time that the R&S CMW waits before it loops back the received data in the loopback voice connection.

Parameters:
<Delay>
Range: 0 s  to  10 s
*RST:0 s
