HSDPA ACK Measurement

The WCDMA Signaling HSDPA ACK measurement evaluates the demodulation of the downlink HS-DSCH by the UE and measures the data throughput. Thus it tests the UE receiver quality. Measurements can be performed in normal signaling mode and in reduced signaling mode. Option R&S CMW-KS401 is required.

HSDPA ACK dialogs

The R&S CMW provides a separate tab and configuration dialog for HSDPA ACK tests, to be accessed from the "Measurement Controller" dialog, entry "RX Measurement...".
