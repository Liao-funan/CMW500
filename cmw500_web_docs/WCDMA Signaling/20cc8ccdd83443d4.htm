HSDPA CQI Measurement Configuration

The signaling HSDPA CQI measurement is included in the WCDMA signaling application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement...". The "HSDPA CQI" tab of the RX measurement view and the related configuration dialog is described in this section.

Option R&S CMW-KS411 is required.
