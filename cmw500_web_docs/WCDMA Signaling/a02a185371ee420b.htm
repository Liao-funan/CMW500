CONFigure:WCDMa:SIGN<i>:FADing:CARRier<c>:FSIMulator:ILOSs:LOSS <InsertionLoss>

Sets the insertion loss for the fading simulator.

A setting is only allowed in USER mode (see CONFigure:​WCDMa:​SIGN<i>:​FADing:​CARRier<c>:​FSIMulator:​ILOSs:​MODE).

Suffix: 
<c>
1..*

Downlink carrier

Parameters:
<InsertionLoss>
Range: 0 dB  to  18 dB
*RST:0 dB
Default unit: dB
Firmware/Software: 

V3.0.30

V3.5.20: added suffix <c>

Options: R&S CMW-KS410, R&S CMW-KE100 and R&S CMW-KE400
Manual operation: See "Insertion Loss"
