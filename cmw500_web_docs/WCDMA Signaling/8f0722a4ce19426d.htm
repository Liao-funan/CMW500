CONFigure:WCDMa:SIGN<i>:CONNection:CSWitched:CRELease <CallRelease>

Specifies the signaling volume during the call release.

Parameters:
<CallRelease>
NORMal | LOCal

NORMal: normal release

LOCal: local end release without signaling

*RST:NORM
