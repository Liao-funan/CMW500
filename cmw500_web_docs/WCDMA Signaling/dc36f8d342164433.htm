Possible Extensions

While the connection is established, you can vary "WCDMA Signaling" settings and observe the behavior of the UE under test using a measurement.

The WCDMA measurement and signaling applications can be enhanced by various options, e.g.:
  • Options R&S CMW-KM401/-KS401 add R5/6 (HSPA) support to R&S CMW-KM400/-KS400.
  • Options R&S CMW-KM405/-KS405 add R9 (dual carrier HSUPA) support to R&S CMW-KM403/-KS403.
