V2.1.30 (Compared to V2.1.20)
New features:
  • Support of dual carrier HSDPA using adjacent carriers (dual cell, requires R&S CMW-KS404)
  • Maximum supported value for UE category increased to 24. Configuration of UE category improved, see "UE Category"
  • H-Set 10 added, see Table "H-Set overview"
  • Automatic mode for OCNS configuration, see "OCNS"
  • Support of RMC with 768 kbps in the uplink (requires R&S CMW-KS410)
  • Configurable cell reselection parameters to be transmitted in system information (requires R&S CMW-KS410), see "Cell Reselection"
  • Configurable number of paging indicators per PICH frame, see "Paging Indications per Frame"
  • Configurable activation time offset for peer messages, see "Activation Time Offset"
  • UE capability information enhanced with release 8 physical layer category, see "UE Capabilities"
  • Event log added to main view, see "Event Log"
  • Support of message monitoring via an external PC, see "Message Monitoring Settings"
