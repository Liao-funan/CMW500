V3.5.20 (Compared to V3.5.10)
New features:
  • 3C-HSDPA, option R&S CMW-KS406 for R10 basic signaling
    –For settings, see "Scenario"
    –For the test setup, see "Test Setup for 3C-HSDPA Scenario"
    –For additional H-Sets, see "H-Set"
  • Fading scenarios for dual band dual carrier HSDPA, see "Scenario"
  • RX diversity for dual band dual carrier HSDPA
    –For settings, see "Scenario"
    –For the test setup, see "Test Setup for Dual Carrier Dual Band RX Diversity"
  • Ciphering of radio bearer added, see "Ciphering"
  • Downlink power control, see "Downlink Power Control Settings"
  • E-AGCH RX measurement, see "E-AGCH Measurement Configuration"
  • E-RGCH RX measurement, see "E-RGCH Measurement Configuration"
  • Additional wizard for HSUPA E-RGCH measurement and HSDPA CQI measurement, see "Using the WCDMA Wizards"
  • Target power offset for TPC, see "Target Power"
  • DPCCH power control preamble trigger for open loop power control measurements in dual carrier HSUPA operation, see "Trigger Signals"
  • Dynamic configuration of DPCH slot format parameters during multi-call, see "Voice Connection Settings"
  • 64-QAM modulation in CQI conformance test settings, see "CQI Table Index, CQI Tables"
  • SG initialized E-AGCH pattern, see "AG Pattern Repetition"
  • Extension of "HS-SCCH Less Operation Settings"
  • Extension of "HS-SCCH Order Configuration"
  • Fading profile for CQI test in multipath fading and HS-SCCH-less demodulation of HS-DSCH, see "Profile"
  • Network inactivity timer and T323 plus UE fast dormancy, see "Timer and Constants" and "Inactivity Settings"
  • Speech connection delay, see "CMW Voice Info"
  • Redirection to another instrument, see "Destination Parameters"
  • Internal fader selectable, see "Scenario"
  • Additional DPCH/F-DPCH settings for downlink power control, see "DPCH / F-DPCH Enhanced"
  • SMS extensions:
    –Additional parameter "Protocol Identifier"
    –Sending of messages stored in a file, see "From File"
    –Storing of incoming messages into a file, see "Select File..."
  • Coding scheme extension for CBS, see "Data Coding Scheme"
