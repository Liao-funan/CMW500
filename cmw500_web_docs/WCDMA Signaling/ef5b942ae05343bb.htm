CONFigure:WCDMa:SIGN<i>:EHICh:SMODe:AVERage <Mode>

Specifies calculation algorithm for average statistics. Only remote command is provided. No corresponding manual setting is existing in the GUI.

The setting is especially useful if "Repetition" = "Continuous".

Parameters:
<Mode>
WINDow | CONTinuous

WINDow: average results calculated per statistic cycle ("Measure Frames")

CONTinuous: average results calculated since the beginning of the measurement

*RST:WIND
Firmware/Software: 

V3.5.40
