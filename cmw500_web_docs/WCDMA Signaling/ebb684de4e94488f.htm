V2.0.10 (Compared to V1.0.15.23)
New features:
  • Support of sending and receiving SMS messages, see "Messaging (SMS) Parameters"
  • Support of operating bands 19 to 21. The S operating bands are now available via option R&S CMW-KS425. See also "Operating Bands"
  • Configurable maximum number of paging repetitions, see "Paging Repetitions"
  • Default IMSI enabled before registration and automatically disabled if other IMSI is registered, can manually only be re-enabled, not disabled, see "Default IMSI"
  • Display of expected initial DPCCH power and expected initial preamble power, see "Physical Channel Uplink Settings"
  • Parameter DPCCH power offset now configurable without option R&S CMW-KS410, see "DPCCH Power Offset"
  • Configurable measurement timeout for remote control (CONFigure:​WCDMa:​SIGN<i>:​BER:​TOUT)
  • Display of connection status added to BER view, see "BER Tab"
  • New command for BER measurement to check limit violations (CALCulate:​WCDMa:​SIGN<i>:​BER?)
  • CONFigure:WCDMa:SIGN<i>:SCENario:SCELl renamed to ROUTe:WCDMa:SIGN<i>:SCENario:SCELl, selection of RF 3 and RF 4 connectors modified, RX and TX modules selectable
  • Additional commands for query of routing settings: ROUTe:​WCDMa:​SIGN<i>:​SCENario? and ROUTe:​WCDMa:​SIGN<i>?
  • Remaining UPLink and DOWNlink commands shortened to UL and DL
  • New command for check of UE measurement report state (FETCh:​WCDMa:​SIGN<i>:​UEReport:​STATe?)
  • Application sheets added to documentation, see "Application Sheets"
