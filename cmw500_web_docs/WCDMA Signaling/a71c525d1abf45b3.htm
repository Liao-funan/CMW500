WCDMA Signaling > Command Reference > Using the WCDMA Wizard > CONFigure:WCDMa:SIGN<i>:PSETtings
CONFigure:WCDMa:SIGN<i>:PSETtings <Selection>

Executes the wizard to apply the selected predefined set of WCDMA settings.

Configure the following selections before executing the wizard:
  • "General Settings"
  • HUMP: see CONFigure:​WCDMa:​SIGN<i>:​PSETtings:​HUMP
  • ERGM: see CONFigure:​WCDMa:​SIGN<i>:​PSETtings:​ERGM
Setting parameters: 
<Selection>
HDMT | HUMT | HSMT | HUMP | DHIP | ERGM | HCQI | OOS

HDMT: HSDPA maximum throughput

HUMT: HSUPA maximum throughput

HSMT: HSPA maximum throughput

HUMP: HSUPA maximum output power

DHIP: Dual carrier HSPA inner loop power control

ERGM: HSUPA E-RGCH measurement

HCQI: HSDPA CQI measurement

OOS: Out-of-sync handling

Usage: Event
