V3.2.60 (Compared to V3.2.10)
New features:
  • Release 9 - HSUPA implemented (option R&S CMW-KS405 and additional SUW required):
    –Dual carrier HSUPA operation, see "Scenario"
    –Enabling the second HSUPA carrier, see "2nd Carrier Enable"
    –Additional "HSUPA UE Capabilities"
    –Test setup with two SUWs, see "Test Setup for 3C-HSDPA Scenario"
    –Additional parameters in the following command:
    SENSe:​WCDMa:​SIGN<i>:​UESinfo:​DINFo?
    –Extended ranges in the following commands:
    CONFigure:​WCDMa:​SIGN<i>:​CELL:​HSUPa:​UECategory:​MANual
    CONFigure:​WCDMa:​SIGN<i>:​CELL:​HSUPa:​UECategory:​REPorted
  • Release 9 - HSDPA implemented (option R&S CMW-KS405 required):
    –Dual band dual carrier HSDPA operation, see "DB DC HSDPA"
    –Additional "HSDPA UE Capabilities"
  • Wizards support dual carrier HSPA, see "WCDMA Wizards"
  • "Codec UE Capabilities"
  • Compressed mode (CM), see:
    –"Compressed Mode"
    –"UL compressed mode trigger"
    –UE capabilities for neighbor cell measurement-related compressed mode, see "Measurement Related UE Capabilities"
    –TPC test setup UL CM according to the conformance test specification 3GPP TS 34.121, section 5.7, see "Active TPC Setup"
  • Neighbor cell measurement:
    –General enabling, see "UE Measurement Report Settings"
    –Enabling for individual neighbor cell, see Figure "Neighbor cell configuration dialog"
    –Retrieving neighbor cell reports, see "Neighbor Cells UTRA FDD"
  • Handover extensions (see "Mobility Management"):
    –Support of PS handover, see "Inter/Intra-RAT... (hotkey)"
    –Support of inter-frequency handover with RX diversity
    –Support of CS fallback from LTE to WCDMA
    –Support of handover WCDMA - GSM within single TX/RX module (GSM signaling version V3.2.30 and higher)
    –Support of redirection WCDMA - WCDMA
  • New scenarios with RX diversity, see "Scenario"
  • Cell broadcast service (option R&S CMW-KS170 required), see "Messaging (CBS) Parameters"
  • HS-SCCH order type 1, see "HS-SCCH Order Configuration"
  • UE information element "RRC State"
  • "External Delay Compensation"
  • "Caller ID"
  • Multiple end-to-end connections used by the different signaling instances in parallel, see CONFigure:​WCDMa:​SIGN<i>:​ETOE
  • Additional fading features:
    –Birth-death profile, see "Profile"
    –Selectable shift of the Doppler frequency, see "Doppler Frequency"
  • Extension of E-HICH results to support two carriers:
    –FETCh:​WCDMa:​SIGN<i>:​EHICh:​THRoughput:​TOTal? etc.
    –FETCh:​WCDMa:​SIGN<i>:​EHICh:​TRACe:​MPTHroughput:​CARRier<c>:​CURRent? etc.
    –FETCh:​WCDMa:​SIGN<i>:​EHICh:​CARRier<c>? etc.
  • Synchronization of the system time / the SFN, see "Synchronization"
  • Emergency service category indication, see SENSe:​WCDMa:​SIGN<i>:​UESinfo:​ESCategory?
  • New commands for the event log, see "Event Log"
  • Additional parameters in the following commands:
    –CONFigure:​WCDMa:​SIGN<i>:​CELL:​CPC:​HORDer:​SEND
    –SENSe:​WCDMa:​SIGN<i>:​CELL:​CONFig?
    –CONFigure:​WCDMa:​SIGN<i>:​NCELl:​GSM:​CELL<n>
    –CONFigure:​WCDMa:​SIGN<i>:​NCELl:​LTE:​CELL<n>
    –CONFigure:​WCDMa:​SIGN<i>:​NCELl:​WCDMa:​CELL<n>
  • Extended parameter ranges in the command CONFigure:​WCDMa:​SIGN<i>:​CELL:​CPC:​UDTX:​LPLength
  • Adaptation of UL logging results for secondary carrier (CARRier<c> added), see "UL Logging Tab"
