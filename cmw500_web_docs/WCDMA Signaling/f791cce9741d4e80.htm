CONFigure:WCDMa:SIGN<i>:SMS:OUTGoing:RMCDelay <Delay>

Defines the time between sending of an SMS message and re-establishment of the RMC connection.

Parameters:
<Delay>
Range: 1 s  to  5 s
*RST:OFF (2 s)

Additional parameters: OFF | ON (disables the delay | enables the delay using the previous/default value)

Example: 

See "Sending / Receiving a Short Message (Signaling)"

Firmware/Software: 

V2.1.20

Manual operation: See "RMC Reestablish Delay"
