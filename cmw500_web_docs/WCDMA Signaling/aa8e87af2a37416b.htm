TPC Test Setup UL CM

The TPC test setup for uplink compressed mode (CM) activates TPC pattern for CM test cases using UL CM trigger.

When the setup is executed, the instrument sends the power commands to the UE according to the selected CM pattern, see "UL CM TX Test Pattern".

The R&S CMW provides pattern A (rising TPC), pattern A (falling TPC) and pattern B as the compressed mode test pattern in line with 3GPP. The following tables below displays the pattern:

Pattern A
1 = rising TPC
2 = falling TPC
Pattern B

As precondition the R&S CMW sets target power before the pattern execution. After the pattern execution, the UE is commanded to set target power again. The R&S CMW uses standardized values as stated in table below.
