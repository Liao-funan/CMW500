CONFigure:WCDMa:SIGN<i>:FADing:CARRier<c>:AWGN:ENABle <Enable>

Enables or disables AWGN insertion via the fading module.

For multi-carrier scenarios, the same settings are applied to all carriers. Thus it is sufficient to configure one carrier.

Suffix: 
<c>
1..*

Downlink carrier

Parameters:
<Enable>
OFF | ON
*RST:OFF
Example: 

See "Configuring Internal Fading"

Firmware/Software: 

V3.0.30

Options: R&S CMW-KS410, R&S CMW-KE100 and R&S CMW-KE400
Manual operation: See "Enable"
