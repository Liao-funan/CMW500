CONFigure:WCDMa:SIGN<i>:CELL:HSUPa:EAGCh:UTTI <UnscheduledTTI>

Defines the transmission in unscheduled TTIs.

Parameters:
<UnscheduledTTI>

DTX: switch E-AGCH off
