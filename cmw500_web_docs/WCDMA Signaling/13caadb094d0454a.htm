CONFigure:WCDMa:SIGN<i>:CELL:HSUPa:HRVersion <Version>

Specifies the HARQ RV configuration value signaled to the UE.

Parameters:
<Version>
RV0 | TABLe

RV0: use always redundancy version 0

TABLe: determine the redundancy version using a table as specified in 3GPP TS 25.212

*RST:RV0
