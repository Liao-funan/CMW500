CONFigure:WCDMa:SIGN<i>:HACK:MSFRames <MeasSubframes>

Defines the number of HSDPA subframes to be measured per measurement cycle (statistics cycle).

Parameters:
<MeasSubframes>
Range: 100  to  1E+6
Increment: 100
*RST:2000
