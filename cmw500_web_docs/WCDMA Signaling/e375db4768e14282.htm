CONFigure:WCDMa:SIGN<i>:CELL:HSDPa:UECategory:MANual <UECatManual>

Configures the UE category to be used by the R&S CMW if no reported value is available or usage of the reported value is disabled, see CONFigure:​WCDMa:​SIGN<i>:​CELL:​HSDPa:​UECategory:​REPorted.

Parameters:
<UECatManual>
Range: 1 to 24, 29 to 32
*RST:12
Example: 

See "Configuring HSDPA Settings"

Firmware/Software: 

V2.1.30

Options: R&S CMW-KS401
Manual operation: See "UE Category"
