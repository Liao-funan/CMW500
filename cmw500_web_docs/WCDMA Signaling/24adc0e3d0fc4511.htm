CONFigure:WCDMa:SIGN<i>:DL:CARRier<c>:OCNS:TYPE <Type>

Selects the type of OCNS channels to be generated, see "Orthogonal Channel Noise Simulator (OCNS)".

You can select the type manually or use the automatic mode.

Suffix: 
<c>
1..*

Downlink carrier

Parameters:
<Type>
R99 | R5 | R6 | R7 | AUTO
*RST:AUTO
