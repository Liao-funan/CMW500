CONFigure:WCDMa:SIGN<i>:CELL:CARRier<c>:HSUPa:ERGCh:MODE <Mode>

Specifies the relative grant sequence transmitted via the E-RGCH.

For definition of a user-defined pattern, see CONFigure:​WCDMa:​SIGN<i>:​CELL:​CARRier<c>:​HSUPa:​ERGCh:​PATTern.

Suffix: 
<c>
1..*

Uplink carrier

Parameters:
<Mode>
ALTernating | HARQ | UP | DOWN | DTX | CONTinuous | SINGle

ALTernating: alternating UP, DOWN - per TTI

HARQ: alternating UP, DOWN - per HARQ cycle

UP: all UP

DOWN: all DOWN

DTX: all DTX

CONTinuous: continuous user-defined pattern

SINGle: single user-defined pattern

*RST:ALT
