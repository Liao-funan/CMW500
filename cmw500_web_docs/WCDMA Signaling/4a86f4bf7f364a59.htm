E-AGCH Measurement Configuration

The signaling E-AGCH measurement is included in the WCDMA signaling application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement...". The "E-AGCH" tab of the RX measurement view and the related configuration dialog is described in this section.
