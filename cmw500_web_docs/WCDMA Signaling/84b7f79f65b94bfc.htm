FETCh:WCDMa:SIGN<i>:RSIGnaling:STATe?

Queries the reduced signaling connection state, see also "Connection States for Reduced Signaling".

Return values: 
<RSigState>
OFF | PROCessing | ON

OFF: reduced signaling Off

ON: reduced signaling On

PROCessing: switching channels On/Off

*RST:OFF
Example: 

See "Setting Up a Reduced Signaling Connection"

Usage: Query only
Firmware/Software: 

V2.1.20

Manual operation: See "Circuit Switched, Packet Switched, Reduced Signaling"
