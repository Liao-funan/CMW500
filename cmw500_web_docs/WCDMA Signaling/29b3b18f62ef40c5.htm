CONFigure:WCDMa:SIGN<i>:CELL:HSDPa:CQI:RVCSequences:QPSK:UDEFined <Length>, <Sequence>...

Specifies an RV coding sequence to be used for signals with QPSK modulation if UDEFined is set via CONFigure:​WCDMa:​SIGN<i>:​CELL:​HSDPa:​CQI:​RVCSequences:​QPSK.

Parameters:
<Length>

The first <Length> entries of the user defined coding sequence are used.

Range: 1  to  8
*RST:8
<Sequence>

Up to 8 values separated by commas.

If you specify n values, they overwrite the first n entries of the user-defined sequence.

Range: 0  to  7
*RST:0

See "Configuring HSDPA Settings"

Options: R&S CMW-KS401
Manual operation: See "RV Coding Sequences"
