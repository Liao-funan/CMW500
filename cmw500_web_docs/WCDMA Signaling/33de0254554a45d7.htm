CONFigure:WCDMa:SIGN<i>:CELL:NTOPeration <Mode>

Selects the network operation mode indicating whether a Gs interface is present in the network (mode I) or not (mode II).

Parameters:
<Mode>
M1 | M2

M1: mode I, Gs interface present

M2: mode II, Gs interface not present

*RST:M1
