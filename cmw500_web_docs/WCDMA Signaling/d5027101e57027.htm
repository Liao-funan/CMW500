CONFigure:WCDMa:SIGN<i>:CONNection:TMODe:KTLReconfig <Enable>

Specifies whether the test loop is kept closed when the operating band or the carrier frequency is reconfigured during an established test mode connection with test loop.

Parameters:
<Enable>
OFF | ON

ON: keep test loop closed

OFF: open test loop, perform reconfiguration, close test loop

*RST:OFF
Example: 

See "Configuring Connection Types"

Firmware/Software: 

V3.0.20

Manual operation: See "Keep Test Loop during Reconfiguration"
