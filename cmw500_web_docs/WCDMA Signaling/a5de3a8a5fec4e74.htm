V3.2.10 (Compared to V3.0.30)
New features:
  • New graphical appearance of the E-HICH measurement results, see "Measurement Results"
  • New graphical appearance of the UL logging measurement results, see "UL Logging Tab"
  • CPC trigger, see "Trigger Signals"
  • UL logging start at CPC cycle 1, see "Start at CPC Cycle1"
  • Clipping counter, see "Clipped Samples"
  • Dual carrier separation setting, see "Carrier Separation"
  • DPCH phase reference, see "Phase Reference"
  • Test mode using CELL_FACH, see "Type"
  • Additional fading profiles, see "Profile"
  • Additional parameters in the UE capability commands:
