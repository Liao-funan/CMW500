Test Setup for Internal Fading Scenarios without RX Diversity

The test setup is the same as for the corresponding scenario without fading. The R&S CMW adds the fading signal to the original downlink signal.

While multi-carrier single band fading scenarios require one IQ fader board, dual band fading scenarios require two IQ boards.
