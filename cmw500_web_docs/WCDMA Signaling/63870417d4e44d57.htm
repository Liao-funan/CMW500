CONFigure:WCDMa:SIGN<i>:DL:ENHanced:DPCH:LSEQuence <AB>, <BD>, <DE>, <EF>

Specifies the level of out-of-sync power mask between the areas A to F.

Parameters:
<AB>
Range: -80 dB  to  0 dB
*RST:-22 dB
<BD>
Range: -80 dB  to  0 dB
*RST:-28 dB
<DE>
Range: -80 dB  to  0 dB
*RST:-24 dB
<EF>
Range: -80 dB  to  0 dB
*RST:-18 dB

See "Configuring Physical Channel DL Settings"
