CONFigure:WCDMa:SIGN<i>:DL:CARRier<c>:LEVel:APOWer?

Queries the accumulated power (total power of all active channels relative to the base level of the generator).

Suffix: 
<c>
1..*

Downlink carrier

Return values: 
<Power>
Range: -80 dB  to  10 dB
Default unit: dB
Example: 

See "Configuring Physical Channel DL Settings"

Usage: Query only
Firmware/Software: 

V2.1.30

Manual operation: See "Accumulated Power"
