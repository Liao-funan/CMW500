New features:

  • The settings of UE category in the GUI of the following wizards:
    –"HSDPA Max. Throughput"
    –"HSUPA Max. Throughput"
    –"HSPA Max. Throughput"

    Refer to "Using the WCDMA Wizards"

  • Ranges of inactivity timers reduced, see "Inactivity Timer"
