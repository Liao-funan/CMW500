Setting Up a Data Connection

Proceed as follows:

  1. Configure the other settings of the signaling application as desired.

  2. Configure the data application unit (see DAU documentation).

  3. Switch on the cell signal. See for example "Switching On the Cell Signal and the UE (Signaling)".

  4. Attach the UE.

  5. Initiate a mobile originated call at the UE.

  6. Generate IP traffic, e.g. using the "IPerf" measurement provided by the DAU.
