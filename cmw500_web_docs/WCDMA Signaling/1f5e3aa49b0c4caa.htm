V3.0.20 (Compared to V3.0.10)
New features:
  • Support of handover (redirection) to LTE, see "Mobility Management"
  • Support of end to end packet data connections, using the data application unit (DAU), see "Packet Data" and "End-to-End Packet Data Connections"
  • New measurements:
    –RLC throughput measurement, see "RLC Throughput Measurement"
    –HSUPA E-HICH measurement, see "E-HICH Measurement"
  • Support of HSUPA, see:
    –Most HSUPA settings: "HSUPA Settings"
    –Physical DL channels: "HSUPA Downlink Channels"
    –Gain factors: "HSUPA"
    –Enabling HSPA in uplink direction: "Direction"
    –Uplink SDU size: "HSUPA UL RLC SDU Size"
    –Wizard providing predefined settings for maximum throughput: "Using the WCDMA Wizards"
  • New connection type "Test Mode" instead of RMC, see "UE term. Connection"
  • Support of HSPA connections without RMC, see "Type"
    The old command for enabling/disabling the HSPA test mode is no longer relevant, but still supported as alias: CONFigure:WCDMa:SIGN:CONNection:RMC:HSPA:TMODe
  • Configurable neighbor cell list for broadcast in system information, see "Neighbor Cell Settings"
  • New PRACH parameter, see "Preambles before AICH Transmission"
  • Generation of PRACH trigger signal, see "Trigger Signals"
  • Dual carrier fading scenario enhanced to support RX diversity handling by external fader, see "Scenario"
  • For dual carrier AWGN noise is no longer configurable per carrier, see "AWGN Noise (Ioc)"
  • Display of IP addresses assigned to the UE, see "Primary PDP Context"
  • The following CONFigure:WCDMa:SIGN:CONNection:RMC:... commands have been renamed (old commands still supported as alias):
    –...:RMC:KTLReconfig to ...:TMODe:KTLReconfig
    –...:RMC:DATA to ...:TMODe:RMC:DATA
    –...:RMC:DLRessources to ...:TMODe:RMC:DLRessources
    –...:RMC:UCRC to ...:TMODe:RMC:UCRC
    –...:RMC:RLCMode to ...:TMODe:RMC:RLCMode
    –...:RMC:DRATe to ...:TMODe:RMC:DRATe
    –...:RMC:TMODe to ...:TMODe:RMC:TMODe
    –...:RMC:HSPA:PROCedure to ...:TMODe:HSPA:PROCedure
    –...:RMC:HSPA:DIRection to ...:TMODe:HSPA:DIRection
    –...:RMC:HSPA:DATA to ...:TMODe:HSPA:DATA
    –...:RMC:HSPA:EINSertion to ...:TMODe:HSPA:EINSertion

Note that base software V3.0.11 or later is required for WCDMA signaling V3.0.20.
