CONFigure:WCDMa:SIGN<i>:CELL:SYNC:ZONE <Zone>

Selects the synchronization zone for the signaling application.

Parameters:
<Zone>
NONE | Z1

NONE: no synchronization

Z1: synchronization to zone 1

*RST:Z1
