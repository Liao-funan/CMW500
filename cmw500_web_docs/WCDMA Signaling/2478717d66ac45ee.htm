V3.5.40 (Compared to V3.5.30)

New features:

  • Automatic RRC transitions, see "Inactivity Settings"
  • Multiple PDP context indications, see "Primary PDP Context"
  • BSIC added in the settings of GSM neighbor cell, see "GSM"
  • Setting of "MOC Alerting Timeout"
  • Multi-rate mode of wideband AMR codec extended, see "WB AMR"
  • "RRC State" displayed in the "UE Info" pane
  • Changed range of "Location Area Code"
  • Extended length of CBS message (internal: up to 1395 char, from file: up to 600 char), see "Message Settings"
  • Remote commands for the average statistics of HSDPA ACK and E-HICH measurements:

    CONFigure:​WCDMa:​SIGN<i>:​HACK:​SMODe:​AVERage
