E-DCH TX Start Time Restrictions

This section describes the parameters for the transmission restrictions in the uplink on the E-DCH, see also "Continuous Packet Connectivity (CPC)".

The parameters from this section are defined in 3GPP TS 25.331 as the DTX-DRX information.

E-DCH TX restriction configuration
MAC DTX Cycle

Specifies pattern of time instances where the start of uplink E-DCH transmission after inactivity is allowed.

Remote command: 

CONFigure:​WCDMa:​SIGN<i>:​CELL:​CPC:​MAC:​CYCLe:​TTI<ms>

 
MAC Inactivity Threshold

E-DCH inactivity time after which the UE can start E-DCH transmission only at given times according to MAC DTX cycle.

Remote command: 

CONFigure:​WCDMa:​SIGN<i>:​CELL:​CPC:​MAC:​CYCLe:​ITHReshold
