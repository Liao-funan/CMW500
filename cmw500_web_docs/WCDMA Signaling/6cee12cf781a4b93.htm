HSUPA Settings

The parameters in this section configure, for example, the HSUPA system information and the contents transmitted via E-AGCH, E-RGCH and E-HICH.

Option R&S CMW-KS401 is required.

Alternatively use the wizard for the quick configuration of the following automatic settings (see "Using the WCDMA Wizards"):
  • HSUPA maximum throughput
  • HSPA maximum throughput
  • HSUPA maximum output power
  • Dual carrier HSPA inner loop power control

For parameter descriptions, refer to the subsections.
