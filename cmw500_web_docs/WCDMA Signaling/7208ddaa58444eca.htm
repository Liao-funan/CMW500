UL Logging Measurement Configuration

The signaling UL logging measurement is included in the WCDMA signaling application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement...". The "UL Logging" tab of the RX measurement view and the related configuration dialog is described in this section.
