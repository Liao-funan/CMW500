CONFigure:WCDMa:SIGN<i>:ULLogging:REPetition <Repetition>

Specifies the repetition mode of the measurement. The repetition mode specifies whether the measurement is stopped after a single-shot or repeated continuously. Use CONFigure:​WCDMa:​SIGN<i>:​ULLogging:​MSFRames to define the number of subframes to be measured per single shot.

See also: "Statistical Settings"

Parameters:
<Repetition>
SINGleshot | CONTinuous

SINGleshot: Single-shot measurement

CONTinuous: Continuous measurement

*RST:SING
