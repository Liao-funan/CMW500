Handover from WCDMA to GSM

This application sheet describes how to perform an inter-RAT handover for a circuit switched WCDMA voice call or RMC connection. The connection is configured and established using the "WCDMA Signaling" application. Then a handover to the "GSM Signaling" application is performed.
