SENSe:WCDMa:SIGN<i>:UESinfo:APN?

Returns all access point names used by the UE during a packet data connection.

Return values: 
<APN>

The names of all connected APNs as a string

Example: 

See "Setting Up a Data Connection"

Usage: Query only

Manual operation: See "Primary PDP Context"
