CONFigure:WCDMa:SIGN<i>:CELL:CARRier<c>:HSUPa:EHICh:MODE <Mode>

Specifies the HARQ acknowledgement indicator sequence transmitted via the E-HICH.

Suffix: 
<c>
1..*

Uplink carrier

Parameters:
<Mode>
CRC | ALTernating | ACK | NACK | DTX

CRC: react on UL CRC (ACK, NACK or DTX)

ALTernating: alternating ACK, NACK

ACK: all ACK

NACK: all NACK

DTX: all DTX

*RST:CRC

See "Configuring HSUPA Settings"
