CONFigure:WCDMa:SIGN<i>:SMS:OUTGoing:SCTStamp:TSOurce <SourceTime>

Selects the date and time source for service center time stamp.

The time source "DATE" is configured via the following commands:
  • CONFigure:​WCDMa:​SIGN<i>:​SMS:​OUTGoing:​SCTStamp:​DATE
  • CONFigure:​WCDMa:​SIGN<i>:​SMS:​OUTGoing:​SCTStamp:​TIME
Parameters:
<SourceTime>
CMWTime | DATE

CMWTime: Windows date and time

DATE: Date and time specified via remote commands

*RST:CMWT
Example: 

See "Sending / Receiving a Short Message (Signaling)"

Firmware/Software: 

V3.2.80

Options: R&S CMW-KS410
Manual operation: See "Time Source"
