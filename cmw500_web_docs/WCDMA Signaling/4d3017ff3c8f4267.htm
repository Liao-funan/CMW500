CARRier<c>

CARRier<c> is used as abbreviation of "CARRier<carrier>". For better readability only the abbreviated form (which is also accepted by the instrument) is given in the command reference.

The <carrier> is relevant for the multi-carrier configurations. It can be omitted for the single-carrier configuration.
