Scheduling Type UL RMC

UL reference measurement channels are intended for UL RF tests, specified in 3GPP TS 36.521, chapter 6. You can use them for the NB-IoT multi-evaluation measurement.

The UL RMCs are defined in 3GPP TS 36.521, Annex A.2.4. The signaling application uses the UL scheduling patterns defined there. A pattern determines which subframes are scheduled.

In the signaling application, a UL RMC can be defined via the following set of parameters:
  • Number of subcarriers (no of SC)
  • Position of the first subcarrier (start SC)
  • MCS index, determining the modulation scheme and the transport block size
  • Number of resource units (no of RU)
  • Number of repetitions
