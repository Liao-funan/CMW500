Performing a BLER Measurement

To measure the downlink BLER, you need a connection with data transfer in the downlink.

In test mode, set up a DL connection. You can, for example, use a DL RMC. This scheduling type includes data transfer on the MAC layer.

When you start the measurement, the R&S CMW sends data to the UE via the NPDSCH. The UE confirms each received transmission with an ACK or NACK via the NPUSCH. The R&S CMW calculates the DL BLER from the received ACKs and NACKs.
