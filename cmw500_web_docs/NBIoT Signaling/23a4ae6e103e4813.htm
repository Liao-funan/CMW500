PDCP UE Capabilities

The following UE capability information indicates in which way the UE supports the packet data convergence protocol (PDCP) described in 3GPP TS 36.323.

PDCP UE capabilities
└ Supported ROHC Profiles
└ Max Num ROHC Context Sessions
Supported ROHC Profiles

Support of the robust header compression profiles with the stated profile identifiers (0x0002, 0x0003, ...).

The profiles are defined in 3GPP TS 36.323, Table 5.5.1.1.

Remote command: 

SENSe:​NIOT:​SIGN<i>:​UECapability:​TRANsfer:​PDCP:​PROFiles?

SENSe:​NIOT:​SIGN<i>:​UECapability:​TRANsfer:​PDCP:​ROHC?

SENSe:​NIOT:​SIGN<i>:​UECapability:​TRANsfer:​PDCP:​ROHC:​ALL?

 
Max Num ROHC Context Sessions

Maximum number of header compression context sessions supported by the UE.

Remote command: 

SENSe:​NIOT:​SIGN<i>:​UECapability:​TRANsfer:​PDCP:​MAXSessions?
