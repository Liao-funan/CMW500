SENSe:NIOT:SIGN<i>:CELL:IBGBand:CHANnel:OFFSet:DL?
SENSe:NIOT:SIGN<i>:CELL:IBGBand:CHANnel:OFFSet:UL?

Query the DL and UL channel raster offsets resulting from the in-band mode or guard-band mode settings.

For the standalone mode, the channel raster offset is zero.

Return values: 
<ChannelOffset>
Default unit: Hz
Example: 

See "Configuring Physical Cell Setup"

Usage: Query only
Firmware/Software: 

V3.7.30

Manual operation: See "NB-IoT Channel Raster Offset"
