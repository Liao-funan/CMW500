Standalone Operation

In the standalone operation mode, the used spectrum is dedicated to NB-IoT only. So the frequencies are not shared with another technology.

One possible deployment scenario is, to use no longer needed GSM spectrum for NB-IoT. An NB-IoT carrier fits perfectly into a no longer used GSM channel.

Another scenario is, to use new spectrum for NB-IoT.
