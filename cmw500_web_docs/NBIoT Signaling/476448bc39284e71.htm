Physical DL Channels and Signals

The NB-IoT downlink uses the physical channels and signals listed in the following tables.

Physical DL channels

Physical DL channel

Purpose

Narrowband physical broadcast channel (NPBCH)

Provides physical layer information of the cell to be read during cell search, e.g. system frame number, scheduling of SIB-NB, transmit antenna info, NRS ports

Narrowband physical downlink control channel (NPDCCH)

Carries UE-specific control information, like scheduling information

Carries ACK/NACK indicators for uplink packets

Narrowband physical downlink shared channel (NPDSCH)

Carries user data

Physical DL signals

Physical DL signal

Purpose

Narrowband reference signal (NRS)

For demodulation

Narrowband primary synchronization signal (NPSS)

Narrowband secondary synchronization signal (NSSS)

Acquisition of cell timing, frequency synchronization, detection of cell identity
