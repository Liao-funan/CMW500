CONFigure:NIOT:SIGN<i>:RFSettings:CHANnel:DL <Channel>
CONFigure:NIOT:SIGN<i>:RFSettings:CHANnel:UL <Channel>

Select the DL and UL channel numbers. They must be valid for the current operating band.

Setting the UL or the DL channel number is sufficient. The other channel number is calculated and set automatically.

For channel numbers depending on operating bands, see "Operating Bands".

Parameters:
<Channel>
Range: depends on operating band
