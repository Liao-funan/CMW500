SENSe:NIOT:SIGN<i>:UESinfo:UEADdress:IPV<version>?

Returns the IPv4 addresses (<version> = 4) or the IPv6 prefixes (<version> = 6) assigned to the UE by the R&S CMW.

Suffix: 
<version>
4, 6
Return values: 
<IPAddresses>

Comma-separated list of IP address/prefix strings

Example: 

See "Querying UE Information"

Usage: Query only
Firmware/Software: 

V3.7.20

Manual operation: See "Default Bearer"
