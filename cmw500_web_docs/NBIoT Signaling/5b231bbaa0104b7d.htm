GUI Reference

The following sections provide detailed reference information on the parameters of the NB-IoT signaling application. Most parameters can be configured via a single configuration dialog. Additional dialogs allow you to configure the measurements included in the signaling application.

Many of the signaling parameters are available in a subset of connection states only. Temporarily unavailable parameters are grayed out in the configuration dialogs; hotkeys appear and disappear dynamically, depending on the connection state.

The screenshots in this chapter show the GUI with all available options installed. Depending on the installed options, some parameters are not configurable (display the default value) or are not visible at all. The required options are stated.
