CONFigure:NIOT:SIGN<i>:CONNection:RRC:TIMer <Timer>

Configures the inactivity timeout for disabled "Keep RRC Connection" (CONFigure:NIOT:SIGN:CONNection:RRC:KEEP OFF).

Parameters:
<Timer>
Range: 1 s  to  255 s
*RST:5 s
Default unit: s
Example: 

See "Configuring General Connection Settings"

Firmware/Software: 

V3.7.30

Manual operation: See "Keep RRC Connection"
