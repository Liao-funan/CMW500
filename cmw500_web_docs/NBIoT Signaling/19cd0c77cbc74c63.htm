CONFigure:NIOT:SIGN<i>:CELL:TOUT:OOSYnc <value>

Specifies the time after which the instrument, having waited for a signal from the connected UE, releases the connection.

Parameters:
<value>
Range: 1 s  to  60 s
*RST:5 s
Default unit: s
