CONFigure:NIOT:SIGN<i>:CELL:SECurity:IALGorithm <Algorithm>

Selects an algorithm for integrity protection.

Parameters:
<Algorithm>
NULL | S3G | AES

NULL: no integrity protection

S3G: SNOW3G (EIA1) algorithm

AES: AES (EIA2) algorithm

*RST:S3G
