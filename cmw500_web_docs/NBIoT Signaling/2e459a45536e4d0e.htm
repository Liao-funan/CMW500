The BLER view provides the measurement results on the left. They are described in the following.

On the right, the view shows common settings of the "NB-IoT signaling" application, see "Settings".

BLER main view
Result table
  • "ACK / NACK / DTX":
    Number of acknowledgments and negative acknowledgments received via the NPUSCH since the start of the measurement. No answer at all (no ACK, no NACK) is counted as DTX.
    The results are presented as absolute number and as percentage relative to the number of DL transmissions.
  • "BLER":
    Block error ratio, percentage of DL transmissions for which no acknowledgment has been received. The formula used to calculate the BLER is configurable, see "Error Ratio Calculation". By default the following formula is used:
    BLER = (NACK + DTX) / (ACK + NACK + DTX)
  • "Throughput":
    Throughput calculated from the number of acknowledged DL bits, divided by the time.
    –"Max. poss." value: Maximum reachable throughput, assuming that all downlink transmissions are acknowledged.
    –"Average" absolute value: Average throughput since the start of the measurement.
    –"Average" relative value: Average throughput as percentage of the maximum reachable throughput.
  • "Samples":
    This value indicates the number of already sent DL transmissions.
