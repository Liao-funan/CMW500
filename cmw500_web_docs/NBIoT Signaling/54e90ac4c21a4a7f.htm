CONFigure:NIOT:SIGN<i>:CELL:SCSPacing <SubCarrSpacing>

Selects the uplink subcarrier spacing.

Parameters:
<SubCarrSpacing>
S3K75 | S15K

S3K75: 3.75 kHz

S15K: 15 kHz

*RST:S15K
Example: 

See "Configuring Physical Cell Setup"

Firmware/Software: 

V3.7.20, V3.7.30 added S3K75
