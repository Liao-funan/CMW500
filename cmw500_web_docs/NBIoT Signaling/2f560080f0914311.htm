SENSe:NIOT:SIGN<i>:UL:ADPower:EFNPower<format>?

Queries the expected NPUSCH power, for the NPUSCH formats 1 and 2.

Suffix: 
<format>
1, 2
Return values: 
<ExpectedPower>
Default unit: dBm
