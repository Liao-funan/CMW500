User-Defined Scheduling

In addition to RMCs required by conformance tests, the signaling application supports flexibly configurable user-defined scheduling.

The signaling application sends a UL grant or a DL grant to the UE at each possible search space occasion. A configurable pattern defines the sequence of grants (UL grants only, DL grants only, alternating UL/DL grants, no grants at all).

The granted scheduling is defined via a set of parameters:
  • Number of subcarriers
  • Position of the first subcarrier
  • MCS index, determining the modulation scheme and the transport block size
  • Number of DL subframes or UL resource units
  • Number of repetitions

The parameter combinations supported by the R&S CMW are described in the following sections. The UL settings apply to NPUSCH format 1. The parameters for NPUSCH format 2 are not configurable. They are identical to the NPUSCH format 2 values for RMCs, see Table "UL RMC parameters, NPUSCH format 2".

Repetitions
User-defined scheduling supports the following numbers of repetitions:
  • UL: 1, 2, 4
  • DL: 1, 2, 4, 8
