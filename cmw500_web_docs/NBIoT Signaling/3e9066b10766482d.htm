CONFigure:NIOT:SIGN<i>:RFSettings:FOFFset:DL <Offset>
CONFigure:NIOT:SIGN<i>:RFSettings:FOFFset:UL <Offset>

Specifies a positive or negative frequency offset to be added to the center frequency of the configured DL or UL channel.

Parameters:
<Offset>
Range: -100E+3 Hz  to  100E+3 Hz
*RST:0 Hz
Default unit: Hz
