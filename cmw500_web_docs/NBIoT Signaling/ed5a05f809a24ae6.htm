CONFigure:NIOT:SIGN<i>:UL:ADPower:PIRPower <TargetPower>

Specifies the "preambleInitialReceivedTargetPower" value, signaled to the UE if advanced UL power configuration applies.

Parameters:
<TargetPower>
Range: -120 dBm  to  -90 dBm
Increment: 2 dB
*RST:-104 dBm
Default unit: dBm
