FETCh:NIOT:SIGN<i>:PSWitched:STATe?

Queries the PS state, see also "Connection States".

Return values: 
<PS State>
OFF | ON | ATTached | CESTablished | DISConnect | CONNecting | SIGNaling

OFF: signal off

ON: signal on

ATTached: UE attached

CESTablished: connection established

DISConnect: disconnect in progress

CONNecting: connection setup in progress

SIGNaling: signaling in progress

*RST:OFF
Example: 

See "Setting Up a Connection"

Usage: Query only

V3.7.20
