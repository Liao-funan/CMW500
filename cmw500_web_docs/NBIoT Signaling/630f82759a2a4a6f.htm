CONFigure:NIOT:SIGN<i>:CONNection:UDEFined:DL:MCSindex?

Queries the configured MCS index and the resulting modulation scheme and transport block size for DL user-defined scheduling, see "User-Defined Scheduling".

Return values: 
<MCSindex>
MI0 | MI1 | MI2 | MI3 | MI4 | MI5 | MI6 | MI7 | MI8 | MI9 | MI10 | MI11 | MI12

MCS index value

<Modulation>
QPSK

Modulation scheme

<TransBlockSize>

Transport block size

Example: 

See "Configuring User-Defined Channels"

Usage: Query only
Firmware/Software: 

V3.7.20

Manual operation: See "MCS Index"
