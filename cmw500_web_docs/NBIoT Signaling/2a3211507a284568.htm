CONFigure:NIOT:SIGN<i>:CONNection:RMC:DL:MCSindex?

Queries the configured MCS index and the resulting modulation scheme and transport block size for the scheduling type DL RMC, see "Scheduling Type DL RMC".

Return values: 
<MCSindex>
MI6

MCS index value

<Modulation>
QPSK

Modulation scheme

<TransBlockSize>

Transport block size

Example: 

See "Configuring DL RMCs"

Usage: Query only
Firmware/Software: 

V3.7.20

Manual operation: See "MCS Index"
