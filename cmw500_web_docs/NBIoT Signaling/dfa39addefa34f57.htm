CONFigure:NIOT:SIGN<i>:CONNection:TMODe <Enable>

Specifies whether the UE is forced into a test mode. If enabled, the message "ACTIVATE TEST MODE" is sent to the UE.

Parameters:
<Enable>
OFF | ON
*RST:ON
