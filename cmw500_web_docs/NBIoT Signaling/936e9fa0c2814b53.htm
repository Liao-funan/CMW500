SENSe:NIOT:SIGN<i>:UECapability:TRANsfer:RF:POWClass?

Returns whether the UE supports a power class with 20 dBm.

The information is returned per supported band. The values have the same order as the bands returned by the command SENSe:​NIOT:​SIGN<i>:​UECapability:​TRANsfer:​RF:​BANDs?.

Return values: 
<PowerClass>
NO | YES

Comma-separated list of values, one value per supported band

Usage: Query only
Firmware/Software: 

V3.7.20

Manual operation: See "Supported Bands"
