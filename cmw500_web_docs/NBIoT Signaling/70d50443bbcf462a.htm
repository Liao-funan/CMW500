CONFigure:NIOT:SIGN<i>:CELL:IBGBand:IBCPosition <IBCarrPos>

Specifies the number of the LTE RB located at the NB-IoT channel position, for the in-band operation mode.

Only specific values within the stated range are allowed, depending on the LTE channel BW, see Table "LTE RB indices allowed for NB-IoT in-band operation, depending on LTE cell BW".

Parameters:
<IBCarrPos>
Range: 2  to  95
*RST:4
