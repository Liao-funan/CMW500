Scheduling Type DL RMC

DL reference measurement channels are intended for DL RF tests, specified in 3GPP TS 36.521, chapter 7 and 8. You can use them for BLER measurements.

The DL RMCs are defined in 3GPP TS 36.521, table A.3.2-1c/1ca. The signaling application uses the DL scheduling patterns defined there. A pattern determines which subframes are scheduled.

In the signaling application, a DL RMC can be defined via the following set of parameters:
  • Number of subcarriers (no of SC)
  • Position of the first subcarrier (start SC)
  • MCS index, determining the modulation scheme and the transport block size
  • Number of subframes (no of SF)
  • Number of repetitions
