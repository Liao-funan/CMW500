What's New in This Version

This documentation describes version 3.7.30 and later of the NB-IoT signaling application. Compared to version 3.7.20, it provides the following new features and changes:

  • In-band operation and guard-band operation, see "Operation Modes"
  • Support of data application mode for tests with DAU, see "Data Tests"
  • UL subcarrier spacing 3.75 kHz, see "UL Subcarrier Spacing"
  • Configurable timers, see "Timer Settings"
  • Configurable power-saving mode (PSM), see "PSM Allowed"
  • Configurable eDRX, see "eDRX (Idle Mode)"
  • Configurable NPRACH settings, see "NPRACH"
  • User-defined scheduling pattern without any grants, see "Pattern"
  • Connection state enhancements, see "Connection States"
    –RRC connection can be released after attach, see "Keep RRC Connection"
    –Hotkeys for RRC connection setup/release, see "Connection control hotkeys"
  • Support of LTE bands 4, 7, 9, 10, 14, 22, 24, 27, 30, 65, 68, see "Operating Bands"
  • Authentication and security can be disabled, see "Security Settings"
  • Configurable AWGN, see "Downlink Power Levels"
  • BLER samples: enhanced range and modified default value, see "No. of Samples"
  • Configurable logging, see "Debug Configuration"
