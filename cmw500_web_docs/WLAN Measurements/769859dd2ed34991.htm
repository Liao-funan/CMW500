V3.2.20 (Compared to V3.2.11)
New features:
  • IEEE 802.11ac SISO signals with 160 MHz contiguous channel (requires option R&S CMW-KM656):
    –Multiple simultaneous measurements: EVM vs. symbol, I/Q constellation, spectrum flatness, transmit spectrum mask, occupied bandwidth, TX measurement (scalar)
    –Limit checks for transmitter constellation error, transmit center frequency error, symbol clock frequency error, spectrum flatness and transmit spectrum mask, see "Limit Settings"
  • Spectral flatness: modified default limits for IEEE 802.11a/g/n according to standard IEEE 802.11-2012, see "Spectrum Flatness Limits OFDM"
  • Transmit spectral mask: independent mask definitions for IEEE 802.11n in 2.4 GHz and 5 GHz band with defaults according to standard IEEE 802.11-2012, see "Transmit Spectrum Mask OFDM, Default Masks"
  • New bandwidth-suffixed limit configuration commands for IEEE 802.11ac SISO supersede their bandwidth-specific predecessors, see "Spectrum Flatness Limits: 802.11ac" and "Transmit Spectrum Mask Limits: 802.11ac"
  • "Generator Shortcut"
