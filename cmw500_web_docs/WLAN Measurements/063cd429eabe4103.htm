Measurement Scope for R&S CMW100/CMW with MUA
OFDM / OFDMA signals

For OFDM / OFDMA signals, you can configure the number of PSDU symbols to be measured. The preamble/header is not measured.

If the PSDU is shorter than the configured number of symbols, the available PSDU symbols are measured.

DSSS signals

For DSSS signals, you can configure the number of PSDU chips to be measured. You can also measure the preamble and header, or skip them.

If the PSDU is shorter than the configured number of chips, the available PSDU chips are measured.

The first 26 chips of the burst and the last 26 chips of the burst are never measured.
