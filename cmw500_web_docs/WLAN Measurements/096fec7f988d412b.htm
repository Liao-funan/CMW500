Return the X-positions of the limit line margins of the transmit spectrum mask, for MIMO measurements, antenna/stream number <n>, bandwidths with one segment.

Positions for the current, average, minimum and maximum traces are returned.

The values described below are returned by FETCh and READ commands. CALCulate commands return limit check results instead, one value for each result listed below.

Suffix: 
<n>
1..8
Return values: 
<Reliability>

"Reliability Indicator"

<OutOfTol>

Out of tolerance result

Range: 0 % to 100 %
Default unit: %
<Margin_AB> ... <Margin_BA>

Comma-separated list of frequencies, one value per margin

The number of margins equals the number of spectrum mask areas and depends on the selected standard, see Table "Spectrum mask areas".

Range: -40E+6 Hz  to  40E+6 Hz
Default unit: Hz
Example: 

See "Performing Single-Shot Measurements (OFDM, CMIMO)"

Usage: Query only
Firmware/Software: 

V3.5.121

For additional information concerning syntax elements and returned values, refer to "Conventions and General Information".
