Trace Sub-Arrays

The optional query parameters <Start>, <Count> and <Decimation> can be used to limit the value array that is returned by a "TRACe" command:

  1. Limit the returned array to the segment beginning with position <Start>.

  2. If necessary, further limit the segment to <Count> values.

  3. If necessary, further decimate the segment <Start> ... <Start>+<Count>-1 by returning only every nth value (<Decimation> = n)

Example: 

FETCh:<FWA>:MEAS:MEV:TRACe:xx? 100, 10, 3 returns every 3rd value of the 10 values beginning with the 100th one.
