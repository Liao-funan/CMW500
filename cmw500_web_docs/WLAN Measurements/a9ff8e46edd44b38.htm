V1.0.10.50 (Compared to V1.0.10.1)
New features:
  • Measuring IEEE 802.11n signals
  • Trigger settings
  • Traces for EVM (vs. subcarrier, vs. symbol, vs. chip)
  • I/Q constellation diagram
  • List mode
  • Enabling/disabling measurements and views
  • Configurable tracking (phase, timing, level)
  • Configurable channel estimation (preamble or payload)
  • EVM vs. chip values now always RMS averaged, no peak values (was configurable)
  • Group command for result enabling (CONFigure:WLAN:MEAS<i>:MEValuation:RESult)
