V2.1.30 (Compared to V2.1.10)
New features:
  • Parallel usage of WLAN measurements and WLAN signaling application (option R&S CMW-KS650/KS651)
  • Configurable position of the secondary relative to the primary 20 MHz RF channel for IEEE 802.11n signals: new command CONFigure:​WLAN:​MEAS<i>:​RFSettings:​FREQuency:​SCHannel
  • New remote commands to set moving average length and reference power for DSSS power measurements: CONFigure:​WLAN:​MEAS<i>:​MEValuation:​PVTime:​ALENgth and CONFigure:​WLAN:​MEAS<i>:​MEValuation:​PVTime:​RPOWer
  • Renamed spectrum mask commands for 20 MHz IEEE 802.11n signals: "NOFDm" replaced by "NOTWenty"
  • New command to query the last modified date of the last saved training data (*.mif) file: CONFigure:​WLAN:​MEAS<i>:​ISIGnal:​TDATa:​FILE:​DATE?
  • "Out of tolerance percentage" added to power vs. time statistical results
