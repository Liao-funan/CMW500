V3.5.20 (Compared to V3.5.10)
New features:
  • 802.11ac SISO: support for 1024-QAM signals
  • 802.11b/g DSSS: transmit filter estimation can be configured, see "DSSS Tx Filter Estimation"
  • New remote commands FETCh|READ:WLAN:MEAS<i>:MEValuation:TRACe:TSMask:FREQuency|MASK return the transmit spectrum mask limit line for the active standard (FREQuency: X axis; MASK: Y axis)
