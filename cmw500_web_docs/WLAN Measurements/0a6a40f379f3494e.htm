V2.1.10 (Compared to V2.0.10)
New features:
  • Power vs. time measurement, see "Views Power vs. Time"
  • Transmit spectrum mask limits for 802.11n SISO 40 MHz channels, see "View Transmit Spectrum Mask"
  • Terminology: "CMIMO" (composite MIMO) replaces "MISO" for 802.11n measurements
  • Training mode and training data handling for 802.11n CMIMO measurements, see "Composite MIMO Measurements"
  • Statistical results for OFDM spectrum flatness, see:
    –"Spectrum Flatness Margin Values"
    –"Spectrum Flatness Margin Positions"
