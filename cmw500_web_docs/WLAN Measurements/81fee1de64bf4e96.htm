CONFigure:WLAN:MEAS<i>:MEValuation:LIST <ListModeState>

Enables or disables the list mode.

Parameters:
<ListModeState>
OFF | ON

OFF: Disable list mode

ON: Enable list mode

*RST:OFF

See "Using WLAN List Mode"
