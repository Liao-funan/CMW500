FETCh:WLAN:MEAS<i>:MEValuation:SINFo:VHTSig:PAID?

Queries the value of Partial AID field signaled in very high throughput signal field for IEEE 802.11ac signal (VHT-SIG).

For the filed NSTS refer to:

<value_dec>
