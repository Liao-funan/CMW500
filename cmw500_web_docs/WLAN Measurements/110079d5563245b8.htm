CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:PVTime:TERRor <TimingError>

Sets the upper limit for timing error.

Parameters:
<TimingError>
Range: 0 s to 100E-6 s
Default unit: s

Additional parameters: OFF | ON (disables the limit check | enables the limit check using the previous limit values)
