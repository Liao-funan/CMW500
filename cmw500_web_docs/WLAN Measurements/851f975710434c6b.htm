ROUTe:WLAN:MEAS<i>:SMIMo?

Returns the configured routing settings for the switched MIMO scenario.

For connector and converter values, see "Values for RF Path Selection".

Return values: 
<Scenario>
SMI4 | MIMO2x2 | MIMO4x4 | MIMO8x8

SMI4: Switched MIMO 4xn (R&S CMW500/2xx with BB Meas with two basic frontends)

MIMO2x2: Switched MIMO 2x2 (R&S CMW100)

MIMO4x4: Switched MIMO 4x4 (R&S CMW100)

MIMO8x8: Switched MIMO 8x8 (R&S CMW100)

<Controller>
