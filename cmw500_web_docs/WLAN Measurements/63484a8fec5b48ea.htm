CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:TSMask:POFDm:BW<bandwidth>:CA:Y:B <TSMLimYRelLevB>

Defines the Y-value of point B (Δf = 1.5 <bandwidth>) on the IEEE 802.11p spectrum mask for power class A and the specified <bandwidth>. For background information, see "Transmit Spectrum Mask OFDM, by Regulation".

Suffix: 
<bandwidth>
5, 10, 20
Parameters:
<TSMLimYRelLevB>
Range: -90 dB  to  10 dB
*RST:-40 dB
Default unit: dB
Example: 

See "Specifying Transmit Spectrum Masks (OFDM)"

Firmware/Software: 

V3.7.10
