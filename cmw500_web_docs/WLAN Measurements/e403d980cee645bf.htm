CONFigure:WLAN:MEAS<i>:RFSettings:MLOFfset <MLOffset>

Varies the input level of the mixer in the analyzer path.

For the combined signal path scenario, use CONFigure:​WLAN:​SIGN<i>:​RFSettings:​MLOFfset.

Parameters:
<MLOffset>
Range: -10 dB to 10 dB, for R&S CMW with TRX160: -10 dB to 16 dB
*RST:8 dB, for R&S CMW with TRX160: 12 dB
Default unit: dB

See "Specifying General Measurement Settings"

Manual operation: See "Mixer Level Offset"
