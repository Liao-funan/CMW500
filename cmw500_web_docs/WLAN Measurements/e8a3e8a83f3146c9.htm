Transmit Spectrum Mask Limits: 802.11p OFDM

The following commands define and enable the relative and absolute transmit spectrum masks for 802.11p OFDM signals.

The CONFigure:​WLAN:​MEAS<i>:​MEValuation:​TSMask:​MSELection switch determines whether relative or absolute limits are used. The applicable relative limits are determined by the DUT's power class (CONFigure:​WLAN:​MEAS<i>:​ISIGnal:​PCLass).
