TRIGger:WLAN:MEAS<i>:MEValuation:CATalog:SOURce? [<fullList>]

Lists all trigger source values that can be set using TRIGger:​WLAN:​MEAS<i>:​MEValuation:​SOURce.

Query parameters: 
<fullList>
OFF | ON

Disables/ enables full list including also invalid trigger sources.

Return values: 
<TrigSource>

Comma-separated list of all supported values. Each value is represented as a string.

Usage: Query only
Firmware/Software: 

V1.0.10.50

Manual operation: See "Trigger Source"
