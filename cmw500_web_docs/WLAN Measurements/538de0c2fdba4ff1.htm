Trigger Modes
The WLAN multi-evaluation measurement can be performed in the following trigger modes:
  • "Free Run": The measurement starts immediately after it is initiated.
    This mode is not supported by the R&S CMW100/CMW with MUA. The R&S CMW500/2xx with BB Meas supports this mode for IEEE 802.11a/b/g/n SISO measurements.
    Using another trigger source makes synchronization easier and generally speeds up the measurement.
  • "IF Power": With an internal IF power trigger, the measurement is triggered by the power ramp of the received WLAN bursts.
  • "External Trigger": External trigger signal fed in via the rear panel of the instrument. The availability of a trigger input connector depends on the instrument model.
  • Additional trigger modes: Other firmware applications, for example the WLAN signaling application or the GPRF generator provide additional trigger modes. Refer to the documentation of the corresponding firmware application for a description of these trigger modes.

For configuration, see "Trigger Settings".
