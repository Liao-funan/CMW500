Modulation Single Values, OFDM

The commands in this section return the statistical modulation results for OFDM signals.

The commands ...:MODulation:CURRent/... query results that are antenna-independent, stream-independent and segment-independent.

For switched MIMO results per antenna/stream, use the commands with MIMO<n> mnemonic. For results per segment (80+80 MHz signals), use the commands with SEGMents mnemonic.

For composite MIMO results, use the CMIMo commands.

See also:
  • "View TX Measurement (Scalar) for OFDM SISO"
  • "View TX Measurement (Scalar) for CMIMO (802.11n, ac)"
  • "View TX Measurement (Scalar) for SMIMO (802.11n, ac, ax)"
