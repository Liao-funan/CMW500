V3.5.121 (Compared to V3.5.120)
New features, all R&S CMW models:
  • Spectrum flatness limits for 80+80 MHz signals independent of 80 MHz limits and 160 MHz limits, see "Spectrum Flatness Limits OFDM"
  • Additional I/Q offset limits for IEEE 802.11n, see "Modulation Limits 802.11n"
  • Additional I/Q offset limits for IEEE 802.11ac, see "Modulation Limits 802.11ac"
  • Redesign of some result query commands. Standard-specific commands are replaced by standard-independent commands. The old commands are still available as alias. Changes:
    –EVM vs. carrier results:
    ...:EVM:CARRier:... replaces ...:EVM:OFDM/NSISo:CARRier:...
    See "EVM Versus Carrier Traces"
    –Modulation single values OFDM:
    Old: ...:MODulation:OFDM/ACSiso/SMIMo:...
    New: ...:MODulation:... and ...:MODulation:MIMO<n>:... and ...:MODulation:SEGMents:... and ...:MODulation:MIMO<n>:SEGMents:...
    See "Modulation Single Values, OFDM"
    –Transmit spectrum mask single values:
    Old: ...:TSMask:OFDM/NSISo/ACSiso/DSSS:...
    New: ...:TSMask:...
    See "Transmit Spectrum Mask Margin Values"
  • Additional minimum results (command only, no GUI), see:
    –"Modulation Single Values, DSSS"
    –"Transmit Spectrum Mask Traces"
  • Commands for results per segment (80+80 MHz), see:
    –"Transmit Spectrum Mask Traces"
    –"Transmit Spectrum Mask Limit Lines"
    –"Transmit Spectrum Mask Margin Values"
    –"Transmit Spectrum Mask Margin Positions"
    –"Transmit Spectrum OBW Results"
New features, R&S CMW100 only:
  • Improved evaluation length configuration, see "Evaluation Length"
  • Free run trigger source no longer supported
  • Configurable channel distance for 80+80 MHz signals, see "Ch. Distance"
  • Support of separate RF connectors for the two segments of 80+80 MHz signals, see "Use Sep. Ant. for 80+80 MHz"
  • Configurable assignment of DUT antennas to RF connectors for switched MIMO, see "Scenario = MIMO 2x2 / MIMO 4x4 / MIMO 8x8"
  • The gain imbalance and the quadrature error can also be measured for IEEE 802.11ac, see "View TX Measurement (Scalar) for OFDM SISO"
  • The power vs time can also be measured for IEEE 802.11ac (up to 40 MHz BW), see "Views Power vs. Time"
  • The EVM vs carrier can also be measured for IEEE 802.11ac (up to 40 MHz BW), see "View Error Vector Magnitude (EVM)"
  • More SMIMO results per antenna: peak burst power, crest factor, DC power, gain imbalance, quadrature error, power backoff, modulation scheme, see "View TX Measurement (Scalar) for SMIMO (802.11n, ac, ax)"
  • More OFDM SISO results: number of measured OFDM symbols, payload bytes, peak burst power, crest factor, DC power, power backoff, see "View TX Measurement (Scalar) for OFDM SISO"
  • ARIB transmit spectrum mask, see "Transmit Spectrum Mask OFDM, Absolute Limits"
  • MIMO 8x8 scenario for 802.11ac signals, see "Scenario = MIMO 2x2 / MIMO 4x4 / MIMO 8x8"
  • Transmit spectrum mask measurement supported for MIMO (no GUI, only remote control commands), see:
    –"Transmit Spectrum Mask Traces"
    –"Transmit Spectrum Mask Limit Lines"
    –"Transmit Spectrum Mask Margin Values"
    –"Transmit Spectrum Mask Margin Positions"
    –"Transmit Spectrum OBW Results"
