V2.0.10 (Compared to V1.0.15.20)
New features:
  • "802.11n MISO" measurement: composite measurement of MIMO 802.11n signals (multiple-input / multiple-output, option R&S CMW-KM652 required)
  • Remote commands for configuration of spectrum flatness limits, see:
    –"Spectrum Flatness Limits: 802.11a/g OFDM"
    –"Spectrum Flatness Limits: 802.11n"
  • Configurable measurement timeout for remote control (CONFigure:​WLAN:​MEAS<i>:​MEValuation:​TOUT)
  • Additional commands for query of routing settings: ROUTe:​WLAN:​MEAS<i>:​SCENario? and ROUTe:​WLAN:​MEAS<i>?
  • Optimized remote commands:
    –ROUTe:​WLAN:​MEAS<i>:​SCENario:​SALone: selection of RF 3 and RF 4 connectors modified, RX module selectable
    –Alias ROUTe:WLAN:MEAS<i>:RFSettings:CONNector no longer supported
    –CONFigure:WLAN:MEAS<i>:ISIGnal:BWIDth (old: CONFigure:WLAN:MEAS<i>:ISIGnal:NOFDm:BWIDth)
    –CONFigure:WLAN:MEAS<i>:ISIGnal:BTYPe (old: CONFigure:WLAN:MEAS<i>:ISIGnal:BTYPe:NOFDm)
    –CONFigure:WLAN:MEAS<i>:ISIGnal:ELENgth (old: CONFigure:WLAN:MEAS<i>:ISIGnal:ELENgth[:DSSS])
    –FETCh:WLAN:MEAS<i>:MEValuation:TRACe:IQConst:QUADrature? (old: ...:IQConst:OFDM:QUADrature? and ...:IQConst:DSSS:QUADrature?), same for READ:...
    –FETCh:WLAN:MEAS<i>:MEValuation:TRACe:IQConst:INPHase? (old: ...:IQConst:OFDM:INPHase? and ...:IQConst:DSSS:INPHase?), same for READ:...
