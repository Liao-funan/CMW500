CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:HTOFdm:SCERror <ClockError>

Defines and activates an upper limit for the symbol clock error (802.11n).

Parameters:
<ClockError>
Range: 0 ppm  to  100 ppm
*RST:25 ppm
Default unit: ppm

Additional parameters: OFF | ON (disables | enables the limit check)

Example: 

See "Specifying Modulation Limits (OFDM)"

Firmware/Software: 

V3.5.121, V3.7.20: range extended

Options: R&S CMW-KM651
