Multi-Evaluation List Mode

In multi-evaluation list mode (MELM, enabled by option R&S CMW-KM012), the measurement interval can be subdivided into multiple segments, each with different basic input signal properties. The list mode can be used to measure different signal types supported by a DUT, in a single measurement.

The MELM for WLAN measurements supports modulation accuracy and transmit spectrum mask measurements. Segments can differ in the underlying standard, burst type and modulation.

  • MELM for WLAN measurements is only available on an R&S CMW500/2xx with BB Meas.
  • MELM is only available for standards IEEE 802.11a, b, g, and n. The remaining standards are not supported.
  • MELM for WLAN measurements is limited to SISO signals with 20 MHz bandwidth.
