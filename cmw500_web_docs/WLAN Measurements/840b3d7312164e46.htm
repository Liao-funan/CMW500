CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:DSSS:CFERror <FreqError>

Defines and activates an upper limit for the center frequency error (transmission scheme DSSS).

Parameters:
<FreqError>
Range: 0 Hz  to  100E+6 Hz
*RST:60000 Hz
Default unit: Hz

Additional parameters: OFF | ON (disables | enables the limit check)

Example: 

See "Specifying Limits (DSSS)"
