Overview

In the overview, a selection of the results can be displayed for SISO measurements. For MIMO measurements, there is only the "TX Measurement (Scalar)" view and for that reason no overview.

See also: "TX Measurements"

Overview

The results to be evaluated and displayed in the overview can be limited using the hotkey "Assign Views" (softkey "Multi Evaluation").

You can enlarge one of the diagrams in the overview and show a detailed view with additional measurement results, see "Selecting and Modifying Views". The traces are described in the following sections.
