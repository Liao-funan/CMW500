Transmit Spectrum Mask Margin Values

The commands in this section return the limit line margin Y-values of the transmit spectrum mask measurement.

For MIMO, use the commands with MIMO<n> mnemonic. For bandwidths with two segments, use the commands with SEGMents mnemonic.

See also "Transmit Spectrum Mask DSSS" and subsequent sections.
