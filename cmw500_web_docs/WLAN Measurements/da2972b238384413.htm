CONFigure:WLAN:MEAS<i>:ISIGnal:STANdard <Standard>

Selects the IEEE 802.11 standard. Several WLAN signal properties depend on the selected standard, see "Physical Layer".

In the combined signal path scenario, selecting a standard that is not supported by the signaling application restores the standalone scenario.

Parameters:
<Standard>
DSSS | LOFDm | HTOFdm | POFDm | VHTofdm | HEOFdm

DSSS: 802.11b/g (DSSS)

LOFDm: 802.11a/g (OFDM)

HTOFdm: 802.11n (requires R&S CMW-KM651)

POFDm: 802.11p (requires R&S CMW-KM655)

VHTofdm: 802.11ac (requires R&S CMW-KM651 and -KM656)

HEOFdm: 802.11ax (R&S CMW with TRX160 only, requires R&S CMW-KM651, -KM656, and -KM657)

*RST:LOFD
Example: 

See "Specifying General Measurement Settings"
