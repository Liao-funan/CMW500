CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:VHTofdm:IQOFfset:BW<BW> <OffsetValue_rel>[, <OffsetValue_abs>]

Defines and activates upper limits for the I/Q origin offset, for 802.11ac and channel bandwidth <BW>.

Suffix: 
<BW>
20, 40, 80, 160, 8080

Channel bandwidth in MHz (8080 means 80+80)

Parameters:
<OffsetValue_rel>

Relative limit

Range: -100 dB  to  0 dB
Default unit: dB

Additional parameters: OFF | ON (disables | enables the limit check)

<OffsetValue_abs>

Absolute limit, only for <BW>=8080

Range: -100 dBm  to  0 dBm
*RST:-20 dBm
Default unit: dBm

Additional parameters: OFF | ON (disables | enables the limit check)

Example: 

See "Specifying Modulation Limits (OFDM)"
