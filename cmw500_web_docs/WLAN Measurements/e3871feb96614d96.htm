CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:HEOFdm:CFERror <CenterFreqError>

Defines and activates an upper limit for the center frequency error in 802.11ax signals.

Parameters:
<CenterFreqError>
ON | OFF
Range: 0 Hz  to  100E+6 Hz
*RST:100E+3 Hz
Default unit: Hz

Additional parameters: OFF | ON (disables | enables the limit check)

Example: 

See "Specifying Modulation Limits (OFDM)"

Firmware/Software: 

V3.7.20

Options: R&S CMW-KM657
