CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:SFLatness:VHTofdm:BW<bandwidth>:ENABle <Enable>

Enables or disables the spectrum flatness limit check for 802.11ac signals with the specified <bandwidth>.

Suffix: 
<bandwidth>
20, 40, 80, 160, 8080
Parameters:
<Enable>
ON | OFF
*RST:ON
