CONFigure:WLAN:MEAS<i>:MEValuation:TSMask:MSELection <MaskSelection>

Selects the spectrum limit mask to be applied to 802.11p signals.

See "Transmit Spectrum Mask OFDM, by Regulation"

Parameters:
<MaskSelection>
IEEE | ETSI | ARIB

IEEE: Relative spectral density limits, IEEE 802.11-2012

ETSI: Absolute emission limits, ETSI EN 302 571 V1.1.1 (2008-09)

ARIB: Absolute emission limits, ARIB STD-T109, only for R&S CMW100/CMW with MUA, only for 10 MHz bandwidth

*RST:IEEE
Firmware/Software: 

V3.2.40, V3.5.121 added ARIB

Manual operation: See "Mask Selection"
