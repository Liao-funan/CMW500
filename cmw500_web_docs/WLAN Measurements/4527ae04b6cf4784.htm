V3.2.11 (Compared to V3.2.10)
New features:
  • Occupied bandwidth (OBW) measurement for SISO signals
    –Graphical and tabular presentation of "Spectrum OBW" results in "Transmit Spectrum Mask" view, see "View Transmit Spectrum Mask"
    –Configurable OBW percentage (between 50% and 100% of the overall spectral power)
    –Remote commands to enable OBW measurement, set the percentage and get the results
  • Subarrays for power vs. time, modulation, spectrum flatness and transmit spectrum mask TRACe commands, see "Trace Sub-Arrays"
  • Spectrum flatness view: results table now displays margins instead of statistical overview, see "View Spectrum Flatness"
  • Minimum center frequency decreased from 100 MHz to 70 MHz, see "Band / Channel / Frequency"
  • Extended value range for "Expected Nominal Power"
