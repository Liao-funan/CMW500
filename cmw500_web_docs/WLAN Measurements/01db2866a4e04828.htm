Measurement Results

The results of the WLAN multi-evaluation measurement are displayed in several different views. Use the "Display" parameters to select the views and to change the appearance and contents of the views.

Which views are available depends on the WLAN standard, the receive mode (SISO / MIMO) and the instrument model, as listed in the following table.
