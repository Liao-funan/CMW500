WLAN Measurements > Command Reference > Combined Signal Path Commands > Signaling Commands for Multi-Evaluation Measurement Settings > CONFigure:WLAN:SIGN<i>:RFSettings:OCWidth
CONFigure:WLAN:SIGN<i>:RFSettings:OCWidth <Value>

Sets the operating channel bandwidth.

Parameters:
<Value>
BW20 | BW40 | BW80 | BW160

BW20: 20 MHz

BW40: 40 MHz

BW80: 80 MHz

BW160: 160 MHz (only R&S CMW with TRX160)

*RST:BW20
Firmware/Software: 

V3.5.120, V3.7.20: added BW80, V3.7.30: added BW160

Options: R&S CMW-KS656 for BW80 and BW160
