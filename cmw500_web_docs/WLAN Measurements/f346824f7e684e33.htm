V3.5.30 (Compared to V3.5.20)
New features, R&S CMW100 only:
  • First software version supporting R&S CMW100
  • IEEE 802.11ac MIMO signals
    –Channel widths 20 MHz, 40 MHz, 80 MHz, 80+80 MHz and 160 MHz
    –Switched and composite measurements
    –2x2 and 4x4 MIMO scenarios
New features, all R&S CMW models:
  • Selection of WLAN standard and receive mode now separated, see "WLAN Input Signal Settings"
  • Possibility to exclude a configurable number of heading and tailing OFDM symbols from modulation measurements, see "Skip OFDM Symbols"
