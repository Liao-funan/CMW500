V3.7.10 (Compared to V3.5.121)
New features, all R&S CMW models:
  • User-defined transmit spectrum mask for IEEE 802.11p signals, selectable via power class "User Defined", see:
    –"Transmit Spectrum Mask OFDM, by Regulation"
    –"Power Class"
  • Connector-specific attenuation for switched MIMO, see "External Attenuation / Ext. Att."
  • Additional reliability values 70 to 78 (R&S CMW100 only), see "Reliability Indicator"
  • Timing drift tracking is activated by default, see "Tracking"
  • Default value of trigger threshold changed, see "Trigger Threshold"
  • Redesign of some limit commands. The old commands are still available as alias. Changes:
    –Old: ...:LIMit:SFLatness:OFDM:...
    New: ...:LIMit:SFLatness:LOFDm:...
    See "Spectrum Flatness Limits: 802.11a/g OFDM"
    –Old: ...:LIMit:SFLatness:POFDm<BW>:...
    New: ...:LIMit:SFLatness:POFDm:BW<bandwidth>:...
    See "Spectrum Flatness Limits: 802.11p OFDM"
    –Old: ...:LIMit:SFLatness:NSTWenty/NSForty:...
    New: ...:LIMit:SFLatness:HTOFdm:BW<bandwidth>:...
    See "Spectrum Flatness Limits: 802.11n"
    –Old: ...:LIMit:SFLatness:AC<BW>:...
    New: ...:LIMit:SFLatness:VHTofdm:BW<bandwidth>:...
    Commands are also enhanced for bandwidth 80+80.
    See "Spectrum Flatness Limits: 802.11ac"
    –Old: ...:LIMit:TSMask:OFDM:...
    New: ...:LIMit:TSMask:LOFDm:...
    See "Transmit Spectrum Mask Limits: 802.11a/g OFDM"
    –Old: ...:LIMit:TSMask:POFDm<BW>:...
    New: ...:LIMit:TSMask:POFDm:BW<bandwidth>:...
    See "Transmit Spectrum Mask Limits: 802.11p OFDM"
    –Old: ...:LIMit:TSMask:NSTWenty/NSForty:...
    New: ...:LIMit:TSMask:HTOFdm:BW<bandwidth>:...
    See "Transmit Spectrum Mask Limits: 802.11n"
    –Old: ...:LIMit:TSMask:AC<BW>:...
    New: ...:LIMit:TSMask:VHTofdm:BW<bandwidth>:...
    Commands are also enhanced for bandwidth 80+80.
    See "Transmit Spectrum Mask Limits: 802.11ac"
