CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:LOFDm:EVM <EVM6M>, <EVM9M>, <EVM12M>, <EVM18M>, <EVM24M>, <EVM36M>, <EVM48M>, <EVM54M>

Defines and activates upper limits for the error vector magnitude (EVM) of the data carriers (802.11a/g, OFDM).

Parameters:

Range: -100 dB  to  0 dB
*RST:-5 dB
Default unit: dB

Additional parameters: OFF | ON (disables | enables the limit check)
