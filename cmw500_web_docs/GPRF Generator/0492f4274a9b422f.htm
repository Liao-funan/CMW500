SOURce:GPRF:GEN<i>:LIST:ESINgle

Starts a single generator cycle through the frequency/level list.

This command is available only if:
  • The list mode is enabled (see SOURce:​GPRF:​GEN<i>:​LIST).
  • And the "Single" list mode is set (SOURce:​GPRF:​GEN<i>:​LIST:​REPetition).
  • And the increment "Dwell Time" is set (SOURce:​GPRF:​GEN<i>:​LIST:​INCRement).
Example: 

See "Using the Arbitrary Mode"

The active list index can be queried using SOURce:​GPRF:​GEN<i>:​LIST:​AINDex?.
