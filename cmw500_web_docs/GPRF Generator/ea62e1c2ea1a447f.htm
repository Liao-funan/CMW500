V1.0.15.0 (Compared to V1.0.10.1)
New features:
  • ARB generator: Processing time can be extended by a specific number of samples. See "Basic Settings".
  • ARB generator: Various marker signals can be used as output trigger signals (waveform marker 2, 3, 4, restart marker, user-defined marker). Delay times for waveform markers and restart marker. See "Marker Delay Settings".
  • ARB generator: Automatic trigger for multi-segment waveform files. The current segment is displayed. See "Trigger Settings".
