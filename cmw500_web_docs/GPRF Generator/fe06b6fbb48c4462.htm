SOURce:GPRF:GEN<i>:LIST:IREPetition:ALL <IndexRepetitions>...

Defines or queries the "Index Repetition" of all frequency/level steps.

Parameters:
<IndexRepetitions>

Comma-separated list of n values, one value per frequency/level step, where n ≤ 2000. The query returns 2000 results.

Range: 1  to  10000
*RST:1
Example: 

See "Using the Generator List Mode"

Firmware/Software: 

V2.0.10, V3.0.12 maximum index repetitions increased to 10000

Manual operation: See "List"
