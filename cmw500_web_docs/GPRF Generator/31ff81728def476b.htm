V1.0.10.1 (Compared to V1.0.4.11)
New features:
  • List mode extensions: Measurement provides initial trigger condition ("List Incr. Enabling") for lists incremented by an ARB file.
  • List mode extensions: Repeated processing of the list with longer first cycle ("Go to Index")
  • ARB generator extensions: repeated processing (SOURce:​GPRF:​GEN<i>:​ARB:​REPetition), query of peak offset value (SOURce:​GPRF:​GEN<i>:​ARB:​POFFset?)
  • Global "Digital Gain" setting
