SOURce:GPRF:GEN<i>:LIST:REPetition <Repetition>

Defines how often the RF generator runs through the list.

Parameters:
<Repetition>
SINGle | CONTinuous

SINGle: The generator runs through the list for a single time. The sequence is triggered via .SOURce:​GPRF:​GEN<i>:​LIST:​ESINgle

CONTinuous: The generator cycles through the list.
