SOURce:GPRF:GEN<i>:LIST:SLISt

This command initiates the list cycling in CONTinuous repetition mode (see SOURce:​GPRF:​GEN<i>:​LIST:​REPetition), for lists incremented by dwell time or ARB file marker (see SOURce:​GPRF:​GEN<i>:​LIST:​INCRement) and with 'Manual' list increment enabling (see SOURce:​GPRF:​GEN<i>:​LIST:​INCRement:​ENABling).

The active list index can be queried using SOURce:​GPRF:​GEN<i>:​LIST:​AINDex?.

Usage: Event
Firmware/Software: 

V3.2.10

Manual operation: See "Additional Softkeys and Hotkeys"
