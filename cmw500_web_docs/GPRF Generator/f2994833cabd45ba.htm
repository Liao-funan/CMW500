V1.0.15.20/21/22 (Compared to V1.0.15.0)
New features:
  • ARB generator: "Segments" dialog shows the "PAR" and "Peak Offset" of multi-segment waveform files. Remote control commands for "Segments" information added. See "Baseband Configuration > ARB > ARB File".
  • ARB generator: Version of loaded waveform file is displayed in the configuration dialog. See "Baseband Configuration > ARB > ARB File".
  • ARB generator: Next segment number is displayed in the configuration dialog. See "Multi-Segment Settings".
  • ARB generator: "Clear List" button in "User Defined Marker" dialog resets the dialog settings. See "User-Defined Marker".
  • List mode: "Restart List" hotkey restarts the list generator at the first frequency/level step. See "List Configuration".
  • List mode: Changed default values, "Mod. On/Off" is enabled for all frequency/level steps. See "List".
