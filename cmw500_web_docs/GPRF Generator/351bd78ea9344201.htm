SOURce:GPRF:GEN<i>:DTONe:RATio <Ratio>

Sets the base RMS level of the constant-frequency RF generator.

Parameters:
<Ratio>
Range: 0 dB  to  30 dB
Increment: 0.01 dB
*RST:0 dB
Default unit: dB
Example: 

See "Generating a Dual-Tone Signal"

Firmware/Software: 

V1.0.0.4
