TRIGger:GPRF:GEN<i>:ARB:SOURce <Source>

Selects the source of the trigger events. Some values are always available in this firmware application. They are listed below. Depending on the installed options, additional values can be available. A complete list of all supported values can be displayed using TRIGger:​GPRF:​GEN<i>:​ARB:​CATalog:​SOURce?.

Parameters:
<Source>
"Manual"

Manual trigger via GPRF generator GUI

"Base1: Cont.10ms Trigger"

Periodical trigger signal with a trigger pulse every 10 ms

"Base1: User Trigger 1", "Base1: User Trigger 2"

TRIGger:BASE:UINitiated<n>:EXECute

*RST:"Manual"
Firmware/Software: 

V1.0.15.20

Manual operation: See "Baseband > ARB > Trigger > Source"
