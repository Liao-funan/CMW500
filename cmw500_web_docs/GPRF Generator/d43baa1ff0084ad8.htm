GPRF Generator > Command Reference > List Mode Settings > SOURce:GPRF:GEN<i>:LIST:IREPetition
SOURce:GPRF:GEN<i>:LIST:IREPetition <Index>, <Repetition>
SOURce:GPRF:GEN<i>:LIST:IREPetition? <Index>

Defines or queries the "Index Repetition" of a selected frequency/level step.

Parameters:
<Repetition>

Repetition of the frequency/level step

Range: 1  to  10E+3
*RST:1
Parameters for setting and query: 
<Index>

Number of the frequency/level step in the table

Range: 0  to  1999
*RST:n/a
Example: 

See "Using the Generator List Mode"

Firmware/Software: 

V2.0.10, V3.0.12 maximum value increased from 1999 to 10000

Manual operation: See "List"
