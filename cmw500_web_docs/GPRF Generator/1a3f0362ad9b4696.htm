SOURce:GPRF:GEN<i>:ARB:REPetition <Repetition>

Defines how often the ARB file is processed.

Parameters:
<Repetition>
CONTinuous | SINGle

CONTinuous: Unlimited, cyclic processing

SINGle: File is processed n times, where n is the number of cycles (see SOURce:​GPRF:​GEN<i>:​ARB:​CYCLes)

*RST:CONT
Example: 

See "Using the Arbitrary Mode"

Firmware/Software: 

V1.0.10.1

Manual operation: See "Baseband Configuration > ARB > Repetition"
