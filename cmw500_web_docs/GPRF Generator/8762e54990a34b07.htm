SOURce:GPRF:GEN<i>:DTONe:OFRequency<source> <Frequency>

Selects a positive or negative offset frequency. The frequency of the modulated signal is equal to the base frequency (see SOURce:​GPRF:​GEN<i>:​LIST:​FREQuency) plus the offset frequency.

Suffix: 
<source>
1..2

No. of source signal

Parameters:
<Frequency>
Range: -40E+6 Hz  to  40E+6 Hz
*RST:0 Hz
Default unit: Hz
Example: 

See "Generating a Dual-Tone Signal"

Firmware/Software: 

V1.0.0.4

Manual operation: See "Baseband Configuration > Dual Tone > Offset Frequency"
