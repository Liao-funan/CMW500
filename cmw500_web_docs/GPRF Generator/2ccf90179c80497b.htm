SOURce:GPRF:GEN<i>:ARB:MARKer:DELays <Marker2>, <Marker3>, <Marker4>, <RestartMarker>

Defines delay times for the ARB output trigger events relative to the marker events.

Parameters:
<Marker2>
Range: -10  to  4000
*RST:0
<Marker3>
Range: -10  to  4000
*RST:0
<Marker4>
Range: -10  to  4000
*RST:0
<RestartMarker>
Range: 0  to  max. (depending on waveform file)
*RST:0
Example: 

See "Using the Arbitrary Mode"

Firmware/Software: 

V1.0.15.0

Manual operation: See "Baseband > ARB > Marker > Waveform > Marker 2 ..."
