SOURce:GPRF:GEN<i>:RFSettings:FREQuency <Frequency>

Selects the frequency of the RF generator (generator frequency). Some of the baseband modes (modulation types) modify the generator frequency.

Parameters:
<Frequency>
Range: 70E+6 Hz  to  6E+9 Hz
*RST:1.2E+9 Hz
Default unit: Hz
