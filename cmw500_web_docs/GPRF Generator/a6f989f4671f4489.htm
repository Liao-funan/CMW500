SOURce:GPRF:GEN<i>:LIST:RLISt

Restarts the list generator at the first frequency/level step. This command provides a fast alternative to a complete restart of the list generator (turn generator off and on again).

The active list index can be queried using SOURce:​GPRF:​GEN<i>:​LIST:​AINDex?.
