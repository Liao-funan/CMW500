GPRF Generator > Command Reference > List Mode Settings > SOURce:GPRF:GEN<i>:LIST:DGAin
SOURce:GPRF:GEN<i>:LIST:DGAin <Index>, <DigitalGain>
SOURce:GPRF:GEN<i>:LIST:DGAin? <Index>

Defines or queries the digital gain of a selected frequency/level step.

Parameters:
<DigitalGain>

Digital gain at the step

Range: -30 dB  to  0 dB
*RST:0 dB
Default unit: dB
Parameters for setting and query: 
<Index>

Number of the frequency/level step in the table

Range: 0  to  1999
*RST:n/a
Example: 

See "Using the Generator List Mode"

Firmware/Software: 

V1.0.0.4

Manual operation: See "List"
