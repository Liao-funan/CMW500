ROUTe:GPRF:GEN<i>:SCENario:SALone <TXConnector>, <RFConverter>

Activates the standalone scenario and selects the output path for the generated RF signal.

For possible connector and converter values, see "Values for Signal Path Selection".

Parameters:
<TXConnector>

RF connector for the output path

For setups with R&S CMWS, select a connector bench.

<RFConverter>

TX module for the output path

Example: 

See "Generating a CW Signal"

Firmware/Software: 

V2.0.10

Manual operation: See "Scenario and Routing"
