GPRF Generator > Command Reference > List Mode Settings > SOURce:GPRF:GEN<i>:LIST
SOURce:GPRF:GEN<i>:LIST <EnableListMode>

Enables or disables the list mode of the RF generator.

Parameters:
<EnableListMode>
ON | OFF

ON: List mode enabled

OFF: List mode disabled (constant-frequency generator)

*RST:OFF
