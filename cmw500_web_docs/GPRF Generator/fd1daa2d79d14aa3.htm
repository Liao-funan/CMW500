ROUTe:GPRF:GEN<i>:SCENario:IQOut <TXConnector>, <TXConverter>

Activates the "IQ Out" scenario and selects the output path for the generated digital baseband (I/Q) signal.

For possible connector and converter values, see "Values for Signal Path Selection".

Parameters:
<TXConnector>

DIG I/Q output connector

<TXConverter>

I/Q TX module

Firmware/Software: 

V3.0.10

Manual operation: See "Scenario and Routing"
