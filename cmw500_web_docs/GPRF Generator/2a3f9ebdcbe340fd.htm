TRIGger:GPRF:GEN<i>:ARB:CATalog:SOURce?

Lists all available trigger sources, to be set via TRIGger:​GPRF:​GEN<i>:​ARB:​SOURce. The list depends on the installed options.

Return values: 
<TriggerSources>

Comma-separated list of all sources. Each value is a string (e.g. "Manual" for manual trigger).

Usage: Query only
Firmware/Software: 

V1.0.15.20

Manual operation: See "Baseband > ARB > Trigger > Source"
