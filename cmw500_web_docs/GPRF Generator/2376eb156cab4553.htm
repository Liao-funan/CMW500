V2.0.10 (Compared to V1.0.15.20/21/22)
New features:
  • ARB generator: In a multi-segment file, it is possible to jump forth and back to an arbitrary segment. See "Baseband > ARB > Trigger > Multi Segment > Next Segment"
  • ARB generator: New query SOURce:​GPRF:​GEN<i>:​ARB:​SCOunt?, returns the current position in the processed waveform file.
  • List mode: Each frequency/level step can be generated repeatedly; see "List".
  • List mode: Each frequency/level step can be reenabled (retriggered); see "List".
  • RF routing: Command ROUTe:GPRF:GEN<i>:RFSettings:CONNector no longer supported; substituted by ROUTe:​GPRF:​GEN<i>:​SCENario:​SALone. New command ROUTe:​GPRF:​GEN<i>?.
