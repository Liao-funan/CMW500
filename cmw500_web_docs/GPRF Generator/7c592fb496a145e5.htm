SOURce:GPRF:GEN<i>:LIST:INCRement:ENABling <Enabling>

For an internally incremented list, this command defines the initial trigger.

Internally incremented list means "List Increment: GPRF Gen<i>: ... Marker ..." or "List Increment: Dwell Time", see SOURce:​GPRF:​GEN<i>:​LIST:​INCRement.

Parameters:
<Enabling>

String parameter specifying the initial trigger

To generate a complete list of all supported triggers, see SOURce:​GPRF:​GEN<i>:​LIST:​INCRement:​ENABling:​CATalog?.

'Immediate': No initial trigger; list increment starts immediately

'Manual': Waits until SOURce:​GPRF:​GEN<i>:​LIST:​SLISt is executed

'<meas trigger>' (e.g. "GPRF Meas<i>: Power" or "GSM Meas<i>: Multi Evaluation"): Some measurement application provides the initial trigger
