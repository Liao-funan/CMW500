SOURce:GPRF:GEN<i>:ARB:FILE <ARBFile>
SOURce:GPRF:GEN<i>:ARB:FILE? [<PathType>]

Selects a waveform file, to be used for the arbitrary waveform generator (see SOURce:​GPRF:​GEN<i>:​BBMode).

This command supports path aliases (e.g. @WAVEFORM). Use MMEMory:ALIases? to discover the available path aliases.

If the selected file does not exist or no file has been selected yet, a query returns "No File Selected".

If the selected file does exist, a query returns:
  • Without <PathType>: The string that has been used to select the file. If an alias has been used, the alias is not substituted.
  • With <PathType>: The absolute path of the file. If an alias has been used to select the file, the alias is substituted.
Parameters:
<ARBFile>

String parameter, specifies the name of the waveform file to be used (.wv).

Query parameters: 
<PathType>
ABSPath

Optional parameter, specifying that a query returns the absolute path.
