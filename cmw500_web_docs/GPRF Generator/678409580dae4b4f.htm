SOURce:GPRF:GEN<i>:RFSettings:EATTenuation <ExtRFOutAtt>

Defines an external attenuation (or gain, if the value is negative), to be applied to the RF output connector.

Parameters:
<ExtRFOutAtt>
Range: -50 dB  to  90 dB
*RST:0 dB
Default unit: dB
