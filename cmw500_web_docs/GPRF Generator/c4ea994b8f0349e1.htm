SOURce:GPRF:GEN<i>:BBMode <BaseBandMode>

Selects the baseband mode for the generator signal.

Parameters:
<BaseBandMode>
CW | DTONe | ARB

CW: Unmodulated CW signal

DTONe: Dual tone signal (see commands SOURce:GPRF:GEN<i>:DTONe...)

ARB: ARB generator (waveform file; see SOURce:​GPRF:​GEN<i>:​ARB:​FILE)

*RST:CW
Example: 

See "Generating a Dual-Tone Signal"
