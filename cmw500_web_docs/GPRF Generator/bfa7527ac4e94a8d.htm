Generating and Transferring Waveform Files

This application sheet describes the transfer of waveform files (*.wav, ARB files) generated with WinIQSIM2 to an R&S CMW500. Waveform files define digital baseband signals. With software versions V2.04.244.14 and higher, WinIQSIM2 can generate waveform files according to R&S CMW specifications and transfer them to the instrument's hard disk.
