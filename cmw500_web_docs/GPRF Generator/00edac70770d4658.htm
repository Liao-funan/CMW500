Loading and Processing Waveform Files

After transferring the waveform file to the R&S CMW, you can load it using the "General Purpose RF Generator" dialog.

  1. Open the GPRF generator dialog from the task list.

  2. Select "Baseband Mode: ARB".

  3. Press the "ARB > Select ARB File..." hotkey to open a dialog from where you can select an ARB file.

  4. Press "OK".
