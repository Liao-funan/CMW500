SOURce:GPRF:GEN<i>:LIST:GOTO <GoToIndex>

Defines the start index for the second and all following generator cycles in continuous mode (SOURce:​GPRF:​GEN<i>:​LIST:​REPetition). The index must be in the selected list section (SOURce:​GPRF:​GEN<i>:​LIST:​SSTop).

Parameters:
<GoToIndex>
Range: 1  to  2000
*RST:0

See "Using the Generator List Mode"

V1.0.10.1

Manual operation: See "Go to Index"
