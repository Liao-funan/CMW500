Options and Equipment Required

Generation and download of waveform files require an R&S CMW tester which is equipped with the following options:

  • Arbitrary RF generator, option R&S CMW-B110x or R&S CMW-B100H
  • WinIQSIM2 option R&S CMW-KWxxx for the desired technology. For a complete list, refer to the R&S CMW product brochure.

The WinIQSIM2 software is installed on a PC which is connected with the R&S CMW via LAN or another hardware channel. The software does not require any additional hardware to generate the waveform files.

Prerequisites for file transfer
  • To access the hard disk of the R&S CMW from WinIQSIM2 and select a file name and directory, enable a remote desktop connection on the tester.
  • To transfer the generated waveform file via LAN, you have to disable the Windows firewall.

Refer to the R&S CMW help system or to the printable operating manual for more information.
