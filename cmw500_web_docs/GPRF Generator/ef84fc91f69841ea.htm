SOURce:GPRF:GEN<i>:ARB:UDMarker:CLISt

Clears the user-defined marker list, i.e. resets the SOURce:​GPRF:​GEN<i>:​ARB:​UDMarker command and sets the "Period" equal to the number of samples in the loaded waveform file. If no waveform file is loaded, the "Period" is reset to 1.
