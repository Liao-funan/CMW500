SOURce:GPRF:GEN<i>:ARB:ASAMples <AddSamples>

Extends the processing time of a waveform file by the specified number of samples. The additional samples are valid in single-shot repetition mode only (see SOURce:​GPRF:​GEN<i>:​ARB:​REPetition).

Parameters:
<AddSamples>
Range: 0  to  max. (depending on waveform file)
*RST:0
Example: 

See "Using the Arbitrary Mode"

Firmware/Software: 

V1.0.15.0

Manual operation: See "Baseband Configuration > ARB > Repetition"
