Available Waveforms and Options

ARB generator signals are defined by waveform files. The R&S CMW processes a waveform file to generate the ARB signal.

Two types of software options are relevant in this context:
  • R&S CMW-KWxxx:
    To process a waveform file generated via the signal generation software R&S WinIQSIM2, the corresponding R&S CMW-KWxxx option is required.
    Generation of waveform files and their transfer from R&S WinIQSIM2 to the R&S CMW is menu-guided, see "Generating and Transferring Waveform Files".
    For most R&S CMW-KWxxx options, Rohde & Schwarz provides also a library containing some already generated waveform files.
  • R&S CMW-KVxxx:
    Additional waveform libraries are offered as R&S CMW-KVxxx options. Such an option allows you to process all waveform files included in the library. Example: Option R&S CMW-KV634 provides waveforms for the T-DMB standard.

Multi-segment waveform files require the options for all included network standards. For a complete list of options, refer to the "SW/HW Equipment" section in the "Setup" dialog or to the R&S CMW product brochure.

Updates of waveform libraries, additional new waveform libraries and the technical information can be downloaded from the R&S CMW customer web.
