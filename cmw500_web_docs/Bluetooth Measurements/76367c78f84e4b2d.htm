What's New in This Version

This documentation describes version 3.7.40 and later of the "Bluetooth TX Measurement" firmware application. Compared to version 3.7.30, it provides the following new features:

  • BR/EDR measurements in normal mode, see:
    –"Parallel Signaling and Measurement"
    –"Power Measurement Results (Normal Mode)"
    –"Modulation Measurement Results (Normal Mode)"
  • Current, average and maximum spectrum trace results for BR, EDR and LE supported, see:
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​TRACe:​SACP:​CURRent? etc.
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​TRACe:​SGACp:​CURRent? etc.
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​TRACe:​SOBW:​CURRent? etc.
  • Single modulation results XMAX and XMIN supported. They provide absolute max and absolute min values. See:
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​MODulation:​BRATe:​XMINimum? etc.
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​MODulation:​LENergy[:​LE1M]:​XMINimum? etc.
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​MODulation:​LENergy:​LE2M:​XMINimum? etc.
    –FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​MODulation:​LENergy:​LRANge:​XMINimum? etc.
  • Reliability indicator code 52 "Connection Error", see "Reliability Indicator"
