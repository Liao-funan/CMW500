Spectrum Measurement Results (LE)

The following commands return the spectrum results (single values).

Commands for LE 1M PHY - uncoded (...:LE1M...), LE 2M PHY - uncoded (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

List of Commands

FETCh:BLUetooth:MEAS<i>:MEValuation:SACP:LENergy[:LE1M]?
READ:BLUetooth:MEAS<i>:MEValuation:SACP:LENergy[:LE1M]?
