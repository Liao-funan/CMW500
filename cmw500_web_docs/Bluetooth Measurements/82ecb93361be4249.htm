Suppress "Sig Off" Message

Enables/disables "Suppress "Sig Off" Message" in combined signal path.

If you press [ON | OFF] while the "Bluetooth Signaling" softkey is selected and the R&S CMW Bluetooth signal is on, a warning can be displayed. It asks you whether you really want to switch off the Bluetooth signal.

The checkbox enables/disables the warning.

Display of signal off message

No remote control is provided for this feature.
