Options and Equipment Required
A Bluetooth combined signal path measurement requires the following equipment:
  • R&S CMW with software version ≥ V3.2.30. The latest software version is recommended.
    This application sheet describes software version V3.2.70.
  • Option R&S CMW-KS610, "Bluetooth BR / EDR, Basic Signaling"
  • Option R&S CMW-KM610, "Bluetooth BR / EDR, TX Measurements"
