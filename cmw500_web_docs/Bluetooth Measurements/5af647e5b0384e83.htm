Measurement Diagrams (EDR)

The "Overview" dialog shows several or all the detailed views in a single diagram.

Bluetooth multi-evaluation: overview in combined signal path scenario (EDR)
The diagrams contain the following results:
  • "Power vs. Time": Absolute measured signal power in dBm in a selectable time interval. The diagram shows both the GFSK and the DPSK portions of the burst.
  • "Differential Error Vector Magnitude": Magnitude of differential error vector within the π/4-DQPSK or 8DPSK portions of the burst; see "DEVM Calculation".
  • "Phase Difference": Normalized phase difference of each π/4-DQPSK or 8DPSK-modulated symbol relative to the preceding symbol. The phase differences are displayed in rad/π, i.e. the phase differences in rad are divided by π; see "Phase Difference Calculation".
    The phase difference for the GFSK modulated part of the Bluetooth EDR burst and of the first guard symbol is set to zero. The phase difference between the second and first guard symbol is the first one to be displayed. The R&S CMW displays phase differences up to the middle of the signal power down ramp. So, it is possible to decode all symbols starting with the second guard symbol. This way, you can, for example, verify the synchronization sequence and trailer symbols in the EDR packets (test purpose TP/PHAS/TRX/VB-07-E from the baseband test specification for Bluetooth wireless technology).
  • "Spectrum Gated ACP": Bar graph or table with the adjacent channel power (ACP) results
    –Either for the 21 channels –10 to 10, where the relative channel number denotes the frequency spacing in MHz relative to the center channel (defined by the selected RF frequency)
    –Or for all Bluetooth channels (0 to 78, corresponding to RF frequencies 2402 MHz, 2403 MHz ... 2480 MHz).

    See "Spectrum Gated ACP Results (EDR)".
    If the ACP measurement mode is set to "ACP 79 Channels", the table shows ACP results in the entire Bluetooth regulatory range. It covers channels 0 to 78, corresponding to RF frequencies 2402 MHz, 2403 MHz ... 2479 MHz. See "ACP Measurement Mode".
  • "I/Q Constellation ...": These diagrams show the constellation points for the DPSK-modulated portion of the EDR bursts (see "Calculation of IQ Constellation Diagrams"). Constellation diagrams give a graphical representation of the signal quality and can help to reveal typical modulation errors causing signal distortions.

See also: "I/Q Constellation Diagram"

IQ constellation absolute

Normalized I/Q vectors of the symbols starting from Sref. The absolute constellation diagram of an ideal signal contains 8 constellation points with relative angles of π/4.

IQ constellation differential
Normalized I/Q amplitude and the phase difference compared to previous symbol. Symbols starting from S1 of the synchronization sequence are displayed.
  • For π/4-DQPSK-modulated signals, differential symbols occur at ±π/4, ±3π/4.
  • For 8DPSK-modulated signals, differential symbols occur at phases 0, ±π/4, ±π/2, ±3π/4, π.
IQ constellation error

Differential error vector for each symbol. The amplitude of a symbol in this diagram is the DEVM for the corresponding symbol within the Bluetooth burst. The closer the vectors are to the origin, the smaller the RMS DEVM (i.e., the better the modulation accuracy) and vice versa. The differential error vector with the largest magnitude corresponds to the peak DEVM in the Bluetooth burst.

Scope of the measurement

The "Power vs. Time" diagram can cover up to five timeslots (5 x 625 μs). In addition, the diagrams also display 160 symbols before the first timeslot and 100 symbols after last timeslot. ("Display > X Scale").

"Differential Error Vector Magnitude", and "Phase Difference" diagrams cover up to five timeslots.

For query of the diagram contents via remote control, see "Trace Results".
