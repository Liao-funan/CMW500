Bluetooth Rx Tests

Within option R&S CMW-KD611, you can perform non-signaling over-the-air (OTA) Rx tests in parallel to the Tx tests. The RX measurement only supports LE 1 Msymbol/s uncoded physical layer (LE 1M PHY), advertiser packets.

Non-signaling Rx measurements are only supported by R&S CMW100/CMW with MUA.

The Rx measurement is installed within the Bluetooth measurement application, option R&S CMW-KM611. The measurement uses an ARB waveform file.
