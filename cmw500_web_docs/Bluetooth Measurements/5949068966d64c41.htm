Returns the current, average, min, and max power results for BR/EDR, normal mode.

The values described below are returned by FETCh and READ commands. CALCulate commands return limit check results instead, one value for each result listed below.

Return values: 
<Reliability>

See "Reliability Indicator"

<BurstOutOfTol>

Out of tolerance result, i.e. percentage of measurement intervals of the statistic count (CONFigure:​BLUetooth:​MEAS<i>:​MEValuation:​SCOunt:​PVTime) exceeding the specified limits, see CONFigure:​BLUetooth:​MEAS<i>:​MEValuation:​LIMit:​BRATe:​PVTime and CONFigure:​BLUetooth:​MEAS<i>:​MEValuation:​LIMit:​EDRate:​PVTime.

Range: 0 %  to  100 %
Default unit: %
<NominalPower>

Average power during the carrier-on state

Range: -99.99 dBm  to  99.99 dBm
Default unit: dBm
Usage: Query only
