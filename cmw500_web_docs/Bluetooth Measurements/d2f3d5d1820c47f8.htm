CONFigure:BLUetooth:MEAS<i>:MEValuation:LIST:SEGMent<no>[:SETup]:FILTer <MeasFilter>

Specifies the measurement filter bandwidth for the segment.

Suffix: 
<no>
1..48

Segment number

Parameters:
<MeasFilter>
NARRow | WIDE

NARRow: narrow-band filter

WIDE: wide-band filter

*RST:NARR
