Multi-Evaluation Measurement Results

The results of the multi-evaluation measurement depend on the current burst type, i.e. whether BR, EDR or LE packets are transmitted by the Bluetooth device. Use the "Display" parameters to select the different views and to change their appearance and contents.

The results to be measured and displayed in the overview can be limited using the hotkey "Assign Views", see "Additional Softkeys and Hotkeys".

You can enlarge one of the diagrams in the overview and show a detailed view with additional measurement results, see "Selecting and Modifying Views".
