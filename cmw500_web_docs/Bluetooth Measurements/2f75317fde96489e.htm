Limits (Modulation LE)

The following commands define limits for results which characterize the modulation accuracy of LE packets.

Commands for LE 1M PHY - uncoded (...:LE1M...), LE 2M PHY - uncoded (...:LE2M...), and LE coded PHY (...:LRANge...) are available.
