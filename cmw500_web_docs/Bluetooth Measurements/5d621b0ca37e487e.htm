Parallel Signaling and Measurement

The Bluetooth multi-evaluation measurement can be used in parallel to the "Bluetooth Signaling" application. A connection to the EUT can be set up by the signaling application and the resulting uplink signal can be measured using the multi-evaluation measurement.

With combined signal path, the following combinations are supported:
  • Signaling: one of the options R&S CMW-KS600 /-KS602/-KS603 for BR/EDR
    Measurement: R&S CMW-KM610 (normal mode)
  • Signaling: Option R&S CMW-KS610 for BR/EDR test mode.
    Measurement: R&S CMW-KM610 (as per Bluetooth test specification)
  • Signaling: Option R&S CMW-KS611 for direct test using LE 1M PHY (uncoded)
    Measurement: R&S CMW-KM611 (as per Bluetooth test specification)
  • Signaling: Option R&S CMW-KS721 for direct test using LE 2M PHY (uncoded) or LE coded PHY
    Measurement: R&S CMW-KM721 (as per Bluetooth test specification)

To use both applications in parallel, the combined signal path scenario must be activated (see "Scenario, Controlled by"). Most signal routing and analyzer settings and some measurement control settings are then configured by the signaling application. The multi-evaluation measurement displays the corresponding signaling settings instead of its own settings. These signaling settings can be configured in both measurement and signaling application GUIs. Use the commands of signaling application to configure the settings via remote control. For a command mapping table, see "Combined Signal Path Commands".

In the measurement GUI the most important signaling parameters can be configured via additional hotkeys, see "Additional Softkeys and Hotkeys".

In the combined signal path scenario, the trigger signal from the signaling application has to be used as the measurement application trigger input. The selection of the trigger is done automatically:

  • "Bluetooth Sig<i>: ACPTrigger" for the 79 channels mode of BR/EDR ACP measurements and for the all channels mode of LE ACP measurements.
  • "Bluetooth Sig<i>: SignallingTrigger" for all other measurements
