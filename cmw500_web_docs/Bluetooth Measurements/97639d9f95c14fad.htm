CONFigure:BLUetooth:MEAS<i>:MEValuation:LIMit:BRATe:DELTa <DeltaF2P99p9>, <DeltaF2P99Enabl>

Defines the lower limit for the frequency deviation Δf2 that must be exceeded by 99.9% of the measured bits.

Parameters:
<DeltaF2P99p9>
Range: 100E+3 Hz  to  200E+3 Hz
*RST:115E+3 Hz
<DeltaF2P99Enabl>
OFF | ON
*RST:ON
