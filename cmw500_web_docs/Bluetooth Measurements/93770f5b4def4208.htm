Bluetooth® Measurements

The "Bluetooth Measurement" application provides transmitter (Tx) tests for Bluetooth devices and Rx tests on LE advertiser packets.

The basic option R&S CMW-KM610 supports GFSK-modulated Basic Rate (BR) asynchronous connection-less (ACL) packets and π/4 DQPSK or 8DPSK-modulated Enhanced Data Rate (EDR) ACL packets.

The basic option R&S CMW-KM611 supports Low Energy (LE) Tx measurements on LE 1 Msymbol/s uncoded physical layer (LE 1M PHY). The supplementary option R&S CMW-KM721 adds support for LE 2 Msymbol/s uncoded physical layer (LE 2M PHY) and LE 1 Msymbol/s Long Range physical layer (LE coded PHY).

The packet types are described in the baseband specification of the core specification for Bluetooth wireless technology. For a definition of measured quantities and conformance requirements, refer to the following test specification for Bluetooth wireless technology:

  • BR and EDR measurements in test mode: RF for 4.2.3
    (R&S CMW-KM610)
  • LE measurements in direct test mode: RF PHY for 5.0.0
    (R&S CMW-KM611, R&S CMW-KM721)

Except standardized tests, the R&S CMW provides also the following measurements:

  • LE measurements with advertisers: in line with core specification 4.2
    (R&S CMW100/CMW with MUA, R&S CMW-KM611 and R&S CMW-KD611 required)
  • Measurements in normal mode: in line with core specification 4.2 (R&S CMW100/CMW with MUA required)

All Tx tests are combined in a single, multi-evaluation measurement group, refer to "Bluetooth Tx Tests".

For generating a Bluetooth signal toward the EUT in parallel to the measurement, you can use:
  • The Bluetooth signaling application, see "Parallel Signaling and Measurement".
  • Or GPRF generator with an option R&S CMW-KW610 - "Bluetooth BR EDR LE, enable WinIQSIM2 waveforms for ARB". This option enables processing of Bluetooth waveform files.

The "Bluetooth Measurement" application provides in a separate tab "Rx Meas" also Rx tests. Option R&S CMW-KD611 is required for generating a Bluetooth signal toward the EUT. So a GPRF generator provides Bluetooth downlink signal for non-signaling Rx tests. Refer to "Bluetooth Rx Tests".

Non-signaling Rx measurements are only supported by R&S CMW100/CMW with MUA.

R&S CMW models

The firmware application supports several instrument models. Depending on the model, only a subset of the software packages and software options is allowed.

To check whether the application is relevant for your instrument model and which software options are supported, refer to the preface.

The following sections distinguish between groups of instrument models and describe differences where required (without repeating the information about supported models and options).

The following terms are used for groups of instrument models:
  • R&S CMW100: Stands for any R&S CMW100 variant.
    The RF ports are built into a radio test head. The test software is running on a connected computer. All tests are performed as non-signaling tests.
  • R&S CMW500/2xx: Stands for the R&S CMW500, 270 and 290.
    The instrument provides RF ports and contains a computer where the test software is running. Combined signal path measurements are possible.
  • R&S CMW100/CMW with MUA: R&S CMW with advanced measurement board:
    –Any R&S CMW100 contains an advanced measurement board.
    –An R&S CMW500/270/290 can be equipped with a measurement unit advanced (MUA, R&S CMW-B100H).
