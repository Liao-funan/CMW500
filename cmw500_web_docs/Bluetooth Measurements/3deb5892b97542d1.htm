Spectrum Gated ACP Measurement

To obtain the adjacent channel power (ACP), the R&S CMW automatically uses the basic test settings from the test specification for Bluetooth wireless technology: 100 kHz resolution bandwidth (fixed), "Statistic Count": 10 (default). The measurement is gated to cover only the DPSK portion of the packet. The required ACP results correspond to the "Maximum" values in the ACP diagrams.

To measure in line with test purpose TP/TRM/CA/BV-13-C, provide a signal with the following characteristics, and adjust the "Bluetooth Input Signal" settings accordingly.
