CONFigure:BLUetooth:SIGN<i>:RFSettings:ENPower <ExpNomPwr>

Sets the expected nominal power of the EUT signal

Parameters:
<ExpNomPwr>

The range of the expected nominal power can be calculated as follows:

Range (Expected Nominal Power) = Range (Input Power) + External Attenuation - User Margin

The input power range is stated in the data sheet.

*RST:10 dBm
Default unit: dBm
Firmware/Software: 

V3.0.12

Manual operation: See "Expected Nominal Power, Auto Ranging"
