Spectrum ACP Measurement

To obtain the adjacent channel power (ACP), the R&S CMW automatically uses the 100 kHz resolution bandwidth required in the test specification for Bluetooth wireless technology.

To measure in line with TX test TP/TRM-LE/CA/BV-03-C (In-band emissions at LE 1M PHY) or TP/TRM-LE/CA/BV-08-C (In-band emissions at LE 2M PHY), proceed as follows:
  • Select the wideband measurement filter ("Measurement Control > Filter > LE/LE2M Filter Bandwidth: Wide"
  • Provide a signal with the following characteristics and adjust the "Bluetooth Input Signal" settings accordingly.

Remarks

Three consecutive measurements at lowest, middle, and highest transmit frequency

Set "Frequency" to
  • 2406 MHz, 2440 MHz and 2476 MHz for connectable devices
  • 2402 MHz, 2426 MHz and 2480 MHz for non-connectable devices

See "Operating Conditions and Frequencies for Testing"

Transmit a PRBS9 sequence as payload

"Bluetooth Input Signal > Pattern Type: Other"

"Other" denotes any pattern except "11110000" and "10101010".

Measurement time: 1 s

"Measurement Control > Spectrum > ACP Statistic Count": 1 for the payload length of 255 bytes

See "Statistical settings for ACP measurements on LE packets" in "ACP and Multi-Shot Measurements".

The power limits specified in the "in-band emissions" test cases apply to the "Maximum" statistical measurement results.

For the all channels ACP measurements in the combined signal path scenario, use the ACP trigger of the "Bluetooth Signaling" application (option R&S CMW-KS611 required).
