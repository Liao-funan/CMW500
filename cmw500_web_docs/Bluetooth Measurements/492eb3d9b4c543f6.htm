CONFigure:BLUetooth:MEAS<i>:ISIGnal:BTYPe <Burst Type>

Specifies the measured burst / packet type.

For the combined signal path scenario, use CONFigure:​BLUetooth:​SIGN<i>:​CONNection:​BTYPe.

Parameters:
<Burst Type>
BR | EDR | LE

BR: "Basic Rate"

EDR: "Enhanced Data Rate"

LE: "Low Energy"

*RST:BR
Example: 

See "Basic Input Signal Properties: EDR Packets"

Firmware/Software: 

V1.0.10.1

V2.1.20: added LE

Options: R&S CMW-KM610 for BR and EDR
R&S CMW-KM611 for LE
Manual operation: See "Burst Type"
