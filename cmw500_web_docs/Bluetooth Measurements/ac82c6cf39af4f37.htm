Payload length

Due to the different measurement procedures, some of the modulation results are valid only if the packet contains enough payload bytes. A packet configuration according to the test specification for Bluetooth wireless technology ensures a sufficient "Payload Length" for all modulation results.

The modulation measurements are in accordance with the test specification for Bluetooth wireless technology, see test purpose TP/TRM/CA/BV-07-C and TP/TRM/CA/BV-08-C.

To obtain the modulation characteristics in accordance with the test specification, proceed as follows:
  • Use the default measurement filter ("Measurement Control > Filter > Basic Rate Filter Bandwidth: Narrow"
  • Use the default statistical settings ("Measurement Control > Modulation > Statistic Count: 10")
  • Provide a signal with the following characteristics and adjust the "Bluetooth Input Signal" settings accordingly.
