CONFigure:BLUetooth:MEAS<i>:ISIGnal:PATTern:LENergy:LRANge <Pattern Type>

Specifies the data pattern type for LE coded PHY, that the EUT transmits as user payload data.

For the combined signal path scenario, use CONFigure:​BLUetooth:​SIGN<i>:​CONNection:​PACKets:​PATTern:​LENergy:​LRANge

Parameters:
<Pattern Type>
ALL1 | OTHer

ALL1: '11111111'

OTHer: any pattern except ALL1

*RST:ALL1
