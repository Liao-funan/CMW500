FETCh:BLUetooth:MEAS<i>:ISIGnal:ADETected:NOSLots:BRATe?

Returns the detected BR number of off slots. A result is available after the R&S CMW has auto-detected a packet (CONFigure:​BLUetooth:​MEAS<i>:​ISIGnal:​DMODe AUTO).

Return values: 
<Reliability>

"Reliability Indicator"

<NoOfOffSlots>
Range: 0  to  9
