CONFigure:BLUetooth:MEAS<i>:ISIGnal:PTYPe:BRATe <Packet Type>

Specifies the BR packet type of the measured signal.

For the combined signal path scenario, use CONFigure:​BLUetooth:​SIGN<i>:​CONNection:​PACKets:​PTYPe:​BRATe.

Parameters:

DH1 | DH3 | DH5
*RST:DH1
