V3.5.70 (Compared to V3.5.60)
New features:
  • Option R&S CMW-KM721 for LE measurements according to the specification version 5.0 for Bluetooth wireless technology. This option is an extension of R&S CMW-KM611 used for LE 1 Msymbol/s (LE 1M PHY) measurements.
  • Option R&S CMW-KM721 supports the following packet types:
    –LE 2 Msymbol/s physical layer (LE 2M PHY)
    –LE long range physical layer (LE coded PHY)

    See "PHY (LE)"
  • Token LE1M added to the commands for LE 1M PHY (...:LENergy[:LE1M]...)
