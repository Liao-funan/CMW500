Rx Measurement Control Settings

The "Rx Measurement" parameters configure the scope of the measurement.

Option R&S CMW-KD611 is required (only for R&S CMW100/CMW with MUA).

Generate ARB during Tx Measurements

Enables / disables the creation of ARB waveform file during Tx measurement, and enables / disables the use of this ARB waveform file during Rx measurements.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​GARB

 
Mode

Selects spot check, PER or sensitivity search measurement, see "Bluetooth Rx Tests".

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​MMODe

 
CMW Scanner Address

Specifies the device address of the R&S CMW. The R&S CMW acts as a scanner. The device address of the EUT is detected automatically.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​SADDress

 
CMW Address Type
The R&S CMW supports both public and random address types:
  • Public: Unique 48-bit address of each Bluetooth LE device using an organizationally unique identifier (OUI) obtained from the IEEE registration authority
  • Random: 48-bit random static, non-resolvable private, or resolvable private device address of a Bluetooth LE device. A random address is optional. It can be directly generated by the beacon.
Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​SATYpe

 
Sensitivity

Specifies settings for "Mode" = "Sensitivity".

Start Level < Sensitivity

Sets Tx start level of for sensitivity search measurement.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​SENSitivity:​STARtlevel

 
Step Size < Sensitivity

Sets the step size for decreasing Tx level of R&S CMW for sensitivity search measurement.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​SENSitivity:​STEPsize

 
Retry < Sensitivity

Specify the number of retry attempts per step for sensitivity search measurement.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​SENSitivity:​RETRy

 
Spot Check > Level

Sets the constant Tx level of R&S CMW for SCAN_REQ transmission for "Mode" = "Spot Check".

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​SPOTcheck:​LEVel

 
PER

Specifies settings for "Mode" = "PER".

Level < PER

Sets the constant Tx level of R&S CMW for SCAN_REQ transmission.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​PER:​LEVel

 
Packets to Send < PER

Defines the number of SCAN_REQ packets for PER measurements.

Remote command: 

CONFigure:​BLUetooth:​MEAS<i>:​RXQuality:​PER:​TXPackets
