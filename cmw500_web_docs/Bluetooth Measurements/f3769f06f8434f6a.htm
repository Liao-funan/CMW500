V2.0.10 (Compared to 1.0.15.20/21/22)
New features:
  • "Spectrum ACP" (adjacent channel power) measurement for BR: Current and average results removed. The R&S CMW provides the PTX(f) results according to the test specification.
    See "Spectrum ACP Results (BR)".
  • "RF Routing": selection of RF 3 and RF 4 connectors modified, RX module selectable (see ROUTe:​BLUetooth:​MEAS<i>:​SCENario:​SALone). New commands ROUTe:​BLUetooth:​MEAS<i>? and ROUTe:​BLUetooth:​MEAS<i>:​SCENario?.
  • Remote control: New command CONFigure:​BLUetooth:​MEAS<i>:​MEValuation:​TOUT, defines a timeout value for the measurement.
