Modulation Measurements

The modulation measurements are in accordance with the test specification for Bluetooth wireless technology, see test purpose TP/TRM/CA/BV-11-C.

To obtain the modulation characteristics in accordance with the test specification, proceed as follows:
  • Select the measurement filter ("Measurement Control > Filter > EDR Filter Bandwidth: Narrow"
  • Use the default statistical settings ("Measurement Control > Modulation > Statistic Count: 10")
  • Provide a signal with the following characteristics and adjust the "Bluetooth Input Signal" settings accordingly.
