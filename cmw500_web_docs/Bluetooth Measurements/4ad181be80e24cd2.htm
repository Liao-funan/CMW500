CONFigure:BLUetooth:MEAS<i>:ISIGnal:OSLots:LENergy:LE2M <NoOfOffSlots>
CONFigure:BLUetooth:MEAS<i>:ISIGnal:OSLots:LENergy[:LE1M] <NoOfOffSlots>

Specifies the number of unused slots between any two occupied slots or slot sequences.

Commands for LE 1M PHY (...:LE1M...) and LE 2M PHY (...:LE2M...) are available.

Parameters:
<NoOfOffSlots>
Range: 1  to  9
*RST:1
Default unit: Multiplies of 625 µs
