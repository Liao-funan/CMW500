V3.2.50 (Compared to V3.2.30)
New features:
  • "ACP 79 Channels" mode available also in the combined signal path scenario
  • Multi-evaluation list mode, see "List Mode"
  • Frequency range measurement:
    –For configuration, see "Frequency Range (BR)"
    –For results, see "Spectrum Frequency Range Results (BR)"
    –For conformance requirements, see Table "Bluetooth spectrum requirements"
    –For limit configuration, see "Frequency Range"
  • Differential phase encoding measurement:
    –For results, see "Differential Phase Encoding Results (EDR)"
    –For conformance requirements, see "Differential Phase Encoding Requirements"
    –For limit configuration, see "Phase Encoding Limits"
  • Additional command to select a measurement view, see CONFigure:​BLUetooth:​MEAS<i>:​DISPlay
  • GPRF generator shortcut, see "Generator Shortcut"
