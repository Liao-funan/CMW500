V3.2.30 (Compared to V3.0.12)
New features:
  • Combined signal path scenario, see "Scenario, Controlled by"
    Additional settings for the combined signal path scenario, see "Frequency, Channel"
  • Packet timing measurements, see:
    "Statistical Power vs. Time Results (BR)" and
    "Statistical Power vs. Time Results (EDR)"
    –Additional packet timing parameter in the following commands:
    FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​PVTime:​BRATe:​CURRent? etc.
    FETCh:​BLUetooth:​MEAS<i>:​MEValuation:​PVTime:​EDRate:​CURRent? etc.
    –Packet timing limit, see "Power Limits"
  • Power and frequency deviation graphs start from -160 symbols relative to bit 0, see:
    –"Trace Points for Basic Rate"
    –"Trace Points for Low Energy"
  • Leakage pre-area of the power measurement starts from -150 symbols relative to bit 0, see:
    –Basic rate: Figure "Definition of power results (BR)"
    –Low energy: Figure "Definition of power results (LE)"
  • Frequency accuracy limit (low energy), see "LE"
