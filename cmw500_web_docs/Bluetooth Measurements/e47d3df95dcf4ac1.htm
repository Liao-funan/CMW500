Phase Difference Calculation

The "Phase Difference" view shows the normalized phase difference of each symbol relative to the preceding symbol. Phase difference ϕ for each symbol is measured as described in "IQ constellation differential".

Phase differences between consecutive symbols are displayed as a fraction of π.
  • For π/4-DQPSK-modulated signals, differential symbols occur at phases ±π/4, ±3π/4.
  • For 8DPSK-modulated signals, differential symbols occur at phases 0, ±π/4, ±π/2, ±3π/4, π.

The binary EDR data can be read from the normalized phase differences according to the mapping tables in the core specification for Bluetooth wireless technology. The binary value no. 2k (b2k) is associated with symbol no. k.

"Phase Difference" graph differs from the "IQ Constellation" diagram:
  • "Phase Difference" is calculated for symbols starting from the guard symbols to the symbol corresponding to the signal power down ramp position. All the DPSK symbols within the burst and beyond are covered.
  • The results are displayed regardless of the detection of the EDR synchronization sequence.
