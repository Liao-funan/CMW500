Trigger Signal

The "Bluetooth Measurement" provides a power trigger signal that can be used by other R&S CMW applications. The trigger is useful for non-signaling Rx measurements for the timing of SCAN_REQ sent by the GPRF generator.

Option R&S CMW-KD611 is required (only for R&S CMW100/CMW with MUA).

To address the trigger signals of the measurement in remote commands, use the following string, with <i> replaced by the instance number of the measurement:
  • "Bluetooth Meas<i>: Power"
