FETCh:BLUetooth:MEAS<i>:ISIGnal:ADETected:PLENgth:LENergy[:LE1M]?

Returns the detected payload length.

Commands for LE 1M PHY - uncoded (...:LE1M...), LE 2M PHY - uncoded (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

A result is available after the R&S CMW has auto-detected a packet (CONFigure:​BLUetooth:​MEAS<i>:​ISIGnal:​DMODe AUTO).

Return values: 
<Reliability>

"Reliability Indicator"

<PayloadLength>
Range: 0 to 255
Default unit: byte
Example: 

See "Automatic Detection Mode"

Usage: Query only
