Measurement Diagrams (BR)

The "Overview" dialog shows several or all the detailed views in a single diagram.

Bluetooth multi-evaluation: overview (BR)
The diagrams contain the following results:
  • Power vs. time: Absolute measured signal power in dBm in a selectable time interval.
  • Frequency deviation: Measured frequency deviation in kHz in a selectable time interval.
  • Spectrum 20 dB bandwidth: Spectrum emissions, measured in a symmetric, 2-MHz wide frequency range around the selected RF "Frequency" and in a 10 kHz resolution bandwidth. The diagram shows the "Maximum" curve; all values are relative to the detected "Peak Emission". See also "Spectrum 20 dB Bandwidth Results (BR)".
  • Spectrum ACP: Bar graph or table with the adjacent channel power (ACP) results
    –Either for the 21 channels –10 to 10, where the relative channel number denotes the frequency spacing in MHz relative to the center channel (defined by the selected RF "Frequency")
    –Or for all Bluetooth channels (0 to 78, corresponding to RF frequencies 2402 MHz, 2403 MHz ... 2480 MHz)

    See "Spectrum ACP Results (BR)" for details.
Scope of the measurement

The "Power vs. Time" and "Frequency Deviation" diagrams cover up to five timeslots (5 x 625 μs). In addition, the diagrams display also 160 symbols before the first timeslot and 100 symbols after the last timeslot ("Display > X Scale").

For query of the diagram contents via remote control, see "Trace Results".
