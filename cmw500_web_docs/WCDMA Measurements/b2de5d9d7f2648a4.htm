CONFigure:WCDMa:MEAS<i>:UESignal:DPDCh <DPDCH>

Defines whether the UL DPCH contains a DPDCH.

For the combined signal path scenario, use CONFigure:​WCDMa:​SIGN<i>:​DL:​LEVel:​DPCH.

Parameters:
<DPDCH>
OFF | ON

OFF: DPCCH only

ON: DPCCH plus DPDCH

*RST:ON
