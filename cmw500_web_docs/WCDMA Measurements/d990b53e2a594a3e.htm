TRIGger:WCDMa:MEAS<i>:MEValuation:SOURce <Source>

Selects the source of the trigger events. Some values are always available in this firmware application. They are listed below. Depending on the installed options, additional values are available. A complete list of all supported values can be displayed using TRIGger:...:CATalog:SOURce?.

Parameters:
<Source>

'Free Run (Standard)': Free run (standard synchronization)

'Free Run (Fast Sync)': Free run (fast synchronization)

'IF Power': Power trigger (normal synchronization)

'IF Power (Sync)': Power trigger (extended synchronization)

*RST:'Free Run (Standard)'
