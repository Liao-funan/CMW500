CONFigure:WCDMa:MEAS<i>:MEValuation:AMODe:MODulation <AnalysisMode>

Defines whether a possible origin offset is included in the measurement results (WOOFfset) or subtracted out (NOOFfset).

Parameters:
<AnalysisMode>
WOOFfset | NOOFfset

WOOFfset: With origin offset

NOOFfset: No origin offset

*RST:WOOF
