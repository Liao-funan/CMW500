CONFigure:WCDMa:MEAS<i>:MEValuation:CDTHreshold:MODulation <Threshold>

Defines the minimum relative signal strength of the (E-)DPDCH in the WCDMA signal (if present) to be detected and evaluated.

Parameters:
<Threshold>
Range: -25 dB  to  10 dB
*RST:-16 dB
Default unit: dB
