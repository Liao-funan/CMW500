V1.0.15.0 (Compared to V1.0.10.1)
New features:
  • New operating bands S, S 170 MHz and S 190 MHz
  • Parallel usage of WCDMA measurements and WCDMA signaling application (option R&S CMW-KS400)
  • The I/Q constellation diagram can be rotated by 45°.
  • New measurement: relative code domain error (RCDE) vs slot
  • List mode enhancements: measuring peak code domain error (PCDE)
