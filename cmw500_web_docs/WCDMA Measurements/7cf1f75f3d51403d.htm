Signal Routing and Analyzer Settings

These parameters configure the RF input path. All parameters are common measurement settings, i.e. they have the same value in all measurements (e.g. TPC measurement and multi-evaluation measurement).

For parameter descriptions, refer to the multi-evaluation measurement, "Signal Routing and Analyzer Settings".
