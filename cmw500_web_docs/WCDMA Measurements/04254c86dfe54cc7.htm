V1.0.4.11 (Compared to V1.0.3.6)
New features:
  • New "UE Power" and "Power Steps" measurement
  • New modulation measurements: EVM vs chip, phase error vs chip, magnitude error vs chip and frequency error
  • New phase discontinuity measurement
  • New RX measurement: bit error rate (BER) and block error ratio (BLER)
  • Support of HSUPA and HSDPA channels in the UL signal (option CMW-KM401)
  • Extended trigger system
