Key Features
The WCDMA DPCCH open loop power control measurement is programmed as follows:
  • The measurement is controlled by SCPI commands with the following syntax: ...WCDMa:MEAS:OLPControl...
  • Use signaling commands of the type ...WCDMa:SIGN... to define the signal routing and perform RF settings.
  • Use general commands of the type ...WCDMa:MEAS... (no :OLPControl mnemonic) to define the general analyzer settings.
  • After a *RST, the measurement is switched off. Use READ:WCDMa:MEAS:OLPControl...? to initiate a single-shot measurement and retrieve the results. You can also start the measurement using INIT:WCDMa:MEAS:OLPControl and retrieve the results using FETCh:WCDMa:MEAS:OLPControl...?.
