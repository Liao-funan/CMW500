Generator Shortcut

This parameter enables starting the GPRF generator and using GPRF-related hotkeys and softkeys from the measurement GUI. All parameters are common measurement settings, i.e. they have the same value in all measurements (e.g. TPC measurement and multi-evaluation measurement).

For parameter descriptions, refer to the multi-evaluation measurement, "Generator Shortcut".
