FETCh:WCDMa:MEAS<i>:TPC:TOTal:UEPower:STATistics?
READ:WCDMa:MEAS<i>:TPC:TOTal:UEPower:STATistics?

Return the "Statistics" values, indicating how many trace values have been considered to derive the maximum, minimum and average values of the maximum output power over all carriers.

Return values: 
<Reliability>

"Reliability Indicator"

<MaxOutputPower>

Number of trace values for maximum output power over all carriers

Range: 0  to  341
Example: 

See "Performing Measurements"

Usage: Query only
Firmware/Software: 

V3.2.70
