Performing Measurements
// *****************************************************************************
// Start the DPCCH OLP measurement and wait until command processing is complete.
// The TPC setup is executed automatically.
// *****************************************************************************
INIT:WCDMa:MEAS:OOSYnc
*OPC?

// *****************************************************************************
// Set the max UE level, change the DPCCH level via signaling application.
// *****************************************************************************
CONFigure:WCDMa:SIGN:UL:TPC:SET ALL1
CONFigure:WCDMa:SIGN:DL:ENHanced:DPCH:LSEQuence:EXECute

// *****************************************************************************
// Query the measurement state (should be "RDY").
// *****************************************************************************
FETCh:WCDMa:MEAS:OOSYnc:STATe?

// *****************************************************************************
// Query statistical results obtained in the measurement.
// *****************************************************************************
FETCh:WCDMa:MEAS:OOSYnc?

// *****************************************************************************
// Query limit check results obtained in the measurement
// *****************************************************************************
CALCulate:WCDMa:MEAS:OOSYnc?
