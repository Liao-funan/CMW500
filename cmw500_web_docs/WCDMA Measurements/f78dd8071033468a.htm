Generator Shortcut

This feature simplifies starting the GPRF generator and provides GPRF-related hotkeys and softkeys within the measurement application. It improves the usability for non signaling tests where the DUT's reaction on varying generator signals is measured.

The "Generator Shortcut" is only relevant for "Standalone (Non Signaling)" mode.

GPRF generator shortcut

When a connection to the GPRF generator instance is established, two additional softkeys with corresponding hotkey bars provide access to the generator configuration, see "ARB/List Mode, GPRF<i> Generator".

Use the appropriate softkey/hotkey combination to access the generator parameters.

For details on the available parameters, see the GPRF generator documentation.
