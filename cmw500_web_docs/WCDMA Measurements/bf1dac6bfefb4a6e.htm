Limit Setting

The "Limit" section defines tolerances for the UE's responses to the DPCCH level transitions in downlink.

For details, see "Limit".

Limit settings
└ Power Off Upper Limit
└ Power On Lower Limit
└ Power Threshold Limit
Power Off Upper Limit

Specifies the transmitted power of the UE below which the UE's transmitter is considered to be off.

Remote command: 

CONFigure:​WCDMa:​MEAS<i>:​OOSYnc:​LIMit:​POFFupper

 
Power On Lower Limit

Specifies the transmitted power of the UE above which the UE's transmitter is considered to be on.

Remote command: 

CONFigure:​WCDMa:​MEAS<i>:​OOSYnc:​LIMit:​PONupper

 
Power Threshold Limit

Specifies the limit for non-default strategy. If the UE transmitter is expected to be on and the UE power is below the limit, results are not reliable.

Remote command: 

CONFigure:​WCDMa:​MEAS<i>:​OOSYnc:​LIMit:​THReshold
