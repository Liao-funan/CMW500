Using Markers

Use the "Marker" parameters to activate markers and to modify their position. The following "Marker" hotkeys are available at the bottom of the GUI:

Hotkey

Description

"UE Power / Power Steps"

Selects for which trace the markers are configured: the UE power vs slot trace or the power steps trace. The other hotkeys apply to the selected trace.

"Ref. Marker" ...

Enable or disable the reference marker and select the marker position.

"Marker 1 /2 ..."

Enable or disable marker 1 or 2 and define the marker position (absolute or relative to the reference marker).
