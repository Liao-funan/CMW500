CONFigure:WCDMa:MEAS<i>:TPC:LIMit:ILPControl:MAXPower:URPClass <Enable>

Enables or disables the use of the UE power class value reported by the UE in the capability report.

This command is only relevant for combined signal path "Inner Loop Power Control" measurements and only if the predefined limit sets are used.

Parameters:
<Enable>
OFF | ON
*RST:ON
Firmware/Software: 

V2.1.20

Manual operation: See "Limits"
