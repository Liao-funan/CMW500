Parameters and Settings

The most important settings of the WCDMA PRACH measurement are displayed in the measurement dialog.

All settings are defined via softkeys and hotkeys or using the "WCDMA PRACH Configuration" dialog. The configuration dialog is described in the following sections. To open the dialog, select the "PRACH Measurement" tab and press the "Config" hotkey.
