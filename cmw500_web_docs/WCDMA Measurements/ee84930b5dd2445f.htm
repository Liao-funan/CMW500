CONFigure:WCDMa:SIGN<i>:UL:CARRier<c>:SCODe <ScramblingCode>

Sets the long code number that the UE has to use to scramble the uplink WCDMA signal.

Suffix: 
<c>
1..*

Uplink carrier

Parameters:
<ScramblingCode>
Range: #H0  to  #HFFFFFF
*RST:#H0
Firmware/Software:
