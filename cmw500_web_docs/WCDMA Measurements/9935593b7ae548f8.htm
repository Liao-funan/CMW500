CONFigure:WCDMa:SIGN<i>:CMODe:PATTern <Selection>

Selects the transmission gap patterns for compressed mode.

Parameters:
<Selection>
NONE | UEReport | SINGle | ULCM

NONE: compressed mode disabled

UEReport: several patterns for different measurement purposes used in parallel

SINGle: selectable pattern for a definite measurement purpose

ULCM: selectable pattern for the UL compressed mode TX test

*RST:UER
Firmware/Software: 

V3.2.60

Options: R&S CMW-KS410
Manual operation: See "Pattern Selection"
