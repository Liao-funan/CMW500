UE Signal Info Settings

The "UE Signal Info" parameters describe properties of the measured uplink WCDMA signal for your information. The WCDMA out-of-sync handling measurement ignores all settings in this section. The application only measures the UE power.

For description of parameters refer to the WCDMA DPCCH open loop power measurement, see "UE Signal Info Settings".
