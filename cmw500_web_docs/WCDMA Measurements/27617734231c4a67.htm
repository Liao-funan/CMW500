Parameters and Settings

The most important settings of the WCDMA out-of-sync handling measurement are displayed in the measurement dialog.

All settings are defined via softkeys and hotkeys or using the "Out-of-Sync Handling Configuration" dialog. The configuration dialog is described in the following sections. To open the dialog, select the "Out-of-Sync Handling" tab and press the "Config" hotkey.
