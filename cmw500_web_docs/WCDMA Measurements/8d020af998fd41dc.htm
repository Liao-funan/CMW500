TPC Setups

The WCDMA signaling application provides several predefined and partly configurable TPC setups with different TPC command patterns. This section provides an overview of these TPC setups from point of view of the TPC measurement. For more details concerning the individual TPC setups, please refer to the description of the corresponding application.

The used measurement mode depends directly on the selected TPC setup.
