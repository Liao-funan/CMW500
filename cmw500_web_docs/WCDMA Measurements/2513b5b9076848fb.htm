CONFigure:WCDMa:MEAS<i>:TPC:LIMit:ILPControl:MINPower <Enable>, <UpperLimit>

Defines an "Inner Loop Power Control" limit: upper limit for the minimum UE output power. Also enables or disables the limit check.

Parameters:
<Enable>
OFF | ON

Disables | enables the limit check

*RST:ON
<UpperLimit>
Range: -70 dBm  to  34 dBm
*RST:-49 dBm
Default unit: dBm

See "Specifying Limits"
