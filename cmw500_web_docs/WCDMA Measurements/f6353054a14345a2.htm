Additional Softkeys and Hotkeys

The WCDMA DPCCH open loop power measurement provides some softkey/hotkey combinations which have no equivalent in the configuration dialog. Most of these hotkeys provide display configurations (like diagram scaling). They are self-explanatory and usually do not have any remote-control commands assigned.

The remaining softkeys and hotkeys are displayed only while the combined signal path scenario is active and are provided by the "WCDMA Signaling" application selected as master application. For the description, refer to "Additional Softkeys and Hotkeys".
