CONFigure:WCDMa:MEAS<i>:PRACh:LIMit:PCONtrol:MAXPower:URPClass <Enable>

Enables or disables the usage of the UE power class value reported by the UE in the capability report.

This setting is only relevant if the combined signal path scenario is active and not relevant if user-defined limits are used instead of the predefined limit sets.

Parameters:
<Enable>
OFF | ON
*RST:ON
