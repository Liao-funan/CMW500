Parameters and Settings

The most important settings of the WCDMA multi-evaluation measurement are displayed in the measurement dialog.

All settings are defined via softkeys and hotkeys or using the "WCDMA Multi Evaluation Configuration" dialog. The configuration dialog is described in the following sections. To open the dialog, select the "Multi Evaluation" tab and press the "Config" hotkey.
