V3.0.10 (Compared to V2.1.30)
New features:
  • List mode enhancement: new commands for retrieval of single results for all measured segments, see "List Mode Results (All Segments, One Result)"
  • Enhanced range for center frequency of RF analyzer: minimum value = 70 MHz
  • The trigger timeout can now be disabled completely, see "Trigger Settings"
  • The WCDMA multi-evaluation measurement and the WCDMA TPC measurement have been grouped in the GUI. The TX measurement entry in the "Measurement Controller" dialog refers to both measurements. The TX measurement view contains both measurements on separate tabs.
  • When the combined signal path scenario is active, the settings of the signaling application can be accessed from the measurement. Even the main configuration dialog of the signaling application can be accessed and the downlink signal can be switched on/off. The connection states of the signaling application are displayed.
  • Maximum configurable value for user margin and expected nominal power increased
