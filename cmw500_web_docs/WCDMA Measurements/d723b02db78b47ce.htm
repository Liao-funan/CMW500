CONFigure:WCDMa:MEAS<i>:MEValuation:LIMit:ACLR:ABSolute <Limit3M84>

Defines an absolute upper limit for the ACLR. If the absolute upper limit is exceeded, relative limits are evaluated (CONFigure:​WCDMa:​MEAS<i>:​MEValuation:​LIMit:​ACLR:​RELative).

Parameters:
<Limit3M84>
Range: -80 dBm  to  33 dBm
*RST:-50 dBm
Default unit: dBm

Additional OFF | ON disables/enables the limit check using the previous/default limit values
