CONFigure:WCDMa:SIGN<i>:DL:LEVel:DPCH <Level>

Set the level of DPCH. The settings of DPCH level and F-DPCH level are equal.

Parameters:
<Level>
Range: -80 dB to 0 dB
*RST:-10.3 dB
Default unit: dB

Additional parameters: OFF | ON (disables the channel | enables the channel using the previous/default level)

Firmware/Software: 

V1.0.15.0

Manual operation: See "UL DPDCH Available"
