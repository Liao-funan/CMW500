CONFigure:WCDMa:MEAS<i>:PRACh:LIMit:PCONtrol:OFFPower <Limit>

Defines an upper OFF power limit. Also enables or disables the limit check.

Parameters:
<Limit>
Range: -90 dBm  to  53 dBm
*RST:-55 dBm
Default unit: dBm

Additional parameters: OFF | ON (disables the limit check | enables the limit check using the previous/default limit values)
