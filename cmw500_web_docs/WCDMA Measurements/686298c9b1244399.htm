TRIGger:WCDMa:MEAS<i>:PRACh:THReshold <Level>

Defines the trigger threshold for power trigger sources.

Parameters:
<Level>
Range: -47 dB  to  0 dB
*RST:-26 dB
Default unit: dB (full scale, i.e. relative to reference level minus external attenuation)
