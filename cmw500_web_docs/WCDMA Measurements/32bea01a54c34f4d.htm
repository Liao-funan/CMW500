ROUTe:WCDMa:MEAS<i>:SCENario:CSPath <Master>

Activates the combined signal path scenario and selects a master. The master controls the signal routing settings, analyzer settings and UE signal info settings while the combined signal path scenario is active.

Parameters:
<Master>

String parameter selecting the master application

For example, 'WCDMA Sig1' or 'WCDMA Sig2'

Firmware/Software: 

V1.0.15.20

Manual operation: See "Scenario = Combined Signal Path"
