READ:WCDMa:MEAS<i>:MEValuation:CARRier<c>:TRACe:UEPower:SDEViation?

Returns the values of the UE power traces for up to 120 slots.

Each current value is averaged over a half-slot or a full-slot, depending on the measurement period (see CONFigure:​WCDMa:​MEAS<i>:​MEValuation:​MPERiod:​MODulation). The number of results depends on the measurement length (see CONFigure:​WCDMa:​MEAS<i>:​MEValuation:​MSCount).

The results of the current, average, minimum, maximum and standard deviation traces can be retrieved. The minimum and standard deviation trace cannot be displayed at the GUI.

See also "Detailed Views: UE Power and Power Steps"

Suffix: 
<c>
1..2

Selects the carrier to be queried - only relevant for dual carrier HSUPA

Return values: 
<Reliability>

"Reliability Indicator"

<UEpower_1> ... <UEpower_n>

One result per measured slot or half-slot

Range: -100 dBm to 55 dBm (SDEViation: 0 dB to 77 dB)
Default unit: dBm (SDEViation: dB)
