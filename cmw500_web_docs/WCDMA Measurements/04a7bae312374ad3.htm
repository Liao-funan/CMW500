V2.0.11 (Compared to V2.0.10)
New features:
  • New trigger mode "IF Power (Sync)"
  • Retriggering of segments in list mode possible
    Parameter <Retrigger> added to CONFigure:​WCDMa:​MEAS<i>:​MEValuation:​LIST:​SEGMent<no>:​SETup
    New command TRIGger:​WCDMa:​MEAS<i>:​MEValuation:​LIST:​MODE
  • Configurable evaluation offset for the list mode
    Defined number of slots after trigger event can be excluded from the measurement (CONFigure:​WCDMa:​MEAS<i>:​MEValuation:​LIST:​EOFFset)
