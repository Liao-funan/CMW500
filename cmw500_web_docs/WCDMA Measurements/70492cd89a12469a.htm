CONFigure:WCDMa:MEAS<i>:MEValuation:LIST:EOFFset <Offset>

Defines the evaluation offset. The specified number of slots at the beginning of each segment is excluded from the evaluation.

Set the trigger delay to 0 when using an evaluation offset (see TRIGger:​WCDMa:​MEAS<i>:​MEValuation:​DELay).

Parameters:
<Offset>
Range: 0 slots  to  1024 slots
*RST:0 slots
