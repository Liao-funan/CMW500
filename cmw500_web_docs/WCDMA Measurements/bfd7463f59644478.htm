WCDMA RX Tests

RX tests can be carried out in parallel to the TX tests. The following sections describe how to perform RX tests in non-signaling mode, using the WCDMA multi-evaluation measurement. In signaling mode (combined signal path), use the RX measurements provided by the WCDMA signaling application.
