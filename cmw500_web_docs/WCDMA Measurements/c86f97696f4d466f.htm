CONFigure:WCDMa:MEAS<i>:TPC:CSELection <Carrier>

Selects the uplink carrier to be measured.

This parameter is relevant only for the dual uplink carrier configuration.

Parameters:
<Carrier>
C1 | C2

C1: primary uplink carrier

C2: secondary uplink carrier
