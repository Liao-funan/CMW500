ROUTe:WCDMa:MEAS<i>:SCENario:MAPRotocol [<Controler>]

Activates the Measure@ProtocolTest scenario and optionally selects the controlling protocol test application.

The signal routing and analyzer settings of the measurement application are ignored. Configure the corresponding settings within the protocol test application used in parallel.

Setting parameters: 
<Controler>

String parameter selecting the protocol test application

For example, 'Protocol Test1'

Usage: Event
Firmware/Software: 

V1.0.15.20

V2.1.30: added <Controler>

Manual operation: See "Scenario = Measure@ProtocolTest"
