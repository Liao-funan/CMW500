CONFigure:WCDMa:MEAS<i>:TPC:DHIB:PATTern <Pattern>

Specifies the pattern and in the same time also the carrier to be tested. Select the pattern 00... for the tested carrier and 11... for the other carrier.

Parameters:
<Pattern>
UD | DU

UD: C1: 11... C2: 00...

DU: C1: 00... C2: 11...

*RST:UD
