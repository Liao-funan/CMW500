V3.2.60 (Compared to V3.2.10)
New features:
  • Option R&S CMW-KM405 - WCDMA R9 HSPA+, TX measurement, uplink for dual carrier HSDPA+ and dual carrier HSUPA. This option supports also the dual band dual carrier HSDPA+ operation, see "UL Configuration"
  • New commands:
    FETCh:​WCDMa:​MEAS<i>:​MEValuation:​LIST:​SEGMent<no>:​UEPower:​CURRent?
    FETCh:​WCDMa:​MEAS<i>:​MEValuation:​LIST:​SEGMent<no>:​PHD:​CURRent?
  • Additional parameter <TestCase> in the command
    CONFigure:​WCDMa:​MEAS<i>:​MEValuation:​LIMit:​PCONtrol:​HSDPcch
  • Dual carrier separation selectable, see "Dual Carrier Separation"
  • Adaptation of the following commands for dual carrier HSUPA and dual band dual carrier HSDPA+ (suffix CARRier<c> added):
