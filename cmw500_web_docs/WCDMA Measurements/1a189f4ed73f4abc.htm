Using Markers

Use the "Marker" parameters to activate markers and to modify their position. The following "Marker" hotkeys are available at the bottom of the GUI:

Hotkey

Description

"Ref. Marker ..."

Enable or disable the reference marker and set the marker position.

"Marker 1/2 ..."

Enable or disable marker 1 or 2 and define the marker position (absolute or relative to the reference marker).
