TRIGger:WCDMa:MEAS<i>:MEValuation:CATalog:SOURce?

Lists all trigger source values that can be set using TRIGger:​WCDMa:​MEAS<i>:​MEValuation:​SOURce.

Return values: 
<TriggerList>

Comma-separated list of all supported values. Each value is represented as a string.

Usage: Query only

Manual operation: See "Trigger Source"
