CONFigure:WCDMa:MEAS<i>:OOSYnc:LIMit:POFFupper <POULimit>

Specifies the transmitted power of the UE below which the UE's transmitter is considered to be off.

Parameters:
<POULimit>
Range: -90 dBm  to  53 dBm
*RST:-55 dBm
