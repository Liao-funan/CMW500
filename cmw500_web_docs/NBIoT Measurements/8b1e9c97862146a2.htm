CONFigure:NIOT:MEAS<i>:RFSettings:EATTenuation <RFinputExtAtt>

Defines an external attenuation (or gain, if the value is negative), to be applied to the RF input connector.

For the combined signal path scenario, use CONFigure:​NIOT:​SIGN<i>:​RFSettings:​EATTenuation:​INPut.

Parameters:
<RFinputExtAtt>
Range: -50 dB  to  90 dB
*RST:0 dB
Default unit: dB

See "Specifying General and Common Measurement Settings"

V3.5.10

Manual operation: See "External Attenuation (Input)"
