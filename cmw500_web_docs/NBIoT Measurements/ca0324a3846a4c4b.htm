NB-IoT NPRACH Measurement
The NB-IoT NPRACH measurement provides quick and flexible tests on NB-IoT FDD random access preambles. The tests cover the following UE transmitter properties:
  • Modulation accuracy for each NPRACH symbol (EVM, magnitude error, phase error)
  • Transmit OFF power, transmit ON power and power ramping between them (power dynamics)
  • I/Q constellation diagram

The NPRACH measurement requires option R&S CMW-KM300.
