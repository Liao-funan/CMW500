FETCh:NIOT:MEAS<i>:PRACh:TRACe:EVPReamble?
READ:NIOT:MEAS<i>:PRACh:TRACe:EVPReamble?

Return the values of the EVM vs. preamble traces.

See also "Views EVM vs Preamble, Power vs Preamble".

Return values: 
<Reliability>

"Reliability Indicator"

<Results>

Comma-separated list of 32 EVM values, for preamble 1 to 32 (NCAP for not measured preambles)

Range: 0 %  to  100 %
Default unit: %
Example: 

See "Performing Single-Shot Measurements"

Usage: Query only
Firmware/Software: 

V3.7.20

For additional information concerning syntax elements and returned values, refer to "Conventions and General Information".
