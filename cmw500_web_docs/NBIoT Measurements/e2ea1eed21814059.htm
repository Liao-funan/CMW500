CONFigure:NIOT:MEAS<i>:RFSettings:FOFFset <Offset>

Specifies a positive or negative frequency offset to be added to the carrier center frequency (CONFigure:​NIOT:​MEAS<i>:​RFSettings:​FREQuency).

For the combined signal path scenario, use CONFigure:​NIOT:​SIGN<i>:​RFSettings:​FOFFset:​UL.

Parameters:
<Offset>
Range: -100E+3 Hz  to  100E+3 Hz
*RST:0 Hz
Default unit: Hz
