FETCh:NIOT:MEAS<i>:PRACh:MODulation:SCSGroup:PREamble<Number>?

Returns the numbers of the subcarriers used by the symbol groups of a selected preamble, for multi-preamble measurements.

See also "NB-IoT Preamble Structure".

Suffix: 
<Number>
1..32

Selects a preamble from the range of measured preambles

Return values: 
<Reliability>

"Reliability Indicator"

<SubCarr1>

Subcarrier number for the first symbol group

Range: 0  to  47
<SubCarr2>

Subcarrier number for the second symbol group

Range: 0  to  47
<SubCarr3>

Subcarrier number for the third symbol group

Range: 0  to  47
<SubCarr4>

Subcarrier number for the fourth symbol group

Range: 0  to  47
Example: 

See "Performing Single-Shot Measurements"

Usage: Query only
