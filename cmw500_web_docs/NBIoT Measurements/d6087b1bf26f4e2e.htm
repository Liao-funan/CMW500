Overview
In the overview, a selection of the following results can be displayed:
  • Error vector magnitude
  • Magnitude error
  • Phase error
  • Error vector magnitude vs preamble
  • Power vs preamble
  • I/Q constellation diagram
  • Power dynamics
  • Most important results of the view "TX Measurement"

See also: "TX Measurements"

NPRACH result overview

The results to be measured and displayed in the overview can be limited using the hotkey "Assign Views", see "Additional Softkeys and Hotkeys".

You can enlarge one of the diagrams in the overview and show a detailed view with additional measurement results, see "Selecting and Modifying Views". The traces are described in the following sections.
