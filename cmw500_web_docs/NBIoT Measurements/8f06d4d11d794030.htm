NB-IoT Multi-Evaluation Measurement

The NB-IoT multi-evaluation measurement provides quick and flexible TX tests on Release 13 NB-IoT uplink signals.

The TX tests cover the following UE transmitter properties:
  • UE output power per subcarrier over the entire bandwidth (inband emissions)
  • UE output power per slot (power monitor)
  • OFF/ON power (power dynamics)
  • Modulation accuracy per SC-FDMA symbol (EVM, magnitude error, phase error)
  • Modulation accuracy per modulation symbol (EVM)
  • I/Q constellation diagram
  • Out-of-band emissions (spectrum emission mask and ACLR)

Many of the tests and conformance requirements are specified in 3GPP TS 36.101 or 3GPP TS 36.521.

The multi-evaluation measurement requires option R&S CMW-KM300.
