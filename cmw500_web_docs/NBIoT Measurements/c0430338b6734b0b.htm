Trigger Modes
The NB-IoT multi-evaluation measurement can be performed in the following trigger modes:
  • "Free Run (No Sync)": The measurement starts immediately after it is initiated, without any synchronization.
    This trigger mode can be used for power monitor, ACLR and emission mask measurements, if the subcarrier allocation and the uplink power are continuous. All other results must be ignored (for example modulation results and power dynamics).
  • "IF Power": With an internal IF power trigger, the measurement is triggered by the power ramp of the received bursts.
  • "External Trigger": External trigger signal fed in via the rear panel of the instrument. The availability of a trigger input connector depends on the instrument model.
  • Additional trigger modes: Other firmware applications, for example the NB-IoT signaling application or the GPRF generator, provide additional trigger modes. Refer to the documentation of the corresponding firmware application for a description of these trigger modes.

For configuration, see "Trigger Settings".
