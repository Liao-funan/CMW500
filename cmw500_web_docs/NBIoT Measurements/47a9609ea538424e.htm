Resource Unit Allocation

For allocation to a UE, the resources are grouped into resource units (RU). A resource unit comprises a certain number of subcarriers (SC) in the frequency domain and a certain number of slots in the time domain.

The allowed values depend on the NPUSCH format and on the subcarrier spacing, as listed in the following table.
