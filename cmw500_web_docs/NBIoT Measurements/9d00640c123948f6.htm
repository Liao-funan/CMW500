CONFigure:NIOT:SIGN<i>:CONNection:RMC:FORMat?

Queries scheduling parameters for a UL RMC for NPUSCH format 2. These settings are not configurable.

Return values: 
<Subcarriers>
SC1

Number of subcarriers

<StartSubcarrier>
Range: 0  to  11
<Modulation>
BPSK
<ResourceUnits>
NRU01

Number of resource units

<Repetitions>
NR1 | NR2 | NR4 | NR8 | NR16 | NR32 | NR64 | NR128

Number of NPUSCH repetitions

Usage: Query only
Firmware/Software: 

V3.7.20

Manual operation: See "Resource Allocation"
