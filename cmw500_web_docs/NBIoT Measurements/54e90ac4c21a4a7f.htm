CONFigure:NIOT:SIGN<i>:CELL:SCSPacing <SubCarrSpacing>

Selects the uplink subcarrier spacing. The current software version supports only 15 kHz spacing, not 3.75 kHz.

Parameters:
<SubCarrSpacing>
S15K
*RST:S15K
Firmware/Software: 

V3.7.20

Manual operation: See "Subcarrier Spacing"
