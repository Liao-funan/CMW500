CONFigure:NIOT:MEAS<i>:MEValuation:NREPetitions <NofRepetitions>

Specifies the number of NPUSCH repetitions.

For the combined signal path scenario, use the uplink scheduling commands of the signaling application.

Parameters:
<NofRepetitions>
NR1 | NR2 | NR4 | NR8 | NR16 | NR32 | NR64 | NR128 | NR256 | NR512 | NR1K | NR2K

Means 1, 2, 4, ..., 512, 1024, 2048

*RST:NR1

V3.5.10
