List Mode

The NB-IoT multi-evaluation list mode requires option R&S CMW-KM012. In this mode, the measurement interval is subdivided into segments, according to basic uplink signal properties like expected power, frequency and NPUSCH configuration (format, resource units, subcarriers, repetitions).

The subcarrier spacing cannot be changed during the measurement. Configure separate measurements for different subcarrier spacings.
