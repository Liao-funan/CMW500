CONFigure:NIOT:MEAS<i>:MEValuation:MODulation:MSCHeme <ModScheme>

Selects the modulation scheme used by the measured signal.

For the combined signal path scenario, use the uplink scheduling commands of the signaling application.

Parameters:
<ModScheme>
BPSK | QPSK
*RST:QPSK
