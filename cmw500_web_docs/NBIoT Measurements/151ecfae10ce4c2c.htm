What's New in This Version

This documentation describes version 3.7.20 and later of the NB-IoT multi-evaluation measurement. Compared to version 3.5.10, it provides the following new features:

  • List mode, see "List Mode"
  • Combined signal path scenario, see "Parallel Signaling and Measurement"
  • Band 21, see "Frequency Bands"
  • Power dynamics limits aligned with latest 3GPP update, see "Power Dynamics Limits"
