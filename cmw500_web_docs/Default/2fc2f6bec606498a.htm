Update Procedure

Connection to power supply

Ensure that the instrument remains connected to the power supply during software modifications (uninstall or update).

Disconnecting the instrument during a software modification can result in an inoperable state of the instrument that can only be resolved by Rohde & Schwarz.

To install an update of one or several software packages, perform the following steps.

  1. Shut down a running test software, for example by using an external keyboard and ALT + F4.

  2. Copy all relevant setup files to the same directory. Use a directory on the system drive, on a USB memory stick or in a connected network (LAN).

  3. If you want to update software packages within an installed branch, uninstall the old packages using the following steps.

    You can use these steps also to uninstall a complete software branch.

    1. Open the "R&S Version Selector", for example via the corresponding icon on the desktop.

    2. In the "R&S Version Selector", disable the option "with Restart".

    3. Select the branch or packages that you want to uninstall and press "Uninstall".

      During the uninstall process, confirm possible popup dialogs. Wait until the process is complete.

    4. If you want to uninstall additional software, repeat the previous step.

    5. Close the "R&S Version Selector".

    See also "R&S Version Selector".

  4. Double-click the setup file that you want to execute, for example Setup_CMW_BASE(Release)_<Version>.exe.

    The "R&S Software Distributor" opens.

  5. Select either "Local Installation" or "Remote Installation", depending on the location of your setup files.

    If you want to install additional packages provided by other setup files, enable "Add other setups from current directory".

    See also "R&S Software Distributor".

  6. In the next screen, select which packages you want to install. You can for example deselect firmware application packages for which you have no software option.

  7. For local installation, click "Install".

  8. For remote installation:

    1. Click "Next" to initiate a hardware scan.

      Wait until the "R&S Software Distributor" displays a list of all R&S instruments connected to the LAN.

      If the hardware scan does not yield the desired results, check the "Options..." settings. The "Device Group" setting must match the corresponding setting in the setup dialogs of the instruments ("Setup" dialog > "System" section > "Software Update" > "Device Group"). For further troubleshooting instructions, refer to the online help of the "R&S Software Distributor".

    2. Select your R&S CMW (or several instruments) from the list. Click "Install".

  9. Follow the instructions of the "R&S Software Distributor" until the installation is complete.

  10. Perform a restart (if not initiated automatically).

  11. Shut down the instrument a second time. Switch-off the instrument using the AC power switch at the rear of the instrument.

  12. Switch-on and start the instrument.

    After the restart, the R&S CMW is ready to operate with the updated software.

You can reinstall an already installed software package via the repair function of the "R&S Version Selector", see also "R&S Version Selector".

Tests during type approval

It is not required to perform a recalibration of the R&S CMW after a software upgrade or downgrade.

The following tests are performed during the type approval of every new software release. The tests ensure that the R&S CMW TX and RX is working according to the specification after a software change.

Test 1:
  • Adjustment (measurement of correction values) and verification with the latest official software.
  • Upgrade to the new software and verification.
Test 2:
  • Adjustment and verification with the new software.
  • Downgrade to the latest official software and verification.

The tests are passed if all verification results show comparable values.

Rohde & Schwarz is certified according to ISO 9001 since May 1995.
