SYSTem:HELP:STATus:BITS?

Returns a list of paths for the bits of the STATus:OPERation registers at the lowest level of the hierarchy.

Each path is represented by a string containing all registers from highest to lowest level separated by colons.

Example: "STATus:OPERation:TASK:A:GPRF:MEASurement:POWer:OFF"

Usage: Query only
