STATus:QUEStionable

The STATus:QUEStionable subsystem controls the status reporting structures of the STATus:QUEStionable register, see "STATus:QUEStionable".

Unless otherwise stated, all following commands are SCPI-confirmed. Note that *RST does not influence the status registers (see also "Reset Values of the Status Reporting System").
