MMEMory:CDIRectory ['<DirectoryName>']

Changes the current directory for mass memory storage.

If '<DirectoryName>' is omitted, the current directory is set to '\'. If '<DirectoryName>' contains not only a directory, but also a drive letter or server name, the command MMEM:MSIS is also executed automatically.

Parameters:
'<DirectoryName>'

String parameter to specify the directory. Wildcards are not allowed.

*RST:a *RST does not change the current directory
Example: MMEM:CDIR 'X:\User\Data'

Changes the current directory to X:\User\Data

Usage: SCPI confirmed
