Signaling Applications

While a signaling application is active, the R&S CMW transmits a downlink (forward link) signal to which the mobile station under test can synchronize to establish a network connection. With an established connection, the R&S CMW can exchange control messages with the mobile, request the mobile capabilities, and perform various TX and RX tests.

The R&S CMW supports signaling applications for various network standards. The applications are similar in structure. However, the details of connection setup, the signaling parameters, and the measurements which you can perform with an established network connection depend on the standards. The following topics describe common features of the signaling applications.
