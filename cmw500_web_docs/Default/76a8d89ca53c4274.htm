SENSe:BASE:IPSet:SMONitor:NAME?

Queries the name of all network nodes detected by the subnet monitor.

Return values: 
<Names>

Comma-separated list of strings, one per network node

Example: SENSe:BASE:IPSet:SMONitor:NAME?

Returns for example 'CMW50050-123456', 'PC1483'

Usage: Query only
Firmware/Software: 

V3.0.10
