Timing and Frequency Error

The R&S CMW must establish time synchronization with the input RF signal and estimate its timing, carrier frequency and power. The frequency error is the offset of the measured carrier frequency from the nominal RF frequency of the measured radio channel.

The calculated reference signal R is modified using the estimated timing, frequency error and power. The resulting corrected reference signal R' is used to determine the error vector magnitude, magnitude error and phase error.

The timing error is the deviation of the measured signal timing from the expected timing, which is derived from a trigger event.
