Windows XP Recovery and Backup

This section is only relevant for instruments with Windows XP operating system.

The system drive of the R&S CMW is partitioned as follows:
  • The system partition (drive C) contains the Windows operating system and the instrument software. This software is used for normal operation of the R&S CMW.
  • The data partition (drive D) contains user data.
  • The backup partition contains a backup version (image) of the complete instrument software. You can replace the system image by this "Factory Default" image and thus restore the initial state of the instrument, for example if the operating system is damaged.

The backup/recovery partition also allows you to save and restore additional backup versions, e.g. to have different instrument configurations available.
