CONFigure:BASE:FDCorrection:CTABle:EXISt? <TableName>

Queries whether a correction table with the specified name exists or not.

Query parameters: 
<TableName>

Table name as string parameter

You can add the prefix "inst<n>/" to address subinstrument number <n>+1.

Return values: 
<Exists>
0 | 1

0: table does not exist

1: table exists

Example: CONF:BASE:FDC:CTABle:EXISt? 'mytable'

Check whether a correction table with the name 'mytable' exists or not.

Usage: Query only
Firmware/Software:
