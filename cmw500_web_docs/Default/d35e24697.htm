MMEMory:DATA '<FileName>', <Data>
MMEMory:DATA? '<FileName>'

Stores the specified block data into the specified file.

Parameters:
<Data>
<dblock>

Data in 488.2 block data format. The delimiter EOI must be selected to achieve correct data transfer. See also "Block Data Format".

Parameters for setting and query: 
'<FileName>'

String parameter to specify the name of the file. Wildcards are not allowed.

Example: MMEM:DATA 'C:\TEMP\TEST01.HCP', #219Content of the file

Stores the data Content of the file to the indicated file. #2 indicates that the next two characters (19) indicate the data length.

Example: MMEM:DATA? 'C:\TEMP\TEST01.HCP'

Returns the data contained in file TEST01.HCP in block data format

Usage: SCPI confirmed
