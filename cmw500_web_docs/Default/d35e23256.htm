SYSTem:ERRor:CODE:ALL?

Queries and at the same time deletes all entries in the error queue.

The command returns the error numbers without any description of the errors. Positive error numbers are instrument-dependent. Negative error numbers are reserved by the SCPI standard.

Example: SYSTem:ERRor:CODE:ALL?

Query all entries in the error queue. "0" is returned if the error queue is empty.

Usage: Query only
SCPI confirmed
