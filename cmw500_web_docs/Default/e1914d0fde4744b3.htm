CONFigure:CMWS:FDCorrection:ACTivate:TX <Connectors>, <Table1>[, <Table2>, <Table3>, <Table4>[, <Table5>, <Table6>, <Table7>, <Table8>]]
CONFigure:CMWS:FDCorrection:ACTivate:RX <Connectors>, <Table1>[, <Table2>, <Table3>, <Table4>[, <Table5>, <Table6>, <Table7>, <Table8>]]

Activates correction tables for R&S CMWS input paths (RX) or output paths (TX).

You can use the commands in two ways:
  • To activate a correction table for a selected RF connector of the R&S CMWS, specify a single connector and a single table name.
  • To activate individual correction tables for all RF connectors of a connector bench, select a bench and specify a table for each connector (4 or 8 connectors/tables).

You can add the prefix "inst<n>/" to table names to address subinstrument number <n>+1.

Setting parameters: 
<Connectors>

Selects a single connector or a connector bench with 4 or 8 connectors

For possible values, see "Values for RF Path Selection".

<Table1>

String parameter identifying the table for the selected single connector or for the first connector of the selected bench (e.g. 1.1)

<Table2>

String parameter identifying the table for the second connector of the selected bench (e.g. 1.2)

<Table3>

Table for third connector of selected bench (e.g. 1.3)

<Table4>

Table for fourth connector of selected bench (e.g. 1.4)

<Table5>

Table for fifth connector of selected bench (e.g. 1.5)

<Table6>

Table for sixth connector of selected bench (e.g. 1.6)

<Table7>

Table for seventh connector of selected bench (e.g. 1.7)

<Table8>

Table for eighth connector of selected bench (e.g. 1.8)

Example: CONFigure:CMWS:FDC:ACTivate:RX R11, 'mytable'

Activates 'mytable' for the input direction of connector 1.1.

Example: CONFigure:CMWS:FDCorrection:ACTivate:TX R214, 'table_a', 'table_x', 'mytable15', 'mytable'

Activates different tables for the output direction of connector 2.1, 2.2, 2.3 and 2.4.

Example: CONFigure:CMWS:FDCorrection:ACTivate:RX R318, 'table_a', 'tab_green', 'table_x', 'tabno1', 'mytable15', 'path4', 'mytable', 'cable5'

Activates different tables for the input direction of connector 3.1 to 3.8.
