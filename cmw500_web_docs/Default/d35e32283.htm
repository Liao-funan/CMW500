SYSTem:TIME:LOCal <Hour>, <Minute>, <Second>

Sets the local time of the operating system clock.

Parameters:
<Hour>
Range: 0  to  23
<Minute>
Range: 0  to  59
<Second>
Range: 0  to  59
Example: SYSTem:TIME:LOCal?

Query the local time. Possible response: 15, 09, 20

Firmware/Software:
