Vertical Toolbar

The toolbar on the left of the main window allows you to rearrange the open windows comfortably and it serves as soft-front panel, see also "Using the Soft-Front Panel and Keyboard Shortcuts".

You can minimize the main window so that only the toolbar is visible.
