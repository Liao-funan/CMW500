*LMC?

Returns the macro labels of all macros of the active connection.

Return values: 
'<Macro Label 1>', '<Macro Label 2>' ...

Comma-separated list of string parameters. An empty string indicates that no macros are defined for the active connection. The macro labels are also used to execute the macros and to reference them in other macro commands (e.g. MMEMory:​STORe:​MACRo, *DMC, *RMC).
