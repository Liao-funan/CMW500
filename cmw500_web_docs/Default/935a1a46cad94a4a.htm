HCOPy:INTerior:DATA?
HCOPy:DATA?

Captures a screenshot and returns the result in block data format, see also "Block Data Format".

HCOPy:DATA captures the entire window, HCOPy:INTerior:DATA only the interior of the window.

It is recommended to "switch on" the display before sending this command, see SYSTem:​DISPlay:​UPDate.

Return values: 
<Data>
<dblock>

Screenshot in 488.2 block data format

Usage: Query only
Firmware/Software: 

V3.0.10
