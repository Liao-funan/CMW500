SENSe:BASE:IPSet:SNODe:NSEGment?

Queries information about the selected network segment and the resulting subnet properties.

Return values: 
<SelectedSegment>
A | B | C

Selected network segment

*RST:A
<IPAddress>

String indicating the first two IP address octets for the subnet

*RST:'172.22.x.x'
<SubnetMask>

String indicating the used subnet mask (fixed value)

*RST:'255.255.0.0'
Usage: Query only
Firmware/Software: 

V3.0.10
