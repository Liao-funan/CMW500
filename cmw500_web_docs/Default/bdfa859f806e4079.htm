General Description

This section provides a general description of the firmware application, independent of a specific operation mode (manual or remote control). It gives a high-level introduction to the capabilities of the firmware application. Background information related to the network standard is given as far as it is directly related to administrable parameters. For measurement applications, a detailed description of measurement results and a description of configurable limits is given, including the relation to conformance requirements defined in network standard specifications.
