How to Read Firmware Application Chapters

Each firmware application is described in a separate chapter. These chapters can be read independently of each other. However, they are all organized as follows:

  1. General description

  2. Application sheets (optional)

  3. GUI reference

  4. Programming examples

  5. Command reference

The chapters "System Overview" and "Remote Control" provide additional important information independent of the individual firmware applications. The most important parts are referenced by the firmware application descriptions.
