Macro Commands

The following remote control commands are related to macro files and macro execution. All macro commands are SCPI-confirmed.

R&S CMW-specific command properties
The following macro command properties differ from SCPI stipulations:
  • The *RST state of *EMC is OFF. Macro execution must be enabled deliberately for every remote connection.
  • Normal remote control execution has priority over macro execution. Macros which have the same name as a remote command supported by the R&S CMW are ignored.
