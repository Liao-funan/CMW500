SENSe:BASE:REFerence:FREQuency:LOCKed?

Queries whether the reference frequency is locked or not.

Return values: 
<Locked>
1 | 0

1: frequency is locked

0: frequency is not locked

Usage: Query only
Firmware/Software: 

V1.0.5.3
