Subinstruments

If the required hardware is available, the instrument can be split into two or four subinstruments which operate independently.

The instrument must be equipped with at least one RX signal path, TX signal path and baseband measurement board per subinstrument.

In the factory default configuration, all resources are grouped in a single subinstrument. Splitting the instrument can help to run tasks in parallel, and minimize the risk of resource conflicts between these tasks.

The following sections are only relevant if your instrument is equipped with at least two RX signal paths, two TX signal paths and two baseband measurement boards.
