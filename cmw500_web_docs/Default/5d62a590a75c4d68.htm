Overview of Syntax Elements

Element

Usage

:

The colon separates the keywords of a command. In a command line, the separating semicolon marks the uppermost command level.

;

The semicolon separates two commands of a command line. It does not alter the path.

,

The comma separates several parameters of a command.

?

The question mark forms a query.

*

The asterisk marks a common command.

', "

Quotation marks introduce a string and terminate it.

#

The hash sign # introduces block data.

Block: #21312

 

A "white space" (ASCII-Code 0 to 9, 11 to 32 decimal, e.g. blank) separates header and parameter.
