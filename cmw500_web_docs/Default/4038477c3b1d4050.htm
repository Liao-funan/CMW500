Real-Time and Arbitrary (ARB) Generator Signals

The properties of real-time generator signals are based on the settings in the generator configuration dialogs. An example for a real-time signal (dual-tone GPRF signal) is described in section "Generating an RF Signal".

In contrast, the arbitrary (ARB) generator signal is based on a "waveform file" (typically, a file generated with R&S WinIQSIM) which is loaded and processed at runtime. The R&S CMW supports waveform files for many network standards.
