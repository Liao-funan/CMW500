Retrieving Measurement Results

The results of a measurement can be retrieved by FETCh...? or READ...? queries. Limit check results are retrieved by CALCulate...? queries. All command types have the same structure:

FETCh:<FWA>:<Context>:<View>:<Statistics>...?
READ:<FWA>:<Context>:<View>:<Statistics>...?
CALCulate:<FWA>:<Context>:<View>:<Statistics>...?

e.g. FETCh:GPRF:MEASurement<i>:POWer:CURRent?

The three identifiers <FWA>, <Context>, <View> and <Statistics> denote the "Firmware Applications", "Measurement Contexts and Views", and the "Statistics Type", respectively. <View> is only required for measurement contexts providing several views.

The number and type of measurement results depends on the measurement context and view; refer to the relevant reference documentation.
