MMEMory:DELete '<FileName>'

Deletes the specified files.

Parameters:
'<FileName>'

String parameter specifying the file to be deleted. The wildcards * and ? are allowed. Specifying a directory instead of a file is not allowed.

Example: MMEM:DEL 'C:\TEMP\TEST01.HCP'

Deletes file TEST01.HCP in directory C:\TEMP

Example: MMEM:DEL 'C:\TEMP\*.*'

Deletes all files in directory C:\TEMP

Usage: Event
SCPI confirmed
