MIB Files
The software package includes two management information base (MIB) files for the management application:
  • RC-COMMON-MIB.mi2: common MIB file, usable for all Rohde & Schwarz instruments with SNMP agent
  • RS-CMW-SNMP-DIAG-MIB.mi2: R&S CMW-specific MIB file
During the installation of the software package, the files are stored on the system drive of the instrument. The path depends on the operating system:
  • Windows 7:
    C:\ProgramData\Rohde-Schwarz\CMW\Snmp
  • Windows XP:
    C:\Documents and Settings\All Users\Application Data\Rohde-Schwarz\CMW\Snmp

You can copy the files from this location to your management application.

MIB files with the extensions .mi2, .mib and .txt have the same file format. You can change the file name extension of the delivered MIB files to .mib or .txt, if necessary.
