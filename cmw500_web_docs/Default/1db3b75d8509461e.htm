Statistics Type

In general, the following types of statistical results are available for scalar results (single values) and traces:

Current: Result of the current measurement interval

Minimum/Maximum: Minimum or maximum of all evaluation periods since the measurement was started

Average: Average referenced to one single-shot measurement length
