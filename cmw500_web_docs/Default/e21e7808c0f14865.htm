Boolean Parameters

Boolean parameters represent two states. The ON state (logically true) is represented by ON. The OFF state (logically false) is represented by OFF. Replacement of ON or OFF by 1 or 0 is not supported.

Example:

Setting command: SOURce:GPRF:GENerator:STATe ON

Query: SOURce:GPRF:GENerator:STATe? returns ON

Some of the remote control commands in the SYSTem... and STATus... subsystems are not implemented as described above. These commands are not needed for measurements or to generate RF signals.
