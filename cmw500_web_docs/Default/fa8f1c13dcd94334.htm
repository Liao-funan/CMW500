Measurements

The R&S CMW provides several measurement applications. Most measurement applications are dedicated to a specific network standard. Some are general-purpose applications, for example for power measurements.

All measurements are controlled in an analogous way. The following topics describe the principles of measurement control and measurement results that are similar in many measurement contexts. For a sample session, refer to "Measuring an RF Signal".
