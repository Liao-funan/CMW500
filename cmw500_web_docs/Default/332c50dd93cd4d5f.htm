SYSTem:COMMunicate:GPIB<i>[:SELF]:ENABle <State>

Enables or disables the GPIB interface.

Suffix: 
<i>
1..4 (depending on installed options)

Selects the remote channel.

Parameters:
<State>

ON | 1: GPIB enabled

OFF | 0: GPIB disabled

*RST:a *RST has no effect on the value
Example: SYSTem:COMMunicate:GPIB:ENABle ON

Enable GPIB interface (channel 1).

Firmware/Software: 

V1.0.0.4
