Four RF Paths, Two Frontends, Four Subinstruments

This section applies to an instrument with four RF paths, two advanced frontends and up to four instances per firmware application. The instrument is split into four subinstruments.

Each subinstrument uses one specific frontend. The TX and RX module numbering is a logical numbering per subinstrument, not per instrument. That means e.g. that within subinstrument 1 the value TX1 refers to another physical TX module than within subinstrument 2.
