Statistic Count

Integer number of measurement intervals per measurement cycle (single-shot measurement). The statistic count can be set independently for any measurement context or view; see "Measurement Contexts and Views".

CONFigure:<FWA>:<Context>:SCOunt:<View> <Count>

e.g. CONFigure:LTE:MEASurement:MEValuation:SCOunt:MODulation 10

(sets the statistic count for LTE multi-evaluation modulation measurements).
