V3.5.40 (Compared to V3.5.10)
New features:
  • DAU and audio board supported by R&S CMW290
  • Setup dialog enhanced for multi-CMW setups, see "Multi-CMW"
  • On-screen keyboard/keypad, see "Startup"
  • The state of an application can now also be changed via right-click of the control softkey, see for example "Generator Control"
  • The date and time settings of the operating system can be configured via the setup dialog, see "System Settings"
