CONFigure:BASE:FDCorrection:CTABle:LENGth? <TableName>

Returns the number of entries (i.e. pairs of frequency and attenuation) of a correction table.

Query parameters: 
<TableName>

String parameter identifying the table. To display a list of existing tables, use the command CONFigure:​BASE:​FDCorrection:​CTABle:​CATalog?.

You can add the prefix "inst<n>/" to address subinstrument number <n>+1.

Return values: 
<TableLength>

Number of table entries

Example: CONF:BASE:FDC:CTABle:LENGth? 'mytable'

For 'mytable' containing four frequency/attenuation pairs, the result is 4.

Usage: Query only
