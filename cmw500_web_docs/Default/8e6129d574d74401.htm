V3.5.10 (Compared to V3.2.70)
New features:
  • Instruments with four RF signal paths and four measurement boards can be split into four subinstruments, see "Subinstruments"
  • Improved help browser, so that the help system opens quickly when you press the HELP button
    For the buttons of the new browser, see "Softkeys"
  • Improved configuration dialog for frequency-dependent attenuation correction tables, see "Frequency-Dependent Correction Tables"
  • Instrument information can be exported to a PDF file, see "Device Footprint Summary Tab"
  • The host name is configurable in the setup dialog, see "System Settings"
  • Support of Windows 7 - which Windows version is installed, depends on the installed controller
  • The parameter "Enable Speech Codec" has been removed from all signaling applications. Instead, the coupled signaling application is now selected in the audio measurement application, via the speech analysis settings. Refer to the audio measurement documentation.
  • First base software release supporting the R&S CMW290. Lower base software releases are not compatible with the R&S CMW290.
