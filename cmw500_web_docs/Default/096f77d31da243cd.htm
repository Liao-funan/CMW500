Quick Start Guide

The quick start guide introduces the R&S CMW and describes how to set up and start working with the product.

A printed version of the manual is delivered with the instrument.

A PDF file is available on the CMW customer web.

For instruments with protocol testing applications, additional printed documentation is delivered. It provides an introduction to protocol testing.
  • The quick start guide "R&S CMW500 Protocol Tester" is delivered with option R&S CMW-KP090.
  • The getting started manual "R&S CMW500 CMWcards Signaling Tester" is delivered with option R&S CMW-KP091.
