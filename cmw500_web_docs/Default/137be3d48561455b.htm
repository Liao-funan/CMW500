MMEMory:DCATalog:LENGth? ['<DirectoryName>']

Returns the number of subdirectories of the current or of a specified directory. The number includes the directory strings "." and ".." so that it corresponds to the number of strings returned by the MMEMory:​DCATalog? command.

Parameters:
'<DirectoryName>'

String parameter to specify the directory. If the directory is omitted, the command queries the contents of the current directory (see MMEMory:​CDIRectory).

If the wildcards ? or * are used, the number of subdirectories matching this pattern are returned.

Example: MMEM:DCAT:LENG?

Response: 5 (corresponding to the MMEMory:​DCATalog? example)

Example: MMEM:DCAT:LENG? 'X:\User\Data\session*'

Returns the number of subdirectories starting with session which are located in directory X:\User\Data.

Usage: Query only
