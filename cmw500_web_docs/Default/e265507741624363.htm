Connecting a LAN Cable

Connect an RJ-45 cable to a LAN port of the R&S CMW. The LAN REMOTE connector on the rear panel and the LAN connector on the front panel are suitable for this purpose. Do not use other LAN connectors for remote operation of the instrument.

Dedicated vs. non-dedicated network connections
There are two methods to establish a LAN connection of the R&S CMW:
  • A non-dedicated network (Ethernet) connection from the tester to an existing network. The tester is assigned an IP address and can coexist with a computer and with other hosts on the same network.
  • A dedicated network connection between the tester and a single computer. The computer must be equipped with a network adapter and is directly connected to the tester. The use of hubs, switches, or gateways is not needed, however, data transfer is still made using the TCP/IP protocol.

Avoid parallel connection

Never use more than one LAN connector to connect the R&S CMW in parallel to the same network. Parallel connections result in connection errors.
