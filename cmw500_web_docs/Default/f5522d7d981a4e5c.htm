Four RF Paths, Two Frontends, One Subinstrument

This section applies to an instrument with four RF paths, two advanced frontends and up to four instances per firmware application. All resources are grouped in one subinstrument.

All firmware application instances can access both frontends. The following table lists the supported parameter values for selection of RF connectors and TX/RX boards.
