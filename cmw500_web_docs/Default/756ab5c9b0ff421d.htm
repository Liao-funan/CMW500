SYSTem:TIME:HRTimer:ABSolute <Timeout>

This command starts a timer. The timeout is specified relative to an already set timestamp, see SYSTem:​TIME:​HRTimer:​ABSolute:​SET.

When the timer expires, "Operation Complete" is indicated. This event can be evaluated by polling, via a *OPC? or via *WAI.

Setting parameters: 
<Timeout>
Range: 0 ms  to  4294967295 ms
Default unit: ms
Example: SYST:TIME:HRT:ABS:SET
SYST:TIME:HRT:ABS 1000
*OPC?

The three commands have the following effects:

Set a timestamp with the current system time.

Start a timer with a timeout value of 1 second relative to the timestamp.

Wait until the timer expires before processing the next command.

Usage: Event
Asynchronous command
