Peak Values
"Peak" values are calculated as the maximum of the magnitude times the sign:
  • For positive quantities such as the EVM, the peak value is equal to the maximum.
  • For negative quantities such as the I/Q offset and the I/Q imbalance, expressed in dB, the peak value is equal to the minimum.
  • For symmetric quantities with alternating sign such as the phase, frequency or timing error, the peak value is either the maximum or minimum, whichever has the larger magnitude.
