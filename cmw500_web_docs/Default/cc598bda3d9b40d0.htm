R&S CMW Models

The R&S CMW software supports several instrument models. Depending on the model, only a subset of the software features is supported. The supported hardware options depend also on the instrument model.

The help system is also applicable to several R&S CMW models. The following tables provide an overview of the differences between the models that are relevant in the context of this documentation.

The supported software options depend on the instrument model. Roughly speaking, the models support the following options:
  • The R&S CMW500 supports most available R&S CMW measurement and signaling options.
  • The R&S CMW270 supports non-cellular measurement and signaling options.
  • The R&S CMW290 supports most basic measurement and signaling options. Advanced options are not supported.
