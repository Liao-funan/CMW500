Installing Software Not from Rohde & Schwarz

The instruments are designed to provide optimum CPU performance for testing. Every additional installed and active software decreases the performance of the instrument and therefore must be avoided.

If you install software other than the software provided by Rohde & Schwarz on the instrument, Rohde & Schwarz cannot take over the responsibility for correct operation of the instrument.
