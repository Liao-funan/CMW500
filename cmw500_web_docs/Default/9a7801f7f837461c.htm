Adapting Windows Firewall Settings

The Windows Firewall is turned on by default.

For protocol testing, all firewall exceptions are automatically added. This task is performed by the CMW FIREWALL EXCEPTIONS installer that is automatically installed and updated when using the Rohde & Schwarz Installation Manager.

For RF testing, the software installers for the firmware applications add necessary firewall exceptions.
