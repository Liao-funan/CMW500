Note for Faceless Instruments

An instrument without display is controlled via a monitor, mouse and keyboard. A soft-front panel is displayed in addition to the GUI. It emulates the front panel control elements of an instrument with display.

Thus descriptions involving front panel keys are applicable to instruments with display (operation via front panel or soft-front panel) and to instruments without display (operation via soft-front panel).
