Using Anti-Malware Software

An effective protection against malware is a prerequisite for secure operation of an instrument in a network.

Recommendation for Rohde & Schwarz instruments

Run scans for threats frequently during non-critical hours at least once per week.

However, do not run anti-malware software in the background ("on-access" mode) on the instrument because it possibly degrades the performance of the instrument.

Recommendation for the R&S CMWC only

Protect the R&S CMWC by installing a suitable anti-malware software (3rd party software). The R&S CMWC has enough performance to run such software also in the background. For more information, see the "Multi-CMW-PCIe" release note.
