V3.2.10 (Compared to V3.0.14)
New features:
  • New hardware for audio measurements, providing also audio connectors at front and rear panel
  • Configurable rotary knob behavior, see "Tree Navigation Mode"
  • The list of active license files can be sorted by category, see "Option Activation and Deactivation"
  • New hotkeys corresponding to SYSTem:DISPlay:UPDate ON/OFF, see "Using the Display during Remote Control"
  • Additional button on the soft-front panel, corresponding to SYS front panel key, see "Using the Soft-Front Panel and Keyboard Shortcuts"
  • A numerical value can be queried with a desired unit instead of the default unit, see "Responses to Queries"
