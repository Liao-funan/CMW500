Operating the Instrument
You can operate the instrument manually or via remote control:
  • Remote control:
    You create scripts to automate repeating settings, tests and measurements. The scripts are executed on a computer controlling the instrument.
    For an introduction, see "Remote Control".
  • Manual operation:
    You control the instrument via a graphical user interface (GUI), using a mouse and a keyboard or a connected touchscreen. If your instrument is equipped with a display, you can also control it via the front panel control elements.
    You display the GUI on a built-in display or on an external monitor or access it via a remote desktop connection.
    The principles of manual operation are explained in this chapter.

To connect a mouse, keyboard or monitor, see "Connecting External Devices".

To establish a remote desktop connection, see "Remote Desktop Connection".

Contents and scope

This chapter describes the operation of an instrument with display and front panel control keys. Control of an instrument without display using emulated front panel controls is analogous; see "Using the Soft-Front Panel and Keyboard Shortcuts".
