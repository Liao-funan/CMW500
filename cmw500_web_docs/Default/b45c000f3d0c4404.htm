SYSTem:BASE:DEVice:RESet

Assigns the available hardware resources to the subinstruments.

Send this command to the subinstrument with the lowest number (device number 0 / assigned instrument 1 / subinstrument 1).

After changing the number of subinstruments via SYSTem:BASE:DEVice:COUNt, always send this command.
