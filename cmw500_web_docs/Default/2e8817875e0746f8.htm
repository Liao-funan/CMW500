Trying Out the Instrument

This chapter helps you to get familiar with the R&S CMW. It provides some sample sessions with manual control of the instrument, using a mouse and a keyboard. You can operate the instrument locally or via a remote desktop connection.

As a prerequisite, the instrument must be set up and started up. The required devices must be connected.

For additional information, see:
  • "Putting the Instrument into Operation"
  • "Connecting External Devices"
  • "Remote Desktop Connection"
Reset

To obtain predictable results, it is recommended to reset the R&S CMW to a definite state before you try out the examples in this chapter. Press RESET to open the "Reset" dialog and perform a preset.
