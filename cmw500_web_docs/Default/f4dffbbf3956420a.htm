User Manual and Help
Separate user manuals are provided for the base unit and the firmware applications:
  • The base unit manual describes the base software and common features of the firmware applications. It also describes basic principles for manual operation and remote control. The manual includes the contents of the quick start guide.
  • Additional PDF files describe the firmware applications, including the graphical user interface of each application and the remote control commands.

All user manuals are available on the CMW customer web.

The contents of the user manuals are also available as help in the R&S CMW. The help offers quick, context-sensitive access to the information needed for operation and programming. If you perform a software update, the help is also updated.
