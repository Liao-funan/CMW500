Enabling Windows Updates

Installation of Microsoft updates is not expected to harm the proper operation or the properties of the instrument.

If you install Microsoft security updates, Rohde & Schwarz cannot guarantee the properties and proper operation of the instrument.

Recommended configuration 1

"Download updates but let me choose whether to install them": This configuration under "Windows Update" does not interfere automated testing.

Windows prompts you when new updates are available but it does not interrupt the current operation of the instrument. You can decide when to install the updates after the automated test session.

Possibly the operation of the instrument is impaired during installation of the update.

Recommended configuration 2

"Install updates automatically (recommended)": This configuration under "Windows Update" ensures a full patch level installation. You can select this configuration if an interruption of the current operation is allowed.

If an update is available, Windows automatically downloads and installs it. The installation possibly impairs the operation of the instrument and possibly reboots the instrument.
