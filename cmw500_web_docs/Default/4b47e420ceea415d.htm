PCIe IN Connector (Optional)

The PCIe interface is used in multi-CMW setups for communication between the signaling units and the R&S CMWC. The connector is included in option R&S CMW-B554N.

An appropriate cable is included in the delivery. Connect it as described in the R&S CMWC manual.
