V3.0.10 (Compared to V2.1.27)
New features:
  • The names displayed for the network adapters in the setup dialog have been improved, see "System Settings"
  • New recommended protocol HiSLIP for remote control via LAN interface, see "Remote Settings"
  • The internal IPv4 subnet of the instrument is configurable, see "IP Subnet Configuration"
  • Trigger signals, see "Trigger"
    –Configurable slope for output trigger signals at TRIG A and TRIG B
    –User initiated trigger signal for synchronous triggering of several applications
  • Logging settings in "Setup" dialog allow you to define a pool of three logging PC IP addresses, see "Logging"
  • Configurable fan control, e.g. for reduction of noise emissions, see "Fan Control"
  • New cell state for signaling applications: RDY (to receive an inter-RAT handover), see "Control of the Cell State"
  • Reliability indicator:
    –Additional reliability values, see "Reliability Indicator"
    –Reliability list displaying all reliability values detected by an application (not only most severe one), see "Current State Tab"
  • Remote trace display in analysis mode can be cleared via TRACe:​REMote:​MODE:​DISPlay:​CLEar
  • HCOPy commands for creation of screenshots, see "Hardcopy Commands"
  • SCPI command shell added to LXI home page, see "LXI Browser Interface"
  • Enhanced commands: SYSTem:PRESet and SYSTem:​RESet
  • Task bar enhancement: maximum number of entries increased to 14
  • Commands for partial save/recall:
    MMEMory:​LOAD:​ITEM, MMEMory:​STORe:​ITEM
  • Extensions of the STATus:OPERation register: support of signaling applications and application instances, see "STATus:OPERation"
