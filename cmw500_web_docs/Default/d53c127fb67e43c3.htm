Emulation Codes

Most remote control interfaces support a protocol for low-level control messages, for example for polling. In contrast, a VISA socket resource provides no protocol functions for this purpose. Instead, emulation codes can be transferred to emulate interface messages.

Most emulation codes are described in the IEEE 1174 standard. The following table provides an overview.

Code

Meaning

Effect on the instrument

&ABO

&BRK

&DCL

(Abort)

(Break)

(Device clear)

Aborts processing of the received commands and sets the command processing software to a defined initial state. Does not change the instrument setting.

&GTL

(Go to local)

Transition to the "Local" state (manual control).

&GET

(Group execute trigger)

Triggers a previously active device function (e.g. a sweep). The effect of the command is the same as the effect of a pulse at the external trigger signal input.

&GTR

(Go to remote)

Transition to the "Remote" state (remote control).

&LLO

(Local lockout)

Disables switchover from remote control to manual control via the (soft-) front panel keys or remote commands.

&NREN

&RLSD

(Not remote enable)

Enables switchover from remote control to manual control via the (soft-) front panel keys or remote commands.

&POL

(Serial poll)

Starts a serial poll.
