Repetition Mode

Single-shot: The measurement is stopped after the number of measurement intervals defined by the "statistic count".

Continuous: The measurement is continued until it is stopped explicitly. Average results are calculated according to the rules given in section "Statistical Results".

Manual and remote control

In contrast to other instrument settings, the repetition modes in manual and remote control are independent and do not overwrite each other. The default repetition mode in manual control is "Continuous" (observe results over an extended period of time). The default mode in remote control is "Single-Shot" (measure one cycle and retrieve results).
