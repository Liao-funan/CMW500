MMEMory:RCL '<FileSource>'

Restores the instrument settings from the specified file.

This command has the same effect as the combination of MMEMory:LOAD:STATe and *RCL.

Parameters:
'<FileSource>'

String parameter specifying the path and filename of the source file. Wildcards are not allowed.

Example: MMEM:RCL '@SAVE\mysavefile.dfl'

Loads and activates the instrument settings from the file mysavefile.dfl located in the directory assigned to the @SAVE alias.

Usage: Event
