Remote Desktop Connection

Remote desktop is a Windows application which can be used to access and control the R&S CMW from a remote computer through a LAN connection. The R&S CMW GUI is then displayed on the remote computer together with an additional soft-front panel, see "Using the Soft-Front Panel and Keyboard Shortcuts").

To set up the first remote desktop connection to the instrument, proceed as follows:

  1. Access the Windows operating system of the instrument:

    Press the Windows logo key on an external keyboard connected to the instrument. Alternatively, press the SYS key on the front panel (only instruments with display).

  2. Open the "Control panel > System settings > Remote settings".

  3. Enable remote desktop access to the instrument. Close the dialog.

  4. Display the R&S CMW GUI (R&S CMW application).

  5. Connect the tester to the network. See "Connecting a LAN Cable".

  6. Assign an IP address to the tester. See "Assigning an IP Address".

  7. At a remote computer integrated in the LAN, create a remote desktop connection using the tester's IP address. You can also use other utilities providing remote PC access, e.g. VNC.

Password protection

Remote access to the R&S CMW requires a user name and password. In the factory configuration, "instrument" is preset both for the user name and for the password.
