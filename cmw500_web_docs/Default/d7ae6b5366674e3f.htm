Starting Protocol Testing Tools

If a protocol test option is installed, you can use your R&S CMW in two different modes:

  • Protocol test mode:
    The software tools for protocol testing are started from the Windows "Start" menu of your R&S CMW.
    If the Windows desktop is not visible, you can access it by pressing the Windows key + D on an external keyboard. Alternatively, press the SYS key on the front panel (only instruments with display). Maximize the "R&S CMW" application again if you want to switch to RF test mode.
  • RF test mode:
    RF tests are performed using the "R&S CMW" application software. Use the task bar to access one of the RF firmware applications (e.g. the GPRF measurements or the GPRF generator). The RF test mode is described in the present help system.
    See also "Accessing Dialogs"
Documentation for protocol testing

The documentation for protocol testing is delivered with the protocol test options.
