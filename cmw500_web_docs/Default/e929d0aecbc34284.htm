What's New in This Version
This documentation describes version 3.7.20 and higher of the R&S CMW base software. Compared to version 3.7.10, it provides the new features listed below.
  • Support of LR-WPAN measurements (R&S CMW-KM680, requires measurement unit advanced (MUA))
  • Enhanced commands for correction tables, so that the tables of all subinstruments can be managed via all remote channels, see "Frequency-Dependent Correction"
