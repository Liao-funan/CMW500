TRIGger:BASE:EXTA:SOURce '<Source>'
TRIGger:BASE:EXTB:SOURce '<Source>'

Selects the output trigger signals to be routed to the TRIG A and TRIG B connectors. The available values depend on the installed options. A complete list of all supported values can be retrieved using TRIGger:...:CATalog:SOURce?.

Parameters:
'<Source>'

Trigger source as string

*RST:'No Connection'
Example: TRIGger:BASE:EXTB:SOURce "GPRF Gen1: Waveform Marker 1"

Select the waveform marker 1 of the GPRF generator as an output trigger signal for connector TRIG B.

Firmware/Software:
