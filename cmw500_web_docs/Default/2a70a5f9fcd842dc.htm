Four Subinstruments

This section describes an instrument split into four subinstruments. Each subinstrument is addressed separately and equipped with independent hardware and software resources to run the tasks assigned to it.

The instrument must provide four RX and TX signal paths, two advanced frontends and four baseband measurement boards. As an example, the instrument provides four firmware application instances. So each subinstrument gets one RX and TX signal path and one firmware application instance.

The basic principles are similar as for two subinstruments. Each firmware application instance, signal path and RF connector are fix assigned to one specific subinstrument. The RX and TX modules of all subinstruments are named identically but refer to different physical modules.
