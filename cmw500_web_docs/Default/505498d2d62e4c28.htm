Accessing the Recovery and Backup Dialog

From the "Recovery and Backup" dialog, you can initiate all actions related to backups.

To access the dialog:

  1. Connect an external keyboard.

  2. Switch on the R&S CMW.

  3. While the boot menu is displayed, select "Backup/Recovery" using the cursor keys.

  4. Press "Enter" to open the dialog.
