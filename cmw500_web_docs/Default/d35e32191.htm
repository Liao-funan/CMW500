SYSTem:DATE:LOCal <Year>, <Month>, <Day>

Sets the local date of the operating system calendar.

Parameters:
<Year>
Range: four-digit number
<Month>
Range: 1  to  12
<Day>
Range: 1 to n (depending on the <Month>)
Example: SYSTem:DATE:LOCal?

Query the local date. Possible response: 2012, 09, 20

Firmware/Software:
