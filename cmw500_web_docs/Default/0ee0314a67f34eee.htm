Variables

The following table lists all variables that you can query from the SNMP agent, for example via GET requests.

The last column is related to the variable rsCmwActive.

Variable

Meaning

Flag

rsCmwIDN

Instrument ID string as returned by the SCPI command *IDN?

no

rsCmwTime

Local time in the format YYYY-MM-DD hh:mm:ss

no

rsCmwActive

Flag (1 | 0) indicating if the tester has been used (1) or not (0) since the last query of the flag.

When you query the flag, the variables are evaluated as indicated in the last table column:
  • "no": The variable has no impact on the flag.
  • ">0": The flag is set to 1 if the variable is greater than zero.
  • "≠": The flag is set to 1 if the variable has changed since the last query of the flag.

no

rsCmwActiveTasks

Number of all active tasks. A zero indicates that the instrument is idle.

An active task is for example a running measurement, an ongoing reset, a save/recall operation or remote control command processing.

no

rsCmwRemoteConnections

Number of established SCPI remote control connections

no

rsCmwActiveMeasTasks

Number of active measurement tasks (type MEAS)

>0

rsCmwActiveGenTasks

Number of active generator tasks (type GEN)

>0

rsCmwActiveSigTasks

Number of active signaling tasks (type SIG)

>0

rsCmwKeyStrokes

Number of keystrokes since the last query

≠

rsCmwRemoteCommands

Number of remote commands received since the last query

≠

rsCmwStartedPTApps

Number of protocol tester applications started since the last query

≠

rsCmwActivePTApps

Number of currently running protocol tester applications

no

rsCmwPTAppsActive

Flag (1 | 0) indicating if a key was pressed or a mouse click was done (1) or not (0) since the last query of the flag.

Key / mouse events of all Windows processes are considered, but only while a protocol tester application is running.

≠

rsCmwStartedPTTests

Number of protocol tester test cases started since the last query

≠

rsCmwEndedPTTests

Number of protocol tester test cases ended since the last query

≠

rsCmwActivePTTests

Number of currently running protocol tester test cases

>0
