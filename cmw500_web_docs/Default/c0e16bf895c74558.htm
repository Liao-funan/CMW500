Malware Protection
Background information

Malware (short for malicious software) is software that is designed to damage, disrupt or gain authorized access to computer systems. The term refers to various forms of intrusive or hostile software, including computer viruses, worms, Trojan horses, and other malicious software.

System drive
The system drive contains three partitions:
  • System – This standard partition contains the Windows system.
  • Data
  • Backup

A boot manager lets you select the boot partition: System or Backup.

For details, see "Backup and Restore Application".

Microsoft security updates

Microsoft frequently provides security update software for their products to fix problems and to improve security. This software reduces the risk to get a malware infection. Security updates are available on the Microsoft Support website. Download the packages from there.

For Windows Embedded Standard 7 x64, visit the "Microsoft Update Catalog":

http://www.catalog.update.microsoft.com/Search.aspx?q=x64+Embedded+Standard+7

To automate Windows updates, you can use the "Windows Server Update Services (WSUS)". For general information about WSUS, visit https://technet.microsoft.com/en-us/windows, and then search for "WSUS". The "Windows Update" service detects, downloads, and installs updates for Windows. Ask your local system administrator for details.

Recommendations
  • Before connecting your instrument to a network, ensure that the network is free of malware and properly maintained.
  • Before connecting USB media to your instrument, ensure that the media are scanned and free of malware.
  • Install Windows security updates. The frequent installation of security updates reduces security risks.
  • Before booting the backup partition:
    –Disconnect your instrument from any network and unplug any USB media. This measure protects your backup partition from malware infections.
    –Scan your standard system partition for threats to ensure that it is clean.
