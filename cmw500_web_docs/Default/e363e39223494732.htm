Utility Keys

The utility keys to the left of the display provide access to the utility dialogs, to the help system and to the operating system. Utility dialogs are used to perform administrative tasks and to reset the instrument to a definite state.

  • RESET – restores a definite instrument state.
    See also "Reset Dialog"
  • INFO – provides an overview of firmware application states and allows you to prepare files for problem reporting.
    See also "Info Dialog"
  • SAVE RCL – stores or recalls instrument settings.
    See also "Save/Recall Dialog"
  • SETUP – opens the "Setup" dialog. Use this dialog to perform administrative tasks, define basic instrument settings, enable options, view the startup results and access service functions.
    See also "Setup Dialog"
  • PRINT – stores a hardcopy of the screen contents.
    See also "Print Dialog"
  • HELP – opens the help system.
  • SYS – minimizes the R&S CMW software application and gives access to the Windows desktop and start menu (toggle function). Use the operating system level to perform system configurations and call up additional software utilities.
