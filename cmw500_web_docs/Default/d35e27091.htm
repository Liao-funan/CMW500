SYSTem:BASE:SSYNc:MODE <Mode>

Specifies the role of the instrument in a multi-CMW setup, concerning the system time synchronization signal.

Parameters:
<Mode>
LIST | GEN | STAN

LISTener: The instrument receives a time synchronization signal at SYS SYNC IN

GENerator: The instrument provides a system synchronization signal at the rear panel

STANdalone: The instrument uses its internal synchronization signal

Example: SYST:BASE:SSYN:MODE GEN

Use the R&S CMW to generate a system synchronization signal.
