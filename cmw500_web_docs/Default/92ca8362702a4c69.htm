High-Resolution Timer

After execution of a command, it can be required to wait a well-defined time before proceeding with command script processing. For example because the DUT needs some time to stabilize after a modification. Waiting can be achieved using the following commands.

List of Commands
SYSTem:TIME:HRTimer:ABSolute
SYSTem:TIME:HRTimer:ABSolute:SET
SYSTem:TIME:HRTimer:RELative
