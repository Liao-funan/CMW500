SYSTem:DISPlay:UPDate <Enable>

Defines whether the display is updated or not while the instrument is in the remote state. If the display update is switched off, the normal GUI is replaced by a static image while the instrument is in the remote state.

Switching off the display can speed up the measurement and is the recommended state.

See also "Using the Display during Remote Control"

Parameters:
<Enable>

ON | 1: Display is shown and updated during remote control

OFF | 0: Display shows static image during remote control

Example: SYSTem:DISPlay:UPDate ON

Switch on the display update.
