Measurement Controller Dialog

The "Measurement Controller" dialog box lists the available measurement firmware applications and allows you to add measurement applications to the task bar.

To open the dialog box, press the MEASURE key on the (soft-) front panel.

In multiple-window mode, the key and the dialog box are not available. Instead, the settings can be accessed directly from the main window, see "Main Window in Multiple-Window Mode".

Measurement Controller dialog box

Use the checkboxes in the dialog to add or remove a task bar entry for a measurement.

For manual control of a firmware application, the application must be added to the task bar. Remote control of a firmware application is possible without a corresponding task bar entry.
