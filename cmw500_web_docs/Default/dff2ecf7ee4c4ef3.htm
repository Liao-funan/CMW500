STATus:OPERation:BIT<n>:ENABle <BitValue>
STATus:OPERation:BIT<n>:NTRansition <BitValue>
STATus:OPERation:BIT<n>:PTRansition <BitValue>

Sets bit no. <n> of the ENABle, NTRansition or PTRansition part of the STATus:OPERation register, see also "Structure of an SCPI Status Register". To set the entire parts, see STATus:​OPERation:​ENABle, STATus:​OPERation:​NTRansition and STATus:​OPERation:​PTRansition.

Suffix: 
<n>
8 to 12

Number of the bit

Parameters:
<BitValue>
0 | 1
Example: STAT:OPER:BIT9:ENAB 1

Set bit no. 9 of the ENABle part of the STATus:OPERation register.
