SYSTem:BASE:DEVice:COUNt <Count>

Splits the instrument into subinstruments or assigns all hardware resources to a single subinstrument.

Send this command to the subinstrument with the lowest number (device number 0 / assigned instrument 1 / subinstrument 1).

To assign/distribute the available hardware resources to the subinstruments, enter SYSTem:​BASE:​DEVice:​RESet after you have changed the number of subinstruments.

Parameters:
<Count>

Number of subinstruments

The allowed values depend on your instrument configuration

*RST:n/a (factory default is 1)
Example: SYSTem:BASE:DEVice:COUNt 2
SYSTem:BASE:DEVice:RESet

Split the instrument into two subinstruments and distribute the available resources to these subinstruments.
