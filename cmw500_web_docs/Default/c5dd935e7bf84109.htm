Application of the Status Reporting System

The purpose of the status reporting system is to monitor the status of one or several devices in a measuring system. The controller must receive and evaluate the information of all devices. The following standard methods described in the following sections are used:

  • Service request (SRQ) initiated by the measuring device
  • Serial poll of all devices in the bus system, initiated by the controller to find out who sent an SRQ and why
  • Parallel poll of all devices
  • Query of a specific instrument status via commands
  • Query of the error queue
