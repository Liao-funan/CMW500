STATus:CONDition:BITS:COUNt? ['<RegExp>']

Returns the number of task states listed by STATus:CONDition:BITS:ALL?.

Query parameters: 
'<RegExp>'

Optional regular expression filtering the task states before they are counted, see also "Regular Expressions".

Example: STATus:CONDition:BITS:COUNt?

List the number of task states returned by STATus:CONDition:BITS:ALL?.

Usage: Query only
