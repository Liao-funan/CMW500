Multi-CMW Configuration

The following commands can only be executed on an R&S CMWC. Their main purpose is to modify a multi-box setup (add or remove an instrument). The settings are also available in the "Misc > Multi-CMW" section of the "Setup" dialog.

List of Commands
INITiate:BASE:MCMW
FETCh:BASE:MCMW:STATe?
