V3.5.100 (Compared to V3.5.90)
New features:
  • New context menu entries (right-click), allowing you to:
    –Open the help system
    –Exand/collapse all nodes of a tree
    –Return to the overview of a multi-evaluation measurement
    –Show the task bar in single-window mode
  • In multiple-window mode, you can minimize the main window to a vertical toolbar, see "Main Window in Multiple-Window Mode"
