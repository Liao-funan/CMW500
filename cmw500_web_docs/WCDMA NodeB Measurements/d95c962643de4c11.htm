CONFigure:WCDMa:MEAS<i>:NB:MEValuation:TMODel <TestModel>

Selects the UTRA test model, as defined in 3GPP TS 25.141, section 6.1.1.

Parameters:
<TestModel>
AUTO | M11 | M12 | M13 | M2 | M31 | M32 | M4 | M51 | M52 | M53

AUTO: auto channel detection

M11: model 1 (16 DPCHs)

M12: model 1 (32 DPCHs)

M13: model 1 (64 DPCHs)

M2: model 2

M31: model 3 (16 DPCHs)

M32: model 3 (32 DPCHs)

M4: model 4

M51: model 5 (16 DPCHs)

M52: model 5 (32 DPCHs)

M53: model 5 (64 DPCHs)

*RST:AUTO
