READ:WCDMa:MEAS<i>:NB:MEValuation:TRACe:MERRor:CHIP:MAXimum?

Returns the values of the magnitude error vs. chip traces, measured in the preselected slot (see CONFigure:​WCDMa:​MEAS<i>:​NB:​MEValuation:​PSLot). One value per chip is returned. The results of the current, average and maximum traces can be retrieved.

See also "Detailed Views: Modulation".

Return values: 
<Reliability>

"Reliability Indicator"

<MagErr1> ... <MagErr2560>
Range: 0 %  to  100 %
Default unit: %
