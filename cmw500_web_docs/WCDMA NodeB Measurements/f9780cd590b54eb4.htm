WCDMA NodeB Measurements

The WCDMA NodeB TX measurement provides quick and flexible TX tests on UTRAN FDD downlink SISO signals.

The tests cover the following NodeB transmitter properties:
  • NodeB output power
  • Modulation accuracy (EVM, phase error, magnitude error and frequency error)
  • Out-of-band emissions (spectrum emission mask and ACLR)
  • Code domain power and code domain error, code domain monitor

Many of the FDD tests and conformance requirements are specified in 3GPP TS 25.104 or 3GPP TS 25.141.

The WCDMA NodeB TX measurement requires option R&S CMW-KN400.
