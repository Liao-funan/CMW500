CONFigure:WCDMa:MEAS<i>:NB:RFSettings:FREQuency <Frequency>

Selects the center frequency of the RF analyzer.

Parameters:
<Frequency>
Range: 70E+6 Hz  to  6E+9 Hz
*RST:2.14E+9 Hz
Default unit: Hz

Using the unit CH the frequency can be set via the channel number. The allowed channel number range depends on the operating band, see "Operating Bands".
