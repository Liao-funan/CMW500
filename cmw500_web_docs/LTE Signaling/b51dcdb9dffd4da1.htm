Selecting and Modifying Views

Use the "Display" hotkeys to select the views and to change the appearance and contents of the views. Depending on the selected view, the following "Display" hotkeys are available at the bottom of the GUI:

"Display" hotkeys

Hotkey

Description

"Select View ..."

Switch to a certain detailed view or to the overview.

Alternatively, select a diagram in the overview and press ENTER or the rotary knob.

"Select Trace ..."

Select the trace types to be displayed in the view.

"X Scale... / Y Scale..."

Modify the ranges of the X-axis and the Y-axis.

"Absolute | Relative"

Toggles between display of absolute and relative results in the HARQ detailed view.
