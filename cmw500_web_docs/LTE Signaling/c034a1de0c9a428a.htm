SENSe:LTE:SIGN<i>:ELOG:ALL? [<HRES>]

Queries all entries of the event log.

For each entry, three parameters are returned, from oldest to latest entry: {<Timestamp>, <Category>, <Event>}entry 1, {<Timestamp>, <Category>, <Event>}entry 2, ...

Query parameters: 
<HRES>
HRES

If you omit this parameter, the timestamp resolution is 1 s (format "hh:mm:ss").

If you send the value HRES, the timestamp resolution is 1 ms (format "hh:mm:ss.sss").

Return values: 
<Timestamp>

Timestamp of the entry as string

<Category>
INFO | WARNing | ERRor | CONTinue

Category of the entry, as indicated in the main view by an icon

<Event>

Text string describing the event, e.g. "RRC Connection Established"

Usage: Query only
Firmware/Software: 

V2.1.30, V3.7.10 <HRES>

Manual operation: See "Event log entries"
