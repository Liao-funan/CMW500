CONFigure:LTE:SIGN<i>:MMONitor:IPADdress <Index>

Selects the IP address to which signaling messages are sent for message monitoring. The address pool is configured globally via CONFigure:BASE:MMONitor:IPADdress<n>.

A query returns both the current index and the resulting IP address.

Parameters:
<Index>
IP1 | IP2 | IP3

Address pool index

Return values: 
<IPAddress>

Used IP address as string
