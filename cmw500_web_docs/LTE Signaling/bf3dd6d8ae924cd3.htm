CONFigure:LTE:SIGN<i>[:PCC]:EMTC:HOPPing:DL:HOFFset <Offset>
CONFigure:LTE:SIGN<i>[:PCC]:EMTC:HOPPing:UL:HOFFset <Offset>

Specifies the size of one frequency hop, DL or UL.

For the number of narrowbands per cell bandwidth, see Table "Narrowbands and resource blocks per cell BW".

Parameters:
<Offset>

Hop size in narrowbands

Range: 1  to  16 (depends on cell BW)
*RST:1
