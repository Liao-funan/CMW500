SENSe:LTE:SIGN<i>:UEReport[:PCC]:RSRQ:RANGe?
SENSe:LTE:SIGN<i>:UEReport:SCC<c>:RSRQ:RANGe?

Returns the RSRQ value range, corresponding to the RSRQ index reported by the UE.

Suffix: 
<c>
1..4
Return values: 
<Lower>
Range: -34 dB  to  2.5 dB
Default unit: dB
<Upper>
Range: -34 dB  to  2.5 dB
Default unit: dB
Usage: Query only
Firmware/Software: 

V2.0.10, SCC command V3.2.70

Manual operation: See "LTE Serving Cell > RSRQ"
