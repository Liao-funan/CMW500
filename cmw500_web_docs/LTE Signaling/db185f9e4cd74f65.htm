CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:UDCHannels:LAA:RBURst:FSUBframes:DL<s> <NumberRB>, <StartRB>, <Modulation>, <TransBlockSizeIdx>

Configures a user-defined downlink channel with contiguous allocation, for LAA, random bursts.

The <NumberRB> and <StartRB> settings apply to all subframes of the burst and to all DL streams. The other settings apply to subframes with full allocation and DL stream <s>.

The allowed input ranges have dependencies and are described in the background information, see "User-Defined Channels for LAA".

Suffix: 
<c>
1..4
<s>
1..2
Parameters:
<NumberRB>

Number of allocated resource blocks

*RST:100
<StartRB>

Position of first resource block

*RST:0
<Modulation>
QPSK | Q16 | Q64 | Q256

Modulation type QPSK | 16-QAM | 64-QAM | 256-QAM

*RST:QPSK
<TransBlockSizeIdx>

Transport block size index

*RST:5

See "Configuring LAA Settings"
