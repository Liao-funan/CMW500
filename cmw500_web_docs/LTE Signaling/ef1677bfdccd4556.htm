User-Defined Channels for eMTC

For eMTC, global user-defined channel configuration is available. TTI-based configuration is not supported. Option R&S CMW-KS510 is required.

User-defined channels allow a more flexible RB allocation than RMCs. The subframe pattern is the same as the standard pattern for RMCs. Repetitions and narrowband hopping are not used.

You can configure the following settings for user-defined channels:
  • Cell bandwidth
  • Half-duplex operation or full-duplex operation
  • Number of used resource blocks (#RB), contiguous allocation
  • Position of the resource blocks within the narrowband (start RB)
  • Narrowband position
  • Modulation type
  • Transport block size (TBS) index

The values allowed for these settings are listed in the following tables.

Meaning of the NB position values:
  • "low" selects NB0, "high" selects the highest NB within the channel bandwidth
  • "mid" selects an NB as listed in the table (above channel center, to avoid PBCH and synchronization signals)
  • "3GPP" selects an NB as listed in the table (values specified in 3GPP TS 36.508, IE "mpdcch-Narrowband-r13")

According to 3GPP, the maximum transport block size allowed for eMTC is 1000 bits. Some supported value combinations result in larger transport blocks.
