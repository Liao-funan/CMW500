Scenarios

The scenario selection is the first setting to be done for test configuration.

The LTE signaling application provides different scenarios for tests with or without MIMO, fading and carrier aggregation (CA). The number of component carriers (CC) is also selected via the scenario (one PCC + n SCC). Selecting a scenario hides/shows parts of the GUI as required by the scenario.
