General Cell Setup Settings

This section describes the following settings at the highest level of the node "Physical Cell Setup".

DL / UL Cell Bandwidth

Define the DL and UL cell bandwidths, also called channel bandwidth by 3GPP. In the current release, the two values are identical. For frame structure type 3, only 20 MHz are allowed.

The resulting maximum number of DL resource blocks is indicated for information. It is smaller than the DL bandwidth divided by 180 kHz, because some space at the channel borders must not be occupied by resource blocks. 3GPP defines the relation as follows:

You can change the cell bandwidth in all main connection states. In state "Connection Established" you can either change it directly or you can perform a handover to reconfigure several parameters, see "Handover".

For carrier aggregation scenarios, you can configure different DL cell bandwidths for the carriers.

Physical Cell ID

The cell ID is used for generation of the physical synchronization signals. During cell search, the UE determines the cell ID from the primary and secondary synchronization signal.

The physical cell ID can be set independent of the E-UTRAN cell identifier sent to the UE via broadcast (see "E-UTRAN Cell Identifier").

If you use carrier aggregation, configure different values for the component carriers.

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​PCID

CONFigure:​LTE:​SIGN<i>:​CELL:​SCC<c>:​PCID

 
Cyclic Prefix

Defines whether a normal or extended cyclic prefix (CP) is used.

An extended cyclic prefix cannot be combined with the transmission mode 8 or with frame structure type 3 (combination not foreseen by 3GPP).

Option R&S CMW-KS510 is required for extended CP.

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CELL:​CPRefix

 
Enable 64-QAM UL Support

Selects whether 64-QAM is allowed in the uplink or not. This information is signaled to the UE in the IEs "enable64QAM" and "enable64QAM-v1270".

The setting affects also the channel configuration. If the checkbox is disabled, you cannot configure 64-QAM for the uplink.

To enable the checkbox, you need option R&S CMW-KS504/-KS554 and two SUA partitions for the carrier, see "Base Band Unit".

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​ULSupport:​QAM<ModOrder>:​ENABle

CONFigure:​LTE:​SIGN<i>:​CELL:​SCC<c>:​ULSupport:​QAM<ModOrder>:​ENABle
