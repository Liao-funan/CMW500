What's New in This Version

This documentation describes version 3.7.30 and later of the LTE signaling application. Compared to version 3.7.20, it provides the following new features and changes:

  • New scenarios, see "Scenarios":
    "3CC - nx4 nx4 nx4", "3CC - Fading - nx4 nx2 nx2", "3CC - Fading - nx2 nx4 nx4"
    "4CC - nx2 nx4 nx2 nx2", "4CC - nx4 nx4 nx2 nx2", "4CC - nx2 nx4 nx4 nx2"
    "4CC - nx4 nx4 nx4 nx2", "4CC - nx2 nx4 nx4 nx4", "4CC - nx4 nx4 nx4 nx4"
    "5CC - nx4 nx2 nx2 nx2 nx2", "5CC - nx2 nx4 nx2 nx2 nx2", "5CC - nx4 nx4 nx4 nx4 nx4"
  • A SUA can optionally be used as coprocessor to reach the maximum throughput. For new scenarios with in total at least nx12, a SUA coprocessor is mandatory. See "Coprocessor (add. Base Band Unit)".
  • UL carrier aggregation supports now up to four component carriers, see "Carrier Aggregation".
    The scenario "5CC - 1x1 1x1 1x1 1x1 1x1" does no longer support an SCC4 UL.
  • eMTC:
    –Enhanced narrowband selection for RMC and user-defined channels, see Table "NB position values depending on bandwidth"
    –UE capabilities for support of CE modes, see "CE UE Capabilities"
