Options and Equipment Required
The described tests require the following equipment:
  • R&S CMW with software version ≥ V2.0.20. The latest software version is recommended.
    This application sheet describes software version V3.2.60.
  • One of the options:
    –R&S CMW-KS500, LTE FDD R8, basic signaling
    –R&S CMW-KS550, LTE TDD R8, basic signaling
  • Option R&S CMW-KM050, data application measurements (requires hardware R&S CMW-B450x, data application unit)
  • Option R&S CMW-KA100, enabling of IP-Data interface for IPv4
