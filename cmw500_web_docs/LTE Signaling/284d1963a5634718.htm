CONFigure:LTE:SIGN<i>:CELL:TDD:SPECific <UseSpecific>

Enables the carrier-specific configuration of the UL/DL configuration and of the special subframe configuration.

  • Enabled: Configuration per carrier via
    CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​ULDL
    CONFigure:​LTE:​SIGN<i>:​CELL:​SCC<c>:​ULDL
    CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​SSUBframe
    CONFigure:​LTE:​SIGN<i>:​CELL:​SCC<c>:​SSUBframe
  • Disabled: Global configuration via
    CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​ULDL
    CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​SSUBframe
Parameters:
<UseSpecific>
OFF | ON
*RST:OFF
