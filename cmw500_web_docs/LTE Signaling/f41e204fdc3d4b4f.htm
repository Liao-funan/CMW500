LTE Signaling > Command Reference > Connection Control and States > Handover Preparation > PREPare:LTE:SIGN<i>:HANDover:CTYPe
PREPare:LTE:SIGN<i>:HANDover:CTYPe <Type>

Selects the call type to be set up at the destination, for handover of VoLTE calls.

Parameters:
<Type>
PSData | PSVolte

PSData: E2E packet data connection

PSVolte: Voice call, use handover with SRVCC

*RST:PSD
Firmware/Software: 

V3.5.40

Options: R&S CMW-KS510
Manual operation: See "Connection Type"
