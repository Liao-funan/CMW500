V3.0.20 (Compared to V3.0.10)
New features:
  • Fading without an external fader, see "Internal Fading"
    –Fading simulator supporting the multipath propagation conditions defined in annex B.2 of 3GPP TS 36.101
    –AWGN generator with configurable bandwidth and signal to noise ratio
  • Handover (redirection) to an external device, e.g. another R&S CMW, see "Handover"
  • New RMC configurations due to changes in 3GPP specification, see "Scheduling Type RMC"
  • Configurable rejection of attach and TAU requests, see "NAS Signaling Settings"
  • Configurable method for information of UE about SIB changes, see "SIB Reconfiguration"
  • The IP address information has been moved to the UE information section, see "UE Info"
    The related command SENSe:LTE:SIGN:UEADdress:IPV<n>? has been changed - old command still available as alias
  • Display of RRC connection state, see "RRC State"
  • Number of LTE neighbor cells increased to 16, see "Neighbor Cell Settings"
  • All kinds of handover can now be started using the same command. So the old command CALL:LTE:SIGN<i>:HANDover:STARt is replaced completely by CALL:LTE:SIGN<i>:PSWitched:ACTion HANDover
  • Code rate displayed for user-defined channels and user-defined TTI-based channels, see "TTI-Based Channel Configuration"
    New commands for query of the code rates:
    –SENSe:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​DL<s>:​CRATe:​ALL?
    –SENSe:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​UL:​CRATe:​ALL?
    –SENSe:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDTTibased:​DL<s>:​CRATe:​ALL?
    –SENSe:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDTTibased:​UL:​CRATe:​ALL?
  • Changed CONFigure:LTE:SIGN<i>:CONNection:ETHRoughput:...? to SENSe:LTE:SIGN<i>:CONNection:ETHRoughput:...?
    Old commands still available as alias
