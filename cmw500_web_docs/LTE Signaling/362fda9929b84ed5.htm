LTE IP-Based Data Tests

This application sheet provides examples for testing LTE data transfer over IP, using the LTE signaling application and the data application unit (DAU). It describes how to prepare the measurements, how to measure the network latency using ping and how to measure the downlink throughput for data transfer via UDP/IP.
