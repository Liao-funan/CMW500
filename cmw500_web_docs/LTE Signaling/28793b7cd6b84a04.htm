SENSe:LTE:SIGN<i>:CONNection[:PCC]:PUCCh:FFCA?

Queries the PUCCH format used for carrier aggregation scenarios.

Return values: 
<Format>
F1BCs | F3

F1BCs: PUCCH format 1b with channel selection

F3: PUCCH format 3

Usage: Query only
Firmware/Software: 

V3.7.10

Manual operation: See "PUCCH"
