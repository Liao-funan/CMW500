V3.2.10 (Compared to V3.0.50)
New features:
  • Detailed HARQ view in the BLER measurement, see "Detailed View: HARQ"
  • Enhancements of internal fading:
    –The I/Q board to be used can be selected, see "Scenario"
    –New fading profile high-speed train (HST), see "Profile"
    –The number of clipped samples is displayed, see "Insertion Loss"
  • Frequency offset, configurable separately for UL and DL, see "RF Frequency"
  • PHICH power offset configurable, see "PHICH Power Offset"
  • The channel commands allow you to query the center frequency of the channel, see:
    –CONFigure:​LTE:​SIGN<i>:​RFSettings[:​PCC]:​CHANnel:​DL
    –CONFigure:​LTE:​SIGN<i>:​RFSettings[:​PCC]:​CHANnel:​UL
  • Command for mixer level offset, see:
    CONFigure:​LTE:​SIGN<i>:​RFSettings[:​PCC]:​MLOFfset
