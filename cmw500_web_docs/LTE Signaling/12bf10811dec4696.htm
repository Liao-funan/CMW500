V3.5.20 (Compared to V3.5.10)
New features:
  • Uplink carrier aggregation:
    –Background information, see "Carrier Aggregation"
    –Enabling SCC uplink, see "Use UL"
    –SCC UL trigger signals, see "Trigger Signals"
    –Joint uplink power control, see "Uplink Power Control"
  • New carrier aggregation scenarios, see "Scenarios"
    List of the new scenarios:
    –"2CC CA - 4 RF Out - Distributed" (with/without fading)
    –"3CC CA - 6 RF Out" (with/without fading)
    –"4CC CA - 4 RF Out" (no fading)
    –"4CC CA - 8 RF Out" (with/without fading)
  • UE capability report enhancement for four carriers, see "RF UE Capabilities"
  • TDD UL/DL configuration and special subframe configuration per component carrier, see "Use Carrier Specific"
  • Multi-cluster allocation enhancements:
    –Commands enabling/disabling multi-cluster allocation, see CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​MCLuster:​UL
    –Multi-cluster allocation for UL user-defined channels, see "User-Defined Channels"
  • The RLC mode is also configurable in test mode, see "Default Bearer"
  • Mobile-originating/terminating circuit-switched fallback to TD-SCDMA, see "CS Fallback (MO)" and "Inter/Intra-RAT (hotkey)"
  • New handover method "Handover" supported for a handover to WCDMA, see "Handover"
  • The following scheduling types are now also supported for transmission mode 8 and 9 (see "CQI Channels"):
    Follow CQI, follow PMI, follow PMI-RI, follow CQI-PMI-RI
  • SCC DL operating bands 252 and 255 for license assisted access (LAA), see "Operating Bands"
  • Short message service enhancements:
    –Configurable protocol identifier TP-PID, see "Protocol Identifier"
    –Information about success of last short message transfer, see "Last Message Sent"
  • Option R&S CMW-KS510 no longer required for setting "EPS Network Feature Support"
