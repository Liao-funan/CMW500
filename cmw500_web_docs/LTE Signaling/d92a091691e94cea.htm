Possible Extensions

While you perform audio tests or speech quality tests, you can vary connection parameters and study the effect on the audio quality.

With option R&S CMW-KM050, you can use the data application unit to add network impairments to the downlink VoLTE connection. Thus you can simulate challenges of real IP networks and test the effect on the speech quality.

Configurable network impairments are for example:
  • Packet delay, static or with jitter distribution
  • Packet loss and packet corruption
  • Reordering and duplication of packets
