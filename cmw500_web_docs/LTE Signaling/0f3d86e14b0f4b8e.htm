CONFigure:LTE:SIGN<i>:CONNection:DEDBearer <ID>

Selects a dedicated bearer as a preparation for a bearer release via CALL:LTE:SIGN:PSWitched:ACTion DISConnect.

Parameters:
<ID>

Dedicated bearer ID as string

String example: "6 (->5, Voice)"

To query a list of IDs for all established dedicated bearers, see CATalog:​LTE:​SIGN<i>:​CONNection:​DEDBearer?.

See "Connecting/Releasing Dedicated Bearers"

Options: R&S CMW-KS510
Manual operation: See "Disconnect"
