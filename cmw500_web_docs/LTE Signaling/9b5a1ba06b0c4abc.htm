CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:PDCCh:SYMBol <PDCCH>

Configures the number of PDCCH symbols per normal subframe.

Suffix: 
<c>
1..4
Parameters:
<PDCCH>
AUTO | P1 | P2 | P3 | P4

AUTO: automatic configuration depending on scheduling type

P1 to P4: 1, 2, 3, 4 symbols

*RST:AUTO
Example: 

See "Configuring General Connection Settings Part 2"

Manual operation: See "PDCCH Symbol Config, #PDCCH Symbols"
