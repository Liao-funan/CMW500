CONFigure:LTE:SIGN<i>:SMS:OUTGoing:SCTStamp:TSOurce <SourceTime>

Selects the source for the service center time stamp.

The date and time for the source DATE is configured via the following commands:
  • CONFigure:​LTE:​SIGN<i>:​SMS:​OUTGoing:​SCTStamp:​DATE
  • CONFigure:​LTE:​SIGN<i>:​SMS:​OUTGoing:​SCTStamp:​TIME
Parameters:
<SourceTime>
CMWTime | DATE

CMWTime: Current date and time of the operation system

DATE: Date and time specified via remote commands

*RST:CMWT
Example: 

See "Sending / Receiving a Short Message"

V3.2.80

Options: R&S CMW-KS510
