VoLTE Call Setup and Audio Tests

This application sheet describes how to set up a voice over LTE (VoLTE) call, using the LTE signaling application and the IMS server of the data application unit (DAU).

For the established VoLTE call, basic audio tests are performed with the R&S CMW audio board. For speech quality tests with a connected R&S UPV, the R&S CMW configuration and the test setup are described.
