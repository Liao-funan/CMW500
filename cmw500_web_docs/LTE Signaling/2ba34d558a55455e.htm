Combined Signal Path Measurements

This application sheet describes how to establish a connection to an LTE user equipment (UE) and perform TX measurements on the received uplink signal using the LTE multi-evaluation measurement. For SRS and PRACH measurements, see "SRS and PRACH Measurements".

Sequencer tool R&S CMWrun

The automated test capabilities of R&S CMWrun make many measurement tasks easier. Option R&S CMW-KT055 provides configurable LTE test modules and test plans for R&S CMWrun.
