CONFigure:LTE:SIGN<i>:CELL:PRACh:NRPReambles <Enable>

Selects whether the application ignores received preambles or not.

Parameters:
<Enable>
OFF | ON | NIPReambles

OFF: respond to received preambles

ON: ignore received preambles

NIPReambles: ignore a configured number of preambles, then respond to subsequent preambles - for configuration see CONFigure:​LTE:​SIGN<i>:​CELL:​PRACh:​NIPRach, only allowed for power ramping step size 0 dB

*RST:OFF
