CONFigure:LTE:SIGN<i>:CONNection:CDRX:ENABle <Enable>

Enables or disables DRX and selects a set of DRX settings.

Parameters:
<Enable>
DRXS | DRXL | UDEFined | ON | OFF

DRXS: DRX_S, 3GPP TS 36.521-3, table H.3.6-1

DRXL: DRX_L, 3GPP TS 36.521-3, table H.3.6-2

UDEFined: user-defined DRX settings

ON: enables DRX with previously selected set

OFF: disables DRX

*RST:OFF
Example: 

See "Configuring Connected DRX"

V3.2.20

Manual operation: See "Connected DRX"
