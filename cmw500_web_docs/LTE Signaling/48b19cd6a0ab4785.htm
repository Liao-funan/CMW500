V3.0.30 (Compared to V3.0.20)
New features:
  • Group hopping (R&S CMW-KS510 required), see "Easy Mode"
  • Support of operating bands 27, 28 and 44, see "Operating Bands"
  • Sending date and time information to the UE (R&S CMW-KS510 required), see "Time"
  • Enhancements of extended BLER measurement:
    –Enhanced range for number of subframes (minimum = 100)
    –Continuous measurement mode in addition to existing single shot mode, see "Repetition"
    –Selectable error ratio type for BLER calculation, see "Error Ratio Calculation"
    –Confidence BLER measurement (R&S CMW-KS510 required), see "Confidence BLER measurements"
    –FETCh:INTermediate:... commands for query of intermediate BLER results, see "Measurement Results"
  • Internal and external fading scenarios require now R&S CMW-KS510
