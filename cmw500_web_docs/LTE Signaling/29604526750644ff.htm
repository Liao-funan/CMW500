CONFigure:LTE:SIGN<i>:FADing:SCC<c>:FSIMulator:ILOSs:MODE <InsertLossMode>

Sets the insertion loss mode.

Suffix: 
<c>
1..7
Parameters:
<InsertLossMode>
NORMal | USER

NORMal: The insertion loss is determined by the fading profile.

USER: The insertion loss is configurable.

*RST:NORM
