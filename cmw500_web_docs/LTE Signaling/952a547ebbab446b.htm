CONFigure:LTE:SIGN<i>:CELL:ACAuse:ATTach <Cause>

Selects whether a cause is added to ATTACH ACCEPT messages or not.

Parameters:
<Cause>
C18 | ON | OFF

OFF: disables sending of a cause

ON / C18: enables sending of attach accept cause 18 (CS domain not available)

*RST:OFF
