Options and Equipment Required
An LTE combined signal path measurement requires the following equipment:
  • R&S CMW with software version ≥ V1.0.15.20. The latest software version is recommended.
    This application sheet describes software version V3.2.10.
  • For FDD tests:
    –Option R&S CMW-KS500, LTE FDD R8, basic signaling
    –Option R&S CMW-KM500, LTE FDD R8, TX measurement
  • For TDD tests:
    –Option R&S CMW-KS550, LTE TDD R8, basic signaling
    –Option R&S CMW-KM550, LTE TDD R8, TX measurement

The following sections describe a combined signal path measurement for FDD. A combined signal path measurement for TDD is performed in the same way, using the R&S CMW-Kx550 options instead of the R&S CMW-Kx500 options.
