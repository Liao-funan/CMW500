CONFigure:LTE:SIGN<i>:CBS:MESSage:FILE:INFO?

Queries information about the message in the selected file (see CONFigure:​LTE:​SIGN<i>:​CBS:​MESSage:​FILE).

Return values: 
<MessageEncoding>

Encoding as string

<MessageText>

Message text as string

<MessageLength>

Number of characters in the message

Range: 0  to  600
Usage: Query only
Firmware/Software: 

V3.5.40

Options: R&S CMW-KS170
Manual operation: See "Message Encoding, Message Text, Message Length"
