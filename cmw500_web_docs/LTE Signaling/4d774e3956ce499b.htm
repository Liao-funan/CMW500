Fixed CQI Channels

This scheduling type is supported for the transmission modes 1 to 9. Option R&S CMW-KS510 is required.

The downlink channel is configured via a set of parameters:
  • Cell bandwidth
  • Number of allocated resource blocks (RB)
  • Position of the first allocated RB
  • CQI index
  • 256-QAM usage

All parameters except the cell bandwidth and the 256-QAM usage can be configured individually for each downlink subframe (TTI) of a radio frame.

The allocated resource blocks are contiguous and the position of the first RB can be configured. The configuration rules are the same as for TTI-based user-defined downlink channels, see "Number and Position of RBs (DL)".

The CQI index determines the channel code rate. The code rate is defined as the number of downlink information bits (including CRC bits) divided by the number of physical channel bits on the PDSCH. The relation is defined in 3GPP TS 36.213, table 7.2.3-1 (without 256-QAM) and table 7.2.3-2 (with 256-QAM).

The modulation scheme is selected automatically according to the table. Indirectly, the table also determines the transport block size. The transport block size is selected automatically so that the resulting effective channel code rate approaches the listed target code rate as far as possible. Thus the transport block size depends on the CQI index and on the number of allocated RBs.
