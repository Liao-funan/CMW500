SENSe:LTE:SIGN<i>:CQIReporting[:PCC]:RPERiod?
SENSe:LTE:SIGN<i>:CQIReporting:SCC<c>:RPERiod?

Queries the reporting period Np in subframes, resulting from the configured "cqi-pmi-ConfigIndex".

Suffix: 
<c>
1..4
Return values: 
<Period>
Range: 1  to  160
Example: 

See "Configuring CQI Reporting"

Usage: Query only
Firmware/Software: 

V3.0.10, SCC command V3.2.70

Options: R&S CMW-KS510 for scenarios without carrier aggregation
R&S CMW-KS512 for scenarios with carrier aggregation
Manual operation: See "CQI/PMI Reporting Period / Offset"
