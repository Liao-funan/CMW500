DL RMCs, Transmission Mode 7

The following tables list the supported parameter sets for downlink RMCs when transmission mode 7 is used.

The TDD RMCs for 5 MHz and 10 MHz bandwidth are defined in 3GPP TS 36.521, table A.3.4.3.1-1. For the other bandwidths and FDD, 3GPP has not yet specified DL RMCs for TM 7, but the listed parameter combinations are supported.

The listed allocated resource blocks are contiguous and at the low or high end of the cell bandwidth. In subframe 0, a non-contiguous RB allocation is applied (not indicated in the tables).
