Possible Extensions

While the connection is established, you can vary "LTE Signaling" settings and "Data Application Measurements" settings and observe the impact on the measurement results. You can, for example, modify the downlink power levels, the downlink channel configuration and the sent bit rate. You can also set up a MIMO configuration (option required, see below) and perform LTE E2E data tests with MIMO.

The applications can be enhanced, for example, by the following options:
  • Option R&S CMW-KS510 provides advanced parameter settings for "LTE Signaling"
  • Option R&S CMW-KS520 adds support of MIMO 2x2 in the downlink
  • Option R&S CMW-KS521 adds support of MIMO 4x2 in the downlink
  • Option R&S CMW-KS522 adds support of MIMO 8x2 in the downlink
  • Option R&S CMW-KA150 adds support of IPv6
  • Option R&S CMW-KAA20 provides an IMS server
