User-Defined TTI-Based Channels

Parameters specific for the scheduling type "User-defined TTI-Based" can only be configured from the main view, not from the configuration tree.

Scheduling settings in the main view

In the main view, you can configure the settings of a selected subframe (TTI) directly. Alternatively, press the button "Edit All" to open a dialog box where you can edit the settings of all subframes.

If a transmission scheme using several data streams is active, the parameter "MIMO DL Stream" allows you to switch between the settings of the downlink streams. The parameter is disabled if all streams use the same set of settings.

For a parameter description, see "TTI-Based Channel Configuration".
