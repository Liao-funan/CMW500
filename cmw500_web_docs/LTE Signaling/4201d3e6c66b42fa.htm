RLC Throughput Measurement Configuration

The "Extended BLER" measurement is included in the "LTE signaling" application. To access the measurement, press the softkey "LTE RX Meas" in the LTE signaling main view. Then select the tab "RLC Throughput". The tab is described in this section.
