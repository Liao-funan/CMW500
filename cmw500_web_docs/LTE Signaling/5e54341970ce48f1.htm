eMTC Compact Scheduling

"Compact" means, that the scheduling in the time domain is more compact than for other scheduling types. Use this scheduling type for maximum throughput.

The following scheduling patterns are used to achieve the maximum throughput:
  • Full duplex: Each subframe is scheduled for DL and UL.
  • Half duplex: A subframe pattern with a periodicity of 40 ms is used. The pattern consists of five times eight subframes. Within every eight subframes, there are three DL subframes, three UL subframes and two subframes for switching between UL and DL.

Compact scheduling does not use repetitions or narrowband hopping.

You can configure the following settings for compact scheduling:
  • Cell bandwidth
  • Half-duplex operation or full-duplex operation
  • Number of used resource blocks (#RB), contiguous allocation
  • Position of the resource blocks within the narrowband (start RB)
  • Modulation type
  • Transport block size (TBS) index

The values allowed for these settings are listed in the following table. The narrowband is selected automatically.
