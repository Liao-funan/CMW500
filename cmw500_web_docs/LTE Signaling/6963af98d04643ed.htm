CONFigure:LTE:SIGN<i>:EBLer:CONFidence:LERate <Rate>

Selects the limit error ratio for a confidence BLER measurement.

Parameters:
<Rate>
P001 | P010 | P050

P001: 0.1 %, 3GPP TS 36.521 annex G.4

P010: 1 %, 3GPP TS 36.521 annex G.4

P050: 5 %, 3GPP TS 36.521 annex G.2

*RST:P050
Example: 

See "Configuring a BLER Measurement"

Firmware/Software: 

V3.0.30

Options: R&S CMW-KS510/-KS512 (without CA/with CA)
Manual operation: See "Limit Error Rate"
