CONFigure:LTE:SIGN<i>:UEReport:FCOefficient:RSRQ <Filter>

Selects the value to be sent to the UE as "filterCoefficientRSRQ". It is used by the UE to measure the reference signal received quality (RSRQ).

Parameters:
<Filter>
FC0 | FC4
*RST:FC4
