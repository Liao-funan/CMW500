V3.7.10 (Compared to V3.5.50)
New features:
  • Scenario enhancements, see "Scenarios"
    –Scenarios for MIMO 4x4 with SUA
    –Scenarios for carrier aggregation with 5 CC and SUA
    –All old scenarios have been renamed.
  • Scenario filter for comfortable search of suitable scenarios, see "Search button"
  • Co-location of component carriers reduces the number of required TX modules, see "RF Paths and Co-Location"
  • UL 64-QAM support (SUA only), see "Enable 64-QAM UL Support"
  • Extended discontinuous reception (eDRX), see "eDRX"
  • SCC synchronization sets for joint state transitions, see "Multiple SCC Actions (hotkey)"
  • SRS for SCC, see "SRS Settings"
  • Configurable SRS power offset, see "pSRS-Offset"
  • Added operating bands 48, 68, 69, 70, 250 and removed band 46, see "Operating Bands"
  • Support of WCDMA band 26 (for example for a handover)
  • Network signaled values NS_25 to NS_32, see "Additional Spectrum Emission"
  • Extended values for timer T3412, see "T3412 Extended"
  • Predefined 4x4 channel matrices, see "4x4 channel model"
  • Additional values for the cDRX settings "onDurationTimer", "drx-RetransmissionTimer", "longDRX-Cycle", "shortDRX-Cycle", see "Connected DRX Settings"
  • Configurable SIB1 field "ims-EmergencySupport-r9", see "IMS Emergency Support"
  • Configurable SIB2 field "nB", see "PCCH-Config nB"
  • PUCCH format for CA selectable, see "PUCCH"
  • New aggregation level 8/8, see "Aggr. Level DL/UL Config, Aggreg. Level ..."
  • ROHC for data connections, see "Enable for"
  • Signaling of UE-specific SRS parameters can be disabled, see "Dedicated Configuration"
  • Configurable initial UL grant for UL dynamic scheduling, see "Initial UL Grant #RBs / MCS Index"
  • Increased timestamp resolution for query of event log entries via remote commands, see "Event Log"
