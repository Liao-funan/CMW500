CONFigure:LTE:SIGN<i>:UEReport:SCC<c>:RSSI:RMTC:SOFFset <Offset>

Specifies the offset of UE measurements for LAA.

The offset must be at least 5 ms smaller than the configured periodicity, see CONFigure:​LTE:​SIGN<i>:​UEReport:​SCC<c>:​RSSI:​RMTC:​PERiod.

Suffix: 
<c>
1..4
Parameters:
<Offset>
Range: 0 ms  to  635 ms
Increment: 5 ms
*RST:20 ms
Default unit: ms

See "Configuring LAA Settings"

V3.7.20

Options: R&S CMW-KS514
Manual operation: See "RMTC Period, RMTC Subframe Offset, Measurement Duration"
