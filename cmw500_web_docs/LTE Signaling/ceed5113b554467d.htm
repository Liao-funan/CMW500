Scheduling Type RMC for eMTC
An RMC can be defined via the following set of parameters:
  • Cell bandwidth
  • Half-duplex operation or full-duplex operation
  • Subframe pattern
  • Number of allocated resource blocks (RB)
  • Position of the first allocated RB within the narrowband
  • Narrowband position
  • Modulation type
  • Transport block size index (TBS index)

RMCs do not use repetitions or narrowband hopping.

The parameter combinations supported for eMTC are listed in the following sections.

In addition to the 3GPP-compliant combinations, the tables list also the configurable combinations without RB allocation ("Allocated RBs" = 0).

If you want to force the UE to use the PUCCH instead of the PUSCH, set the number of UL resource blocks to 0. Thus the UE is not allowed to use the PUSCH and must use the PUCCH to send ACK/NACKs.
