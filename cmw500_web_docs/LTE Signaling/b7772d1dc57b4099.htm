CONFigure:LTE:SIGN<i>:SCC<c>:FSTRucture <Structure>

The frame structure is only configurable for the TDD user-defined band. In any other case, only the query is relevant.

Suffix: 
<c>
1..4
Parameters:
<Structure>
T1 | T2 | T3

T1: Type 1 - FDD

T2: Type 2 - TDD normal operation

T3: Type 3 - LAA operation mode

Example: 

See "Configuring LAA Settings"

Firmware/Software: 

V3.7.20

Options: R&S CMW-KS500 for T1, R&S CMW-KS550 for T2
R&S CMW-KS514 for T3
Manual operation: See "Frame Structure"
