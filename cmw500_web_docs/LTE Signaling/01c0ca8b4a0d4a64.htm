CONFigure:LTE:SIGN<i>:CQIReporting:CSIRmode <Mode>

Configures the CSI reporting mode.

Parameters:
<Mode>
S1 | S2

S1: submode 1

S2: submode 2

*RST:S2
Example: 

See "Configuring CQI Reporting"

Firmware/Software: 

V3.5.10

Options: R&S CMW-KS510 for scenarios without carrier aggregation
R&S CMW-KS512 for scenarios with carrier aggregation
Manual operation: See "CSI - Report Mode"
