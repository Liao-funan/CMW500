CONFigure:LTE:SIGN<i>:DL[:PCC]:CSIRs:MODE <Mode>
CONFigure:LTE:SIGN<i>:DL:SCC<c>:CSIRs:MODE <Mode>

Selects a configuration mode for the used CSI-RS power offset.

Suffix: 
<c>
1..4
Parameters:
<Mode>
ACSirs | MANual
ACSirs

The used power offset matches the signaled value.

For configuration of the signaled value, see CONFigure:​LTE:​SIGN<i>:​CONNection:​SCC<c>:​TM<no>:​CSIRs:​POWer.

MANual

The used power offset is independent from the signaled value.

For configuration of the used power offset, see CONFigure:​LTE:​SIGN<i>:​DL:​SCC<c>:​CSIRs:​POFFset.

*RST:ACS
Example: 

See "Configuring DL Power Levels"

V3.5.40
