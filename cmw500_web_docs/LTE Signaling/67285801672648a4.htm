Scheduling Type RMC for LAA
For an RMC, you can define the following settings:
  • Burst type
  • Partial subframe configuration for random bursts
  • Modulation type
Two burst types are supported:
  • Fixed bursts: Full allocation for the subframes 0 and 3 to 9 of each radio frame. Subframes 1 and 2 are not used.
  • Random bursts: The subframe pattern is determined according to 3GPP TS 36.521, section B.8.
For random bursts, you can configure partial subframes as follows:
  • Full allocation only
  • Partial allocation allowed for initial subframes
  • Partial allocation allowed for ending subframes
  • Partial allocation allowed for initial and ending subframes

With allowed partial allocation, the rules defined in 3GPP TS 36.521 section B.8 determine whether partial allocation is used for a subframe or not. For ending subframes, S2 is {6, 9, 12, 14}.
