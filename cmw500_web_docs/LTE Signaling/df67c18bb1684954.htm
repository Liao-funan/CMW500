V3.2.82 (Compared to V3.2.81)
New features:
  • The PCC scheduling can be copied to an SCC, see "Copy (button)"
  • Support of operating band 29 for LTE neighbor cells, see "Neighbor Cell Settings"
  • Additional spectrum emission: new values NS_19, NS_21 to NS_24, see "Additional Spectrum Emission"
  • Additional RMCs for transmission mode 7 and 8, see "Scheduling Type RMC"
  • More flexible PDCCH settings, see "PDCCH"
  • Reset value changed for the SPS interval, see "SPS Configuration"
