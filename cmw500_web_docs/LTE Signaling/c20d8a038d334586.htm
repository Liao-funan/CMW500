Using Markers

The "Marker" softkey displays the following hotkeys at the bottom of the GUI:

Hotkey

Description

"Ref. Marker"

Enable or disable the reference marker and select the marker position. If several traces can be displayed, a trace can also be selected.

"Marker 1/2"

Enable or disable marker 1 or 2 and define the marker position (absolute or relative to the reference marker).

Depending on the trace mode, a trace can also be selected.

"Select Trace Mode"

Define whether markers 1 and 2 are set to the same trace as the reference marker (collective) or to selectable individual traces.

See also: "Markers"
