Overview of Scenarios

Most scenario names follow the scheme "<n>CC - <PCC> <SCC1> <SCC2> ...".

<n> is the number of DL component carriers. <PCC>, <SCC1>, and so on, state the antenna configuration for the DL component carriers: SISO 1x1, MIMO nx2 or MIMO nx4.

The number of UL component carriers is configurable. It is limited by the number of DL component carriers and by the absolute limit 4. So you can configure 1 to min(<n>, 4) UL component carriers.

Fading

The string "- Fading -" in the scenario name indicates fading support.

External fading is possible with SUW plus I/Q board. Internal fading is possible with SUA or with SUW plus I/Q board. External fading can be added via a connected R&S SMW200A.

Scenario name

Explanation

"1CC - Fading - 4x2"

MIMO 4x2 and internal extended fading or external fading (no CA)

"1CC - External RF Fading - 4x2"

MIMO 4x2 and external RF fading (no I/Q fading, no CA)

"1CC - IQ Out, RF In - 1x1"

RF uplink as for "1CC - 1x1", baseband downlink via the I/Q board.

Allows you to insert an R&S SMU200A into the downlink path.
