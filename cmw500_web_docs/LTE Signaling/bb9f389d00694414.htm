Setting Up a Data Connection

Proceed as follows:

  1. Configure the other settings of the signaling application compatible to your UE.

  2. Configure the data application unit (see DAU documentation).

  3. Switch on the cell signal and attach the UE.

  4. Set up a data connection.

  5. Generate IP traffic, for example using the iperf measurement provided by the DAU.
