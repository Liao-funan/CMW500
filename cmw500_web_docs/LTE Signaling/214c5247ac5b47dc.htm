CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:LAA:FBURst:PBTR <Periodicity>

Specifies the burst transmission periodicity, for LAA with fixed bursts.

The minimum allowed value equals the configured burst length, see CONFigure:​LTE:​SIGN<i>:​CONNection:​SCC<c>:​LAA:​FBURst:​BLENgth.

Suffix: 
<c>
1..4
Parameters:
<Periodicity>
Range: 1  to  100
*RST:10
Example: 

See "Configuring LAA Settings"

Firmware/Software: 

V3.7.20

Options: R&S CMW-KS514
Manual operation: See "Periodicity of Burst Transmissions"
