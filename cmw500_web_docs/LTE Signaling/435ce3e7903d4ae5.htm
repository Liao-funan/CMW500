Throughput, SUA Usage and Coprocessing

The number of SUA partitions required by a scenario is listed in "Prerequisites for Scenarios".

For some scenarios, you can assign additional SUA resources to increase the reachable maximum throughput:
  • If the scenario requires only one SUA partition for the PCC, you can nevertheless assign two SUA partitions.
  • If coprocessing is optional for the scenario, you can enable coprocessing (that means, assign an additional SUA).

Assigning additional SUA partitions is relevant in particular for maximum throughput tests with the data application unit (DAU).

The following table lists maximum throughputs reachable in the data application mode, depending on: the SUA configuration, the number of uplink component carriers and the protocol.

Examples for selected scenarios

Assume that you have 8 DL layers, scenario "4CC - nx2 nx2 nx2 nx2".

If you assign one SUA partition to the PCC, you can reach via UDP: 600 Mbit/s DL, 50 Mbit/s UL. If you want to increase the DL throughput or the UL throughput, you need two SUA partitions for the PCC.

Troubleshooting
To reach the maximum throughput, consider the following:
  • At the DAU:
    –Enable IP buffering for TCP tests.
    –Disable IP buffering for UDP tests.
  • Use up-to-date DAU hardware (for example R&S CMW-B450H, not -B450D or lower).
  • Connect the DUT via high-quality RF cables.
  • Ensure that the RS EPRE setting is high enough.
