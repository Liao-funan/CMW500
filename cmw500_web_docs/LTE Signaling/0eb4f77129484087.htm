SENSe:LTE:SIGN<i>:CONNection:ETHRoughput:UL[:PCC]?
SENSe:LTE:SIGN<i>:CONNection:ETHRoughput:UL:SCC<c>?

Returns the expected maximum throughput (averaged over one frame) for the uplink of one component carrier. The throughput is calculated for the currently selected scheduling type.

Suffix: 
<c>
1..4
Return values: 
<Throughput>
Default unit: Mbit/s
Example: 

See "Configuring User-Defined Channels"

Usage: Query only
Firmware/Software: 

V3.0.20

Manual operation: See "Max Throughput"
