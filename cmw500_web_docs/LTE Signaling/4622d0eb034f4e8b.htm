BLER Measurement Configuration

The "Extended BLER" measurement is included in the "LTE signaling" application. To access the measurement, press the softkey "LTE RX Meas" in the LTE signaling main view. Then select the tab "Extended BLER". The views and configuration dialogs of the tab are described in this section.
