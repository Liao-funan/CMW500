V3.7.20 (Compared to V3.7.10)
New features:
  • Enhanced machine type communication, see "eMTC"
  • LAA, see "Licensed-Assisted Access (LAA)"
  • Enhancements of UE capability report:
    –Enhanced: "RF UE Capabilities"
    –Enhanced: "Measurement UE Capabilities"
    –New: "LAA UE Capabilities"
  • Added operating band 71, see "Operating Bands"
  • Configurable CQI reporting parameter "simultaneousAckNackAndCQI", see "Simultaneous AckNack and CQI"
  • Attach accept cause 18 can be sent to UE, see "Attach Accept Cause"
  • Connected DRX supported without option R&S CMW-KS510, see "Connected DRX Settings"
  • Scenario "1CC - nx4" with two layers: allowed with R&S CMW-KS521 (R&S CMW-KS540 no longer needed)
  • Configurable logging, see "Debug Configuration"
