MAC UE Capabilities

This section indicates UE capabilities for the MAC layer.

MAC capabilities
Logical Channel SR Prohibit Timer

UE supports the logical channel SR prohibit timer as specified in 3GPP TS 36.321.

Remote command: 

SENSe:​LTE:​SIGN<i>:​UECapability:​MAC:​LCSPtimer?

 
Long DRX Command

UE supports the long DRX command MAC control element as specified in 3GPP TS 36.321.

Remote command: 

SENSe:​LTE:​SIGN<i>:​UECapability:​MAC:​LDRXcommand?
