General Settings

This section describes the settings at the highest level of the node "eMTC".

Search Space

Selects where the signaling application puts the MPDCCH.

"Common"

MPDCCH in common search space

This selection is only supported for the scheduling type "eMTC Auto Mode".

"UE Specific"

MPDCCH in UE-specific search space
