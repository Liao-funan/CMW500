SENSe:LTE:SIGN<i>:UECapability:TAUeeutra:IRAT:GERan:SUPPorted?

Returns a list of values indicating the support of the individual GERAN operating bands by the UE.

Return values: 
<SupportedBand>
OFF | ON

11 values: GSM 450, GSM 480, GSM 710, GSM 750, GSM 810, GSM 850, P-GSM 900, E-GSM 900, R-GSM 900, GSM 1800, GSM 1900

See "Querying UE Capability Report Contents"

Usage: Query only

V2.1.30, FAUeeutra / TAUeeutra V3.2.80

Manual operation: See "Supported Bands"
