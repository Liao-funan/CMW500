SENSe:LTE:SIGN<i>:DL[:PCC]:FCPower?
SENSe:LTE:SIGN<i>:DL:SCC<c>:FCPower?

Queries the "Full Cell BW Power". The power results from the configured RS EPRE and the cell bandwidth.

Suffix: 
<c>
1..4
Return values: 
<Level>
Range: -220 dBm  to  48 dBm
Default unit: dBm
Example: 

See "Configuring DL Power Levels"

Usage: Query only
Firmware/Software: 

V3.0.10, SCC command V3.2.50

Manual operation: See "RS EPRE"
