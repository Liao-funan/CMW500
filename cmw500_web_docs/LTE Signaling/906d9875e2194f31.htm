RF Paths and Co-Location

For full carrier aggregation flexibility, you need one TX module per output path. For a list of required TX modules per scenario, see "Scenarios".

To reduce the number of required TX modules, you can let two DL carriers share TX modules. This feature is called co-location. It reduces the number of TX modules required due to carrier aggregation, but not the number of TX modules required due to MIMO. The following table gives some examples.

Restrictions for co-located output paths:
  • No fading. Fading scenarios do not allow co-location.
  • The RS EPRE of co-located carriers can differ by maximum 30 dB.
  • The co-located channels must be located in the same band, within the 80 MHz bandwidth of a TX module. So the maximum carrier center frequency spacing equals 80 MHz minus half of the two cell bandwidths.
    Example: 20 MHz channel + 10 MHz channel
    Max spacing = 80 MHz - 10 MHz - 5 MHz = 65 MHz

The GUI takes care of these restrictions. With co-location, the allowed value ranges are adapted automatically.

Configuring co-location

To co-locate two carriers, proceed as follows.

  1. Select the signaling units for the two carriers. You need two different signaling units, located in the same instrument.

  2. Select the same TX modules for both carriers.

Co-location is indicated at the GUI as follows:
  • The icons on the component carrier tabs change.
    Carriers with the same number in the icon are co-located to each other.
  • The operating band setting of one carrier shows the coupling to the other carrier.
