CONFigure:LTE:SIGN<i>:CONNection[:PCC]:PUCCh:FFCA <Format>

Selects the PUCCH format used for carrier aggregation scenarios.

Parameters:
<Format>
F1BCs | F3

F1BCs: PUCCH format 1b with channel selection (if allowed)

F3: PUCCH format 3

*RST:F1BC
