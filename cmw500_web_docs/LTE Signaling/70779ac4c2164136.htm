eMTC

To use the LTE signaling application for enhanced machine type communication (eMTC), you need option R&S CMW-KS590.

eMTC is specified by 3GPP in Release 13. It is designed for the Internet of things (IoT). The focus is on long battery life, low device cost and extended coverage. eMTC UEs are typically delay-tolerant and can be located in areas with poor coverage, for example in basements.

eMTC uses two modes of operation for coverage enhancement (CE), CE mode A and CE mode B. CE mode A is mandatory for UE category M1, supports full mobility and results in a small coverage enhancement. CE mode B is optional, supports only limited mobility and results in a much larger coverage enhancement.

CE mode B not supported

The current software version supports only CE mode A, though there are some settings related to CE mode B on the GUI.

To enhance the coverage, most physical channels support repeated transmissions. The allowed number of repetitions in CE mode B is much higher than in CE mode A.

Narrowbands

eMTC uses narrowband operation. A narrowband covers 1.4 MHz and contains six resource blocks. An LTE channel can contain several eMTC narrowbands. A 10-MHz LTE channel, for example, contains eight eMTC narrowbands.

One eMTC connection uses only one narrowband at a time. But repeated transmissions can be combined with frequency hopping. So the same information is transmitted repeatedly in a changing narrowband.

The number and location of the narrowbands within the cell bandwidth is specified by 3GPP. There are as many narrowbands as fit into the bandwidth. Depending on the bandwidth, the center RB is not used. If there are more unused RBs, they are at the edge of the bandwidth. The narrowbands are numbered 0 to n, with increasing frequency.
