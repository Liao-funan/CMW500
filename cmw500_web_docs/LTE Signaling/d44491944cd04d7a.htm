V3.5.10 (Compared to V3.2.82)
New features:
  • New scenarios "3CC..." for carrier aggregation with three downlink carriers (one PCC plus two SCCs), see "Scenario"
  • Transmission mode 9, including MIMO 8x2, see "MIMO and Beamforming"
  • New scheduling type "Follow WB PMI-RI", see "Follow WB PMI and PMI-RI Channels"
  • UL RMCs with resource allocation type 1, see "UL RMCs, Multi-Cluster"
  • Internal standard fading for four and eight DL TX antennas, see "Internal Fading"
  • HARQ for uplink transmissions, see "UL HARQ"
  • Duplex mode configurable per component carrier, see "Duplex Mode"
  • Configurable PUCCH resources for scheduling requests, see:
    –"sr-PUCCH ResourceIndex"
    –"sr-ConfigIndex"
  • Special subframe configuration 9, see "Special Subframe"
  • The parameter "Enable Speech Codec" has been removed from all signaling applications. Instead, the coupled signaling application is now selected in the audio measurement application. For VoLTE audio tests, you must couple the audio board to the IMS server of the DAU. Refer to the audio measurement documentation or to "VoLTE Call Setup and Audio Tests".
  • Option R&S CMW-KS510 is required no longer for:
    –Audio tests, see "Audio Tests and Speech Quality Tests"
    –Setting "IMS Voice Over PS Session Indicator"
  • The duplex mode can be changed via intra-RAT handover, see "Inter/Intra-RAT (hotkey)"
  • Enhanced range for band indicator for user-defined bands, see "Band Indicator"
  • Configurable UL frame timing, see "Timing Advance Control"
  • New DL operating band 32, see "Operating Bands"
