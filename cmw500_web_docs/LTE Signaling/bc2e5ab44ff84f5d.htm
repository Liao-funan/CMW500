V3.5.40 (Compared to V3.5.30)
New features:
  • Redesign of UL RMCs by 3GPP, see "UL RMCs, Contiguous Allocation"
  • Cell broadcast services for alerting networks, see "Messaging (CBS) Parameters"
  • All scenarios support the selection of the signaling unit, see "Base Band Unit"
  • Support of operating bands 45, 46, 65, 66 and 67, see "Operating Bands"
  • Support of WCDMA bands 22 and 25 (for example for a handover)
  • Handover of VoLTE call to WCDMA (SRVCC), see "Connection Type"
  • Internal fading, AWGN enhancements:
    –Configurable frequency offset, see "Frequency Offset"
    –Enhanced range for ratio noise BW to cell BW, see "Frequency Offset"
  • UE capability report enhancements:
    –UL and DL UE category, see "General UE Capability Information"
    –All command result arrays involving LTE bands have been restructured, so that they do not need to be changed for future new LTE bands below OB255.
    –Configurable information element "requestedFrequencyBands", see "Capabilities"
  • 256-QAM downlink enhancements:
    –256-QAM for DL user-defined channels with TTI-based configuration, see "User-Defined Channels"
    –256-QAM for DL CQI channels, see "Use 256-QAM" and "Scheduled CQI"
  • TM 7: Port 0 can be mapped to one or two output paths, see "Port 0 Mapping"
  • TM 8 enhancements:
    –Precoding matrix as beamforming matrix, see "Beamforming Mode"
    –Channel matrix configurable, see "Channel Matrix 2x2 TM8"
  • TM 9, CSI-RS enhancements:
    –Follow WB CQI: separate CQI-MCS mapping table for subframes with CSI-RS, see "DL Follow WB Tab - CQI Variant"
    –The CSI-RS power offset value Pc signaled to the UE can be configured independent from the used power offset, see "CSI-RS"
  • Power at antenna port 7/8 configurable, see "PDSCH"
  • Transmission gaps for neighbor cell measurements can be disabled, see "Measurement Gap Enable"
  • New reject cause "Network failure", see "Attach Reject Cause"
  • CQI reporting and CDRX are now possible in parallel
  • A mobile-originating request for CS fallback can be rejected, see "CS Fallback (MO)"
  • Configurable reaction to UE power-saving-mode requests, see "PSM Allowed"
  • Configurable user data header for outgoing SMS, see "User Data Header"
  • Configurable timer T3402, see "Timer and Constants"
  • Configurable signaled setting "ue-TransmitAntennaSelection", see "UE Transmit Antenna Selection"
  • Configurable signaled SRS settings "srs-BandwidthConfig", "srs-Bandwidth" and "srs-HoppingBandwidth", see "SRS"
