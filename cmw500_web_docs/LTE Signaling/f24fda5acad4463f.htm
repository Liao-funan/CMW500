CONFigure:LTE:SIGN<i>:CONNection:UECategory:MANual <UECatManual>

Configures the UE category to be used by the R&S CMW if no reported value is available or usage of the reported value is disabled, see CONFigure:​LTE:​SIGN<i>:​CONNection:​UECategory:​REPorted.

Parameters:
<UECatManual>
Range: 0  to  15
*RST:3

See "Configuring General Connection Settings Part 1"

V3.0.10
