UL RMCs

UL RMCs for eMTC use a contiguous RB allocation.

The position of the RBs within the cell bandwidth is configured via two parameters:
  • The RB position selects the position within the narrowband. You can use the lower end of the narrowband, starting with the first RB of the narrowband. Or you can use the upper end of the narrowband, up to the last RB of the narrowband.
  • The NB position selects the narrowband. The allowed values are the same as for user-defined channels, see Table "NB position values depending on bandwidth".

Subframe pattern

The subframe pattern defines which subframes of the radio frame are scheduled. For some tests, 3GPP defines subframe patterns deviating from the standard pattern.

You can select which pattern you want to use. For easy configuration, the patterns are identified via the chapter numbers of 3GPP TS 36.521 where they are defined.

Some patterns restrict the allowed values for the UL settings, as follows:
  • "6.5.2.1EA.2-A" and "6.5.2.1EA.2-B" allow only:
    –NB position "low"
    –RB position "low"
    –6 RB plus QPSK or
    5 RB plus 16-QAM
