V3.2.60 (Compared to V3.2.50)
New features:
  • Button for exchange of PCC and SCC settings, see "Swap (button)"
  • Configurable "srs-SubframeConfig", see "SRS"
  • Enhanced range for UL power settings, see "Max. allowed Power P-Max" and "Closed Loop Target Power"
  • Command for identical configuration of all MIMO DL streams, see CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​DLEQual
  • The parameter "Enable Data end to end" is no longer required. Several applications with software version 3.2.60 or higher can use the data application unit (DAU) in parallel.
