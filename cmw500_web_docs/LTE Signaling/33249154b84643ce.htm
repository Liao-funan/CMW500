UE Based Network Performance Measurement UE Capabilities

This section indicates UE capabilities for UE-based network performance measurements.

Network performance measurement capabilities
logged Measurements Idle

Support of logged measurements in idle mode.

Remote command: 

SENSe:​LTE:​SIGN<i>:​UECapability:​UBNPmeas:​LMIDle?

 
Standalone GNSS Location

Indicates whether the UE is equipped with a GNSS receiver or not.

Remote command: 

SENSe:​LTE:​SIGN<i>:​UECapability:​UBNPmeas:​SGLocation?

 
Logged MBSFN Measurements

Support of logged MBSFN measurements in RRC idle and connected mode.

Remote command: 

SENSe:​LTE:​SIGN<i>:​UECapability:​LMMeas?
