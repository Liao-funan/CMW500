CONFigure:LTE:SIGN<i>:CONNection[:PCC]:PZERo:MAPPing <Port>
CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:PZERo:MAPPing <Port>

Selects the mapping of antenna port 0 to the RF output paths.

Only for TM 7 in scenarios with two RF output paths, without fading.

Suffix: 
<c>
1..7
Parameters:
<Port>
R1 | R1R2

R1: Map port 0 to the first RF output path.

R1R2: Map port 0 to both RF output paths.

*RST:R1
Example: 

See "Configuring MIMO Settings"

Options: R&S CMW-KS520
Manual operation: See "Port 0 Mapping"
