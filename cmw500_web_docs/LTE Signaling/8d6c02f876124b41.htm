V3.2.50 (Compared to V3.2.20)
New features:
  • Downlink carrier aggregation, see for example:
    –"Carrier Aggregation"
    –"Test Setup for CA Scenarios (Single CMW)"
    –"SCC States"
  • Relative power control, see "Relative Power Control Tests"
  • New handover mechanism "mobile terminating CS fallback", see "Handover"
  • External delay compensation, see "RF Signal Routing"
  • Synchronization of the system time / the SFN, see "Synchronization"
  • Inactivity timer for release of RRC connection, see "Keep RRC Connection"
  • Support of operating bands 29, 30 and 31, see "Operating Bands"
  • HARQ can be enabled for scheduling type "CQI Follow WB"
  • Reset/preset value changed for:
    –"Accept Multiple Default Bearer"
    –"Integrity Algorithm"
