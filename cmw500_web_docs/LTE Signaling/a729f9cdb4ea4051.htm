V3.2.70 (Compared to V3.2.60)
New features:
  • Carrier aggregation enhancements:
    –Internal and external fading (SISO and MIMO), see "Scenario"
    For internal fading with CA, base software version 3.2.40 or higher is required.
    –CQI reporting for CA, see "CQI Reporting"
    "CQI Follow WB" for CA, see "TTI-Based Channel Configuration"
    –HARQ for CA, see "DL HARQ"
    –Separate measurement reports for PCC and SCC of serving cell, see "UE Measurement Report"
    –Configurable measurement period for SCell measurement reports in state "RRC Added", see "Measurement Cycle SCell"
    –BLER measurements "CQI Reporting", "PMI - RI" and "HARQ" also for CA, see "Extended BLER Measurement"
  • RMC enhancements:
    –Additional UL RMC configurations, see "UL RMCs, Contiguous Allocation"
    –Number of RB = 0 allowed for DL RMC with multiple TX antennas, see "DL RMCs, Multiple TX Antennas (TM 2 to 6)"
    –Additional setting to distinguish ambiguous RMCs, see "Version"
  • New MIMO transmission modes, see "MIMO and Beamforming"
    –Mode 2 - transmit diversity
    –Mode 6 - closed loop spatial multiplexing, single layer
    –Mode 7 and 8, single/dual-layer beamforming

    New configuration method. Instead of transmission scheme, configure transmission mode and DCI format.
  • Precoding matrix configurable for transmission mode 6, see Table "Transmission scheme overview"
  • Scenario for MIMO 4x2 with external RF fading (four RF outputs), see "Test Setup for MIMO 4x2 with External RF Fading"
  • Cell reselection settings enhanced, see "Cell Reselection"
  • Connection to the audio board for audio tests
  • UL dynamic scheduling to force DRX, see "UL Dynamic Scheduling"
  • New reject cause "Roaming not allowed in this TA", see "Attach Reject Cause"
  • Short messages in binary format, see "Messaging (SMS) Parameters"
  • UE-specific SRS timing, see "Configuration Index"
  • New network signaled values, see "Additional Spectrum Emission"
