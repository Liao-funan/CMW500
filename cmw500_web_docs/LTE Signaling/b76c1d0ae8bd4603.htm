V3.0.10 (Compared to V2.1.30)
New features:
  • Support of external fading for standard cell and "Two RF Out Ports" scenarios, see "External Fading"
  • New scenario "IQ out - RF in", see "Test Setup for Scenario 1CC - IQ Out, RF In - 1x1"
  • Redirection to another signaling application supported, see "Handover"
  • Blind inter-band and inter-frequency handover are now also supported for TDD, see "Operating Band Change, Frequency Change"
  • Support of FDD operating bands 23 and 26, see "Operating Bands"
  • New scheduling type "CQI", see "CQI Channels"
  • Support of periodic CQI reporting, see "CQI Reporting"
  • BLER measurement enhanced/improved (see "Extended BLER Measurement"):
    –Measurement reorganized in views, overview added
    –New view providing results derived from reported CQI indices
    –Median reported CQI indices added to throughput diagram (traces and single values)
  • Configurable cell reselection parameters Sintrasearch and Qrxlevmin, see "Cell Reselection"
  • Support of uplink-downlink configuration 5 for TDD, see "Use Carrier Specific"
  • An attached UE can be detached via a hotkey, see "Connection control hotkeys"
  • If the UE indicates IPv6 support, an IPv6 prefix is assigned to the UE, see "Connection Status"
  • New timer T3412 for periodic tracking area update, see "Timer and Constants"
  • The UE category can be specified manually or taken from the capability report, see "UE Category"
  • A single pattern can now contain up to 35 TPC commands, see "Single Pattern"
  • Additional spectrum emission: new values NS_11 to NS_15, see "Additional Spectrum Emission"
  • Precoding matrix for transmission mode 4 can be selected, see "Precoding Matrix"
  • Signaling of the maximum allowed UE output power P-Max can be disabled, see "Max. allowed Power P-Max"
  • Sending a DNS IP address to the UE can be disabled, see "Send DNS PCO"
  • Enhanced range for uplink user-defined channels, 16-QAM: TBS index maximum = 26, see "Supported Transport Block Size Indices"
  • Query of full cell bandwidth power via remote command: SENSe:​LTE:​SIGN<i>:​DL[:​PCC]:​FCPower?
  • Configurable mixer level offset, see "Mixer Level Offset"
  • Message monitoring: external PC address pool configured globally, see "Message Monitoring Settings"
