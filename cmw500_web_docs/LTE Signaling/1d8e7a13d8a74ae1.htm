CONFigure:LTE:SIGN<i>:CELL:NAS:EMCBs <Support>

Configures the field "Emergency bearer services indicator" of the information element "EPS Network Feature Support".

Parameters:
<Support>
NSUPported | SUPPorted

NSUPported: not supported

SUPPorted: supported

*RST:NSUP

See "Configuring Other Network Settings"
