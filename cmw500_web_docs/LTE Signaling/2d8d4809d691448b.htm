CQI Channels for LAA
The following scheduling types are also supported for CQI tests with LAA. Option R&S CMW-KS510/-KS512 is required as without LAA:
  • Follow wideband CQI
  • Follow wideband PMI
  • Follow wideband PMI-RI
  • Follow wideband CQI-RI
  • Follow wideband CQI-PMI-RI

For these scheduling types, you can configure the same DL settings as without LAA. For details, see "CQI Channels".

In addition, you can configure the following settings:
  • Number of subframes per burst
  • Periodicity of bursts (a burst starts every nth subframe)
The following additional characteristics apply:
  • Fixed transmission bursts only, no random transmission bursts
  • Only full allocation, even in the first and last subframe of the burst
