V3.0.50 (Compared to V3.0.30)
New features:
  • MIMO 4x2, see "MIMO and Beamforming" and "Antenna Configuration"
  • HARQ settings, see "DL HARQ"
    BLER measurement HARQ results, see "Result Overview"
  • New scheduling type for CQI tests, with downlink MCS following the wideband CQI report, see "CQI Channels"
  • Display of PDCCH configuration, possible PDCCH resource reduction, see "PDCCH"
  • Extended cyclic prefix, see "Cyclic Prefix"
  • Uplink CRC check for BLER measurement, see "Result Overview"
  • The "cqi-pmi-ConfigIndex" (ICQI/PMI) can now be configured separately for FDD and TDD, see "CQI/PMI Config Index"
  • Neighbor cell measurement reports:
    –For report contents, see "UE Measurement Report"
    –Configuration of reports per neighbor cell, see "Neighbor Cell Settings"
    –Measurement gap period and WCDMA measurement quantity configuration, see "UE Measurement Report Settings"
  • TDD enhancements:
    –All TDD UL-DL configurations supported, see "Use Carrier Specific"
    –CQI reporting also for TDD, see "CQI Reporting"
    –Error insertion also for TDD, see "Downlink MAC Error Insertion"
    –User-defined band allows different UL and DL frequencies even for TDD, see "Band Definition"
  • Uplink power settings:
    –Advanced uplink power settings, see "PRACH and Initial PUSCH Power"
    –The closed loop target power can no longer be configured separately for PUCCH and PUSCH. The setting in the TPC section now applies to both. The command CONFigure:LTE:SIGN:UL:PUCCh:CLTPower is still supported as alias.
    –The open loop nominal power command has been changed to CONFigure:LTE:SIGN:UL:OLNPower. The old command is still supported as alias (...UL:PUSCH:OLNPower).
    –Improved TPC setup handling, see "TX Power Control (TPC)"
