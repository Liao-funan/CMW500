eMTC Auto Mode

eMTC uses cross-subframe scheduling. If you want to use repetitions and narrowband hopping, you must consider many aspects to configure a meaningful scheduling and to fit all channels into the narrowband.

To facilitate the scheduling configuration for eMTC, the signaling application provides an auto mode. The auto mode takes care of all these aspects. It uses the configured repetitions and the configured hopping and creates a scheduling without collisions.

The auto mode uses half-duplex. The scheduling contains alternating DL and UL phases:
  • DL phase: MPDCCH, then PDSCH, then PUCCH
    The DL phase includes the DL information (MPDCCH), the DL data (PDSCH) and the acknowledgments of the DL data (PUCCH).
  • UL phase: MPDCCH, then PUSCH
    The UL phase includes the scheduling (MPDCCH) and the UL data (PUSCH).
As for other scheduling types, you can configure the resource block allocation for the eMTC auto mode. The following settings are available:
  • Number of used resource blocks (#RB), contiguous allocation
  • Position of the resource blocks within the narrowband (start RB)
  • Narrowband used for the first transmission in the first DL phase, before hopping
  • Modulation type
  • Transport block size (TBS) index
