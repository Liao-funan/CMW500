Connection Status

The connection status area displays the following information.

Connection status area of the main view

For background information about the displayed states, see "Connection States".

For control of the states, see "Signaling Control".

Cell

Displays the current state (or state transition) of the downlink signal generator.

Remote command: 

SOURce:​LTE:​SIGN<i>:​CELL:​STATe

 
Packet Switched

Displays the current state or state transition of the packet-switched network domain.

Remote command: 

FETCh:​LTE:​SIGN<i>:​PSWitched:​STATe?

 
RRC State

Indicates whether a PCC RRC connection is established ("Connected") or not ("Idle").

Remote command: 

SENSe:​LTE:​SIGN<i>:​RRCState?

 
SCC<n> State

Displays the current state of the secondary component carrier (SCC) number <n>. Only visible for carrier aggregation scenarios.

Remote command: 

FETCh:​LTE:​SIGN<i>:​SCC<c>:​STATe?
