FETCh:LTE:SIGN<i>:A:STATe?
FETCh:LTE:SIGN<i>:B:STATe?

Query the state of the SCC synchronization set A or B, see also "SCC States".

Return values: 
<SyncSetBState>
OFF | ON | RRCadded | MACactivated

OFF: SCC off

ON: SCC on

RRCadded: RRC added

MACactivated: MAC activated

Usage: Query only
Firmware/Software: 

V3.7.10

Manual operation: See "Connection control hotkeys"
