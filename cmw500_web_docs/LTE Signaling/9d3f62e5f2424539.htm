User-Defined Channels for eMTC

The parameters in this section configure user-defined channels for eMTC. Option R&S CMW-KS510 is required.

To display these settings, select the scheduling type "User-Defined Channels", see "Scheduling Type".

To configure the channels, proceed as follows (for UL and DL):

  1. Select the cell bandwidth (see "Physical Cell Setup").

  2. Configure half duplex or full duplex.

  3. Select the number of allocated resource blocks (RB).

  4. Select the RB position within the narrowband (NB).

  5. Select the NB position.

  6. Select the modulation type.

  7. Select the transport block size index.

For valid parameter combinations and background information, see "User-Defined Channels for eMTC".

For carrier aggregation scenarios, you can configure the settings per component carrier.

Half Duplex

Selects between half-duplex operation and full-duplex operation.

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​HDUPlex

 
# Resource Blocks, Start Resource Block

Selects the number of allocated resource blocks and the position of the first allocated resource block within the narrowband.

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​A:​DL

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​A:​UL

 
NB Position

Selects the narrowband, see also Table "NB position values depending on bandwidth".

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​NBPosition:​DL

 
Modulation Type

Selects the modulation type. This parameter influences the transport block size index.

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​A:​DL

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​A:​UL

 
Transport Block Size Index, Transport Block Size

Selects the TBS index. The resulting "Transport Block Size" in bits is displayed

Remote command: 

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​A:​DL

CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​EMTC:​A:​UL

 
Throughput

Displays the expected maximum throughput in Mbit/s (averaged over one frame).

Remote command: 

SENSe:​LTE:​SIGN<i>:​CONNection:​ETHRoughput:​DL[:​PCC]:​STReam<s>?

SENSe:​LTE:​SIGN<i>:​CONNection:​ETHRoughput:​UL[:​PCC]?

 
Code Rate

Only displayed in the main view: Effective channel code rate, i.e. the number of information bits (including CRC bits) divided by the number of physical channel bits on PDSCH/PUSCH.

Remote command: 

SENSe:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​DL<s>:​CRATe:​ALL?

SENSe:​LTE:​SIGN<i>:​CONNection[:​PCC]:​UDCHannels:​UL:​CRATe:​ALL?
