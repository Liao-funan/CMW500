FETCh:LTE:SIGN<i>:EBLer:ALL:CONFidence?

Returns the overall pass/fail result of a confidence BLER measurement.

Return values: 
<Reliability>

See "Reliability Indicator"

<Confidence>
EPASs | EFAil | PASS | FAIL | UNDecided

EPASs, EFAil: early pass, early fail

PASS, FAIL: pass, fail

UNDecided: undecided

See "Performing a Confidence BLER Measurement"
