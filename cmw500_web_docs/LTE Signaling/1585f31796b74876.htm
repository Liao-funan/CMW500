CONFigure:LTE:SIGN<i>:CONNection[:PCC]:RMC:RBPosition:UL <Position>
CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:RMC:RBPosition:UL <Position>

Selects the position of the allocated uplink resource blocks within the cell bandwidth, for contiguous allocation.

The RBs can always be at the lower end, starting with RB number 0 (LOW), or at the upper end of the channel (HIGH). Other values are only allowed for certain RMC configurations, see "Scheduling Type RMC".
