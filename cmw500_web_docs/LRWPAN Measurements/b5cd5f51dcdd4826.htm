What's New in This Revision

This document describes version 3.5.20 and later of the "LR-WPAN TX Measurement". Compared to version 3.5.10, the following features have been added:

  • Margin measurement of average spectrum traces, see "Detailed Views: Power Spectral Density"
  • Additional results of EVM vs chip measurement, see "Detailed Views: Modulation"
    –Absolute EVM
    –LO leakage
    –EVM results within header, payload and complete PPDU
  • Additional modulation limits, see "Modulation Limits"
    –Absolute EVM limits
    –LO leakage limit
    –EVM limits for header portion, payload and complete PPDU
