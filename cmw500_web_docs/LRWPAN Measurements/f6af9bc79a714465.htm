CONFigure:WPAN:MEAS<i>:MEValuation:LIMit:SRATe <SymbolRate>, <SymbolRateEnble>

Defines upper limit for symbol rate error.

Parameters:
<SymbolRate>
Range: 0 ppm  to  80 ppm
*RST:40 ppm
Default unit: ppm
<SymbolRateEnble>
OFF | ON

Disables | enables the limit check for symbol rate error

*RST:ON
