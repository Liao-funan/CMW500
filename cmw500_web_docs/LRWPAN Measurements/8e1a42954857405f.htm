Returns the power single results.

The values described below are returned by FETCh and READ commands. CALCulate commands return limit check results instead, one value for each result listed below.

Return values: 
<Reliability>

"Reliability Indicator"

<BurstOutOfTol>

Out of tolerance result, i.e. percentage of measurement intervals of the statistic count (CONFigure:​WPAN:​MEAS<i>:​MEValuation:​SCOunt:​PVTime) exceeding the specified limits, see "Power Limits".

Additional parameters: OFF | ON (disables | enables this check)

Range: 0 %  to  100 %
Default unit: %
<AveragePower>

Average transmit power of the DUT

Range: -128 dBm to 30 dBm
Default unit: dBm
Example: 

See "Performing Continuous Measurements"

Usage: Query only

V3.5.10
