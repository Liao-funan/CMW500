LR-WPAN TX Measurement

The Low Rate Wireless Personal Area Network (LR-WPAN) multi-evaluation measurement provides transmitter (TX) tests for LR-WPAN devices.

The basic option R&S CMW-KM680 supports O-QPSK physical layer (PHY): direct sequence spread spectrum (DSSS) PHY employing offset quadrature phase-shift keying (O-QPSK) modulation, operating in the 2450 MHz band.

The tests cover the following transmitter properties:
  • Power: average power versus time
  • Modulation: absolute and offset EVM for PSDU chips, frequency accuracy and symbol rate error
  • Spectrum: power spectral density

Conformance requirements are specified in LR-WPAN standard IEEE 802.15.4.

Transmitting a well-defined signal toward the DUT facilitates many measurement tasks. To generate modulated RF signals, the R&S CMW must be equipped with the ARB and real time baseband generator module. The following option enables processing of LR-WPAN waveform files:

R&S CMW-KV680: LR-WPAN IEEE 802.15.4 (ZigBee), waveform for ARB.
