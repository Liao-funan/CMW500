TRIGger:WPAN:MEAS<i>:MEValuation:THReshold <Power>

Defines the trigger threshold for the power trigger.

Parameters:
<Power>
Range: -50 dB  to  0 dB
*RST:-30 dB
Default unit: dB (full scale, i.e. relative to reference level minus external attenuation)

Additional parameters: OFF | ON (disables | enables threshold using the previous/default values)

See "Basic Input Signal Properties"
