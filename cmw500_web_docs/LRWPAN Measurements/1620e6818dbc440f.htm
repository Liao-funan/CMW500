Measurement Results

The "LR-WPAN Multi-Evaluation Measurement" dialog shows all results in several alternative views; see detailed description in "Measurement Results".

The multi-evaluation measurement provides an overview dialog and a detailed view for each diagram in the overview. Each dialog shows the most important RF and analyzer settings. The dialogs also visualize the limit check results.

See also: "Limit Check"

LR-WPAN multi-evaluation: results
Traces

To retrieve the values in the traces, use commands of the following type.

Remote command: 

FETCh:​WPAN:​MEAS<i>:​MEValuation:​TRACe:​PVTime:​CURRent? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​TRACe:​EVMChip[:​OFFSet]:​CURRent? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​TRACe:​EVMChip:​ABSolute:​CURRent? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​TRACe:​IQABsolute? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​TRACe:​IQOFfset? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​TRACe:​PSDensity:​CURRent[:​RELative]? etc.

 
Statistical Values

To retrieve the additional values in the detailed views, use the following commands.

Remote command: 

FETCh:​WPAN:​MEAS<i>:​MEValuation:​MODulation[:​OFFSet]:​CURRent? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​MODulation:​ABSolute:​CURRent? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​PVTime:​CURRent? etc.

FETCh:​WPAN:​MEAS<i>:​MEValuation:​SPECtrum:​CURRent? etc.
