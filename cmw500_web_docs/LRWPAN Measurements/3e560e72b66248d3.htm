CONFigure:WPAN:MEAS<i>:MEValuation:TRIGger:MGAP <TriggerTimeout>

Sets a minimum time during which the IF signal must be below the trigger threshold before the trigger is armed so that the measurement can be started.

Parameters:
<TriggerTimeout>
Range: 0 s  to  0.01 s
*RST:0 s

Additional parameters: OFF | ON (disables | enables timeout using the previous/default values)
