Generator Shortcut

Enables you to start the GPRF generator and to use GPRF-related hotkeys and softkeys within the measurement application.

As soon as a connection to the GPRF generator instance is established, two additional softkeys with corresponding hotkey bars provide access to the generator configuration, see "Additional Softkeys and Hotkeys".

Use the appropriate softkey/hotkey combination to access the generator parameters.

For details on the available parameters, see the GPRF generator documentation.
