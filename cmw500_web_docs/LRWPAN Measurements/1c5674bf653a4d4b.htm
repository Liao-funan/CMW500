CONFigure:WPAN:MEAS<i>:MEValuation:LIMit:SPECtrum <PSDAbsolute>, <PSDRelative>, <PSDEnabled>

Defines upper limits of power spectrum density for the absolute power and for the power relative to the reference power.

Parameters:
<PSDAbsolute>
Range: -80 dBm  to  5 dBm
*RST:-30 dBm
Default unit: dBm
<PSDRelative>
Range: -80 dB  to  0 dB
*RST:-20 dB
Default unit: dB
<PSDEnabled>
OFF | ON

Disable or enable limit check.

*RST:ON
Example: 

See "Limit Settings"

Firmware/Software: 

V3.5.10

Manual operation: See "Power Spectral Density Limit"
