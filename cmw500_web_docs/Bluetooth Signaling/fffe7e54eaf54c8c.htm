SENSe:BLUetooth:SIGN<i>:EUT:CAPability:SCO?

Gets the SCO-related capabilities of the connected EUT. For each capability, either OFF or ON is returned

Return values: 
<CQDD>
OFF | ON

Channel quality driven data rate

<Link>
OFF | ON

SCO link

<TSData>
OFF | ON

Transparent SCO data

<HV2P>
OFF | ON

HV2 packets

<HV3P>
OFF | ON

HV3 packets

<ULAW>
OFF | ON

μ-law log

<ALAW>
OFF | ON

A-law log

<CVSD>
OFF | ON

Continuous variable slope delta modulation

Example: 

See "Query results"

Usage: Query only
Firmware/Software: 

V3.0.12

Manual operation: See "Packet Type and Data Link Type Capabilities"
