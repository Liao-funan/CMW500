CONFigure:BLUetooth:SIGN<i>:CONNection:PCONtrol:EPCMode <PCMode>

Activates/deactivates enhanced power control mode.

Parameters:
<PCMode>
AUTO | OFF

AUTO : instrument uses enhanced power control if EUT supports it, otherwise it uses legacy power control

OFF : instrument uses legacy power control

*RST:AUTO
Example: 

See "Initialization and Basic Configuration"
