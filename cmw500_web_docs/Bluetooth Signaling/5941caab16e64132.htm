RX Quality Measurement Configuration

The signaling RX measurement is included in the "Bluetooth Signaling" application. It must be activated in the "Measurement Controller" dialog via the entry "RX Meas.". The softkey is visible when operating mode is set to RF test, see "Operating Mode, Profile". The RX measurement views and the related configuration dialogs are described in this section.
