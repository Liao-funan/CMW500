Configure the dirty transmitter.

Commands for BR (...:BRATe...), EDR (...:EDRate...), LE 1M PHY (...:LE1M...), LE 2M PHY (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

Parameters:
<DTXMode>
SINGle values | SPEC table

SING: single set of dirty transmitter parameters. No periodic change of the frequency offset, modulation index, and symbol timing error occurs.

SPEC: settings according to the test specification for Bluetooth wireless technology, see "Dirty Tx Mode".

*RST:SPEC
