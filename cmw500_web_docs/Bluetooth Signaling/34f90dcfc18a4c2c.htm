V3.0.12

This version is the initial version, where the R&S CMW implements a BR/EDR (BR/EDR) master that is able to connect to a single slave.

In particular it supports the following features:
  • Inquiry (device discovery)
  • Setup of an asynchronous connection-less (ACL) link
    –Paging a previously discovered device or paging a default device without preceding inquiry
    –Determine properties and capabilities of the connected device
