CONFigure:BLUetooth:SIGN<i>:RXQuality:SEARch:LIMit:MPER:LENergy[:LE1M] <Limit>

Specifies the upper PER limit for LE PER search measurements.

Commands for LE 1M PHY (...:LE1M...), LE 2M PHY (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

Parameters:
<Limit>
Range: 0 %  to  100 %
*RST:30.8 %
Default unit: %

Additional parameters: OFF | ON (disables the limit | enables the limit using the previous/default level)
