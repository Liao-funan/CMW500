CONFigure:BLUetooth:SIGN<i>:CONNection:PAGing:TOUT <Timeout>

Sets/gets the Page_Timeout configuration parameter, i.e. the maximum time the local link manager waits for a baseband page response from the EUT.

Parameters:
<Timeout>
Range: 22  to  65535
*RST:8192
Default unit: slot (625 µs)
Example: 

See "Configure Paging"

Firmware/Software: 

V3.0.12

V3.5.30: changed range

Manual operation: See "Paging Timeout"
