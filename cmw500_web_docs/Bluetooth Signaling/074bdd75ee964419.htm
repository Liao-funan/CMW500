Connection Test (BR/EDR)
Option R&S CMW-KS600 provides the following BR/EDR results:
  • Basic information about the connection status and the connected device, such as its name and link manager protocol (LMP) version (see "Connection Status Tab - EUT Info (BR/EDR)")
  • Extended information about the EUT's capabilities (see "Connection Status Tab - EUT Capabilities (BR/EDR)")
Executing Connection Tests

Proceed as follows:

  1. Connect your Bluetooth device to the R&S CMW. For the test setup, refer to "Test Setups".

  2. Open the "Bluetooth Signaling" firmware application and press [ON | OFF] until the "Bluetooth Signaling" control softkey indicates the "ON" state.

  3. Select the "HW Interface".

  4. For a USB to RS232 adapter, configure the transmission parameters. See "USB to RS232".

    • If a USB connection is used, you can press "Initialize EUT" to reset and discover the EUT via USB. Continue from step 8.
    • For a connection to the default device, set its BD address and the page scan repetition mode. Continue from step 8.
    • Otherwise ensure that the EUT is discoverable by enabling inquiry scan mode and then press the "Inquire" button. Wait for the EUT to be found and its BD address to be displayed in the "BD Address" dialog that pops up on the screen.

  6. Wait for the inquiry process to finish or press "Stop Inquiry" at any time to return to the standby state.

  7. Select the target device in the "For Paging" filed. If the R&S CMW does not find any device during the inquiry, you can only select the default device.

  8. Press "Connect" and wait until the "Connection Status" pane indicates the signaling state "Connected".

  9. Details about the EUT can be seen in the "EUT Info" and "EUT Capabilities" pane, see "Connection Status Tab - EUT Capabilities (BR/EDR)".

Checks for Failed Connection
If the connection fails, check the following R&S CMW settings:
  • The "TX Level (CMW)" must be sufficiently high so that the EUT can receive the transmitted signal.
  • The "Exp. Nominal Power" must be in accordance with the EUT's signal power.
  • The "HW Interface" must be in accordance with the test setup, see "Test Setups".
  • For "HW Interface" = "USB to RS232", the transmission parameters (typically the baud rate) must match with the EUT configuration.
  • The installed USB driver must support the connected EUT, see "Tests with USB Interface".
