CONFigure:BLUetooth:SIGN<i>:CONNection:BTYPe <Burst Type>

Defines the Bluetooth burst type to be used.

Parameters:
<Burst Type>
BR | EDR | LE

BR: "Basic Rate"

EDR: "Enhanced Data Rate"

LE: "Low Energy"

*RST:BR
