Bluetooth® Signaling

The "Bluetooth Signaling" firmware application (R&S CMW-KS600) generates a Bluetooth signal and attempts a connection to the equipment under test (EUT). Once a connection is established, various properties of the connected device can be retrieved.

The basic signaling functionality provided by R&S CMW-KS600 for Basic Rate (BR) and Enhanced Data Rate (EDR) signals can be enhanced by the following options:
  • R&S CMW-KS602 "Bluetooth hands-free audio profile, basic signaling"
  • R&S CMW-KS603 "Bluetooth A2DP audio profile, basic signaling"
  • R&S CMW-KS610 "Bluetooth classic version 4.2, signaling, test mode"
The basic signaling functionality for Low Energy (LE) signals is provided by R&S CMW-KS611 "Bluetooth LE version 4.2, direct test mode via USB". The option supports LE 1 Msymbol/s physical layer (LE 1M PHY). To support also LE 2 Msymbol/s physical layer (LE 2M PHY) and LE Long Range physical layer (LE coded PHY), it can be enhanced by the following option:
  • R&S CMW-KS721 "Bluetooth LE version 5.0, direct test mode via USB"

Most tests can be performed using the Bluetooth multi-evaluation measurement. Measurements for BR and EDR are included in the option R&S CMW-KM610. Option R&S CMW-KM611 provides LE TX measurements on LE 1M PHY. Option R&S CMW-KM721 extends multi-evaluation measurements for LE 2M PHY and LE coded PHY measurements.

Additional RX quality measurements are provided by the "Bluetooth Signaling" application. For details, refer to "RX Quality Measurement Configuration".
