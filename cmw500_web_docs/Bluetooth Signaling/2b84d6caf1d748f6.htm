Return the frequency offset under the periodic change according to the test specification for Bluetooth wireless technology (10 values for BR and LE, 3 values for EDR).

Commands for BR (...:BRATe...), EDR (...:EDRate...), LE 1M PHY (...:LE1M...), LE 2M PHY (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

For dirty transmitter parameters according to the test specification for Bluetooth wireless technology, see also "Dirty Tx Mode".

Return values: 
<FreqOffset>
Range: -250E+3 Hz  to  250E+3 Hz
Default unit: Hz
Example: 

See "Configure Dirty Transmitter"

Usage: Query only
