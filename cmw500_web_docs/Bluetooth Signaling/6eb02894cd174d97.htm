SOURce:BLUetooth:SIGN<i>:STATe <MainState>

Sets/gets the main state of the "Bluetooth Signaling" application. Signaling actions such as inquiry or paging are initiated using the CALL:​BLUetooth:​SIGN<i>:​CONNection:​ACTion command.

Parameters:
<MainState>
OFF | ON

When turned ON, the R&S CMW switches to standby state (see FETCh:​BLUetooth:​SIGN<i>:​CONNection:​STATe?)

Firmware/Software: 

V3.0.12

Manual operation: See "CMW (Master)"
