V3.5.50 (Compared to V3.5.41)

New features:

  • Additional "Link Info Tab"
  • Audio links eSCO added, see "BR/EDR: SCO and eSCO Packets"
  • Codec mSBC added, see "Voice Link > Speech Codec"
  • Additional Rx measurements BER search and PER search
    –For description, see "BER Search / PER Search Measurements"
    –For configuration, see "RX Quality Measurement Configuration"
  • NAK calculation within the BER Rx quality measurements includes also access code errors and packet length errors, see "BER Measurements for BR and EDR"
  • R&S CMW acts as master or slave, see "CMW Role"
  • Remote commands for "Adaptive Frequency Hopping Control"
  • Remote commands for "Stack Delay Control"
  • eSCO capability information, see "Connection Status Tab - EUT Capabilities (BR/EDR)"
  • Configurable drift frequency of LE dirty transmitter, see "Dirty Tx Mode"
