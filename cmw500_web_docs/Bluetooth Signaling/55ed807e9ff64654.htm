CONFigure:BLUetooth:SIGN<i>:RFSettings:AFHopping <AdaptiveHopping>, <Mode>

Specifies the parameters of adaptive hopping.

Parameters:
<AdaptiveHopping>
OFF | ON

Disables, enables adaptive hopping.

*RST:OFF
<Mode>
EUT | NORM | USER

EUT: only the EUT reports bad channels

NORM: both, the EUT and instrument report bad channels

USER: bad channels specified manually via CONFigure:​BLUetooth:​SIGN<i>:​RFSettings:​AFHopping:​UCHannels

*RST:NORM
