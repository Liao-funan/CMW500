Enhanced power control mode configuration

This section is not applicable to LE.

Enhanced Power Control Mode

Activates or deactivates enhanced power control mode. Enhanced power control is only applicable if supported by the EUT, otherwise the R&S CMW uses legacy power control.

Remote command: 

CONFigure:​BLUetooth:​SIGN<i>:​CONNection:​PCONtrol:​EPCMode
