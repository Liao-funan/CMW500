CONFigure:BLUetooth:SIGN<i>:CONNection:BDADdress:EUT <BDAddress>

Sets/gets the Bluetooth device address (BD_ADDR) of a default device to attempt a connection to. If no inquiry was made before, this BD_ADDR is used for paging; otherwise, the device to page can be set via CONFigure:​BLUetooth:​SIGN<i>:​CONNection:​PAGing:​PTARget.

Parameters:
<BDAddress>
Range: #H0 to #HFFFFFFFFFFFF (12 hexadecimal digits)
*RST:#H123456789012
Example: 

See "Manually specify BD address"

Firmware/Software: 

V3.0.12

Manual operation: See "BD Address"
