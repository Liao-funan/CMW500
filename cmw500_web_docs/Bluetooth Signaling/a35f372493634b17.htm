CONFigure:BLUetooth:SIGN<i>:RFSettings:AFHopping:UCHannels <ChannelList>...

Specifies user-defined channels for adaptive frequency hopping (AFH). The setting is relevant for mode = USER, see CONFigure:​BLUetooth:​SIGN<i>:​RFSettings:​AFHopping.

Parameters:
<ChannelList>
0 | 1

79 comma-separated values, one value per channel:

0: channel is blocked for AFH

1: channel is released for AFH

*RST:1

See "Configure Test Mode"
