Connection Status Tab - EUT Info (BR/EDR)

The "EUT Info" pane displays basic device information retrieved during paging (connection setup).

EUT information pane

This section is not relevant for the burst type LE.

└ Device Name
└ LMP Version and Subversion
└ Power Control, Power State
Device Name

Displays name of the connected device; up to 255 characters long.

Remote command: 

SENSe:​BLUetooth:​SIGN<i>:​EUT:​INFormation:​NAME?

 
LMP Version and Subversion

Bluetooth link manager protocol (LMP) version and subversion of the connected device.

Remote command: 

SENSe:​BLUetooth:​SIGN<i>:​EUT:​INFormation:​VERSion?

 
Power Control, Power State

Displays actual power control mode.

Power state indicates the status of EUT TX power. This information is only visible if the selected power control mode is supported by the EUT.

To command the EUT, press one of the hotkeys "Power Up / Power Down / Max Power (hotkey)".

Check the EUT support of power control within the "Connection Status Tab - EUT Capabilities (BR/EDR)".

Remote command: 

SENSe:​BLUetooth:​SIGN<i>:​EUT:​PCONtrol:​STATe:​LEGacy?

SENSe:​BLUetooth:​SIGN<i>:​EUT:​PCONtrol:​STATe?

SENSe:​BLUetooth:​SIGN<i>:​EUT:​PCONtrol:​STATe:​DPSK?

SENSe:​BLUetooth:​SIGN<i>:​EUT:​PCONtrol:​STATe:​DQPSk?

SENSe:​BLUetooth:​SIGN<i>:​EUT:​PCONtrol:​STATe:​GFSK?
