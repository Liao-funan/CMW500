CONFigure:BLUetooth:SIGN<i>:RFSettings:EATTenuation:INPut <ExternalAtt>

Defines an external attenuation (or gain, if the value is negative), to be applied to the RF input connector.

Parameters:
<ExternalAtt>
Range: -50 dB  to  90 dB
*RST:0 dB
Default unit: dB
