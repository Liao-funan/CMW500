What's New in This Version

This documentation describes version 3.7.40 and later of the "Bluetooth Signaling" firmware application. Compared to version 3.7.30 it provides the following new features:

  • "Refresh Devices (hotkey)"
  • Reliability indicator code 52 "Connection Error", see "Reliability Indicator"
