Return all results of PER search RX measurement.

Commands for LE 1M PHY (...:LE1M...), LE 2M PHY (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

The values described below are returned by FETCh and READ commands. CALCulate commands return limit check results instead, one value for each result listed below.

Return values: 
<Reliability>

See "Reliability Indicator"

<PER>

Packet error rate

Range: 0 %  to  100 %
Default unit: %
<PacketsReceived>

Number of correct packets received and reported by the EUT

Range: 0  to  30E+3
<SearchResult>

TX level of the R&S CMW resulting in the configured PER search limit

Range: -1000 dBm  to  1000 dBm
Default unit: dBm
