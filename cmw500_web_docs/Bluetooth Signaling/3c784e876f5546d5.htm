SENSe:BLUetooth:SIGN<i>:EUT:CAPability:PSAVing?

Gets the power saving-related capabilities of the connected EUT. For each capability, either OFF or ON is returned

Return values: 
<Hold>
OFF | ON

Hold mode

<Sniff>
OFF | ON

Sniff mode

<Park>
OFF | ON

Park mode

Usage: Query only
Firmware/Software: 

V3.0.12

Manual operation: See "Power Saving and Power Control Capabilities"
