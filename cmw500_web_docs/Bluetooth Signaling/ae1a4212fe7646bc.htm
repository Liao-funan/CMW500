BER Search / PER Search Measurements

In addition to BER/PER results, the search measurements also determine the TX level of R&S CMW for a given BER/PER value. It measures the RX sensitivity level of the EUT. The search iteration is performed at decreasing TX RF output levels until the target BER/PER is found, or the minimum CMW output level is reached.

The BER/PER value used for search mechanism is specified in the configuration tree as a limit for BER search / PER search measurement, see "Limits".
