V3.2.30 (Compared to V3.0.12)
New features:
  • BR/EDR test mode, see "General Setup"
  • Signal characteristics settings, see "Signal Characteristics Configuration"
  • Additional parameters for the test mode in the following commands:
    –FETCh:​BLUetooth:​SIGN<i>:​CONNection:​STATe:​ALL?
    –FETCh:​BLUetooth:​SIGN<i>:​CONNection:​STATe?
    –CALL:​BLUetooth:​SIGN<i>:​CONNection:​ACTion
  • Trigger signal for the parallel signaling and measurement, see "Trigger Signals"
  • Dirty transmitter, see "Dirty Transmitter Configuration"
  • RX quality measurement, see "RX Quality Measurement Configuration"
  • Legacy power control, see "Power Up / Power Down / Max Power (hotkey)" and "Power Control, Power State"
  • Better synchronization between the R&S CMW and EUT due to collecting clock information
