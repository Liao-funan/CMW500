CONFigure:BLUetooth:SIGN<i>:CONNection:PHY:LENergy <PHY>

Selects the physical layer used for LE connections.

Parameters:
<PHY>
LE1M | LE2M | LELR

LE1M: LE 1 Msymbol/s PHY

LE2M: LE 2 Msymbol/s PHY

LELR: Long range (LE coded PHY)

*RST:LE1M

See "Direct test mode"
