Trigger Signals

The "Bluetooth Signaling" application provides trigger signals that can be used by can be used by other R&S CMW applications to synchronize to the generated Bluetooth downlink signal.

To address the trigger signals in remote commands, use the following strings, with <I> replaced by the instance number of the signaling application:
  • "Bluetooth Sig<i>: ACPTrigger"
  • "Bluetooth Sig<i>: SignallingTrigger"
ACP Trigger

The ACP trigger event indicates the expected start of the first symbol of the Bluetooth burst at the EUT receiver. Between two successive ACP trigger events, the R&S CMW waits from 100 s to 125 s before the next ACP trigger is generated.

This trigger is suitable for the following measurements within Bluetooth multi-evaluation measurements:
  • 79 channels ACP BR/EDR measurements (option R&S CMW-KM610)
  • All channels ACP LE measurements (option R&S CMW-KM611)
Signaling Trigger

Trigger event indicating the expected start of the first symbol at the beginning of each Bluetooth burst received by the EUT.

This trigger is suitable for all Bluetooth multi-evaluation measurements in combined signal path except 79 channels ACP BR/EDR measurements and all channels ACP LE measurements.
