CONFigure:BLUetooth:SIGN<i>:RXQuality:PACKets:LENergy:LRANge <NumberPackets>
CONFigure:BLUetooth:SIGN<i>:RXQuality:PACKets:LENergy:LE2M <NumberPackets>
CONFigure:BLUetooth:SIGN<i>:RXQuality:PACKets:LENergy[:LE1M] <NumberPackets>

Defines the number of data packets to be measured per measurement cycle (statistics cycle).

Commands for LE 1M PHY (...:LE1M...), LE 2M PHY (...:LE2M...), and LE coded PHY (...:LRANge...) are available.

Parameters:
<NumberPackets>
Range: 1  to  30E+3
*RST:1500
