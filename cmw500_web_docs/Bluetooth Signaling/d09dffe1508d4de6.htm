V3.5.30 (Compared to V3.5.20)

New features:

  • USB interface supported also for BR and EDR, see "EUT Control"
  • Direct USB interface supported (without USB to RS232 adapter), see "USB"
  • Basic device information of the active USB device, see "USB Info"
  • Alternating pattern added, see "Packet Type (BR, EDR)"
  • Clear event log button, see "Event Log"
