CONFigure:BLUetooth:SIGN<i>:CONNection:INQuiry:NOResponses <NumberResponses>

Sets/gets the maximum number of responses recorded during an inquiry.

Parameters:
<NumberResponses>

The maximum number of responses, where 0 means "unlimited".

Range: 0  to  12
*RST:12
Example: 

See "Inquire or Manually Specify EUT"

Firmware/Software: 

V3.0.12
