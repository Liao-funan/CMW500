V3.5.70 (Compared to V3.5.60)

New features:

  • Signaling option R&S CMW-KS721 for LE 2 Msymbol/s (LE 2M PHY) and LE long range (LE coded PHY). This option is an extension of R&S CMW-KS611 used for LE 1 Msymbol/s physical layer (LE 1M PHY).
  • Option R&S CMW-KS603 for A2DP, see "Audio Link Setup"
  • Physical layer for LE 2 Msymbol/s (LE 2M PHY) and LE coded PHY, see "PHY (LE)":
    –LE2M PHY: commands ...:LE2M
    –LE coded PHY: commands ...:LELR for LE long range
    –Rx measurements with LE 2M PHY and LE coded PHY connections, see "RX Quality Tabs"
  • Token LE1M added to the commands for LE 1M PHY (...:LENergy[:LE1M]...)
