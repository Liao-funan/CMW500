Test Setup

For the standalone scenario, connect the external RF signal source (base station, signal generator etc.) to one of the bidirectional RF connectors on the front panel of the R&S CMW.

For the "Two RF In" scenario, use two bidirectional RF connectors on the same basic frontend (scenario not supported by advanced frontend and not supported by R&S CMW100). For correct time alignment results, the RF cables for the two signals must have the same length.

See also: "RF Connectors"
