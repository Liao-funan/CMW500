LTE eNodeB Measurements

The LTE eNodeB multi-evaluation measurement provides quick and flexible TX tests on LTE downlink signals.

With option R&S CMW-KN500, you can measure FDD signals. With option R&S CMW-KN550, you can measure TDD signals.

The tests cover the following eNodeB transmitter properties:
  • eNodeB output power, output power dynamics (OFDM symbol power)
  • Modulation accuracy for each OFDM symbol (EVM, magnitude error, phase error)
  • I/Q constellation diagram
  • Out-of-band emissions (spectrum emission mask and ACLR)
  • eNodeB power variation across subcarriers (spectrum flatness)
  • Time alignment of two MIMO antenna signals (not supported by R&S CMW100)
  • Transmit OFF power

Many of the tests and conformance requirements are specified in 3GPP TS 36.104 or 3GPP TS 36.141.
