Overview
In the overview, a selection of the following results can be displayed:
  • Error vector magnitude
  • Magnitude error
  • Phase error
  • OFDM symbol power
  • Spectrum flatness
  • Spectrum emission mask
  • Spectrum ACLR
  • I/Q constellation diagram
  • ON/OFF power (TDD only)
  • Most important results of detailed view "TX Measurement"

See also: "TX Measurements"

Overview

The results to be measured and displayed in the overview can be limited using the hotkey "Assign Views", see "Additional Softkeys and Hotkeys".

You can enlarge one of the diagrams in the overview and show a detailed view with additional measurement results, see "Selecting and Modifying Views". The traces and bar graphs are described in the following sections.
