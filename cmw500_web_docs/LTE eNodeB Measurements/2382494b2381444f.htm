Power Settings

The following parameters configure the power measurement settings. They are contained in section "Measurement Control".

Power settings
Statistic Count

Defines the number of measurement intervals per measurement cycle (statistics cycle, single-shot measurement). This value is also relevant for continuous measurements, because the averaging procedures depend on the statistic count.

For power results, the measurement interval is completed when the R&S CMW has measured a radio frame.

Remote command: 

CONFigure:​LTE:​MEAS<i>:​ENB:​MEValuation:​SCOunt:​POWer

 
Noise Correction

Enables or disables the compensation of the noise floor of the instrument.

If this setting is enabled, the noise floor of the instrument is measured and subtracted from power measurement results. This compensation improves the accuracy of the measurement of low powers, for example of the OFF power (ON/OFF power measurement).

Remote command: 

CONFigure:​LTE:​MEAS<i>:​ENB:​MEValuation:​POWer:​NCORrection
