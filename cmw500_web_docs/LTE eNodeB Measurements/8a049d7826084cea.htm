Parameters and Settings

The most important settings of the LTE eNodeB multi-evaluation measurement are displayed in the measurement dialog.

All settings are defined via softkeys and hotkeys or using the LTE eNodeB multi-evaluation configuration dialog. The configuration dialog is described in the following sections. To open the dialog, press the "Config" hotkey.
