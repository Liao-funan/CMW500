CONFigure:LTE:MEAS<i>:ENB:RFSettings:FREQuency <AnalyzerFreq>

Selects the center frequency of the RF analyzer.

Using the unit CH the frequency can be set via the channel number. The allowed channel number range depends on the operating band, see "Operating Bands".

The supported frequency range depends on the instrument model and the available options. The supported range can be smaller than stated here. Refer to the preface of your model-specific base unit manual.

Parameters:
<AnalyzerFreq>
Range: 70E+6 Hz  to  6E+9 Hz
*RST:2.14E+9 Hz
Default unit: Hz
