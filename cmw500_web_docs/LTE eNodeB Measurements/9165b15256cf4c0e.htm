ROUTe:LTE:MEAS<i>:ENB:SCENario:SALone <RXConnector>, <RFConverter>

Activates the standalone scenario and selects the RF input path for the measured RF signal.

For possible connector and converter values, see "Values for RF Path Selection".

Parameters:
<RXConnector>

RF connector for the input path

<RFConverter>

RX module for the input path

Firmware/Software: 

V3.0.20
