CONFigure:LTE:MEAS<i>:ENB:MEValuation:MIMO <MIMOconfig>

Specifies the number of used TX antennas.

Parameters:
<MIMOconfig>
TA1 | TA2

TA1: One antenna, SISO

TA2: Two antennas, MIMO 2x2

*RST:TA1
