CONFigure:LTE:MEAS<i>:ENB:MEValuation:LIMit:QAM<ModOrder>:TALignment <TimingAlignment>

Defines an upper limit for the time alignment error (16-QAM or 64-QAM modulation).

Suffix: 
<ModOrder>
16, 64

16-QAM or 64-QAM

Parameters:
<TimingAlignment>
Range: 0 ns  to  1000 ns
*RST:90 ns, ON
Default unit: ns

Additional parameters: OFF | ON (disables | enables the limit check)

See "Specifying Limits"
