Occupied Bandwidth Limits

The occupied bandwidth is the width of a symmetric frequency interval around the nominal RF carrier frequency that contains 99 % of the total integrated power of the transmitted spectrum.

According to 3GPP, the occupied bandwidth must be less than the (theoretical) channel bandwidth. This requirement must be verified with the test model E-TM1.1.

In the configuration dialog, you can set a limit for the occupied bandwidth, depending on the channel bandwidth.
