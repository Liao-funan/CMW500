What's New in This Version

This documentation describes version 3.7.20 and later of the LTE eNodeB multi-evaluation measurement. Compared to version 3.5.30, it provides the following new features:

  • Frame trigger signal provided by the eNodeB measurement, see "Trigger signals provided by the LTE eNodeB measurement"
  • Support of R&S CMW100
