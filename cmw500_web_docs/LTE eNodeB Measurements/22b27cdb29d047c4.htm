CONFigure:LTE:MEAS<i>:ENB:MEValuation:ETEStmodel <EUTRAtestmodel>

Selects the E-UTRA test model, as defined in 3GPP TS 36.141, section 6.1.1 "E-UTRA Test Models".

Parameters:
<EUTRAtestmodel>
ETM11 | ETM12 | ETM20 | ETM31 | ETM32 | ETM33

E-TM 1.1 to E-TM 3.3

*RST:ETM11
