CONFigure:LTE:MEAS<i>:ENB:MEValuation:LIMit:ACLR:UTRA:CBANdwidth<Band> <RelativeLevel>, <AbsoluteLevel>

Defines relative and absolute limits for the ACLR measured in adjacent UTRA channels. The settings are defined separately for each channel bandwidth.

Suffix: 
<Band>
14, 30, 50, 100, 150, 200

Channel bandwidth in 0.1 MHz

Parameters:
<RelativeLevel>
Range: -256 dB  to  256 dB
*RST:44.2 dB, ON
Default unit: dB

Additional parameters: OFF | ON (disables | enables the limit check)

<AbsoluteLevel>
Range: -256 dBm/MHz  to  256 dBm/MHz
*RST:-50 dBm/MHz, ON
Default unit: dBm/MHz

Additional parameters: OFF | ON (disables | enables the limit check)
