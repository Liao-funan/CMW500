Trigger Modes
Trigger modes for LTE eNodeB measurements
The LTE eNodeB multi-evaluation measurement can be performed in the following trigger modes:
  • "Free Run (Fast Sync)": The measurement starts immediately after it is initiated. The R&S CMW decodes the signal to derive its slot, subframe and frame timing so that the measurement can start at a radio frame boundary.
  • "Free Run (No Sync)": The measurement starts immediately after it is initiated, without any synchronization.
    This trigger mode is faster than the "Free Run (Fast Sync)" mode. It can be used for ACLR and emission mask measurements. All other results must be ignored (e.g. modulation results).
  • "IF Power": With an internal IF power trigger, the measurement is triggered by the power ramp of the received bursts. This mode can be used for TDD downlink signals, which always contain bursts because of the uplink subframes.
  • "External Trigger": External trigger signal fed in via the rear panel of the instrument. The trigger signal must be aligned to the radio frame boundary. The availability of a trigger input connector depends on the instrument model.
  • Additional trigger modes: Other firmware applications, e.g. the GPRF generator, provide additional trigger modes. Refer to the documentation of the corresponding firmware application for a description of these trigger modes. The trigger signal/marker must be aligned to the radio frame boundary.

For configuration, see "Trigger Settings".

Trigger signals provided by the LTE eNodeB measurement

The eNodeB measurement provides a frame trigger signal that can be used by other R&S CMW applications for synchronization. The frame trigger signal is only supported by R&S CMW100, not by R&S CMW500/2xx.

To address the trigger signal in remote commands, use the following string, with <i> replaced by the instance number of the eNodeB measurement:
  • "LTE eNodeB Meas<i>: FrameTrigger"

The frame trigger provides a trigger event at the beginning of each uplink radio frame.

A typical use case is to synchronize a generated UL signal to the measured DL signal. You can generate an UL signal with the GPRF generator and a suitable ARB file and select the frame trigger signal in the GPRF generator as trigger source.
