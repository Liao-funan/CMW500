Views EVM, Magnitude Error, Phase Error
This section applies to the following detailed views:
  • Error vector magnitude
  • Magnitude error
  • Phase error

Each of the detailed views shows a diagram and a statistical overview of results.

Error vector magnitude view

The diagrams (bar graphs) show the average EVM, magnitude error, and phase error for each OFDM symbol in the measured subframe. The 14 symbols in the subframe are labeled 0 to 13. Only OFDM symbols carrying PDSCH are evaluated. For PDCCH OFDM symbols, no bars are displayed (symbol 0 in the figure above).

The bar graphs show RMS-averaged and therefore positive values. The average runs over all modulation symbols in the OFDM symbol. The R&S CMW calculates two values (e.g. EVMl and EVMh) for each OFDM symbol and displays both values; see "Calculation of Modulation Results".

For the results in the table, see "View TX Measurement".

For other screen elements, refer to "Common View Elements".
