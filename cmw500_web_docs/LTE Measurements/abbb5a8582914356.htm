V3.0.10 (Compared to V2.1.30)
New features:
  • The BLER measurement has been enhanced, see "RX measurement" and "BLER > Scheduled Subfr./Frame":
    –Missing answers (no ACK/NACK) are counted as DTX
    –PUSCH is counted as NACK
    –BLER result is calculated from ACK, NACK and DTX
    –The number of scheduled subframes per radio frame must be specified. The number of already processed scheduled subframes is indicated as result.
  • Signals containing SRS symbols can now also be measured, see "Sounding RS (SRS)"
  • Support of FDD operating bands 23 and 26, see "Frequency Bands"
  • List mode enhancements:
    –Retrieval of segment reliability: FETCh:​LTE:​MEAS<i>:​MEValuation:​LIST:​SRELiability?
    –Definition of RB allocation per segment: CONFigure:​LTE:​MEAS<i>:​MEValuation:​LIST:​SEGMent<no>:​RBALlocation
  • The LTE multi-evaluation measurement, the LTE PRACH measurement and the LTE SRS measurement have been grouped in the GUI. The "TX Measurement" entry in the "Measurement Controller" dialog refers to all three measurements. The TX measurement view contains all measurements on separate tabs.
  • When the combined signal path scenario is active, the settings of the signaling application can be accessed from the measurement. Even the main configuration dialog of the signaling application can be accessed and the downlink signal can be switched on/off. The connection states of the signaling application are displayed.
  • Maximum configurable value for user margin and expected nominal power increased
