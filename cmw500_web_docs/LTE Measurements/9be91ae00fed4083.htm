What's New in This Version

This documentation describes version 3.7.30 and later of the LTE SRS measurement application. Compared to version 3.5.40, it provides the following new features:

  • Redesign of GUI and commands concerning carrier selection. The terms PCC and SCC1 are replaced by CC<n>. Old commands are still supported but no longer documented.
