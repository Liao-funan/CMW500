CONFigure:LTE:MEAS<i>:MEValuation:SRS:ENABle <Enable>

Specifies whether a sounding reference signal is allowed (ON) or not (OFF).

For the combined signal path scenario, use CONFigure:​LTE:​SIGN<i>:​CELL[:​PCC]:​SRS:​ENABle.

Parameters:
<Enable>
OFF | ON

OFF: no SRS signal

ON: SRS signal allowed in the last SC-FDMA symbol of each subframe

*RST:OFF
