CONFigure:LTE:MEAS<i>:RFSettings:FOFFset <Offset>

Specifies a positive or negative frequency offset to be added to the carrier center frequency (CONFigure:​LTE:​MEAS<i>:​RFSettings:​CC<no>:​FREQuency).

For the combined signal path scenario, use:
  • CONFigure:​LTE:​SIGN<i>:​RFSettings[:​PCC]:​FOFFset:​UL
  • CONFigure:​LTE:​SIGN<i>:​RFSettings:​SCC<c>:​FOFFset:​UL
  • CONFigure:​LTE:​SIGN<i>:​RFSettings[:​PCC]:​FOFFset:​UL:​UCSPecific
Parameters:
<Offset>
Range: -100E+3 Hz  to  100E+3 Hz
*RST:0 Hz
Default unit: Hz
