CONFigure:LTE:MEAS<i>:RFSettings:CC<no>:FREQuency <AnalyzerFreq>

Selects the center frequency of component carrier CC<no>. Without carrier aggregation, you can omit <no>.

Using the unit CH, the frequency can be set via the channel number. The allowed channel number range depends on the operating band, see "Frequency Bands".

For the combined signal path scenario, use:
  • CONFigure:​LTE:​SIGN<i>:​RFSettings[:​PCC]:​CHANnel:​UL
  • CONFigure:​LTE:​SIGN<i>:​RFSettings:​SCC<c>:​CHANnel:​UL

The supported frequency range depends on the instrument model and the available options. The supported range can be smaller than stated here. Refer to the preface of your model-specific base unit manual.
