CONFigure:LTE:MEAS<i>:PRACh:PFOFfset <PRACHfreqOffset>

Specifies the PRACH frequency offset. This setting is only relevant if automatic detection is disabled, see CONFigure:​LTE:​MEAS<i>:​PRACh:​PFOFfset:​AUTO.

For the combined signal path scenario, use CONFigure:​LTE:​SIGN<i>:​CELL:​PRACh:​PFOFfset.

Parameters:
<PRACHfreqOffset>
Range: 0 to <Total RB - 6> depending on channel bandwidth, see table below
*RST:0
