CONFigure:LTE:MEAS<i>:MEValuation:RBALlocation:MCLuster <Enable>

Specifies whether the UL signal uses multi-cluster allocation or not.

For the combined signal path scenario, use:
  • CONFigure:​LTE:​SIGN<i>:​CONNection[:​PCC]:​MCLuster:​UL
  • CONFigure:​LTE:​SIGN<i>:​CONNection:​SCC<c>:​MCLuster:​UL
Parameters:
<Enable>
OFF | ON

OFF: contiguous allocation, resource allocation type 0

ON: multi-cluster allocation, resource allocation type 1

*RST:OFF
