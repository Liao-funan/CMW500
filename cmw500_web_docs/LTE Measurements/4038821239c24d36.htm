Key Features
The LTE SRS measurement is programmed as follows:
  • The measurement is controlled by SCPI commands with the following syntax: ...LTE:MEAS:SRS...
  • Use general commands of the type ...:LTE:MEAS... (no :SRS mnemonic) to define the signal routing and perform RF and analyzer settings.
  • After a *RST, the measurement is switched off. Use READ:LTE:MEAS:SRS...? to initiate a single-shot measurement and retrieve the results. You can also start the measurement using INIT:LTE:MEAS:SRS and retrieve the results using FETCh:LTE:MEAS:SRS...?.
