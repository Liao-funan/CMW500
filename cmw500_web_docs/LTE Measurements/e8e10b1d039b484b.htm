CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:ASEMission:CAGGregation <Value>

Selects a value signaled to the UE as additional ACLR and spectrum emission requirement for the SCC<c>.

The setting is only relevant if the SCC uplink is enabled.
