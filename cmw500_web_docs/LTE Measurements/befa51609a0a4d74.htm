CONFigure:LTE:MEAS<i>:MEValuation:CTVFilter <ChannelType>

Specifies, enables or disables the channel type view filter. If the filter is active, only slots with detected channel type PUSCH or PUCCH are measured.

Parameters:
<ChannelType>
PUSCh | PUCCh | ON | OFF

PUSCh: measure only physical uplink shared channel

PUCCh: measure only physical uplink control channel

ON: enable the filter

OFF: disable the filter

*RST:OFF (PUSC)
