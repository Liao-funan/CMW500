FETCh:LTE:MEAS<i>:MEValuation:TRACe:IQ:LOW?
FETCh:LTE:MEAS<i>:MEValuation:TRACe:IQ:HIGH?

Returns the results in the I/Q constellation diagram for low and high EVM window position.

See also "View I/Q Constellation"

Return values: 
<Reliability>

"Reliability Indicator"

<I_Phase_1> <Q_Phase_1> ... <I_Phase_n> <Q_Phase_n>

Comma-separated list of normalized I and Q amplitudes, one value per modulation symbol

Range: -2  to  2

See "Performing Single-Shot Measurements"

Usage: Query only
