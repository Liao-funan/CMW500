Parallel Signaling and Measurement

You can use the multi-evaluation measurement in parallel to the LTE signaling application (option R&S CMW-KS500/-KS550). Set up a connection to the UE with the signaling application. Then measure the resulting uplink signal with the multi-evaluation measurement.

To use both applications in parallel, the combined signal path scenario must be activated (see "Scenario = Combined Signal Path"). Most signal routing and analyzer settings and some measurement control settings are then configured by the signaling application. The multi-evaluation measurement displays the corresponding signaling settings instead of its own settings. These signaling settings can be configured both in the measurement GUI and in the GUI of the signaling application.

To configure these settings via remote commands, use the commands of the signaling application. For a command mapping table, see "Combined Signal Path Commands".

The most important signaling parameters not relevant for standalone measurements can nevertheless be configured both in the measurement GUI and in the GUI of the signaling application. In the measurement GUI, they can be accessed via hotkeys.

Whenever the combined signal path scenario is activated or the controlling application is changed, the frame trigger signal provided by the controlling signaling application is selected automatically as trigger source.

Carrier names

In a standalone measurement, the measurement does not know which carrier it measures - whether it is a PCC or a certain SCC. You can measure any uplink carrier.

Even with contiguous uplink carrier aggregation, the measurement does not care which carriers you aggregate. The carriers are numbered in the GUI as CC1, CC2, and so on.

In a combined signal path measurement, the signaling application informs the measurement about the carrier configuration. The measurement displays the mapping between CC<n> and PCC/SCC<m>.

Measurement instances in multi-CMW setups

Each measurement instance is running on a specific measurement board and thus in a specific CMW. The measurement instance can only measure carriers that are available in the same CMW.

In standalone measurements, you can only select RF input connectors that are compatible to the measurement instance.

But in combined signal path measurements, you can select carriers that use RF input connectors that are incompatible to the measurement instance. In that case, the measurement fails, showing the reliability indicator value 104 ("not functional").

To identify the measurement instance compatible to a certain carrier, you can proceed as follows.

  1. In the standalone scenario, check for each measurement instance which RF connectors are available in the GUI.

    In each measurement instance, you see the connectors of one CMW. Write a mapping list between measurement instances and CMW numbers.

    The mapping remains valid as long as you do not change your multi-CMW configuration (that means the cabling between CMWs and R&S CMWC and the hardware equipped in each CMW).

  2. Check which RF input connector the relevant carrier uses and thus in which CMW the carrier is available.

    You can check it in the signaling application. Or you can check it in the measurement, in the combined signal path scenario, after selecting the carrier via the setting "Controlled by".
