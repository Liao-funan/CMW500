FETCh:LTE:MEAS<i>:PRACh:TRACe:EVPReamble?
READ:LTE:MEAS<i>:PRACh:TRACe:EVPReamble?

Return the values of the EVM vs. preamble traces.

See also "Views EVM vs Preamble, Power vs Preamble".

Return values: 
<Reliability>

"Reliability Indicator"

<Results>

32 EVM values, for preamble 1 to 32 (NCAP for not measured preambles)

Range: 0 %  to  100 %
Default unit: %
Example: 

See "Performing Single-Shot Measurements"

Usage: Query only
Firmware/Software: 

V2.1.20, V3.5.20 increased number of results

For additional information concerning syntax elements and returned values, refer to "Conventions and General Information".
