V3.0.10 (Compared to V2.1.25)
New features:
  • The LTE multi-evaluation measurement, the LTE PRACH measurement and the LTE SRS measurement have been grouped in the GUI. The "TX Measurement" entry in the "Measurement Controller" dialog refers to all three measurements. The TX measurement view contains all measurements on separate tabs.
  • When the combined signal path scenario is active, the settings of the signaling application can be accessed from the measurement. Even the main configuration dialog of the signaling application can be accessed and the downlink signal can be switched on/off. The connection states of the signaling application are displayed.
