V3.7.10 (Compared to V3.5.50)
New features:
  • Enhanced machine type communication, see "eMTC"
  • Support of high dynamic mode by combined signal path scenario, see "High Dynamic Mode"
  • Added operating bands 48, 68, 70, 250 and removed band 46, see "Frequency Bands"
  • Network signaled value NS_25 to NS_32, see "Network Signaled Value"
  • Additional spectrum emission limits for NS_27 (set of limits number four, including new resolution bandwidths), see "Spectrum Emission Mask"
