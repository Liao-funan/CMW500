CONFigure:LTE:MEAS<i>:MEValuation:LIST:OSINdex <OfflineSegIndex>

Selects the number of the segment to be displayed in offline mode. The index refers to the range of measured segments, see CONFigure:​LTE:​MEAS<i>:​MEValuation:​LIST:​LRANge.

Setting a value also enables the offline mode.

Parameters:
<OfflineSegIndex>
Range: 1  to  <number of measured segments>
*RST:OFF

Additional parameters: OFF (disables the offline mode)

Example: 

See "Performing Single-Shot Measurements"

Firmware/Software: 

V2.0.10

Options: R&S CMW-KM012
Manual operation: See "List Mode > Offline Segment No."
