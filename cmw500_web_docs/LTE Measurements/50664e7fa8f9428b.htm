CONFigure:LTE:SIGN<i>:CONNection[:PCC]:MCLuster:UL <Multicluster>
CONFigure:LTE:SIGN<i>:CONNection:SCC<c>:MCLuster:UL <Multicluster>

Enables/disables multi-cluster allocation for the UL.

Suffix: 
<c>
1..4
Parameters:
<Multicluster>
OFF | ON

OFF: contiguous allocation, resource allocation type 0

ON: multi-cluster allocation, resource allocation type 1

Firmware/Software: 

V3.5.20

Options: R&S CMW-KS510/-KS512 (without CA/with CA)
Manual operation: See "Multicluster"
