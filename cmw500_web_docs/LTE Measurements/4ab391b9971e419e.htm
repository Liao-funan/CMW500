List Mode Results (All Segments, One Result)

Each of the following commands returns a selected list mode result for all measured segments. The number of returned results depends on the number of measured segments, see CONFigure:​LTE:​MEAS<i>:​MEValuation:​LIST:​LRANge.

To configure the list mode, use the commands described in "List Mode Settings".

For a description of the list mode, see "List Mode".

The indicated ranges apply to all statistical results except standard deviation results. The minimum for standard deviation results equals 0. The maximum equals the width of the indicated range divided by two. Exceptions are explicitly stated.
