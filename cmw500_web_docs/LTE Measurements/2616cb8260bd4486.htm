CONFigure:LTE:MEAS<i>:MEValuation:TMODe:SCOunt <SubframeCount>...

Defines the subframe counts for all entries of the "TPC Mode" list.

For definition of the corresponding expected nominal power values, see CONFigure:​LTE:​MEAS<i>:​MEValuation:​TMODe:​ENPower.

Parameters:
<SubframeCount>

Comma-separated list of 16 values, for list entry number 0 to 15

Range: 1  to  320
*RST:320
