CONFigure:LTE:MEAS<i>:PRACh:MODulation:LRSindex <LogRootSeqIndex>

Specifies the logical root sequence index to be used for generation of the preamble sequence.

For the combined signal path scenario, use CONFigure:​LTE:​SIGN<i>:​CELL:​PRACh:​LRSindex.

Parameters:
<LogRootSeqIndex>
Range: 0 to 837 (for preamble format 4: 0 to 137)
*RST:0

See "Specifying Required PRACH Settings"

V2.0.10

Manual operation: See "Logical Root Sequence Index"
