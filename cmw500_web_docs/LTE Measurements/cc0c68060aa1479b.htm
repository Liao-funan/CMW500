TRIGger:LTE:MEAS<i>:MEValuation:AMODe <AcquisitionMode>

Selects whether the R&S CMW synchronizes to a slot boundary or to a subframe boundary. The parameter is relevant for "Free Run (Fast Sync)" and for list mode measurements with "Synchronization Mode" = "Enhanced".

Parameters:
<AcquisitionMode>
SLOT | SUBFrame
*RST:SLOT
