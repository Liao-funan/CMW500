CONFigure:LTE:MEAS<i>:PRACh:PFOFfset:AUTO <PRACHfreqAuto>

Enables or disables automatic detection of the PRACH frequency offset. To configure the offset manually for disabled automatic detection, see CONFigure:​LTE:​MEAS<i>:​PRACh:​PFOFfset.

Parameters:
<PRACHfreqAuto>
OFF | ON
*RST:ON
