Return equalizer spectrum flatness single value results (maximum within a range) for all measured list mode segments.

The values described below are returned by FETCh commands. CALCulate commands return limit check results instead, one value for each result listed below.

Suffix: 
<no>
1..2

Selects the range for which the maximum is returned

Return values: 
<Reliability>

"Reliability Indicator"

<MaxR>

Comma-separated list of values, one per measured segment

Range: -20 dB  to  20 dB
Default unit: dB
Example: 

See "Retrieving Single Results for All Segments"

Usage: Query only
Firmware/Software: 

V2.1.30

Options: R&S CMW-KM012
