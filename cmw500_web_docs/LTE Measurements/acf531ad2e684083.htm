V3.5.40 (Compared to V3.5.30)
New features:
  • The evaluation of the measured subframe can be restricted to the first or second slot, see "Measurement Subframe"
  • Additional EVM trace results, see "View Error Vector Magnitude"
    –EVM for all modulation symbols in an SC-FDMA symbol
    –Peak value over all modulation symbols in an SC-FDMA symbol
  • EVM result for SRS signals, see "View TX Measurement and BLER"
  • Total TX power result in the power monitor view, see "View Power Monitor"
  • Operating bands 45, 46, 65 and 66, see "Frequency Bands"
  • PUCCH format 3, see "PUCCH Format"
