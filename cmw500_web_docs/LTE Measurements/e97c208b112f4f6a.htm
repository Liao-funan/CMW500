LTE RX Tests

You can perform RX tests in parallel to the TX tests. The following sections describe how to perform LTE BLER tests in non-signaling mode. In signaling mode (combined signal path), use the BLER measurement provided by the LTE signaling application.

For RX tests in non-signaling mode, you need the GPRF generator and an LTE waveform file. Option R&S CMW-KW500 is required to process LTE waveform files.
