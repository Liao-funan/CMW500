CONFigure:LTE:MEAS<i>:CAGGregation:MODE:CSPath?

Queries the carrier aggregation mode in the CSP scenario. The mode is configured indirectly via ROUTe:​LTE:​MEAS<i>:​SCENario:​CSPath.

Return values: 
<CAmode>
OFF | INTRaband

OFF: no carrier aggregation

INTRaband: intra-band contiguous CA (BW class B & C)

Usage: Query only
Firmware/Software: 

V3.7.30

Manual operation: See "Carrier Aggregation Mode"
