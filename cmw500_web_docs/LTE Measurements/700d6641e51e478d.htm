CONFigure:LTE:MEAS<i>:MEValuation:LIST:CMWS:CMODe <ConnectorMode>

Specifies how the input connector is selected for LTE list mode measurements with the R&S CMWS.

Parameters:
<ConnectorMode>
GLOBal | LIST

GLOBal: The same input connector is used for all segments. It is selected in the same way as without list mode, for example via ROUTe:LTE:MEAS<i>:SCENario:SALone.

LIST: The input connector is configured individually for each segment. See CONFigure:​LTE:​MEAS<i>:​MEValuation:​LIST:​SEGMent<no>:​CMWS:​CONNector.

*RST:GLOB
