CONFigure:LTE:MEAS<i>:MEValuation:LIST:SEGMent<no>:RBALlocation <Auto>, <NoRB>, <Offset>

Allows you to define the resource block allocation manually for segment <no>. By default, the RB allocation is detected automatically.

Suffix: 
<no>
1..2000

Segment number

Parameters:
<Auto>
OFF | ON

OFF: manual definition via <NoRB> and <Offset>

ON: automatic detection of RB allocation

*RST:ON
<NoRB>

Number of allocated resource blocks in each measured slot

Range: see table below
*RST:100
<Offset>

Offset of first allocated resource block from edge of allocated UL transmission bandwidth

Range: see table below
*RST:0
Example: 

See "Specifying List Mode Settings"

V3.0.10
