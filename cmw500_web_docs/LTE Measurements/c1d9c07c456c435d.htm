V3.5.20 (Compared to V3.5.10)
New features:
  • Contiguous UL CA measurement with combined signal path scenario, see "Carrier Aggregation"
  • The physical cell ID of the measured SCC is configurable, see "Carrier Aggregation Settings"
  • The minimum segment length for spectrum list mode measurements with channel bandwidths > 10 MHz has been reduced to nine subframes, see "Spectrum measurements"
