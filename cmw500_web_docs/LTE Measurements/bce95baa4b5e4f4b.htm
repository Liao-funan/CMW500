General Description

The LTE SRS measurement captures an uplink LTE sounding reference signal (SRS) and provides power dynamics measurement results. The signal to be measured must not contain any additional components, e.g. a PUSCH or PUCCH.

Both FDD signals (option R&S CMW-KM500) and TDD signals (option R&S CMW-KM550) can be measured.
