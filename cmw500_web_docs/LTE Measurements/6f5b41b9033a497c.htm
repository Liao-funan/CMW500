LTE PRACH Measurement
The LTE PRACH measurement provides quick and flexible tests on LTE FDD and TDD random access preambles. The tests cover the following UE transmitter properties:
  • Modulation accuracy for each PRACH subcarrier (EVM, magnitude error, phase error)
  • Transmit OFF power, transmit ON power and power ramping between them (power dynamics)
  • I/Q constellation diagram

The PRACH measurement requires option R&S CMW-KM500 for FDD signals and R&S CMW-KM550 for TDD signals.
