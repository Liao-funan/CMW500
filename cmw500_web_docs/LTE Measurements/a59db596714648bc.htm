What's New in This Version

This documentation describes version 3.7.30 and later of the LTE multi-evaluation measurement application. Compared to version 3.7.20, it provides the following new features:

  • Redesign of GUI and commands concerning carrier selection. The terms PCC and SCC1 are replaced by CC<n>. The old commands are still supported but no longer documented.
    Two measured carriers with intra-band contiguous aggregation can be any carriers. Examples: PCC+SCC1, PCC+SCC3, SCC1+SCC3.
  • Power monitor: table of statistical results enhanced with results per component carrier, see "View Power Monitor"
