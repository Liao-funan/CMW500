SENSe:GSM:SIGN<i>:RREPort:SVARiance:RANGe?

Returns the signal variance range, corresponding to the "Signal Variance" index reported by the MS.

Return values: 
<Lower>
Range: 0 dB²  to  15.75 dB²
Default unit: dB²
<Upper>
Range: 0.25 dB²  to  15.75 dB²
Default unit: dB²
Example: 

See "Retrieving PS Receiver Reports"

Usage: Query only
Firmware/Software: 

V2.0.20

Manual operation: See "Sign. Var. (PS, TBF level = GPRS)"
