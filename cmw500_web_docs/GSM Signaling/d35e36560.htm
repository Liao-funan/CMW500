SENSe:GSM:SIGN<i>:SMS:INComing:INFO:MTEXt?

Returns the text of the last SMS message received from the MS. Only 7-bit ASCII text is supported.

Return values: 
<MessageText>

Message text as string

Example: 

See "Sending / Receiving an SMS"

Usage: Query only
Firmware/Software: 

V2.0.10

Manual operation: See "Message Text / Message Length"
