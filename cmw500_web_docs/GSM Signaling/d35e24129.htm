PREPare:GSM:SIGN<i>:HANDover:CHANnel:TCH <Channel>

Selects the TCH/PDCH channel in the destination GSM band. The range of values depends on the selected band (PREPare:​GSM:​SIGN<i>:​HANDover:​TARGet); for an overview see "GSM Bands and Channels". The values below are for GSM 900.

Parameters:
<Channel>
Range: 512 to 885
*RST:711
