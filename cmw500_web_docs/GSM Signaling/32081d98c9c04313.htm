CONFigure:GSM:SIGN<i>:CELL:ATIMeout:MOC <Time>

Defines the time period of R&S CMW alerting state.

Parameters:
<Time>

0: the alerting state is skipped

1 to 255: time period the R&S CMW waits before changes to "Call Established" state

Range: 0  to  255
*RST:0
Default unit: s
Example: 

See "Setting Timers and Constants"

V3.5.30
