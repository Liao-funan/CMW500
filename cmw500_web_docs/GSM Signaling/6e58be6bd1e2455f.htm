BER PS Measurement

The bit error rate (BER) circuit switched (PS) measurement is included in the "GSM Signaling" application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement ...". The measurement provides an own tab and configuration dialog described in this section.

For background information, see "BER PS Measurement".
