SENSe:GSM:SIGN<i>:RREPort:RXLevel:RANGe?

Returns the power level range, corresponding to the "RX Level Full" index reported by the MS.

Return values: 
<Lower>
Range: -110 dBm  to  -48 dBm
Default unit: dBm
<Upper>
Range: -110 dBm  to  -48 dBm
Default unit: dBm
Example: 

See "Retrieving CS Receiver Reports"

Usage: Query only
Firmware/Software: 

V2.0.10

Manual operation: See "RX Level Full / Sub (CS)"
