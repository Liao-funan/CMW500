CONFigure:GSM:SIGN<i>:CONNection:PSWitched:SERVice <Service>

Selects a service mode for the PS connection.

Parameters:
<Service>
TMA | TMB | BLER | SRB

TMA: test mode A

TMB: test mode B

BLER: BLER mode

SRB: EGPRS switched radio block loopback mode

*RST:BLER
