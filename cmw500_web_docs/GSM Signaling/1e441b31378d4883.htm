RLC Throughput Measurement

The signaling RLC throughput measurement is included in the "GSM Signaling" application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement...". The "RLC Throughput" tab of the RX measurement view and the related configuration dialog is described in this section.
