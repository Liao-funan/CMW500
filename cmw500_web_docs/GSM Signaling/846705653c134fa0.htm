SENSe:GSM:SIGN<i>:MSSinfo:RXPower?

Indicates the quality of the received uplink power.

Return values: 
<Power>
OK | UFL | OFL

OK: in range

UFL: underflow (underdriven)

OFL: overflow (overdriven)

Example: 

See "Querying MS Info"

Usage: Query only
Firmware/Software: 

V3.2.30

Manual operation: See "RX Power"
