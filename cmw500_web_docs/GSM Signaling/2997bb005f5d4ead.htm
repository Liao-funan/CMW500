CONFigure:GSM:SIGN<i>:BER:CSWitched:MMODe <Mode>

Selects the measurement mode of the BER CS measurement. For a detailed description of the modes, see "BER CS Measurement".

Parameters:
<Mode>
BBBurst | BER | RFER | FFACch | FSACch | RUFR | AIFer | MBEP | SQUality | BFI

BBBurst: "Burst by Burst" mode

BER: "BER" mode

RFER: "RBER/FER" mode

FFACch: "FER FACCH" mode

FSACch: "FER SACCH" mode

RUFR: "RBER/UFR" mode

AIFer: "AMR Inband FER" mode

MBEP: "Mean BEP" mode

SQUality: "Signal Quality" mode

BFI: "Bad Frame Indication" mode

*RST:BBB

See "Measuring in Burst by Burst Mode"
