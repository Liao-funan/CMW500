FETCh:GSM:SIGN<i>:BER:PSWitched?
READ:GSM:SIGN<i>:BER:PSWitched?

Returns the results of the BER PS measurement over all carriers.

For the details of the results, see "BER PS Measurement".

Return values: 
<Reliability>

See "Reliability Indicator"

<Frames>

Number of already transmitted blocks

Range: 0  to  500E+3
<BER>

BER

Range: 0 %  to  100 %
Default unit: %
<DBLER>

DBLER

Range: 0 %  to  100 %
Default unit: %
<USF_BLER>

USF BLER

Range: 0 %  to  100 %
Default unit: %
<FalseUSFdetect>

False USF BLER

Range: 0 %  to  100 %
Default unit: %
<CRCerrors>

CRC errors

Range: 0  to  500E+3
<NonAssignedUSF>

Number of USFs in data blocks not assigned to the MS

Range: 0  to  500E+3

See "BER PS Tests"

Usage: Query only
