Bits Per Radio Block / RLC Data Block

The number of bits contained in an RLC data block depends on the (modulation and) coding scheme. Using the following table you can determine the number of bits contained in a radio block or RLC data block.

Please note that a BER PS measurement with test mode B is not supported for the EGPRS2-A modulation and coding schemes DAS-i and UAS-i.
