CONFigure:GSM:SIGN<i>:CELL:TIME:TSOurce <SourceTime>

Selects the date and time source.

The time source DATE is configured via the following commands:
  • CONFigure:​GSM:​SIGN<i>:​CELL:​TIME:​DATE
  • CONFigure:​GSM:​SIGN<i>:​CELL:​TIME:​TIME
  • CONFigure:​GSM:​SIGN<i>:​CELL:​TIME:​DSTime
  • CONFigure:​GSM:​SIGN<i>:​CELL:​TIME:​LTZoffset
Parameters:
<SourceTime>
CMWTime | DATE

CMWTime: Windows date and time

DATE: "Date / Time" specified via remote commands

*RST:CMWT
Example: 

See "Sending Date and Time Information to the MS"
