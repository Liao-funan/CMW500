Programming

The following sections provide programming examples for the GSM signaling application.

The examples contain SCPI commands supported by the R&S CMW and the following symbolic scripting commands:
  • // <comment>:
    A <comment> ignored by the used programming tool.
  • WHILE <query> <> <value>:
    Waits until the <query> returns a certain <value>, e.g. a specific state is reached.
  • WAITKEY <message>:
    Displays a dialog box with a <message> and waits until the box is closed manually.
