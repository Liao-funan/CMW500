CONFigure:GSM:SIGN<i>:CELL:IMSI <MCC>, <MNC>, <MSIN>

Defines the default IMSI which is used to set up the connection if the mobile does not initiate a location update. See also CONFigure:​GSM:​SIGN<i>:​CELL:​LUPDate.

Parameters:
<MCC>
Range: 0  to  999
*RST:001
<MNC>
Range: 01 to 99 (2-digit MNC) or 001 to 999 (3-digit MNC)
*RST:01
<MSIN>
Range: 0 to 9999999999 (2-digit MNC) or 0 to 999999999 (3-digit MNC)
*RST:1000000095
