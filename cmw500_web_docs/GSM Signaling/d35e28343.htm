CONFigure:GSM:SIGN<i>:FADing:AWGN:BWIDth:NOISe?

Queries the noise bandwidth.

Return values: 
<NoiseBandwidth>
Range: 0 Hz  to  80E+6 Hz
Default unit: Hz
Usage: Query only
Firmware/Software: 

V3.0.20

Options: R&S CMW-KS210, R&S CMW-KE100 and R&S CMW-KE200
Manual operation: See "Noise Bandwidth"
