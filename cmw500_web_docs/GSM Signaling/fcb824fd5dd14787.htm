CONFigure:GSM:SIGN<i>:CONNection:CSWitched:AMR:CMODe:NB:FRATe:GMSK:DL <CodecMode>
CONFigure:GSM:SIGN<i>:CONNection:CSWitched:AMR:CMODe:NB:FRATe:GMSK:UL <CodecMode>

Select the codec modes to be used by the R&S CMW (downlink) and the MS (uplink) for the full-rate narrowband AMR codec (GMSK modulation).

Only active codec modes can be selected. For configuration and activation/deactivation of the codec modes, see CONFigure:​GSM:​SIGN<i>:​CONNection:​CSWitched:​AMR:​RSET:​NB:​FRATe:​GMSK.

Parameters:
<CodecMode>
Range: 1  to  4 (if all codec modes are active, otherwise less)
*RST:3

Additional parameters OFF (ON) disables (enables) codec mode.
