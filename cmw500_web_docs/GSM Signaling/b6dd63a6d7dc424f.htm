CMR Performance Measurement

The AMR codec mode request (CMR) performance measurement is included in the GSM signaling application. It must be activated in the "Measurement Controller" dialog via the entry "RX Measurement ...". The measurement provides an own tab and configuration dialog described in this section.

For background information, see "CMR Performance Measurement".

Option R&S CMW-KS210 required.
