CONFigure:GSM:SIGN<i>:RFSettings:FOFFset:UL <Offset>

Specifies a positive or negative frequency offset to be added to the uplink center frequency of the configured channel, see CONFigure:​GSM:​SIGN<i>:​RFSettings:​CHANnel:​TCH[:​CARRier<c>].

Parameters:
<Offset>
Range: -100000 Hz to 100000 Hz
*RST:0 Hz
Default unit: Hz
