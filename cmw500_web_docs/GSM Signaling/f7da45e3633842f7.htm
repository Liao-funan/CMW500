Show Features at Inactive SW Licenses

Some parameters can only be configured if a specific option (software license) is installed. If the option is not installed, the parameter is either grayed out, showing the used fixed value or it is hidden completely. If licenses are missing, several parameters are hidden. You can show those hidden parameters with grayed out values by enabling the following setting at the bottom of the configuration tree.
