CONFigure:GSM:SIGN<i>:CONNection:PSWitched:BPERiod<no> <Value>

Configures the BEP_PERIOD2 defined in 3GPP TS 45.008 that the MS uses for the mean BEP and the CV BEP calculation.

Suffix: 
<no>
2

Fixed suffix

Parameters:
<Value>
Range: 0  to  15
*RST:15

ON (OFF) commands the MS to apply (not apply) the BEP period 2.

Example: 

See "Configuring PS Connection Settings"

Firmware/Software: 

V3.2.30

Manual operation: See "BEP Period 2"
