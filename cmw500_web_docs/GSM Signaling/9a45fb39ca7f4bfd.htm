FETCh:GSM:SIGN<i>:PSWitched:STATe?

Returns the PS connection state. Use CALL:​GSM:​SIGN<i>:​PSWitched:​ACTion to initiate a transition between different connection states.

The PS state changes to ON when the signaling generator is started (see SOURce:​GSM:​SIGN<i>:​CELL:​STATe).

To make sure that a GSM cell signal is available, query the cell state. It must be ON, ADJ (see SOURce:​GSM:​SIGN<i>:​CELL:​STATe:​ALL?).

Return values: 
<PS State>
OFF | ON | ATT | TBF | PDP | AIPR | RAUP | PAIP | CTIP | REL | PDIP | DIPR

For a description of the states, refer to "Connection States".

The values indicate the following states:

ATT = attached

TBF = TBF established

PDP = PDP context activated

AIPR = attaching (attach in progress)

RAUP = routing area update

PAIP = PDP context activation (PDP context activation in progress)

CTIP = connecting (connecting TBF in progress)

REL = releasing

PDIP = PDP context deactivation (PDP context deactivation in progress)

DIPR = detaching (detach in progress)
