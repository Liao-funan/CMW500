CONFigure:GSM:SIGN<i>:BER:CSWitched:LIMit:CIIBits <ClassIIBits>

Specifies upper limits for the BER and RBER class II bit results of the BER CS measurement. A limit for the burst by burst mode can be set separately, see CONFigure:​GSM:​SIGN<i>:​BER:​CSWitched:​LIMit:​BER.

Parameters:
<ClassIIBits>
Range: 0 %  to  100 %
*RST:0.2 %
Default unit: %
Example: 

See "Measuring in BER Mode"

Firmware/Software: 

V2.0.10

Manual operation: See "Limits"
