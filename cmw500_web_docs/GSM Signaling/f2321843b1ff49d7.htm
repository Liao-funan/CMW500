CONFigure:GSM:SIGN<i>:CELL:SECurity:SIMCard <SIMcardType>

Selects the type of the used SIM card.

Parameters:
<SIMcardType>
C3G | C2G

C3G: 3G USIM

C2G: 2G SIM

*RST:C3G

See "Configuring Security Settings"
