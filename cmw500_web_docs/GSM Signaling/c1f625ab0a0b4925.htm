ROUTe:GSM:SIGN<i>:SCENario?

Returns the active scenario.

Return values: 
<Scenario>
SCEL | IORI | BATC | SCF | SCFDiversity

SCEL: "Standard Cell"

IORI: "IQ out - RF in"

BATC: "BCCH and TCH/PDCH"

SCF: "Standard Cell Fading"

SCFDiversity: "Standard Cell Fading with RX Diversity"

<Fader>
EXTernal | INTernal

Only returned for fading scenarios, e.g. SCF

Indicates whether internal or external fading is active.

Usage: Query only
