CONFigure:GSM:SIGN<i>:CONNection:PSWitched:DPControl:PFIeld <PRfield>

Indicates the power level reduction of the current RLC block.

Parameters:
<PRfield>
DB0 | DB3 | DB7 | NUSable

DB0: 0 dB to 3 dB (excluded) less than BCCH level - P0

DB3: 3 dB to 7dB (excluded) less than BCCH level - P0

DB7: 7 dB to 10 dB less than BCCH level - P0

NUSable: not usable - MS has to ignore PR field

*RST:NUS

See "Configuring PS Connection Settings"

Firmware/Software: 

V3.2.30

Manual operation: See "PR Field"
