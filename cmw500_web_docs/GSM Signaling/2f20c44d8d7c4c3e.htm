V3.0.20 (Compared to V3.0.10)
New features:
  • Support of end to end packet data connections, using the data application unit (DAU), see "End-to-End Packet Data Connections"
  • Support of fading for standard cell scenarios
    –For internal fading, see "Internal Fading"
    –For external fading, see "External Fading"
  • New BER CS measurement mode, see "Mode AMR Inband FER"
    CS loop mode I, see "Test Loops"
  • The measured UL slot setting is corrected automatically during connection setup (if necessary), see "Measurement Slot UL"
  • Sending date and time information to the MS, see "Time"
  • Additional cell settings for PS:
    –"PC Meas Channel"
    –"T avg_t/w"
    –"BEP Period"
  • Additional connection settings for PS:
    –"Incremental Redundancy"
    –"Extended Dynamic Allocation"
  • Enhancement of MS capability information, see "Extended Dynamic Allocation"
  • Display of IP addresses assigned to the MS, see "MS IPv4 Address / IPv6 Prefix"
  • Information about established UL/DL TBF, see "Connection Status"
  • Information about maximum possible RLC throughput resulting from PS settings, see "Circuit Switched / Packet Switched"
  • Support of authentication, see "Security Settings"
    The command CONFigure:GSM:SIGN:CELL:AREQuest has been renamed to CONFigure:GSM:SIGN:CELL:SECurity:AUTHenticat (old command available as alias)
