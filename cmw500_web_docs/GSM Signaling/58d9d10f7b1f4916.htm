V3.2.10 (Compared to V3.0.20)
New features:
  • New remote command to specify fader for internal fading, see ROUTe:GSM:SIGN<i>:SCENario:SCFading:INTernal
  • Frequency offset, configurable separately for UL and DL, see "Frequency Offset"
  • Mixer level offset, see "Mixer Level Offset"
  • Clipping counter, see "Clipping Counter"
  • Additional fading propagation profiles, see CONFigure:​GSM:​SIGN<i>:​FADing:​FSIMulator:​STANdard
    New profiles:
    –TU25 (6 path)
    –TU1.5, TU3, TU25, TU50, HT100 (12 path)
  • Changed parameter range in the command CONFigure:​GSM:​SIGN<i>:​FADing:​AWGN:​SNRatio
