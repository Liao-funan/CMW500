CONFigure:GSM:SIGN<i>:SMS:OUTGoing:SCTStamp:TIME <Hour>, <Minute>, <Second>

Specifies the service center time stamp time for the time source DATE (see CONFigure:​GSM:​SIGN<i>:​SMS:​OUTGoing:​SCTStamp:​TSOurce).

Parameters:
<Hour>
Range: 0  to  23
*RST:11
<Minute>
Range: 0  to  59
*RST:11
<Second>
Range: 0  to  59
*RST:0

See "Sending / Receiving an SMS"
