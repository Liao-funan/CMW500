V3.2.30 (Compared to V3.2.20)
New features:
  • Message monitoring to an external PC, see "Message Monitoring Settings"
  • Enhanced CS measurement report, see "Enhanced Measurements (CS)"
  • Mean BEP and signal quality CS BER measurement, see "Measure Mode"
  • Mean BEP PS BER measurement, see "Measure Mode"
  • Additional PS BER measurement results (see "PS BER Tab")
    –Results for each slot separately
    –False USF detection
  • Neighbor cell MS measurement reports for CS connections:
    –General enabling, see "MS Measurement Report Settings"
    –Enabling of neighbor cell measurement for individual cell, see "Neighbor Cell Settings"
    –Retrieving MS measurement reports, see "MS Measurement Report"
  • Frequency offset for TCH, see "Frequency Offset"
  • Service category indication during eCall, see "Service Category"
  • Indication of "APN"
  • Codec mode request performance measurement, see "CMR Performance Measurement"
  • "External Delay Compensation"
  • NITZ function applied "at Attach/Synchronize", see "Send Time"
  • Timer T3122 and T3142 configurable, see "T3122, T3142"
  • Support of TD-SCDMA neighbor cells, see "TD-SCDMA"
  • "Cell Reselect Hysteresis" configurable
  • "Cell Identity" configurable
  • "NCC Permitted" configurable
  • RACH control parameter "Max Retrans" configurable
  • "Paging with MS Identity" IMSI/TMSI
  • Selectable response Accept/Reject/Ignore to the PS and CS connection request, see "Connection Request (CS and PS)"
  • Indication of connection error, see "Connection Error (CS and PS)"
  • Synchronization of the system time and frame number, see "Synchronization"
  • CS call release immediate/normal, see "Call Release"
  • "BEP Period 2" configurable
  • DL power control for PS connections, see "Downlink Power Control"
  • LTE CS fallback procedure support, see "Mobility Management"
  • Redirection GSM to TD-SCDMA, see "Mobility Management"
  • Concatenated MO and MT SMS, see "Segment"
  • Cell channel description list, see "Cell Channel Description"
  • "Always send RLC Data Blocks" On/Off, see "Always send RLC Data Blocks"
  • The PS slot configuration with selectable "USF Duty Cycle"
  • "Round Trip Delay"
  • New commands:
    SENSe:​GSM:​SIGN<i>:​MSSinfo:​RXPower?
    CONFigure:​GSM:​SIGN<i>:​CONNection:​ASConfig
