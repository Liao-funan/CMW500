CONFigure:GSM:SIGN<i>:BAND:BCCH <Band>

Selects the GSM band used for the BCCH and initially also for the TCH. The TCH band can be changed via a handover.

To check the current TCH band, see SENSe:​GSM:​SIGN<i>:​BAND:​TCH?.

Parameters:
<Band>
G085 | G09 | G18 | G19

GSM 850, GSM 900, GSM 1800, GSM 1900 bands

*RST:G09

See "Configuring BCCH, TCH and PDCH"
