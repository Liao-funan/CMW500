CONFigure:GSM:SIGN<i>:BER:CSWitched:LIMit:FFACch <FERFACCH>
CONFigure:GSM:SIGN<i>:BER:CSWitched:LIMit:FSACch <FERSACCH>

Specifies an upper limit for the frame error rate (FER) results of the BER CS measurement in the measurement modes FER FACCH and FER SACCH.

Parameters:
<FERSACCH>
Range: 0 %  to  100 %
*RST:0.2 %
Default unit: %
Example: 

See "Measuring in FER FACCH and FER SACCH Mode"

V2.1.25

Options: R&S CMW-KS210
Manual operation: See "Limits"
