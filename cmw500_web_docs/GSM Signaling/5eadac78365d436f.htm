CONFigure:GSM:SIGN<i>:CELL:RESelection:HYSTeresis <Hysteresis>

Sets the hysteresis for the cell reselection algorithm.

Parameters:
<Hysteresis>
Range: 0 dB  to  14 dB
Increment: 2 dB
*RST:14 dB
Default unit: dB
