CONFigure:GSM:SIGN<i>:SMS:OUTGoing:CGRoup <CodingGroup>

Defines how to interpret SMS signaling information.

Coding groups are defined in 3GPP TS 23.038 chapter 4.

Parameters:
<CodingGroup>
GDCoding | DCMClass

GDCoding: general data coding

DCMClass: data coding / message class
