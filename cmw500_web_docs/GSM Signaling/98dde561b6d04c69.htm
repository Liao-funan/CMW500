V2.1.60 (Compared to V2.1.25)
New features:
  • Support of AMR with 8PSK modulation, see "Traffic Mode"
  • EGPRS switched radio block loopback mode (SRB mode) for BER PS measurements, see "Test Modes"
  • Configurable data source for the circuit switched downlink traffic channel, see "Data Source"
  • Burst type to be used by MS for CTRL_ACK messages can be selected, see "Control Ack Type"
  • Additional trigger signal generated, see "Control ACK trigger"
  • Subchannel to be used for half-rate coding can be selected, see "HR Subchannel"
  • Most parameters of the slot configuration dialog can now be reconfigured in state "TBF Established", see "Slot Configuration Dialog"
  • New command, combining several existing PS connection configuration commands: CONFigure:​GSM:​SIGN<i>:​CONNection:​PSWitched:​SCONfig:​COMBined:​CARRier<c>
  • Changing the CS timeslot does no longer affect the "Measurement Slot UL", see "Measurement Slot UL"
