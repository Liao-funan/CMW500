CONFigure:GSM:SIGN<i>:CONNection:PSWitched:CSCHeme:UL <CScheme>

Selects the coding scheme for uplink packet data channels.

The selected value must be compatible to the configured set of modulation and coding schemes, see CONFigure:​GSM:​SIGN<i>:​CONNection:​PSWitched:​TLEVel.

Parameters:
<CScheme>
C1 | C2 | C3 | C4 | MC1 | MC2 | MC3 | MC4 | MC5 | MC6 | MC7 | MC8 | MC9 | UA7 | UA8 | UA9 | UA10 | UA11

C1 to C4: CS-1 to CS-4

MC1 to MC9: MCS-1 to MCS-9

UA7 to UA11: UAS-7 to UAS-11

*RST:MC1
