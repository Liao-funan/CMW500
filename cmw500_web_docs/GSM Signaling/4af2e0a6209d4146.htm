V2.0.10 (Compared to V1.0.15.23)
New features:
  • Scenario "IQ out - RF in", see "Test Setups"
  • Support of sending and receiving SMS messages, see "Outgoing SMS Parameters"
  • Support of voice services over adaptive multi-user channels on one slot (VAMOS), see "VAMOS"
  • Additional traffic modes supported (full-rate V1/V2, half-rate V1, AMR narrowband GMSK full-rate/half-rate), see "Traffic Mode"
  • Additional loop types supported, see "Circuit Switched General Connection Parameters"
  • More timeslots supported for CS (TS1 to TS7)
  • Configurable frame trigger signal, see "Trigger Signal Settings"
  • Frequency hopping, see "TCH/PDCH Settings"
  • MS measurement reports enhanced, see "MS Measurement Report"
  • Configurable expected nominal power and margin, including an automatic mode according to UL power control settings, see "Expected Uplink Power Settings"
  • Timer configuration: parameter "Alerting Timeout" added, see "Alerting Timeout"
  • Configurable time of TCH assignment during call setup, see "Circuit Switched General Connection Parameters"
  • Configurable measurement timeout for remote control:
    –CONFigure:​GSM:​SIGN<i>:​BER:​CSWitched:​TOUT
  • ROUTe:GSM:SIGN_i_:SCENario:SCELl - selection of RF 3 and RF 4 connectors modified, RX and TX modules selectable
  • Additional commands for query of routing settings: ROUTe:​GSM:​SIGN<i>:​SCENario? and ROUTe:​GSM:​SIGN<i>?
