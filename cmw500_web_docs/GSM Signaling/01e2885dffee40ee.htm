Level Settings

This section configures parameters of the "Messaging (CBS)", level 1 and level 2.

CBS - level parameters

└ Level 2 (DRX)
└ Enable

Level 1 (CBCH) > Enable

Enables CBS generally.

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CBS:​CBCH:​ENABle

 
Level 2 (DRX)

A scheduling message informs the MS which CB messages will be sent in the next DRX schedule period. The MS reads then the CB message of interest in DRX mode. The following parameters configure DRX for CBS scheduling.

Enable < Level 2 (DRX)

Enables discontinuous reception (DRX) for the CBS scheduling.

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CBS:​DRX:​ENABle

 
Length of CBS Sched. Period (L) < Level 2 (DRX)

Specifies the length of the DRX used for the specific CB message. Define value matching with the position of the particular CB message within the CBS scheduling period.

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CBS:​DRX:​LENGth

 
Offset to start of Sched. Period (O) < Level 2 (DRX)

Configures an offset within scheduling period for the transmission of a scheduling message.

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CBS:​DRX:​OFFSet
