CONFigure:GSM:SIGN<i>:SMS:OUTGoing:UDHeader <Header>

Configures the TP user data header.

Parameters:
<Header>

Up to 16 hexadecimal digits

Range: #H0  to  #HFFFFFFFFFFFFFFFF
*RST:OFF

Additional parameters: OFF | ON (disables | enables sending the header)

See "Sending / Receiving an SMS"
