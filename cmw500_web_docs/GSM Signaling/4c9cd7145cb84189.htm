CONFigure:GSM:SIGN<i>:FADing:FSIMulator:DSHift <Frequency>

Displays the maximum Doppler frequency for the fading simulator.

A setting is only allowed in USER mode (see CONFigure:​GSM:​SIGN<i>:​FADing:​FSIMulator:​DSHift:​MODE).

Parameters:
<Frequency>
Range: 1 Hz  to  2000 Hz
*RST:2.63 Hz
Default unit: Hz
Example: 

See "Configuring Internal Fading"

Firmware/Software: 

V3.2.20

Options: R&S CMW-KS210, R&S CMW-KE100 and R&S CMW-KE200
Manual operation: See "Doppler Frequency, Mode"
