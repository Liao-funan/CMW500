CONFigure:GSM:SIGN<i>:CONNection:CSWitched:TCHassign <TCHassignment>

Specifies when is the traffic channel assigned during connection setup.

Parameters:
<TCHassignment>
VEARly | EARLy | LATE | ON | OFF

VEARly: The TCH is assigned very early. Signaling is done via the fast associated control channel (FACCH).

EARLy: The TCH is assigned early, which means that alerting takes place on the TCH. For call setup to the traffic channel, signaling is done via the standalone dedicated control channel (SDCCH).

LATE: The traffic channel is assigned late, which means after alerting. For call setup to the traffic channel and alerting, signaling is done via the SDCCH.

OFF (ON) disables (enables) the TCH assignment.

*RST:VEAR
