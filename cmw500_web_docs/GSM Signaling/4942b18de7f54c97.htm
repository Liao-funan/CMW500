CONFigure:GSM:SIGN<i>:BER:CSWitched:LIMit:CIBBits <ClassIbBits>

Specifies upper limits for the BER and RBER class Ib bit results of the BER CS measurement.

Parameters:
<ClassIbBits>
Range: 0 %  to  100 %
*RST:0.4 %
Default unit: %
