CONFigure:GSM:SIGN<i>:CELL:DTX <Mode>

Specifies whether the mobile station supports operating mode discontinuous transmission (DTX).

Parameters:
<Mode>
OFF | ON

Enable | disable DTX mode

*RST:OFF
