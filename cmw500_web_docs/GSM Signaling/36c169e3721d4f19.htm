CONFigure:GSM:SIGN<i>:CBS:DRX:LENGth <LengthOfPeriod>

Specifies the length of DRX (L) that the MS can use for the processing of particular CB message. Define the value matching with the position of the specific CB message within the CBS scheduling period.

Parameters:
<LengthOfPeriod>
Range: 1  to  40
*RST:32
Example: 

See "Sending a Cell Broadcast Message"

Firmware/Software: 

V3.5.20

Options: R&S CMW-KS170
Manual operation: See "Length of CBS Sched. Period (L)"
