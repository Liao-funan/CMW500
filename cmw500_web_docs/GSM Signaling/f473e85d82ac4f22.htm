SENSe:GSM:SIGN<i>:RREPort:CSWitched:MBEP:RANGe?

Returns the bit error probability (BEP) range, corresponding to the mean BEP index reported by the MS for a DL signal.

Return values: 
<Lower>

Log10(lower end of BEP range)

Range: -3.6 to -0.6
<Upper>

Log10(upper end of BEP range)

Range: -3.6 to -0.6
Example: 

See "Querying MS Measurement Reports"

Usage: Query only
Firmware/Software: 

V3.2.30

Manual operation: See "Mean BEP"
