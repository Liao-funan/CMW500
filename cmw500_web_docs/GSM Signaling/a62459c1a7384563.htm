SENSe:GSM:SIGN<i>:MSSinfo:AMR:CMODe:WB:FRATe:GMSK:UL?

Query the DL AMR codec mode requested by the MS (:DL) and the actual UL codec mode used by the MS (:UL). Separate commands are available for the half-rate (HRATe) and full-rate (FRATe) narrowband (NB) and wideband (WB) AMR codecs, for GMSK and 8PSK modulation.

For the modes used in downlink and requested for uplink, refer to the CONFigure:GSM:SIGN<i>:CONNection:CSWitched:AMR:CMODe:... commands.

Return values: 
<CodecMode>
Range: 1 to 4 (1 to 3 for WB:FRATe:GMSK and WB:HRATe:EPSK)

See "Configuring AMR Settings"

Usage: Query only
