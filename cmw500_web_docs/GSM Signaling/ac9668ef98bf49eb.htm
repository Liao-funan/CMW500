CONFigure:GSM:SIGN<i>:CELL:TIME:LTZoffset <TimeZoneOffset>

Specifies a time zone offset for the time source DATE (see CONFigure:​GSM:​SIGN<i>:​CELL:​TIME:​TSOurce).

Parameters:
<TimeZoneOffset>
Range: -19.75 h  to  19.75 h
Increment: 0.25 h
*RST:0 h
