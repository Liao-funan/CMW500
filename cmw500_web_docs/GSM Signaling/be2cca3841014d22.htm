CONFigure:GSM:SIGN<i>:MSLot:UL <Slot>

Specifies the uplink measurement slot, i.e. the slot evaluated by measurements running in parallel to the "GSM Signaling" application.

Parameters:
<Slot>
Range: 0  to  7
*RST:3
