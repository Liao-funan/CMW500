V2.1.25 (Compared to V2.1.10)
New features:
  • FACCH frame error rate tests including repeated FACCH tests; see "Mode FER FACCH"
  • SACCH frame error rate tests including repeated SACCH tests; see "Mode FER SACCH"
  • Support for wideband AMR (AMR-WB); see "Traffic Mode"
  • Configuration of UL coding scheme in the packet switched handover prepare session; see Figure "Mobility management dialog (PS connections)"
  • "RX Power" indicator in the "Connection Status" panel; see "Connection Status"
  • "Clear" button for incoming SMS; see "Message Text / Message Length"
