CONFigure:GSM:SIGN<i>:CONNection:CSWitched:AMR:CMODe:WB:HRATe:EPSK:DL <CodecMode>
CONFigure:GSM:SIGN<i>:CONNection:CSWitched:AMR:CMODe:WB:HRATe:EPSK:UL <CodecMode>

Select the codec modes to be used by the R&S CMW (downlink) and the MS (uplink) for the half-rate wideband AMR codec (8PSK modulation).

Only active codec modes can be selected. For configuration and activation/deactivation of the codec modes, see CONFigure:​GSM:​SIGN<i>:​CONNection:​CSWitched:​AMR:​RSET:​WB:​HRATe:​EPSK.

Parameters:
<CodecMode>
Range: 1  to  3 (if all codec modes are active, otherwise less)
*RST:3

Additional parameters OFF (ON) disables (enables) codec mode.
