V3.0.10 (Compared to V2.1.60)
New features:
  • New scenario "BCCH and TCH/PDCH" providing separate downlink paths for BCCH and TCH/PDCH, see "General Settings"
  • Event log added to main view, see "Event Log"
  • New channels 940 to 954 in GSM 900 band, see "GSM Bands and Channels"
  • Procedure for reception of inter-RAT handover from WCDMA has been changed:
    –The GSM cell is switched on automatically by the signaling application handing over a call.
    –The new cell state RDY indicates that the GSM signaling application is ready to receive a handover.
    –The CS state during the handover has been changed to "Incoming Handover in Progress".
  • RX measurement changes:
    –The measurements have been combined in a single RX measurements view.
    –The connection states are displayed in the RX measurement view.
    –The signaling application can be controlled and configured from the RX measurement view.
