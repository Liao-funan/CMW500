V3.2.20 (Compared to V3.2.10)
New features:
  • "Auto Slot Config" function, see "Connection Setup"
  • RLC throughput measurement, see "RLC Throughput Measurement"
  • Corrupted BCS data testing:
    –Settings, see "BCS Data Corruption Rate"
    –BLER results, see FETCh:​GSM:​SIGN<i>:​BLER:​OALL? etc.
  • AMR threshold, see "Threshold"
  • Neighbor cell list broadcast, see "Neighbor Cell Settings"
  • Cell reselection parameters for LTE (E-UTRAN), WCDMA (UTRAN) and GSM, see "Cell Reselection"
  • Speech codec, see "Data Source"
  • Loop type D, see and BER measurement mode RBER/UFR, see:
    –"Loop" and
    –"Mode RBER/UFR"
  • Redirection to LTE, see "Inter/Intra RAT... (hotkey)"
  • Fading Doppler frequency for internal fading simulator, see "Doppler Frequency, Mode"
  • Indication of mobile circuit switched codec support during call setup, see "Codec List"
  • Parameter "Packet Switched Data Source" can be changed in "TBF Established" state, see "Data Source"
  • Scenario change between "Standard Cell" and "BCCH and TCH/PDCH" possible in "Call Established" / "TBF Established" states, see "Scenario"
  • SMS extensions:
    –SMS via PS domain, see "SMS Domain"
    –SMS text in binary format, see "Outgoing SMS binary"
  • PS hopping, see "Enable"
  • Changed parameter syntax in fading profiles, see CONFigure:​GSM:​SIGN<i>:​FADing:​FSIMulator:​STANdard
