CONFigure:GSM:SIGN<i>:CBS:MESSage:DCSCheme <DataCodeScheme>

Specifies language using the GSM 7-bit default alphabet.

Parameters:
<DataCodeScheme>

0: coding group 0000, language 0001 (English)

1: coding group 0001, language 0000 (GSM 7-bit default alphabet; message preceded by language indication)

Range: 0  to  1
*RST:0
Example: 

See "Sending a Cell Broadcast Message"

Firmware/Software: 

V3.5.20

Options: R&S CMW-KS170
Manual operation: See "Data Coding Scheme"
