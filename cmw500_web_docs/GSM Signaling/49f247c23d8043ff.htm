CONFigure:GSM:SIGN<i>:BER:CSWitched:RTDelay <Mode>, <Bursts>

Specifies the number of bursts used as the round-trip delay.

Parameters:
<Mode>
AUTO | MANual

AUTO: number of bursts set automatically

MAN: number of bursts specified manually

*RST:AUTO
<Bursts>

Round-trip delay

Range: 0  to  24
*RST:4
Default unit: burst
Example: 

See "Measuring in Mean BEP Mode"

Firmware/Software: 

V3.2.30

Manual operation: See "Round Trip Delay"
