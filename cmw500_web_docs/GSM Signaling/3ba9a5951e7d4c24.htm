CONFigure:GSM:SIGN<i>:FADing:FSIMulator:ILOSs:LOSS:NORMal?

Queries the insertion loss for the fading simulator.

The command is only relevant in NORMal mode (see CONFigure:​GSM:​SIGN<i>:​FADing:​FSIMulator:​ILOSs:​MODE).

Return values: 
<InsertionLoss>
Range: 0 dB  to  18 dB
Default unit: dB
Example: 

See "Configuring Internal Fading"

Usage: Query only
Firmware/Software: 

V3.5.30

Options: R&S CMW-KS210, R&S CMW-KE100 and R&S CMW-KE200
Manual operation: See "Insertion Loss"
