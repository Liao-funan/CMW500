Packet Switched Domain

Selects whether the emulated cell supports packet switched connections. Circuit switched connections are always supported.

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CELL:​PSDomain

 
Network Support

Selects the support of GPRS or EGPRS in packet domain.

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CELL:​NSUPport

 
Dual Transfer Mode

Enables or disables dual transfer mode (CS + PS connections in parallel).

To configure slot in dual transfer mode automatically, enable "DTM Slot Config", see "Auto Slot Config / DTM Slot Config"

Remote command: 

CONFigure:​GSM:​SIGN<i>:​CELL:​DTMode
