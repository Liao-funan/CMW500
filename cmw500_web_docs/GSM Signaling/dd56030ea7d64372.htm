CONFigure:GSM:SIGN<i>:CELL:RESelection:QUALity:RXLevmin:EUTRan <Qrxlevmin>

Defines the minimum RX level at a UE antenna required for access to the LTE cell. This parameter is transmitted via BCCH.

Parameters:
<Qrxlevmin>
Range: -140 dBm  to  -78 dBm
Increment: 2 dB
*RST:-132 dBm
Example: 

See "Configuring Neighbor Cell and Reselection Parameters"

Firmware/Software: 

V3.2.20

Options: R&S CMW-KS210
Manual operation: See "E-UTRAN Q RxLevMin"
