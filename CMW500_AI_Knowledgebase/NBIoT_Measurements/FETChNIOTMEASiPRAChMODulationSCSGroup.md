FETCh:NIOT:MEAS<i>:PRACh:MODulation:SCSGroup? 
Returns the numbers of the subcarriers used by the symbol groups of the preamble, for single-preamble measurements.
See also 
"NB-IoT Preamble Structure"
.
Return values: 
<Reliability>
"Reliability Indicator"
<SubCarr1>
Subcarrier number for the first symbol group
Range: 
0  to  47
<SubCarr2>
Subcarrier number for the second symbol group
Range: 
0  to  47
<SubCarr3>
Subcarrier number for the third symbol group
Range: 
0  to  47
<SubCarr4>
Subcarrier number for the fourth symbol group
Range: 
0  to  47
Example: 
See 
"Performing Single-Shot Measurements"
Usage: 
Query only
Firmware/Software: 
V3.7.20
