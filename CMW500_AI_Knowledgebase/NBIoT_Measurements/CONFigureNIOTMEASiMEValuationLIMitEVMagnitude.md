CONFigure:NIOT:MEAS<i>:MEValuation:LIMit:EVMagnitude 
<RMS>, <Peak>
Defines upper limits for the RMS and peak values of the error vector magnitude (EVM).
Parameters:
<RMS>
Range: 
0 %  to  100 %
*RST:
17.5 %, ON
Default unit: 
%
Additional parameters: OFF | ON (disables the limit check | enables the limit check using the previous/default limit values)
<Peak>
Range: 
0 %  to  100 %
*RST:
35 %, OFF
Default unit: 
%
Additional parameters: OFF | ON (disables the limit check | enables the limit check using the previous/default limit values)
