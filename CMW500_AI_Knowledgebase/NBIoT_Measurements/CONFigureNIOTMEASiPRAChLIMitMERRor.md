CONFigure:NIOT:MEAS<i>:PRACh:LIMit:MERRor 
<RMS>, <Peak>
Defines upper limits for the RMS and peak values of the magnitude error.
Parameters:
<RMS>
Range: 
0 %  to  100 %
*RST:
17.5 %, OFF

%
Additional parameters: OFF | ON (disables the limit check | enables the limit check using the previous/default limit values)

Range: 
0 %  to  100 %
*RST:

%
