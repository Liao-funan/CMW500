ROUTe:GSM:SIGN<i>:SCENario:SCELl:FLEXible 
<BBBoard>, <RXConnector>, <RXConverter>, <TXConnector>, <TXConverter>
Activates the "Standard Cell" scenario and selects the signal paths.
For possible connector and converter values, see 
"Values for Signal Path Selection"
.
Parameters:
<BBBoard>
Signaling unit
<RXConnector>
RF connector for the input path
<RXConverter>
RX module for the input path
<TXConnector>
RF connector for the output path
<TXConverter>
TX module for the output path
