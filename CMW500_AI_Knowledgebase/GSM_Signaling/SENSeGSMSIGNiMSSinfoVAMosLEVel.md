SENSe:GSM:SIGN<i>:MSSinfo:VAMos:LEVel? 
Indicates the VAMOS support of the MS and the VAMOS level supported.
Return values: 
<Level>
0
: VAMOS not supported
1
: VAMOS I supported
2
: VAMOS II supported
3
: VAMOS III supported
Range: 
0  to  3

"Querying MS Capabilities"
