ROUTe:GSM:SIGN<i>:SCENario:IORI:FLEXible 
<BBBoard>, <RXConnector>, <RXConverter>, <TXConnector>, <TXConverter>
Activates the "IQ out - RF in" scenario and selects the signal paths.
For possible connector and converter values, see 
"Values for Signal Path Selection"
.
Parameters:
<BBBoard>
Signaling unit
<RXConnector>
RF connector for the input path
<RXConverter>
RX module for the input path
<TXConnector>
DIG IQ OUT rear panel connector for the output path
<TXConverter>
For future use. In this software version, always send KEEP to ensure compatible settings.
