SENSe:GSM:SIGN<i>:RREPort:NCELl:WCDMa:CELL<no>? 
Returns measurement report values for a selected WCDMA neighbor cell.
Suffix: 
<no>
1..4
Selects the WCDMA neighbor cell
Return values: 
<RSCP>
RSCP as dimensionless index
Range: 
-5  to  91
<EcNO>
Ec/No as dimensionless index
Range: 
0  to  49
Example: 
See 
"Querying MS Measurement Reports"
Usage: 
Query only
Firmware/Software: 
V3.2.30
Options: 
R&S CMW-KS210
Manual operation: 
See 
"WCDMA > RSCP, EcNO"
