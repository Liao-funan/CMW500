"Reliability Indicator"

Current OBW value

Hz

Average OBW value
Default unit: 
Hz
<OBWvalueMax>
Maximum OBW value
Default unit: 
Hz
<OBWvalueStdDev>
Standard deviation OBW value
Default unit: 
Hz
<OBWleft>
Lower edge frequency of OBW
Default unit: 
Hz
<OBWright>
Upper edge frequency of OBW
Default unit: 
Hz
