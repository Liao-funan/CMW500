Transmit Spectrum Mask Traces
The following commands return the transmit spectrum mask traces.
For MIMO, use the commands with 
MIMO<n>
 mnemonic. For bandwidths with two segments, use the commands with 
SEGMent<seg>
 mnemonic.
See also 
"View Transmit Spectrum Mask"
