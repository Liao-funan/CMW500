CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:HEOFdm:EVMPilot 
<EVMPilot>
Defines and activates an upper limit for the error vector magnitude (EVM) of the pilot carriers in 802.11ax signals.
Parameters:
<EVMPilot>
Range: 
-100 dB  to  0 dB
*RST:
-8 dB
Default unit: 
dB
Additional parameters: OFF | ON (disables | enables the limit check)
Example: 
See 
"Specifying Modulation Limits (OFDM)"
Firmware/Software: 
V3.7.20
Options:
