CONFigure:WLAN:MEAS<i>:MEValuation:LIMit:MODulation:VHTofdm:CFERror 
<CenterFreqError>
Defines and activates an upper limit for the center frequency error in 802.11ac signals.
Parameters:
<CenterFreqError>
Note that the reset value is identical for all standards
Range: 
0 Hz  to  100E+6 Hz
*RST:
100E+3 Hz
Default unit: 
Hz
Additional parameters: OFF | ON (disables | enables the limit check)
Example: 
See 
"Specifying Modulation Limits (OFDM)"

V3.5.121, V3.7.20: range extended
