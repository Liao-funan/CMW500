CONFigure:WLAN:MEAS<i>:MEValuation:COMPensation:SKIPsymbols 
<SkipSymbols_Head>, <SkipSymbols_Tail>
Defines how many head and tail symbols are excluded from OFDM modulation measurements.
Parameters:
<SkipSymbols_Head>
Number of heading symbols to be skipped
Range: 
0 symbols  to  100 symbols
*RST:
0 symbols
Default unit: 
symbol
<SkipSymbols_Tail>
Number of tailing symbols to be skipped
Range: 
0 symbols  to  100 symbols
*RST:
0 symbols
Default unit: 
symbol

"Specifying Measurement-Specific Settings"

V3.5.30
