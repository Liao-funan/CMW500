CONFigure:LTE:MEAS<i>:ENB:MEValuation:LIMit:QPSK:EVMagnitude 
<RMS>, <Peak>
Defines upper limits for the RMS and peak values of the error vector magnitude (EVM) for QPSK.
Parameters:
<RMS>
Range: 
0 %  to  100 %
*RST:
18.5 %, ON
Default unit: 
%
Additional parameters: OFF | ON (disables | enables the limit check)
<Peak>
Range: 
0 %  to  100 %
*RST:
35 %, OFF
Default unit: 
%
Additional parameters: OFF | ON (disables | enables the limit check)
