List Mode Settings
The following commands configure the list mode. For retrieving list mode results, see 
"List Mode Results (One Segment)"
.
For a description of the list mode, see 
"List Mode"
.
The segment number <no> in the following commands refers to the complete range of configured segments (1..48).
