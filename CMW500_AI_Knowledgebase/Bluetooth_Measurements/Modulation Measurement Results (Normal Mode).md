Modulation Measurement Results (Normal Mode)
The following commands return the modulation results in normal mode.
Commands for BR/EDR (
...:NMODe:CLASsic...
) are available.
Normal mode is only supported in combined signal path, see 
"Parallel Signaling and Measurement"
.
