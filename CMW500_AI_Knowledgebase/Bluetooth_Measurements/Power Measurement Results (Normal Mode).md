Power Measurement Results (Normal Mode)
The following commands return the power results (single values) in normal mode.
Commands for BR/EDR (
...:NMODe:CLASsic...
) are available.
Normal mode is only supported in combined signal path, see 
"Parallel Signaling and Measurement"
.
