SOURce:GPRF:GEN<i>:ARB:MSEGment:DURation? 
Queries the durations (processing times) of all segments in the loaded multisegment waveform file. The duration is given by the number of samples divided by the clock rate.
Return values: 
<Duration>
Comma-separated list of durations, one value for each segment
Range: 
1E-9 s  to  0.999999999999999E+15 s
*RST:
n/a
Default unit: 
s
Example: 
See 
"Using the Arbitrary Mode"
Usage: 
Query only
Firmware/Software: 
V1.0.15.20
Manual operation: 
See 
"Baseband Configuration > ARB > ARB File"
