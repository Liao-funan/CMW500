SOURce:GPRF:GEN<i>:LIST:DGAin:ALL 
<AllDigitalGains>...
Defines the digital gains of all frequency/level steps.
Parameters:
<AllDigitalGains>
Comma-separated list of n values, one per frequency/level step, where n < 2001. The query returns 2000 results.
Range: 
-30 dB  to  0 dB
*RST:
0 dB
Default unit: 
dB
