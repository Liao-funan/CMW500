SOURce:GPRF:GEN<i>:ARB:MSEGment:POFFset? 
Queries the peak offset of all segments in the loaded multisegment waveform file.
Return values: 
<PeakOffset>
Comma-separated list of all peak offset values as specified in WinIQSIM2, one value for each segment
Default unit: 
dB
Example: 
See 
"Using the Arbitrary Mode"
Usage: 
Query only
Firmware/Software: 
V1.0.15.20
Manual operation: 
See 
"Baseband Configuration > ARB > ARB File"
