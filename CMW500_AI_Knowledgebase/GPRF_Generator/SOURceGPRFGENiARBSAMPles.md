SOURce:GPRF:GEN<i>:ARB:SAMPles? 
Queries the number of samples in the loaded waveform file. The R&S
 
CMW supports waveform files with a size up to 512 MB.
Return values: 
<Samples>
Number of samples, integer value.

See 
"Using the Arbitrary Mode"
Usage: 
Query only

V1.0.0.4
Manual operation: 
See 
"Baseband Configuration > ARB > ARB File"
