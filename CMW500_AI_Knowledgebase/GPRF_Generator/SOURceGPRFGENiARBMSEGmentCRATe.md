SOURce:GPRF:GEN<i>:ARB:MSEGment:CRATe? 
Queries the clock rates of all segments in the loaded multisegment waveform file. The clock rates of waveform file created with R&S WinIQSIM2 are compatible with the R&S
 
CMW; see 
"Generating and Transferring Waveform Files"
.
Return values: 
<ClockRate>
Comma-separated list of clock rates, one value for each segment
Range: 
as defined in the waveform file
*RST:
n/a
Default unit: 
Hz
Example: 
See 
"Using the Arbitrary Mode"
Usage: 
Query only
Firmware/Software: 
V1.0.15.20
Manual operation: 
See 
"Baseband Configuration > ARB > ARB File"
