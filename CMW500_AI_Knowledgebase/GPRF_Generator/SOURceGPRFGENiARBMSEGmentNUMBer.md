SOURce:GPRF:GEN<i>:ARB:MSEGment:NUMBer? 
Queries the segment numbers of all segments in the loaded multisegment waveform file.
Return values: 
<SegNumber>
Comma-separated list of segment numbers, one value for each segment
Range: 
integer values
*RST:
n/a
Example: 
See 
"Using the Arbitrary Mode"
Usage: 
Query only
Firmware/Software: 
V1.0.15.20
Manual operation: 
See 
"Baseband Configuration > ARB > ARB File"
