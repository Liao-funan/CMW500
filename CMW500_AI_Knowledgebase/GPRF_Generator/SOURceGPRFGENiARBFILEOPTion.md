SOURce:GPRF:GEN<i>:ARB:FILE:OPTion? 
Returns the R&S CMW-KVxxx and R&S CMW-KWxxx options that are required to process the loaded ARB file with the arbitrary RF generator.
Return values: 
<Options>
A comma-separated list of KV and KW options.
Usage: 
Query only
Firmware/Software: 
V3.0.10
Manual operation: 
See 
"Baseband Configuration > ARB > ARB File"
