TRIGger:GPRF:MEAS<i>:POWer:PSET:OFFSet:ALL 
<TriggerOffset>...
Defines a delay time relative to the trigger event for all parameter sets.
Parameters:
<TriggerOffset>
Comma-separated list of 32 trigger offsets, for parameter set no. 0 to 31
Range: 
0 s  to  1 s
*RST:
50E-6 s
Default unit: 
s
