ROUTe:GPRF:MEAS<i>:SCENario:CATalog:CSPath? 
Queries the possible master firmware applications for a combined signal path scenario. The returned list contains all installed signaling applications.
Return values: 
<CSP Masters>
Comma-separated list of string parameters
For example "1xEV-DO Sig1", "GSM Sig2"
"No Connection" means that no signaling application is installed.
Usage: 
Query only
Firmware/Software: 
V1.0.15.20
Manual operation: 
See 
"Scenario"
