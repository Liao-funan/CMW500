TRIGger:GPRF:MEAS<i>:IQVSlot:MGAP 
<MinimumGap>
Sets a minimum time during which the IF signal must be below the trigger threshold before the trigger is armed so that an IF power trigger event can be generated.

0 s  to  0.01 s
