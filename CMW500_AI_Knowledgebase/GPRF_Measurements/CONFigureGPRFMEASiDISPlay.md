CONFigure:GPRF:MEAS<i>:DISPlay 
<MeasTab>
Selects the displayed measurement tab. This command is useful, if you want to observe the GUI during remote control. The GUI controls are disabled in that case, so that you cannot select a tab via the GUI.
To display the GUI, use 
SYSTem:DISPlay:UPDate ON
.
