CONFigure:DATA:MEAS<i>:IPLogging:FSIZe 
<FileSize>
Configures the maximum log file size. When this file size is reached, logging stops.
The default value 0 bytes means that no limit is defined.

<FileSize>

0 bytes  to  1E+9 bytes
