SENSe:DATA:MEAS<i>:IPANalysis:IPConnect:STATistics? 
Queries the statistical information provided by the "IP Connectivity" view.
Return values: 
<NoOfConn>
Total number of connections
<NoOfOpenC>
Number of open connections
<NoOfClosedC>
Number of closed connections
<OpenTCPC>
Number of open TCP connections
<ClosedTCPC>
Number of closed TCP connections
<OpenUDPC>
Number of open UDP connections
<ClosedUDPC>
Number of closed UDP connections
Example: 
See 
"Performing IP Analysis"
Usage: 
Query only
Firmware/Software: 
V3.2.11
Options: 
R&S CMW-KM051
Manual operation: 
See 
"Results"
