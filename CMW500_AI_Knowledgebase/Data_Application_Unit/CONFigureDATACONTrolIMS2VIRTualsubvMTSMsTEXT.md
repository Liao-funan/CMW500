CONFigure:DATA:CONTrol:IMS2:VIRTualsub<v>:MTSMs:TEXT 
<Text>
Defines the text for messages to be sent by virtual subscriber number <v>.
For generic SMS, it defines the contents of the RPDU via hexadecimal characters.
Suffix: 
<v>
1..20
Parameters:
<Text>
Message text or RPDU contents as string
*RST:
"R&S Short Message Service Text. The quick brown fox jumps over the lazy dog. THE QUICK BROWN FOX JUMPS OVER THE LAZY DOG. 0123456789 !"#\*%+-/()<>?=;@$,"
