CONFigure:DATA:CONTrol:IMS2:PCSCf:CREate
Updates the internal list of P-CSCF profiles.
If your command script adds P-CSCF profiles, you must insert this command before you can use the new profiles.
It is sufficient to insert the command once, after adding the last P-CSCF profile / before using the profiles.
