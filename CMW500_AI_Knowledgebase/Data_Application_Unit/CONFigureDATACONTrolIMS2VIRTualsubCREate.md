CONFigure:DATA:CONTrol:IMS2:VIRTualsub:CREate
Updates the internal list of virtual subscriber profiles.
If your command script adds virtual subscriber profiles, you must insert this command before you can use the new profiles.
It is sufficient to insert the command once, after adding the last virtual subscriber profile / before using the profiles.
