CONFigure:DATA:CONTrol:DNS:ASERvices:ADD 
<Name>, <Url>, <Protocol>, <Port>
Adds an entry to the database of the local DNS server for type SRV DNS queries.
Setting parameters: 
<Name>
String specifying the service name, e.g. 
'pcscf'
<Url>
String specifying the URL of the domain, e.g. 
'www.example.com'
<Protocol>
UDP |
 
 TCP
<Port>
Range: 
0  to  65654
