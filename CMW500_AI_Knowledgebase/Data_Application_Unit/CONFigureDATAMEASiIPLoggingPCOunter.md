CONFigure:DATA:MEAS<i>:IPLogging:PCOunter 
<PacketCounter>
Configures the maximum number of IP packets to be logged. When this number of packets is reached, logging stops.
The default value 0 means that no limit is defined.
Parameters:
<PacketCounter>
Range: 
0  to  1E+6
*RST:
0
