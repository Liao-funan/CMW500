CONFigure:DATA:CONTrol:DNS:LOCal:DELete 
<URLorIP>
Deletes an entry from the database of the local DNS server for type A or type AAAA DNS queries.
Each entry consists of two strings, one specifying a domain and the other indicating the assigned IP address. Enter one of these strings to select the entry to be deleted.
Setting parameters: 
<URLorIP>
String selecting the entry to be deleted
