SENSe:WCDMa:SIGN<i>:UECapability:UEPosition:GANSs? 
Returns UE capability information related to the Galileo and additional navigation satellite systems (GANSS).
Return values: 
<GALILEO>
NO |
 
 YES
Indicates if a UE supports Galileo standard
<SBAS>
NO |
 
 YES
Indicates if a UE supports the satellite-based augmentation system
<ModernizedGPS>
NO |
 
 YES
Indicates if a UE supports the modernized global positioning system
<QZSS>
NO |
 
 YES
Indicates if a UE supports the quasi-zenith satellite system
<GLONASS>
NO |
 
 YES
Indicates if a UE supports the global navigation satellite system
