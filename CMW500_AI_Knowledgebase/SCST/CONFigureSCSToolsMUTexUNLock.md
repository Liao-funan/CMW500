CONFigure:SCSTools:MUTex:UNLock 
<Name>, <Key>
Unlocks a locked mutex at the end of a critical section.
Setting parameters: 
<Name>
String with the name of the mutex to be unlocked
<Key>
Key received as response to the successful lock command (integer value greater than zero)
Usage: 
Event
Firmware/Software:
