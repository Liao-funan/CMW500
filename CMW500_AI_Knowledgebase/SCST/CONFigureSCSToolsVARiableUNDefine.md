CONFigure:SCSTools:VARiable:UNDefine 
[<Name>]
Deletes a specific variable or all user-defined variables.
You cannot delete the variable "SinceLastBoot".
Setting parameters: 
<Name>
String with the name of the variable to be deleted
If you omit this parameter, all user-defined variables are deleted.
