CONFigure:LTE:SIGN<i>:EBLer:SFRames 
<Subframes>
Defines the number of subframes (= number of transport blocks) to be processed per measurement cycle.
For confidence BLER measurements, this parameter specifies only the length of the throughput result trace but does not influence the duration of the measurement.
Parameters:
<Subframes>
Range: 
100  to  400E+3
*RST:
10E+3
