CONFigure:LTE:SIGN<i>:UEReport:SCC<c>:RSSI:COTHreshold 
<Threshold>
Specifies a threshold for channel occupancy measurements for LAA. The setting is signaled to the UE as "channelOccupancyThreshold".
The same value applies to all SCCs with frame structure type 3.
