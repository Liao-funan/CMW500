ROUTe:LTE:SIGN<i>:SCENario:IORI:FLEXible 
<PCCBBBoard>, <RXConnector>, <RXConverter>, <TXConnector>, <TXConverter>
Activates the scenario "1CC - IQ Out, RF In - 1x1" and selects the signal paths.
For possible parameter values, see 
"Values for Signal Path Selection"
.
Parameters:
<PCCBBBoard>
Signaling unit
<RXConnector>
RF connector for the input path
<RXConverter>
RX module for the input path
<TXConnector>
DIG IQ OUT rear panel connector for the output path
<TXConverter>
For future use. Send KEEP to ensure compatible settings.
