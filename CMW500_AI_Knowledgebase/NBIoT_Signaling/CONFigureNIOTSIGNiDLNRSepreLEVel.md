CONFigure:NIOT:SIGN<i>:DL:NRSepre:LEVel 
<Level>
Defines the energy per resource element (EPRE) of the narrowband reference signal (NRS). The power levels of resource elements used for other channels/signals are derived from this power level.
The allowed value range depends on many settings, for example on the used connector, the external attenuation, the AWGN state and the operation mode.
Parameters:
<Level>
*RST:
-85 dBm/15kHz
