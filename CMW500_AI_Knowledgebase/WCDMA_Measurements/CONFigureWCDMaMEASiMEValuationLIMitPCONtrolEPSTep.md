CONFigure:WCDMa:MEAS<i>:MEValuation:LIMit:PCONtrol:EPSTep 
<Expected0dB>, <Expected1dB>, <Expected2dB>, <Expected3dB>, <Expected4to7dB>
Defines tolerance values ("Expected Power Step Limits") depending on the nominal power step size.
Parameters:
<Expected0dB>
Tolerance value for power step size 0 dB
Range: 
0 dB  to  5 dB
*RST:
0.5 dB
Default unit: 
dB
<Expected1dB>
Tolerance value for power step size 1 dB
Range: 
0 dB  to  5 dB
*RST:
0.5 dB
Default unit: 
dB
<Expected2dB>
Tolerance value for power step size 2 dB
Range: 
0 dB  to  5 dB
*RST:
1.0 dB
Default unit: 
dB
<Expected3dB>
Tolerance value for power step size 3 dB
Range: 
0 dB  to  5 dB
*RST:
1.5 dB
Default unit: 
dB
<Expected4to7dB>
Tolerance value for power step size 4 dB to 7 dB
Range: 
0 dB  to  5 dB
*RST:
2.0 dB
Default unit: 
dB
