Limits (Code Domain)
The following commands define limits for relative code domain error (CDE) results and specify the channel configuration of the uplink signal. Knowledge of the channel configuration is required for relative CDE limit checks.
The channel configuration can also be specified via the general commands 
CONFigure:WCDMa:MEAS:UECHannels:...
, see 
"
UE Signal Info"
.
