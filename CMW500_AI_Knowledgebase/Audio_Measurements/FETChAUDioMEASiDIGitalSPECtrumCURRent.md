FETCh:AUDio:MEAS<i>:DIGital:SPECtrum:CURRent? 
READ:AUDio:MEAS<i>:DIGital:SPECtrum:CURRent? 
Returns the current spectrum trace of a digital single tone measurement.
Return values: 
<Reliability>
"Reliability Indicator"
<Current>
Comma-separated list of values, one level value (Y-value) for each trace point
First value corresponds to 0 Hz, last value to 24 kHz
Range: 
-150 dBFS  to  0 dBFS
Default unit: 
dBFS
Example: 
See 
"Single Tone Measurement"
Usage: 
Query only
Firmware/Software: 
V3.2.10
