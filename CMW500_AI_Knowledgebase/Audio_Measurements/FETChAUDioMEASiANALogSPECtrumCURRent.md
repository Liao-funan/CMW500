FETCh:AUDio:MEAS<i>:ANALog:SPECtrum:CURRent? 
READ:AUDio:MEAS<i>:ANALog:SPECtrum:CURRent? 
Returns the current spectrum trace of an analog single tone measurement.
Return values: 
<Reliability>
"Reliability Indicator"
<Current>
Comma-separated list of values, one level value (Y-value) for each trace point
First value corresponds to 0 Hz, last value to 24 kHz
Range: 
-150 dBV  to  36 dBV
Default unit: 
dBV
Example: 
See 
"Single Tone Measurement"
Usage: 
Query only
Firmware/Software: 
V3.2.10
