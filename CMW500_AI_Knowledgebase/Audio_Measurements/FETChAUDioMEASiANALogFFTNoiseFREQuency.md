FETCh:AUDio:MEAS<i>:ANALog:FFTNoise:FREQuency? 
READ:AUDio:MEAS<i>:ANALog:FFTNoise:FREQuency? 
Returns the X-values of the traces measured with an analog FFT noise measurement.
Return values: 
<Reliability>
"Reliability Indicator"
<Frequency>
Comma-separated list of values, one frequency value (X-value) for each trace point
Range: 
0 Hz  to  24E+3 Hz
Default unit: 
Hz
Example: 
See 
"FFT Noise Measurement"
Usage: 
Query only

V3.2.10
