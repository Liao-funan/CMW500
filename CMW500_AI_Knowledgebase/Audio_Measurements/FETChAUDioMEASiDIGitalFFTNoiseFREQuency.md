FETCh:AUDio:MEAS<i>:DIGital:FFTNoise:FREQuency? 
READ:AUDio:MEAS<i>:DIGital:FFTNoise:FREQuency? 
Returns the X-values of the traces measured with a digital FFT noise measurement.
Return values: 
<Reliability>
"Reliability Indicator"
<Frequency>
Comma-separated list of values, one frequency value (X-value) for each trace point
Range: 
0 Hz  to  24E+3 Hz
Default unit: 
Hz

See 
"FFT Noise Measurement"

Query only
