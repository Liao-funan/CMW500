V3.7.10 (Compared to V3.5.130)
New features and changes:
GUI redesign:
–
Standard setting and channel bandwidth setting moved to top of configuration tree, see 
"Global Settings"
–
Standard setting moved within main view, see 
"Settings"
–
Baseband unit selection renamed, see 
"Base Band Unit"
–
RF settings optimized, see 
"RF Settings"
–
Many connection settings optimized, see 
"Connection Settings"
–
IPv4/v6 and IP version support setting optimized, see 
"IP Support"
Official support of the SUA and of the following SUA-related features:
–
Option R&S CMW-KS656, IEEE 802.11ac
–
40 MHz bandwidth for IEEE 802.11n
Password for WPA/WPA2 personal enhanced, up to 63 freely configurable characters, see 
"Passphrase"
The old command 
CONFigure:WLAN:SIGN<i>:CONNection:SECurity:TYPE
 is still supported but no longer documented.
