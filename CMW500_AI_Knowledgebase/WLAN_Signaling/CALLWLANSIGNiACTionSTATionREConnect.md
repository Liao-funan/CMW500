CALL:WLAN:SIGN<i>:ACTion:STATion:REConnect
Re-establishes the existing association to the AP under test. The command has the same effect as a disconnect, followed immediately by a connect.
The command is only relevant in the operation mode "Station" with connection mode "Manual".
