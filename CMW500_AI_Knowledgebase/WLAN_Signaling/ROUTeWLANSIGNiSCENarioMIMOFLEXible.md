ROUTe:WLAN:SIGN<i>:SCENario:MIMO:FLEXible 
<PCCBBBoard>, <RXConnector>, <RXConverter>, <TXConnector>, <TXConverter>, <TX2Connector>, <TX2Converter>
Defines the RX and TX routing for the MIMO scenario.
For possible connector and converter values, see 
"Values for Signal Path Selection"
.
Parameters:
<PCCBBBoard>
Signaling unit
<RXConnector>
RF connector for the input path
<RXConverter>
RX module for the input path
<TXConnector>
RF connector for output path 1
<TXConverter>
TX module for output path 1
<TX2Connector>
RF connector for output path 2
<TX2Converter>
TX module for output path 2
