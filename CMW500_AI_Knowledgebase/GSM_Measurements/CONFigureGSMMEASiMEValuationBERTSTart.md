CONFigure:GSM:MEAS<i>:MEValuation:BER:TSTart 
<ThresholdStart>
Selects the threshold start value for BER tests. This value is the maximum bit error rate in the first burst of the BER measurement.
Parameters:
<ThresholdStart>
Range: 
0 %  to  100 %
*RST:
10 %
