List Mode Settings
The following commands configure the list mode. For retrieving list mode results see 
"List Mode Results (One Segment)"
, 
"List Mode Results (All Segments, Result Groups)"
 and 
"List Mode Results (All Segments, One Result)"
.
For a description of the list mode, see 
"List Mode"
.
The segment number <no> in the following commands refers to the complete range of configured segments (1..2000).
