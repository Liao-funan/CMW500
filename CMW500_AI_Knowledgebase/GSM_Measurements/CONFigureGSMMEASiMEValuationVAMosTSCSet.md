CONFigure:GSM:MEAS<i>:MEValuation:VAMos:TSCSet

Specifies the expected VAMOS training sequence code (TSC) set of the measured GSM uplink signal. With a specific TSC set selection, the R&S
 
CMW analyzes bursts with this TSC set only.
