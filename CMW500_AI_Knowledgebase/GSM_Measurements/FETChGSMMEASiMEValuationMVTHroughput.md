FETCh:GSM:MEAS<i>:MEValuation:MVTHroughput? 
Returns the modulation view throughput, i.e. the percentage of measurement intervals where the detected burst pattern was found to correspond to the 
"Modulation View"
 settings.
See also 
"Mod. View Throughput"
Return values: 
<Reliability>
"Reliability Indicator"
<MVThroughput>
Modulation view throughput
Range: 
0 %  to  100 %
Example: 
See 
"Performing Single-Shot Measurements"
Usage: 
Query only
Firmware/Software: 
V3.0.20
